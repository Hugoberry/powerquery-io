# Type.ReplaceTablePartitionKey


Returns a new table type with the partition key replaced by the specified partition key.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Returns a new table type with the partition key replaced by the specified partition key.

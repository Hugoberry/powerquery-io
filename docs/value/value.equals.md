# Value.Equals


Returns whether two values are equal.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Returns true if value `value1` is equal to value `value2`, false otherwise.



## Category
Values

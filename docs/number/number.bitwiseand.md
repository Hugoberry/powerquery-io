# Number.BitwiseAnd


Returns the result of performing a bitwise "And" operation between the two inputs.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returns the result of performing a bitwise "And" operation between `number1` and `number2`.



## Category
Number.Bytes

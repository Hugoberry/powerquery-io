# Number.Atan2


Returns the arctangent of the division of the two numbers.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Returns the angle, in radians, whose tangent is the quotient `y`/`x` of the two numbers `y` and `x`.

Number.Trigonometry

# Number.BitwiseXor


Returns the result of performing a bitwise "XOR" (Exclusive-OR) between the two inputs.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returns the result of performing a bitwise "XOR" (Exclusive-OR) between `number1` and `number2`.



## Category
Number.Bytes

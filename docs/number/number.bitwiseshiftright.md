# Number.BitwiseShiftRight


Shifts the bits set to the right.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returns the result of performing a bitwise shift to the right on `number1`, by the specified number of bits `number2`.



## Category
Number.Bytes

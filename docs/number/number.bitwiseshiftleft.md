# Number.BitwiseShiftLeft


Shifts the bits set to the left.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returns the result of performing a bitwise shift to the left on `number1`, by the specified number of bits `number2`.



## Category
Number.Bytes

# Number.Cos


Returns the cosine of the number.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Returns the cosine of the specified angle.

-   `number`: An angle, measured in radians.


## Examples

### Example #1
Find the cosine of the angle 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Find the cosine of π radians.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

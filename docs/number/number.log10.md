# Number.Log10


Returns the base 10 logarithm of the number.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Returns the base 10 logarithm of a number, `number`. If `number` is null `Number.Log10` returns null.


## Examples

### Example #1
Get the base 10 logarithm of 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

# Number.BitwiseOr


Returns the result of performing a bitwise "Or" between the two inputs.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returns the result of performing a bitwise "Or" between `number1` and `number2`.



## Category
Number.Bytes

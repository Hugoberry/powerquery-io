# Number.Abs


Returns the absolute value of the number.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Returns the absolute value of `number`. If `number` is null, `Number.Abs` returns null.

-   `number`: A `number` for which the absolute value is to be calculated.


## Examples

### Example #1
Absolute value of -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

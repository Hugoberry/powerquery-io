# Text.Length


Returns the number of characters.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Returns the number of characters in the text `text`.


## Examples

### Example #1
Find how many characters are in the text "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

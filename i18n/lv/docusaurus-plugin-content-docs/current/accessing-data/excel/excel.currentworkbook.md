# Excel.CurrentWorkbook


Atgriež pašreizējās Excel darbgrāmatas saturu.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Atgriež pašreizējās Excel darbgrāmatas saturu. Tas atgriež tabulas, nosauktos diapazonus un dinamiskos masīvus. Pretēji `Excel.Workbook`, tas neatgriež lapas.

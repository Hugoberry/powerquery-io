# Cube.AttributeMemberId


Tiek atgriezts unikālais dalībnieka identifikators no dalībnieka rekvizīta vērtības.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Tiek atgriezts unikālais dalībnieka identifikators no dalībnieka rekvizīta vērtības. `attribute`. Citām vērtībām tiek atgriezta vērtība Null.

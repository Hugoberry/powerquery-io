# Cube.ApplyParameter


Atgriež kubu pēc parametra lietošanas.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Atgriež kubu pēc `parameter` ar `arguments` lietošanas vienumam `cube`.

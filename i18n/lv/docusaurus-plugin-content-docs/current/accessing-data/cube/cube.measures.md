# Cube.Measures


Atgriež tabulu, kas satur pieejamo mēru kopu.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Atgriež tabulu, kas satur to mēru kopu, kas pieejami šeit: `cube`. Katrs mērs ir attēlots kā funkcija. Mērus var lietot kubam, izmantojot Cube.AddMeasureColumn.

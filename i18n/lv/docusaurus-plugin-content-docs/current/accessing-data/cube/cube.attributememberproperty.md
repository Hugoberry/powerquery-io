# Cube.AttributeMemberProperty


Atgriež dimensijas atribūta rekvizītu.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Atgriež rekvizītu `propertyName` no dimensijas atribūta `attribute`.

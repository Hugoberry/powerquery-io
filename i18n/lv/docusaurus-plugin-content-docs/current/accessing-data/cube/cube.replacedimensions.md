# Cube.ReplaceDimensions


Aizstāj dimensiju kopu, ko atgrieza cube.Dimensions.


## Syntax

```powerquery
Cube.ReplaceDimensions(
    cube as table,
    dimensions as any
) as table
```


## Remarks

Aizstāj dimensiju kopu, ko atgrieza `Cube.Dimensions`. Piemēram, šo funkciju var izmantot, lai dimensijas atribūtam pievienotu ID kolonnu, lai datu avots varētu grupēt pēc ID, nevis parādītās vērtības.

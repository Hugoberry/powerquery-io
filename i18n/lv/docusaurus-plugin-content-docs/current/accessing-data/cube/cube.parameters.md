# Cube.Parameters


Atgriež tabulu, kurā iekļauta parametru kopa, ko var lietot kubam.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Atgriež tabulu, kurā iekļauta parametru kopa, ko iespējams lietot vienumam `cube`. Katrs parametrs ir funkcija, kuru iespējams izsaukt, lai iegūtu `cube`, kam lietots parametrs un tā argumenti.

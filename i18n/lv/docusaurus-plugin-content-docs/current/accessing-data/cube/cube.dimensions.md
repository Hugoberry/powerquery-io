# Cube.Dimensions


Atgriež tabulu, kas satur pieejamo dimensiju kopu.


## Syntax

```powerquery
Cube.Dimensions(
    cube as table
) as table
```


## Remarks

Atgriež tabulu, kas satur to dimensiju kopu, kas pieejamas šeit: `cube`. Katra dimensija ir tabula, kas satur dimensijas atribūtu kopu, un katrs dimensijas atribūts ir attēlots kā dimensijas tabulas kolonna. Dimensijas var izvērst kubā, izmantojot funkciju Cube.AddAndExpandDimensionColumn.

# Cube.DisplayFolders


Atgriež ligzdotu koku ar tabulām, kurās attēlota objektu (piemēram, dimensiju un mēru) hierarhija parādāmajā mapē.


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Atgriež ligzdotu koku ar tabulām, kurās attēlota tādu objektu (piemēram, dimensiju un mēru) hierarhija parādāmajā mapē, kuri ir pieejami izmantošanai šeit: `cube`.

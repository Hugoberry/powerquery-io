# Cube.CollapseAndRemoveColumns


Maina kuba filtra konteksta dimensiju granularitāti, sakļaujot norādītajām kolonnām kartētos atribūtus.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Maina `cube` filtra konteksta dimensiju granularitāti, sakļaujot norādītajām kolonnām `columnNames` kartētos atribūtus. Kolonnas arī tiek noņemtas no kuba tabulveida skata.

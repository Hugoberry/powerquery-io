# Exchange.Contents


Atgriež satura rādītāju no Microsoft Exchange konta.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Atgriež Microsoft Exchange konta `mailboxAddress` satura rādītāju. Ja konts `mailboxAddress` nav norādīts, tiks izmantots noklusējuma akreditācijas datu konts.

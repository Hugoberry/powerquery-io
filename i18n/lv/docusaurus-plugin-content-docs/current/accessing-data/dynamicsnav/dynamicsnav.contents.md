# DynamicsNav.Contents


Ievadiet sava Dynamics NAV OData pakalpojuma galapunkta vietrādi URL.


## Syntax

```powerquery
DynamicsNav.Contents(
    url as text,
    optional company as text
) as table
```


## Remarks

Atgriež tabulu ar atbilstošiem datiem no risinājuma Dynamics NAV.

# Soda.Feed


Tiek atgriezta tabula no satura norādītajā vietrādī URL, kas formatēta atbilstoši SODA 2.0 API.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

Tiek atgriezta tabula no satura norādītajā vietrādī URL `url`, kas formatēta atbilstoši SODA 2.0 API. Vietrādim URL ir jānorāda uz derīgu ar SODA saderīgu avotu, kura beigās ir paplašinājums .csv.

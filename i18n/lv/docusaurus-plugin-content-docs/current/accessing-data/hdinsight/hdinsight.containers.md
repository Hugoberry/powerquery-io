# HdInsight.Containers


Atgriež navigācijas tabulu ar konteineriem, kas atrasti norādītajā kontā no Azure krātuves akreditācijas datu komplekta.


## Syntax

```powerquery
HdInsight.Containers(
    account as text
) as table
```


## Remarks

Atgriež navigācijas tabulu ar rindām par katru konteineri, kas atrasts, izmantojot konta vietrādi URL, `account`, no Azure krātuves akreditācijas datu komplekta. Katrā rindā ir saite uz konteinera BLOB failiem.

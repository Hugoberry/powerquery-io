# Function.InvokeAfter


Pēc norādītā ilguma tiek izsaukta konkrētā funkcija.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Tiek atgriezts rezultāts, kas tiek iegūts, pēc ilguma `delay` izsaucot funkciju `function`.

# Text.Length


Tiek atgriezts rakstzīmju skaits.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Tiek atgriezts rakstzīmju skaits tekstā `text`.


## Examples

### Example #1
Uzziniet, cik rakstzīmju ir tekstā Hello World.
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

# List.NonNullCount


Tiek atgriezts to saraksta vienumu skaits, kuru vērtība nav Null.


## Syntax

```powerquery
List.NonNullCount(
    list as list
) as number
```


## Remarks

Tiek atgriezts to saraksta `list` vienumu skaits, kuru vērtība nav Null.

# List.Split


Sadala norādīto sarakstu sarakstu sarakstā, izmatojot norādītos lapas izmērus.


## Syntax

```powerquery
List.Split(
    list as list,
    pageSize as number
) as list
```


## Remarks

Sadala `list` sarakstu sarakstā, kur pirmais izvades saraksta elements ir saraksts, kas satur pirmos `pageSize` elementus no avotu saraksta, nākamais izvades saraksta elements ir saraksts, kas satur nākamos `pageSize`elementus no avotu saraksta utt.

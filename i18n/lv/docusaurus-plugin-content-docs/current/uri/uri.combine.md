# Uri.Combine


Tiek atgriezts absolūts URI, kas tiek iegūts, apvienojot ievades bāzes URI un relatīvo URI.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Tiek atgriezts absolūts URI, kas tiek iegūts, apvienojot ievades `baseUri` un `relativeUri`.

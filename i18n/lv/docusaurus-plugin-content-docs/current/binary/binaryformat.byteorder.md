# BinaryFormat.ByteOrder


Atgriež bināru formātu, kura baitu secība ir norādīta funkcijā.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Atgriež bināru formātu, kura baitu secība ir norādīta ar `binaryFormat`. Noklusējuma baitu secība ir `ByteOrder.BigEndian`.

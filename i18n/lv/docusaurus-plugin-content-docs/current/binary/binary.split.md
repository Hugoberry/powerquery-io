# Binary.Split


Sadala norādīto bināro elementu bināro failu sarakstā, izmantojot norādītos lappuses izmērus.


## Syntax

```powerquery
Binary.Split(
    binary as binary,
    pageSize as number
) as list
```


## Remarks

Sadala `binary` bināro failu sarakstā, kur pirmais izvades saraksta elements ir binārs, kas satur pirmos `pageSize` baitus no bināra avota, nākamais izvades saraksta elements ir binārs, kas satur nākamos `pageSize` baitus no bināra avota, un tā tālāk.

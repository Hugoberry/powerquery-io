# BinaryFormat.Binary


Atgriež bināru formātu, kas satur bināru vērtību.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Atgriež bināru formātu, kas satur bināru vērtību. Ja ir norādīts `length`, tas nozīmē, ka binārajā vērtībā ir tik daudz baitu. Ja nav norādīts `length`, tas nozīmē, ka binārajā vērtībā ir atlikušie baiti. Vērtību `length` var norādīt kā skaitli vai kā bināru formātu garumam, kas atrodas bināro datu priekšā.

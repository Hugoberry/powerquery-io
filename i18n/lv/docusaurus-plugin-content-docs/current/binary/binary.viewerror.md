# Binary.ViewError


Izveido modificētu kļūdas ierakstu, kas neaktivizēs atkāpšanos, kad to aktivizēs skatam noteiktais apdarinātājs (izmantojot Binary.View).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Izveido modificētu kļūdas ierakstu no `errorRecord`, kas neaktivizēs atkāpšanos, kad to aktivizēs skatam noteiktais apdarinātājs (izmantojot Binary.View).

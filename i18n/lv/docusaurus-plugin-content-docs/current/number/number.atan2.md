# Number.Atan2


Tiek atgriezts divu skaitļu dalījuma arktangenss.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Atgriež leņķi radiānos, kura tangente ir divu skaitļu `y` un `x` dalījums `y`/`x`.

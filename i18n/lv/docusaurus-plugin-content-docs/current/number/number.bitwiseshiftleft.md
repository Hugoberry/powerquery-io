# Number.BitwiseShiftLeft


Bitu kopa tiek pārbīdīta pa kreisi.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Tiek atgriezts rezultāts, kas tiek iegūts, veicot vērtības `number1` bitu pārbīdi pa kreisi par norādīto bitu skaitu `number2`.

# Number.Abs


Tiek atgriezta skaitļa absolūtā vērtība.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Atgriež parametra `number` absolūto vērtību. Ja parametra `number` vērtība ir Null, funkcija `Number.Abs` atgriež vērtību Null.

-   `number`: tipa `number` vērtība, kuras absolūtā vērtība ir jāaprēķina.


## Examples

### Example #1
Skaitļa -3 absolūtā vērtība.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

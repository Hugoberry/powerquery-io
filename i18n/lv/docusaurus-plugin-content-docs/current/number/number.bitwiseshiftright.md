# Number.BitwiseShiftRight


Bitu kopa tiek pārbīdīta pa labi.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Tiek atgriezts rezultāts, kas tiek iegūts, veicot vērtības `number1` bitu pārbīdi pa labi par norādīto bitu skaitu `number2`.

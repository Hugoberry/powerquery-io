# Number.Ln


Tiek atgriezts skaitļa naturālais logaritms.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Tiek atgriezts parametra `number` vērtības naturālais logaritms. Ja parametra `number` vērtība ir Null, funkcija `Number.Ln` atgriež vērtību Null.


## Examples

### Example #1
Iegūstiet skaitļa 15 naturālo logaritmu.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

# Number.BitwiseOr


Tiek atgriezts rezultāts, kas tiek iegūts, ar divām ievades vērtībām veicot bitu operāciju Or.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Tiek atgriezts rezultāts, kas tiek iegūts, ar vērtībām `number1` un `number2` veicot bitu operāciju Or.

Number.Bytes

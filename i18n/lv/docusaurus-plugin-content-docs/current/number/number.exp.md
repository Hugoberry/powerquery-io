# Number.Exp


Skaitlis e tiek kāpināta norādītajā pakāpē.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Atgriež rezultātu, kas tiek iegūts, skaitli e kāpinot šādā pakāpē: `number` (eksponenciāla funkcija).

-   `number`: tipa `number` vērtība, kurai ir jāaprēķina eksponenciālā funkcija. Ja `number` vērtība ir Null, funkcija `Number.Exp` atgriež vērtību Null.


## Examples

### Example #1
Kāpiniet konstanti e 3. pakāpē.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

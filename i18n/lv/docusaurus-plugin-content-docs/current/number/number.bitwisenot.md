# Number.BitwiseNot


Tiek atgriezts baits, kurā katra bita vērtība ir pretēja ievades datiem.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Tiek atgriezts rezultāts, kas tiek iegūts, ar vērtību `number` veicot bitu operāciju Not.

Number.Bytes

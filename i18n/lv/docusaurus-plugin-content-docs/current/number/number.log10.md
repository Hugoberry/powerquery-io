# Number.Log10


Tiek atgriezts skaitļa logaritms ar bāzi 10.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Tiek atgriezts skaitļa `number` logaritms ar bāzi 10. Ja `number` vērtība ir Null, funkcija `Number.Log10` atgriež nulles vērtību.


## Examples

### Example #1
Iegūstiet skaitļa 2 logaritmu ar bāzi 10.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

# Number.BitwiseAnd


Tiek atgriezts rezultāts, kas tiek iegūts, ar divām ievades vērtībām veicot bitu operāciju And.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Tiek atgriezts rezultāts, kas tiek iegūts, ar vērtībām `number1` un `number2` veicot bitu operāciju And.

Number.Bytes

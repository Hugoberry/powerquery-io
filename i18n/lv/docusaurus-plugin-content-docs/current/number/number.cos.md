# Number.Cos


Tiek atgriezts skaitļa kosinuss.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Atgriež norādītā leņķa kosinusu.

-   `number`: leņķis, kas tiek mērīts radiānos.


## Examples

### Example #1
Iegūstiet 0 grādu leņķa kosinusu.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Atrodiet kosinusu π radiāniem.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

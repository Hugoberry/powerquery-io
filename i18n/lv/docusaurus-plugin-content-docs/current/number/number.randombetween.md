# Number.RandomBetween


Tiek atgriezts gadījumskaitlis diapazonā starp diviem skaitļiem.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Tiek atgriezts gadījumskaitlis diapazonā no `bottom` līdz `top`.


## Examples

### Example #1
Iegūstiet gadījumskaitli diapazonā no 1 līdz 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

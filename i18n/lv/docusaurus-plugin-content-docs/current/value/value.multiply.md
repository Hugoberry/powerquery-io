# Value.Multiply


Tiek atgriezts abu vērtību iznākums.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Tiek atgriezts `value1` un `value2` reizinājums. Varat norādīt neobligātu parametru `precision`; pēc noklusējuma tiek lietots `Precision.Double`.

# Value.Divide


Tiek atgriezts rezultāts, kas iegūts, pirmo vērtību dalot ar otro vērtību.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Tiek atgriezts rezultāts, kas iegūts, `value1` dalot ar `value2`. Varat norādīt neobligātu parametru `precision`; pēc noklusējuma tiek lietots `Precision.Double`.

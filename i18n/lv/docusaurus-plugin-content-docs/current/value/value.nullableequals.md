# Value.NullableEquals


Tiek atgriezts, vai abas vērtības ir vienādas.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Ja kāds no argumentiem `value1` vai `value2` ir null, atgriež null, pretējā gadījumā atbilst Value.Equals.

# Variable.Value


Atgriež norādītā mainīgā vērtību.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Atgriež norādītā mainīgā `identifier` vērtību, ko definē pašreizējā novērtēšanas vide. Ja mainīgais nav definēts, rodas kļūda.

# Value.Equals


Tiek atgriezts, vai abas vērtības ir vienādas.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Ja vērtība `value1` ir vienāda ar vērtību `value2`, tiek atgriezta vērtība True, pretējā gadījumā tiek atgriezta vērtība False.

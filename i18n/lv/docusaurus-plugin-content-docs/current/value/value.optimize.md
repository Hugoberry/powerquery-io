# Value.Optimize


Signalizē vērtības izteiksmi, lai vērtībai atgrieztu optimizētu izteiksmi.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Ja tiek izmantots ar vērtības izteiksmi un ja `value` attēlo vaicājumu, ko var optimizēt, šī funkcija norāda, ka ir jāatgriež optimizētā izteiksme. Pretējā gadījumā bez izmaiņām tiks nodots `value`.

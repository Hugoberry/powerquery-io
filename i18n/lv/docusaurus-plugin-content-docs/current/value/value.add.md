# Value.Add


Tiek atgriezta abu vērtību summa.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Tiek atgriezta `value1` un `value2` summa. Varat norādīt neobligātu parametru `precision`; pēc noklusējuma tiek lietots `Precision.Double`.

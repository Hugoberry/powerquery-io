# Value.Subtract


Tiek atgriezta abu vērtību starpība.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Tiek atgriezta `value1` un `value2` starpība. Varat norādīt neobligātu parametru `precision`; pēc noklusējuma tiek lietots `Precision.Double`.

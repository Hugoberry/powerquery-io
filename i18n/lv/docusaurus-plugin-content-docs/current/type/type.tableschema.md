# Type.TableSchema


Atgriež tabulu ar kolonnu aprakstu (t. i., shēmu) ar norādīto tabulas tipu.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Atgriež tabulu, kurā aprakstītas `tableType` kolonnas.

Iegūtās tabulas aprakstu skatiet `Table.Schema` dokumentācijā.

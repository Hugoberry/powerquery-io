# Type.ListItem


Atgriež vienuma tipu no saraksta tipa.


## Syntax

```powerquery
Type.ListItem(
    type as type
) as type
```


## Remarks

Atgriež vienuma tipu no saraksta `type`.


## Examples

### Example #1
Atrodiet vienuma tipu sarakstā `{number}`.
```powerquery
Type.ListItem(type {number})
```

Result: 
```powerquery
type number
```

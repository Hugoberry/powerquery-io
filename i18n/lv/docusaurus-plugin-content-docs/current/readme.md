# Iepazīstiet valodu
Power Query M formulu valoda ir optimizēta ļoti elastīgu datu sapludināšanas vaicājumu veidošanai. Tā ir funkcionāla, reģistrjutīga valoda, kas līdzīga F#. Power Query formulu valoda tiek izmantota vairākos Microsoft produktos, piemēram, Power BI Desktop, Excel un Analysis Services.

Šī vietne kalpo kā atsauce Power Query funkcijām, piedāvājot ātru un tiešu piekļuvi detalizētai informācijai un praktiskiem piemēriem katrai funkcijai.
:::note
Lūdzu, ņemiet vērā, ka autors nepretendē ne uz kādām autortiesībām attiecībā uz šajā vietnē sniegtajiem materiāliem. Informācija tiek apkopota un sniegta cerībā, ka tā būs noderīga tiem, kuri vēlas paplašināt savas zināšanas un Power Query lietojumu.
:::

Meklēšanas funkcijai šajā vietnē vajadzētu vienkāršot plašā Power Query funkciju klāsta atklāšanas procesu. Noteikti izmēģiniet to (Ctrl+K).

![Meklēšanas funkciju nodrošina Algolia](/img/search.png)

Tiem, kurus interesē dziļāka izpēte vai ieviešanas detaļas, papildu informāciju var atrast šādā GitHub repozitorijā: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Šajā repozitorijā var būt papildu piemēri, atjauninājumi un resursi, kas attiecas uz Power Query izstrādi un lietošanu.

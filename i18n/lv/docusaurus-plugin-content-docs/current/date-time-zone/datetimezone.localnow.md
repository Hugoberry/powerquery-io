# DateTimeZone.LocalNow


Atgriež pašreizējo datumu un laiku vietējā laika joslā.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Atgriež `datetimezone` vērtību kopu uz sistēmas pašreizējo datumu un laiku. Atgrieztā vērtība ietver informāciju par laika joslu, atainojot vietējo laika joslu.

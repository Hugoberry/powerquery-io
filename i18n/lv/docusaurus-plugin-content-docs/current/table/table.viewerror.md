# Table.ViewError


Izveido modificētu kļūdas ierakstu, kas neaktivizēs atkāpšanos, kad to aktivizēs skatam noteiktais apdarinātājs (izmantojot Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Izveido modificētu kļūdas ierakstu no `errorRecord`, kas neaktivizēs atkāpšanos, kad to aktivizēs skatam noteiktais apdarinātājs (izmantojot Table.View).

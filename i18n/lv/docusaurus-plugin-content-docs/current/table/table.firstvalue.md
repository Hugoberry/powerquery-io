# Table.FirstValue


Tiek atgriezta pirmās rindas pirmā kolonna, kas iekļauta tabulā vai norādītajā noklusējuma vērtībā.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Tiek atgriezta pirmās rindas pirmā kolonna, kas iekļauta tabulā `table` vai norādītajā noklusējuma vērtībā.

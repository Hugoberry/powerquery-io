# Tables.GetRelationships


Iegūst tabulu kopas relācijas.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Iegūst tabulu kopas relācijas. Tiek uzskatīts, ka kopas `tables` struktūra ir līdzīga navigācijas tabulā ietvertās kopas struktūrai. Kopā `dataColumn` definētajā kolonnā ir ietvertas faktiskās datu tabulas.

# File.Contents


Belirtilen dosyanın içeriğini ikili olarak döndürür.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

`path` dosyasının içeriğini ikili olarak döndürür. `options` parametresi şu anda yalnızca dahili kullanıma yöneliktir.

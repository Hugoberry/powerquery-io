# Soda.Feed


Belirtilen URL'deki içeriğin SODA 2.0 API'sine göre biçimlendirilmiş bir tablosunu döndürür.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

Belirtilen URL `url` içeriğinin SODA 2.0 API'sine göre biçimlendirilmiş bir tablosunu döndürür. URL, SODA uyumlu ve bir .csv uzantısı ile biten geçerli bir kaynağa işaret etmelidir.

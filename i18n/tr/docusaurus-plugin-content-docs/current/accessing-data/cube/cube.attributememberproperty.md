# Cube.AttributeMemberProperty


Boyut özniteliğinin bir özelliğini döndürür.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

`attribute` boyut özniteliğinin `propertyName` özelliğini döndürür.



## Category
Cube

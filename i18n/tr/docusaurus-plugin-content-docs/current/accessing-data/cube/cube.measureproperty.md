# Cube.MeasureProperty


Bir ölçünün bir özelliğini (hücre özelliği) döndürür.


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

`measure` ölçüsünün `propertyName` özelliğini döndürür.



## Category
Cube

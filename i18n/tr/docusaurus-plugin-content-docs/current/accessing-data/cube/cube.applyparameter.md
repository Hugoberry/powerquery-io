# Cube.ApplyParameter


Parametre uygulandıktan sonra bir küp döndürür.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

`cube` öğesine `arguments` ile `parameter` uygulandıktan sonra bir küp döndürür.

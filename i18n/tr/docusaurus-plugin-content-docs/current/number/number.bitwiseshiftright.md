# Number.BitwiseShiftRight


Bit kümesini sağa kaydırır.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` üzerinde `number2` belirtilen bit sayısı kadar sağa bit tabanlı kaydırma gerçekleştirmenin sonucunun döndürür.

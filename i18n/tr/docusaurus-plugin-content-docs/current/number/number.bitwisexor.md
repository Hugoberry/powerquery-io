# Number.BitwiseXor


İki girdi arasında bit tabanlı "XOR" (Hariç VEYA) işlemi uygulamanın sonucunu döndürür.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` ve `number2` arasında bit tabanlı "XOR" (Hariç VEYA) işlemi uygulamanın sonucunu döndürür.

Number.Bytes

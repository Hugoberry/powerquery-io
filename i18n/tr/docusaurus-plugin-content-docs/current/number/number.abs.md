# Number.Abs


Sayının mutlak değerini döndürür.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

`number` öğesinin mutlak değerini döndürür. `number` null ise `Number.Abs` null döndürür.

-   `number`: Mutlak değeri hesaplanacak olan `sayı`.


## Examples

### Example #1
\-3'ün mutlak değeri.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

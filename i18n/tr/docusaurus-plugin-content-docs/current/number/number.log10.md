# Number.Log10


Sayının 10 tabanındaki logaritmasını döndürür.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Bir sayının (`number`) 10 tabanındaki logaritmasını döndürür. `number` null ise `Number.Log10` null döndürür.


## Examples

### Example #1
2'nin 10 tabanındaki logaritmasını alır.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

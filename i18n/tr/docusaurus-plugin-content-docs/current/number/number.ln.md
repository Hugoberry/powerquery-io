# Number.Ln


Sayının doğal logaritmasını döndürür.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Sayıların doğal logaritmasını döndürür, `number`. `number` null ise `Number.Ln` null döndürür.


## Examples

### Example #1
15'in doğal logaritmasını alır.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

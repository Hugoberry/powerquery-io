# Number.BitwiseShiftLeft


Bit kümesini sola kaydırır.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` üzerinde `number2` belirtilen bit sayısı kadar sola bit tabanlı kaydırma gerçekleştirmenin sonucunun döndürür.

Number.Bytes

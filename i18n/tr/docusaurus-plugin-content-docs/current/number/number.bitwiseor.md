# Number.BitwiseOr


İki girdi arasında bit tabanlı "Or" işlemi uygulamanın sonucunu döndürür.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` ve `number2` arasında bit tabanlı "Or" işlemi uygulamanın sonucunu döndürür.

Number.Bytes

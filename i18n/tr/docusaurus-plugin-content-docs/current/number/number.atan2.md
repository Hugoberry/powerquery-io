# Number.Atan2


İki sayının bölümünün arktanjantını döndürür.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

İki sayı `y` ve `x`'ün tanjantı `y`/`x` olan açıyı radyan cinsinden döndürür.



## Category
Number.Trigonometry

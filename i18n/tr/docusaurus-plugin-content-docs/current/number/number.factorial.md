# Number.Factorial


Sayının faktöriyelini döndürür.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

`number` sayısının faktöriyelini döndürür.


## Examples

### Example #1
10'un faktöriyelini bulur.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

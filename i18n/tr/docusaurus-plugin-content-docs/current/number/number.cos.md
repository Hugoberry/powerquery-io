# Number.Cos


Sayının kosinüsünü döndürür.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Belirtilen açının kosinüsünü döndürür.

-   `number`: Radyan cinsinden ölçülen açı.


## Examples

### Example #1
0 açısının kosinüsünü bulur.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
π radyanın kosinüsünü bulun.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

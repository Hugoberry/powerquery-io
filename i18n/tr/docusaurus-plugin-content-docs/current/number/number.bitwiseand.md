# Number.BitwiseAnd


İki girdi arasında bit tabanlı "And" işlemi uygulamanın sonucunu döndürür.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` ve `number2` arasında bit tabanlı "And" işlemi uygulamanın sonucunu döndürür.

Number.Bytes

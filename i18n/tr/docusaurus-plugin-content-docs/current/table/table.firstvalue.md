# Table.FirstValue


Tablonun ilk satırının ilk sütununu veya belirtilen varsayılan bir değeri döndürür.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

`table` tablosunun ilk satırının ilk sütununu veya belirtilen bir varsayılan değeri döndürür.



## Category
Table.Row operations

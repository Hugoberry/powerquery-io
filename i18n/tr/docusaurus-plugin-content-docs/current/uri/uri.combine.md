# Uri.Combine


Girdi taban URI'si ile göreli URL birleşimi olan tam bir URI döndürür.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

`baseUri` ve `relativeUri` girdisinin birleşimi olan tam bir URI döndürür.

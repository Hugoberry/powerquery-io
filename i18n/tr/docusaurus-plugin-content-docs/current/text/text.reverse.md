# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Sağlanan `text` değerini tersine çevirir.


## Examples

### Example #1
"123" metnini tersine çevirir.
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

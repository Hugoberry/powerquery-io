# Function.InvokeAfter


Belirtilen süre dolduktan sonra verilen işlevi çağırır.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

`delay` süresi dolduktan sonra `function` çağırmanın sonucunu döndürür.



## Category
Function

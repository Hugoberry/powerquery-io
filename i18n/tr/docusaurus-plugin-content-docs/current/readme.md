# Dili keşfedin
Power Query M formül dili, son derece esnek veri birleştirme sorguları oluşturmak için optimize edilmiştir. F#'a benzer, işlevsel ve büyük/küçük harfe duyarlı bir dildir. Power Query Formül Dili, Power BI Desktop, Excel ve Analysis Services gibi birçok Microsoft ürününde kullanılır.

Bu site, Power Query işlevleri için bir başvuru kaynağı olarak hizmet verir ve her işlev için ayrıntılı bilgilere ve pratik örneklere hızlı ve doğrudan erişim sunar.
:::note
Lütfen unutmayın, yazar bu sitede sunulan materyaller üzerinde herhangi bir telif hakkı talep etmemektedir. Bilgiler, Power Query bilgisini ve uygulamasını genişletmek isteyenler için yararlı olacağı umuduyla toplanmış ve sağlanmıştır.
:::

Bu web sitesindeki arama işlevi, geniş Power Query işlevleri yelpazesinin keşif sürecini basitleştirmelidir. Mutlaka deneyin (Ctrl+K).

![Arama işlevi Algolia tarafından sağlanmaktadır](/img/search.png)

Daha derin keşif veya uygulama ayrıntılarıyla ilgilenenler için, aşağıdaki GitHub deposunda daha fazla bilgi bulunabilir: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Bu depo, Power Query geliştirme ve kullanımıyla ilgili ek örnekler, güncellemeler ve kaynaklar içerebilir.

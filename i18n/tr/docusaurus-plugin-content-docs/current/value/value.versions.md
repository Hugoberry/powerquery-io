# Value.Versions


Değerin kullanılabilir sürümlerini içeren bir gezinme tablosu döndürür.


## Syntax

```powerquery
Value.Versions(
    value as any
) as table
```


## Remarks

`value`'in mevcut sürümlerini içeren bir gezinme tablosu döndürür.

# Value.Optimize


Bir değer için iyileştirilmiş ifadeyi döndürmek üzere Value.Expression'a sinyal gönderir.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Value.Expression içinde kullanıldığında, `value` iyileştirilebilecek bir sorguyu temsil ediyorsa bu işlev, iyileştirilmiş ifadenin döndürüleceğini belirtir. Aksi takdirde `value`, hiçbir etki olmadan geçirilir.

Expression

# Variable.Value


Belirtilen değişkenin değerini döndürür.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Geçerli değerlendirme ortamı tarafından tanımlanan belirtilen değişken `identifier`'in değerini döndürür. Değişken tanımlanmamışsa, bir hata oluşur.

# Number.Atan2


Devuelve el arco tangente de la división de los dos números.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Devuelve el ángulo, en radianes, cuya tangente es el cociente `y`/`x` de los dos números `y` y `x`.

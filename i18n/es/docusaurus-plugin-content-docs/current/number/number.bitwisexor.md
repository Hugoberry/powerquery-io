# Number.BitwiseXor


Devuelve el resultado de realizar una operación "XOR" (OR exclusivo) entre las dos entradas.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devuelve el resultado de realizar una operación bit a bit "XOR" (OR exclusivo) entre `number1` y `number2`.



## Category
Number.Bytes

# Number.Cos


Devuelve el coseno del número.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Devuelve el coseno del ángulo especificado.

-   `number`: un ángulo medido en radianes.


## Examples

### Example #1
Buscar el coseno del ángulo 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Busque el coseno de π radianes.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

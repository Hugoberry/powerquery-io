# Number.BitwiseAnd


Devuelve el resultado de realizar una operación bit a bit "Y" entre las dos entradas.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devuelve el resultado de realizar una operación bit a bit "Y" entre las `number1` y `number2`.



## Category
Number.Bytes

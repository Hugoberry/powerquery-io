# Number.BitwiseOr


Devuelve el resultado de realizar una operación bit a bit "OR" entre las dos entradas.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devuelve el resultado de realizar una operación bit a bit "O" entre `number1` y `number2`.



## Category
Number.Bytes

# Number.BitwiseShiftRight


Desplaza los bits establecidos a la derecha.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devuelve el resultado de realizar un desplazamiento bit a bit a la derecha en `number1`, el número especificado de bits `number2`.

# Number.Abs


Devuelve el valor absoluto del número.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Devuelve el valor absoluto de `number`. Si `number` es "null", `Number.Abs` devuelve "null".

-   `number`: un `number` cuyo valor absoluto se va a calcular.


## Examples

### Example #1
Valor absoluto de -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

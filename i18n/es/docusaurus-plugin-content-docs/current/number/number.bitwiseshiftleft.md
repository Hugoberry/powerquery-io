# Number.BitwiseShiftLeft


Desplaza los bits establecidos a la izquierda.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devuelve el resultado de realizar un desplazamiento bit a bit a la izquierda en `number1`, el número especificado de bits `number2`.

Number.Bytes

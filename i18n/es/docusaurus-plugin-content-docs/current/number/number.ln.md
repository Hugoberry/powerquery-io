# Number.Ln


Devuelve el logaritmo natural del número.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Devuelve el logaritmo natural de un número `number`. Si `number` es NULL, `Number.Ln` devuelve NULL.


## Examples

### Example #1
Obtener el logaritmo natural de 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

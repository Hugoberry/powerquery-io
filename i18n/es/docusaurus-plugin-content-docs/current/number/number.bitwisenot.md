# Number.BitwiseNot


Devuelve un byte donde cada bit es el opuesto de la entrada.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Devuelve el resultado de realizar una operación bit a bit "Not" en `number`.



## Category
Number.Bytes

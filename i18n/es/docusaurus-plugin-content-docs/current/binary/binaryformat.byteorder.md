# BinaryFormat.ByteOrder


Devuelve un formato binario con el orden de bytes especificado por una función.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Devuelve un formato binario con el orden de bytes especificado por `binaryFormat`. El orden de bytes predeterminado es `ByteOrder.BigEndian`.

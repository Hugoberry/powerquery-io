# Value.Equals


Devuelve si dos valores son iguales.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Devuelve true si el valor `value1` es igual que el valor `value2`; false, en caso contrario.

Values

# Variable.Value


Devuelve el valor de la variable especificada.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Devuelve el valor de la variable `identifier` especificada definida por el entorno de evaluación actual. Si la variable no está definida, se genera un error.

# Value.NullableEquals


Devuelve si dos valores son iguales.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Devuelve null si el argumento `value1` o `value2` es null; de lo contrario, equivale a Value.Equals.

Values

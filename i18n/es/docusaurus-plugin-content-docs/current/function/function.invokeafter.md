# Function.InvokeAfter


Invoca la función determinada cuando termina la duración especificada.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Devuelve el resultado de la invocación de `function` cuando termina la duración `delay`.

Function

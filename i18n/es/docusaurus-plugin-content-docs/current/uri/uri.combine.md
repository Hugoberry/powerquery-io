# Uri.Combine


Devuelve un URI absoluto que es la combinación del URI de base de entrada y del URI relativo.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Devuelve un URI absoluto que es la combinación del `baseUri` de entrada y de `relativeUri`.

# Cube.Parameters


Devuelve una tabla que contiene el conjunto de parámetros que se pueden aplicar al cubo.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Devuelve una tabla que contiene el conjunto de parámetros a los que se puede aplicar `cube`. Cada parámetro es una función que se puede invocar para obtener `cube` con el parámetro y sus argumentos aplicados.

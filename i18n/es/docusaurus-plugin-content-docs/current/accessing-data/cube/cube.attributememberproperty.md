# Cube.AttributeMemberProperty


Devuelve una propiedad de un atributo de dimensión.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Devuelve la propiedad `propertyName` del atributo de dimensión `attribute`.

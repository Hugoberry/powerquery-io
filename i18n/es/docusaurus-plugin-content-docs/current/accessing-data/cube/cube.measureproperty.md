# Cube.MeasureProperty


Devuelve la propiedad de una medida (propiedad de celda).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Devuelve la propiedad `propertyName` de la medida `measure`.

Cube

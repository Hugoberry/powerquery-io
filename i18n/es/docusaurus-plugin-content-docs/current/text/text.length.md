# Text.Length


Devuelve el número de caracteres.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Devuelve el número de caracteres del texto `text`.


## Examples

### Example #1
Buscar cuántos caracteres hay en el texto "Hola mundo".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

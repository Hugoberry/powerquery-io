# Table.Profile


Muestra el perfil de las columnas de una tabla.


## Syntax

```powerquery
Table.Profile(
    table as table,
    optional additionalAggregates as list
) as table
```


## Remarks

Muestra un perfil para las columnas de `table`.

Se muestra la siguiente información de cada columna (cuando es aplicable):

-   mínimo
-   máximo
-   promedio
-   desviación estándar
-   recuento
-   recuento nulo
-   recuento distinto

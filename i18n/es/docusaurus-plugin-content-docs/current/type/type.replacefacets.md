# Type.ReplaceFacets


Sustituye las facetas de un tipo.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Sustituye las facetas de `type` por las facetas que contiene el registro `facets`.

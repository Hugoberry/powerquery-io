# Type.ReplaceTablePartitionKey


Devuelve un nuevo tipo de tabla con la clave de partición reemplazada por la clave de partición especificada.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Devuelve un nuevo tipo de tabla con la clave de partición reemplazada por la clave de partición especificada.

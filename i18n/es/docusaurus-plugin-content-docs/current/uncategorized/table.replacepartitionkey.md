# Table.ReplacePartitionKey


Reemplaza la clave de partición de la tabla especificada.


## Syntax

```powerquery
Table.ReplacePartitionKey(
    table as table,
    partitionKey as list
) as table
```


## Remarks

Reemplaza la clave de partición de la tabla especificada.

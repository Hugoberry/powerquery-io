# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

反向所提供的 `text`。


## Examples

### Example #1
反向文本 "123"。
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

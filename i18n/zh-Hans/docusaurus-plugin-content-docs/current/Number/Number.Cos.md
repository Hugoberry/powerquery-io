# Number.Cos


返回数的余弦。


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

返回指定角度的余弦。

-   `number`: 以弧度为单位的角度。


## Examples

### Example #1
计算角 0 的余弦。
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
求 π 弧度的余弦值。
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

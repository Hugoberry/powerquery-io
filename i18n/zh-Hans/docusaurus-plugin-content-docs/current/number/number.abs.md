# Number.Abs


返回数的绝对值。


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

返回 `number` 的绝对值。如果 `number` 为 null，则 `Number.Abs` 返回 null。

-   `number`: 要计算其绝对值的 `number`。


## Examples

### Example #1
\-3 的绝对值。
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

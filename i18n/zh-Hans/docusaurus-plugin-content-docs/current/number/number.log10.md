# Number.Log10


返回数值的以 10 为底的对数。


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

返回数值 `number` 的以 10 为底的对数。如果 `number` 为 null，则 `Number.Log10` 返回 null。


## Examples

### Example #1
获取 2 的以 10 为底的对数。
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

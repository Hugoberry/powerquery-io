# Binary.ViewError


创建修改后的错误记录，该记录在视图上(通过 Binary.View)定义的处理程序引发时将不会触发回退。


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

根据 `errorRecord` 创建修改后的错误记录，该记录在视图上(通过 Binary.View)定义的处理程序引发时将不会触发回退。

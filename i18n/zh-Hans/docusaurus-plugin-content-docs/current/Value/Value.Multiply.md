# Value.Multiply


返回两个值的乘积。


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

返回将 `value1` 与 `value2` 相乘的乘积。可以指定一个可选 `precision` 参数，默认情况下使用 `Precision.Double`。

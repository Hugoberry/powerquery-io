# Value.Subtract


返回两个值的差。


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

返回 `value1` 和 `value2` 的差。可以指定一个可选 `precision` 参数，默认情况下使用 `Precision.Double`。

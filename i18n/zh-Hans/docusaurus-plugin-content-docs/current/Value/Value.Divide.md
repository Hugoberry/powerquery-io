# Value.Divide


返回将第一个值除以第二个值的结果。


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

返回将 `value1` 除以 `value2` 的结果。可以指定一个可选 `precision` 参数，默认情况下使用 `Precision.Double`。

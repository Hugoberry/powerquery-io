# 探索这门语言
Power Query M 公式语言经过优化，可用于构建高度灵活的数据混搭查询。它是一种类似于 F# 的函数式、区分大小写的语言。Power Query 公式语言被用于多款 Microsoft 产品，例如 Power BI Desktop、Excel 和 Analysis Services。

本站作为 Power Query 函数的参考资料，为每个函数提供快速、直接的详细信息和实用示例访问途径。
:::note
请注意，作者对本站所呈现的材料不主张任何版权。这些信息的收集和提供旨在帮助那些希望拓展 Power Query 知识和应用的人。
:::

本网站的搜索功能可简化对种类繁多的 Power Query 函数的发现过程。请务必试用一下（Ctrl+K）。

![搜索功能由 Algolia 提供](/img/search.png)

对于有兴趣进行更深入探索或了解实现细节的用户，可以在以下 GitHub 存储库中找到更多信息：[https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io)。该存储库可能包含与 Power Query 开发和使用相关的更多示例、更新和资源。

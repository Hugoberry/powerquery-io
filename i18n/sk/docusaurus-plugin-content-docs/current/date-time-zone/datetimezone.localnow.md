# DateTimeZone.LocalNow


Vráti aktuálny dátum a čas v miestnom časovom pásme.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Vráti hodnotu `datetimezone` nastavenú na aktuálny dátum a čas v systéme. Vrátená hodnota obsahuje informácie o časovom pásme predstavujúce miestne časové pásmo.

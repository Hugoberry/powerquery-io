# Value.Add


Vráti súčet dvoch hodnôt.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vráti súčet hodnôt `value1` a `value2`. Možno stanoviť voliteľný parameter `precision`, v predvolenom nastavení sa používa `Precision.Double`.

# Value.NullableEquals


Vráti informácie o tom, či sa dve hodnoty rovnajú.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Vráti hodnotu null, ak je niektorý z argumentov `value1` alebo `value2` null, inak je ekvivalentná funkcii Value.Equals.

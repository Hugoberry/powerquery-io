# Variable.Value


Vráti hodnotu zadanej premennej.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Vráti hodnotu zadanej premennej `identifier`, ktorá je definovaná aktuálnym prostredím hodnotenia. Ak premenná nie je definovaná, bude to mať za následok chybu.

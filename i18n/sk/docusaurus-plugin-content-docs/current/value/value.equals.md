# Value.Equals


Vráti informácie o tom, či sa dve hodnoty rovnajú.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Vráti hodnotu True, ak sa hodnota `value1` rovná hodnote `value2`, v opačnom prípade vráti hodnotu False.

# Value.Divide


Vráti výsledok delenia prvej hodnoty druhou hodnotou.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vráti výsledok delenia hodnoty `value1` hodnotou `value2`. Možno stanoviť voliteľný parameter `precision`, v predvolenom nastavení sa používa `Precision.Double`.

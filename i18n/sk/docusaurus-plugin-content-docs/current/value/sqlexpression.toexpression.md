# SqlExpression.ToExpression


Konvertuje zadaný dotaz SQL na kód M. Táto funkcia je určená iba na interné použitie.


## Syntax

```powerquery
SqlExpression.ToExpression(
    sql as text,
    environment as record
) as text
```


## Remarks

Konvertuje zadaný dotaz `sql` na kód M s dostupnými identifikátormi definovanými `environment`. Táto funkcia je určená iba na interné použitie.

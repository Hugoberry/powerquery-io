# Value.Alternates


Vyjadruje alternatívne plány dotazov.


## Syntax

```powerquery
Value.Alternates(
    alternates as list
) as any
```


## Remarks

Vyjadruje alternatívne plány dopytu v rámci výrazu plánu dopytu získaného prostredníctvom `Value.Expression(Value.Optimize(...))`. Nie je určené na iné použitie.

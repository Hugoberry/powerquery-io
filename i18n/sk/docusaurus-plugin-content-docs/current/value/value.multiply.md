# Value.Multiply


Vráti súčin dvoch hodnôt.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vráti súčin vynásobením hodnoty `value1` hodnotou `value2`. Možno stanoviť voliteľný parameter `precision`, v predvolenom nastavení sa používa `Precision.Double`.

# BinaryFormat.Binary


Vráti binárny formát, ktorý prečíta binárnu hodnotu.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Vráti binárny formát, ktorý prečíta binárnu hodnotu. Ak je zadaná položka `length`, binárna hodnota bude obsahovať taký počet bajtov. Ak položka `length` nie je zadaná, binárna hodnota bude obsahovať zostávajúci počet bajtov. Položku `length` možno zadať buď ako číslo, alebo ako binárny formát s dĺžkou, ktorá predchádza binárne údaje.

# BinaryFormat.ByteOrder


Vráti binárny formát s poradím bajtov zadaným pomocou funkcie.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Vráti binárny formát s poradím bajtov zadaným pomocou výrazu `binaryFormat`. Predvolené poradie bajtov je `ByteOrder.BigEndian`.

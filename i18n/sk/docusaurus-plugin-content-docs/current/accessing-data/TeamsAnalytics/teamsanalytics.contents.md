# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Konektor Teams Analytics vám umožní získať prehľady o tom, ako používate Teams. Údaje sú k dispozícii pre vašu osobnú aktivitu v službe Teams, ako aj aktivitu v tímoch, ktorých ste členom.

Dostupné sú údaje za posledných 90 dní.

Podrobnosti o jednotlivých typoch údajoch nájdete v tejto pomocnej dokumentácii

-   **Používanie služby Teams:** https://docs.microsoft.com/sk-sk/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Aktivita používateľa v službe Teams:** https://docs.microsoft.com/sk-sk/microsoftteams/teams-analytics-and-reports/user-activity-report

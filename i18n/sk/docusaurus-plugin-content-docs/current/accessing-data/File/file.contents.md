# File.Contents


Vráti obsah zadaného súboru ako binárny údaj.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Vráti obsah súboru `path` ako binárny údaj. Parameter `options` je momentálne určený len na interné použitie.

# Cube.CollapseAndRemoveColumns


Zmení granularitu dimenzie kontextu filtra pre kocku prostredníctvom zbalenia atribútov mapovaných na zadané stĺpce.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Zmení granularitu dimenzie kontextu filtra pre kocku `cube` prostredníctvom zbalenia atribútov mapovaných na zadané stĺpce `columnNames`. Z tabuľkového zobrazenia kocky sa odstránia aj stĺpce.

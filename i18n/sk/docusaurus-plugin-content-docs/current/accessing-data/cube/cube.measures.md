# Cube.Measures


Vráti tabuľku obsahujúcu množinu dostupných mierok.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Vráti tabuľku obsahujúcu množinu dostupných mierok v rámci kocky `cube`. Každá mierka je znázornená ako funkcia. Mierky možno v kocke použiť pomocou funkcie Cube.AddMeasureColumn.

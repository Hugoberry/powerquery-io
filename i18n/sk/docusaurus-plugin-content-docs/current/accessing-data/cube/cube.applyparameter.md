# Cube.ApplyParameter


Vráti kocku, keď sa na ňu použije parameter.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Vráti kocku, keď sa `parameter` s `arguments` použije na `cube`.

# Exchange.Contents


Vráti tabuľku obsahu z konta Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Vráti obsah z konta Microsoft Exchange `mailboxAddress`. Ak nie je zadané konto `mailboxAddress`, použije sa predvolené konto poverenia.

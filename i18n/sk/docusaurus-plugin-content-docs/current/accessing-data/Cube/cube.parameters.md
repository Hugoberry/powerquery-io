# Cube.Parameters


Vráti tabuľku obsahujúcu množinu parametrov, ktoré možno použiť na kocku.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Vráti tabuľku obsahujúcu množinu parametrov, ktoré možno použiť na `cube`. Každý parameter je funkcia, ktorú možno vyvolať na získanie `cube` s parametrom a argumentmi, ktoré sú naň použité.

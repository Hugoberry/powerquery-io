# Cube.AttributeMemberId


Vráti jedinečný identifikátor člena z hodnoty vlastnosti členov.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Vráti jedinečný identifikátor člena z hodnoty vlastnosti členov. `attribute`. Vráti hodnotu null pre všetky ostatné hodnoty.

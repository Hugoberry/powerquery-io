# Function.InvokeAfter


Po uplynutí zadaného trvania vyvolá zadanú funkciu.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Vráti výsledok vyvolania `function` po uplynutí trvania `delay`.



## Category
Function

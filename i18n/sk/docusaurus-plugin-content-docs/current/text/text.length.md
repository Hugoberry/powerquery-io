# Text.Length


Vráti počet znakov.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Vráti počet znakov v texte `text`.


## Examples

### Example #1
Zistite, koľko znakov sa nachádza v texte "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

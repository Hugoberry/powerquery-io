# Type.TableSchema


Vráti tabuľku s popisom stĺpcov (napr. schému) zadaného typu tabuľky.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Vráti tabuľku s popisom stĺpcov tabuľky `tableType`.

Popis výslednej tabuľky nájdete v dokumentácii pre `Table.Schema`.

# Uri.Combine


Vráti absolútny identifikátor URI, ktorý je kombináciou vstupného identifikátora URI základu a relatívneho identifikátora URI.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Vráti absolútny identifikátor URI, ktorý je kombináciou vstupu `baseUri` a identifikátora `relativeUri`.

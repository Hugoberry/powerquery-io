# List.NonNullCount


Vráti počet položiek s hodnotami rôznymi od null v zozname.


## Syntax

```powerquery
List.NonNullCount(
    list as list
) as number
```


## Remarks

Vráti počet položiek s hodnotami rôznymi od null v zozname `list`.

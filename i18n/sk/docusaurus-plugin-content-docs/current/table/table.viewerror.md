# Table.ViewError


Vytvorí upravený záznam chyby, ktorý nespustí náhradné riešenie, keď ho vyvolá obslužná rutina definovaná v zobrazení (prostredníctvom Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Vytvorí upravený záznam chyby z `errorRecord`, ktorý nespustí náhradné riešenie, keď ho vyvolá obslužná rutina definovaná v zobrazení (prostredníctvom Table.View).

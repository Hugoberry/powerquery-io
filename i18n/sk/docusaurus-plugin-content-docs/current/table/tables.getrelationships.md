# Tables.GetRelationships


Získa vzťahy v rámci množiny tabuliek.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Získa vzťahy v rámci množiny tabuliek. Predpokladá sa, že množina `tables` má podobnú štruktúru ako navigačná tabuľka. Stĺpec definovaný položkou `dataColumn` obsahuje skutočné tabuľky údajov.

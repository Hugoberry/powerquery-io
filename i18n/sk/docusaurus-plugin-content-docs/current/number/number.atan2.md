# Number.Atan2


Vráti arkustangens delenia dvoch čísel.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Vráti uhol v radiánoch, ktorého tangens je podiel `y`/`x` dvoch čísel, `y` a `x`.

Number.Trigonometry

# Number.Log10


Vráti dekadický logaritmus (so základom 10) daného čísla.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Vráti dekadický logaritmus (so základom 10) čísla `number`. Ak hodnota `number` je null, funkcia `Number.Log10` vráti hodnotu null.


## Examples

### Example #1
Získajte dekadický logaritmus (so základom 10) čísla 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

# Number.BitwiseShiftLeft


Posunie množinu bitov doľava.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vráti výsledok vykonania bitového posunu doľava vo vstupe `number1` o stanovený počet bitov `number2`.

Number.Bytes

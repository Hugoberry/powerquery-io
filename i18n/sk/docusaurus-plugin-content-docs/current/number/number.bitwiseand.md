# Number.BitwiseAnd


Vráti výsledok vykonania bitovej operácie "And" medzi dvomi vstupmi.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vráti výsledok vykonania bitovej operácie "And" medzi vstupmi `number1` a `number2`.

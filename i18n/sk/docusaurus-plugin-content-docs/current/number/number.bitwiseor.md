# Number.BitwiseOr


Vráti výsledok vykonania bitovej operácie "Or" medzi dvomi vstupmi.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vráti výsledok vykonania bitovej operácie "Or" medzi vstupmi `number1` a `number2`.

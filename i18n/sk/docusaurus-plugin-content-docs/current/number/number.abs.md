# Number.Abs


Vráti absolútnu hodnotu čísla.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Vráti absolútnu hodnotu čísla `number`. Ak hodnota `number` je null, funkcia `Number.Abs` vráti hodnotu null.

-   `number`: Číslo `number`, pre ktoré sa má vypočítať absolútna hodnota.


## Examples

### Example #1
Absolútna hodnota čísla –3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

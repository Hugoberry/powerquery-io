# Number.Ln


Vráti prirodzený logaritmus čísla.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Vráti prirodzený logaritmus čísla `number`. Ak hodnota `number` je null, funkcia `Number.Ln` vráti hodnotu null.


## Examples

### Example #1
Získajte prirodzený logaritmus čísla 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

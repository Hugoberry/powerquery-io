# Number.Tan


Vráti tangens čísla.


## Syntax

```powerquery
Number.Tan(
    number as number
) as number
```


## Remarks

Vráti tangens čísla `number`.


## Examples

### Example #1
Nájdite tangens uhla 1.
```powerquery
Number.Tan(1)
```

Result: 
```powerquery
1.5574077246549023
```

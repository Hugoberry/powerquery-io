# Number.RandomBetween


Vráti náhodné číslo medzi dvomi číslami.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Vráti náhodné číslo medzi číslami `bottom` a `top`.


## Examples

### Example #1
Získajte náhodné číslo medzi číslami 1 a 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

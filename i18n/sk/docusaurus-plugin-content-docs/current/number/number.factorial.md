# Number.Factorial


Vráti faktoriál čísla.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

Vráti faktoriál čísla `number`.


## Examples

### Example #1
Nájdite faktoriál čísla 10.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

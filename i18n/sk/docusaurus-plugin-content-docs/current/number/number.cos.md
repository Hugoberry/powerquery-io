# Number.Cos


Vráti kosínus čísla.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Vráti kosínus zadaného uhla.

-   `number`: Uhol meraný v radiánoch.


## Examples

### Example #1
Nájdite kosínus uhla 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Nájdite kosínus radiánov π.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

# Number.BitwiseShiftRight


Posunie množinu bitov doprava.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vráti výsledok vykonania bitového posunu doprava vo vstupe `number1` o stanovený počet bitov `number2`.

Number.Bytes

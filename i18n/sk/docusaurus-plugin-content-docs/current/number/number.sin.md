# Number.Sin


Vráti sínus čísla.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Vráti sínus čísla `number`.


## Examples

### Example #1
Nájdite sínus uhla 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

# Number.BitwiseXor


Vráti výsledok vykonania bitovej operácie "XOR" (Exclusive-OR) medzi dvomi vstupmi.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vráti výsledok vykonania bitovej operácie "XOR" (Exclusive-OR) medzi vstupmi `number1` a `number2`.

Number.Bytes

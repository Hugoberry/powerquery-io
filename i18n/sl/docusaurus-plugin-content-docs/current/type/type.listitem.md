# Type.ListItem


Vrne vrsto elementa z vrste seznama.


## Syntax

```powerquery
Type.ListItem(
    type as type
) as type
```


## Remarks

Vrne vrsto elementa s seznama `type`.


## Examples

### Example #1
Poiščite vrsto elementa s seznama `{number}`.
```powerquery
Type.ListItem(type {number})
```

Result: 
```powerquery
type number
```

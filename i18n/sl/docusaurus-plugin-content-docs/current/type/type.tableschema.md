# Type.TableSchema


Vrne tabelo z opisom stolpcev (npr. shemo) določene vrste tabele.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Vrne tabelo z opisom stolpcev tabele `tableType`.

Glejte dokumentacijo za `Table.Schema` za opis nastale tabele.

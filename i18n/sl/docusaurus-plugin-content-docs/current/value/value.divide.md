# Value.Divide


Vrne rezultat deljenja prve vrednosti z drugo vrednostjo.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vrne rezultat deljenja vrednosti `value1` z vrednostjo `value2`. Določite lahko izbirni parameter `precision`; privzeto je uporabljen `Precision.Double`.

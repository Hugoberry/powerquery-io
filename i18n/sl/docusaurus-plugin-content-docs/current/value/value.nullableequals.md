# Value.NullableEquals


Vrne podatek, ali sta dve vrednosti enaki.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Vrne"null", če je argument `value1` ali `value2` ničeln, sicer je enak vrednosti"Value.Equals".

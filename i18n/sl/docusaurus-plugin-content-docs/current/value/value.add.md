# Value.Add


Vrne vsoto dveh vrednosti.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vrne vsoto vrednosti `value1` in `value2`. Določite lahko izbirni parameter `precision`; privzeto je uporabljen `Precision.Double`.

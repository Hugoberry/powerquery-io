# Value.Multiply


Vrne zmnožek dveh vrednosti.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vrne zmnožek vrednosti `value1` in `value2`. Določite lahko izbirni parameter `precision`; privzeto je uporabljen `Precision.Double`.

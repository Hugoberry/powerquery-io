# Variable.Value


Vrne vrednost navedene spremenljivke.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Vrne vrednost določene spremenljivke `identifier`, ki je opredeljena s trenutnim okoljem vrednotenja. Če spremenljivka ni določena, je prikazana napaka.

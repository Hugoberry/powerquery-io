# Value.Subtract


Vrne razliko dveh vrednosti.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vrne razliko vrednosti `value1` in `value2`. Določite lahko izbirni parameter `precision`; privzeto je uporabljen `Precision.Double`.

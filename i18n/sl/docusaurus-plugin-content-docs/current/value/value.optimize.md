# Value.Optimize


Pošlje signal funkciji Value.Expression, naj vrne optimiziran izraz za vrednost.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Če je uporabljen v funkciji Value.Expression in če `value` predstavlja poizvedbo, ki jo je mogoče optimizirati, ta funkcija označuje, da je treba vrniti optimiziran izraz. V nasprotnem primeru bo `value` naveden brez vpliva.

Expression

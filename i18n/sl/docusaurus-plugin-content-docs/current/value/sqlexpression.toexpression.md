# SqlExpression.ToExpression


Pretvori navedeno poizvedbo SQL v kodo M. Ta funkcija je namenjena le interni uporabi.


## Syntax

```powerquery
SqlExpression.ToExpression(
    sql as text,
    environment as record
) as text
```


## Remarks

Pretvori podano poizvedbo `sql` V kodo M z razpoložljivimi identifikatorji, ki jih `environment`. Ta funkcija je namenjena le interni uporabi.

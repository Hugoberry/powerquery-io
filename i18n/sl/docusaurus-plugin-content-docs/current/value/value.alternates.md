# Value.Alternates


Prikaže nadomestne načrte poizvedb.


## Syntax

```powerquery
Value.Alternates(
    alternates as list
) as any
```


## Remarks

Izraženi so nadomestni načrti poizvedb v izrazu načrta poizvedbe, pridobljenim z `Value.Expression(Value.Optimize(...))`. Ni namenjeno za druge načine uporabe.

# Value.Equals


Vrne podatek, ali sta dve vrednosti enaki.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Vrne"true", če je vrednost `value1` enaka kot vrednost `value2`, sicer vrne"false".

Values

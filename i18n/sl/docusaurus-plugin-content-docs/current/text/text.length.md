# Text.Length


Vrne število znakov.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Vrne število znakov v besedilu `text`.


## Examples

### Example #1
Ugotovite, koliko znakov je v besedilu"Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

# Table.FirstValue


Vrne prvi stolpec prve vrstice tabele ali določeno privzeto vrednost.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Vrne prvi stolpec prve vrstice tabele `table` ali določeno privzeto vrednost.

# Tables.GetRelationships


Pridobi relacije med naborom tabel.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Pridobi relacije med naborom tabel. Za nabor `tables` se predvideva, da ima strukturo, ki je podobna strukturi tabele za krmarjenje. Stolpec, določen s/z `dataColumn`, vsebuje dejanske podatkovne tabele.

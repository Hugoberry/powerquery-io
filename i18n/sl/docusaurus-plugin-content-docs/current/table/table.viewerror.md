# Table.ViewError


Ustvari spremenjen zapis o napaki, ki ne bo sprožil rezervnega ukrepa, če ga vrne rutina, ki je definirana v pogledu (prek pogleda Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Ustvari spremenjen zapis o napaki iz `errorRecord`, ki ne bo sprožil rezervnega ukrepa, če ga vrne rutina, ki je definirana v pogledu (prek pogleda Table.View).

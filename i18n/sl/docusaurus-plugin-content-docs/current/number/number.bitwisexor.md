# Number.BitwiseXor


Vrne rezultat izvajanja bitne operacije"XOR"(Exclusive-OR) med dvema vnosoma.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrne rezultat izvajanja bitne operacije"XOR"(Exclusive-OR) med `number1` in `number2`.

Number.Bytes

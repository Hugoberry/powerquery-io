# Number.Sin


Vrne sinus števila.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Vrne sinus števila `number`.


## Examples

### Example #1
Poiščite sinus kota 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

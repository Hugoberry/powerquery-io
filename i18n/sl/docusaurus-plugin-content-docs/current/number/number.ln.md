# Number.Ln


Vrne naravni logaritem števila.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Vrne naravni logaritem števila `number`. Če ima `number` ničelno vrednost, `Number.Ln` vrne"null".


## Examples

### Example #1
Poiščite naravni logaritem števila 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

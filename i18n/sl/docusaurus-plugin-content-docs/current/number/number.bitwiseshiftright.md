# Number.BitwiseShiftRight


Premakne nabor bitov v desno.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrne rezultat izvajanja bitnega premika v desno za `number1` za navedeno število bitov `number2`.

Number.Bytes

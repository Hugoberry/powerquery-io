# Number.BitwiseOr


Vrne rezultat izvajanja bitne operacije"Or"med dvema vnosoma.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrne rezultat izvajanja bitne operacije"Or"med `number1` in `number2`.

Number.Bytes

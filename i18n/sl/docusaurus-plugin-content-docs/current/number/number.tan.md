# Number.Tan


Vrne tangens števila.


## Syntax

```powerquery
Number.Tan(
    number as number
) as number
```


## Remarks

Vrne tangens števila `number`.


## Examples

### Example #1
Poiščite tangens kota 1.
```powerquery
Number.Tan(1)
```

Result: 
```powerquery
1.5574077246549023
```

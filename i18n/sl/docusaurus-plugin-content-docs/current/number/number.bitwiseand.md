# Number.BitwiseAnd


Vrne rezultat izvajanja bitne operacije"And"med dvema vnosoma.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrne rezultat izvajanja bitne operacije"And"med `number1` in `number2`.

Number.Bytes

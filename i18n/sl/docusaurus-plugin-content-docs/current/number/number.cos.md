# Number.Cos


Vrne kosinus števila.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Vrne kosinus navedenega kota.

-   `number`: kot, izmerjen v radianih.


## Examples

### Example #1
Poiščite kosinus kota 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Poiščite kosinus π radianov
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

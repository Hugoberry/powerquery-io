# Number.Log10


Vrne logaritem števila z osnovo 10.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Vrne logaritem števila `number` z osnovo 10. Če ima `number` ničelno vrednost, `Number.Log10` vrne"null".


## Examples

### Example #1
Poiščite logaritem števila 2 z osnovo 10.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

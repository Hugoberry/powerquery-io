# Number.Exp


Potencira"e"na dani eksponent.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Vrne rezultat potenciranja"e"na eksponent `number` (eksponentna funkcija).

-   `number`: `number`, za katero bo izračunana eksponentna funkcija. Če ima `number` ničelno vrednost, `Number.Exp` vrne"null".


## Examples

### Example #1
Potencirajte"e"na eksponent 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

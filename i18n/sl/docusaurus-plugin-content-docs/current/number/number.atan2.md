# Number.Atan2


Vrne arkus tangens deljenja dveh števil.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Vrne kot v radianih, katerega tangenta je kvocient `y`/`x` dveh številk `y` in `x`.

# Number.Factorial


Vrne fakulteto števila.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

Vrne fakulteto števila `number`.


## Examples

### Example #1
Poiščite fakulteto števila 10.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

# Number.BitwiseShiftLeft


Premakne nabor bitov v levo.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrne rezultat izvajanja bitnega premika v levo za `number1` za navedeno število bitov `number2`.

Number.Bytes

# Number.Abs


Vrne absolutno vrednost števila.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Vrne absolutno vrednost števila `number`. Če ima `number` ničelno vrednost, `Number.Abs` vrne"null".

-   `number`: `number`, za katero bo izračunana absolutna vrednost.


## Examples

### Example #1
Absolutna vrednost števila –3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Uri.Combine


Vrne absolutni URI, ki je kombinacija vhodnega osnovnega URI-ja in relativnega URI-ja.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Vrne absolutni URI, ki je kombinacija vnosa `baseUri` in `relativeUri`.

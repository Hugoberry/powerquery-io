# DateTimeZone.FixedUtcNow


Vrne trenutni datum in uro v času UTC (časovni pas GMT). Ta vrednost je nespremenljiva in se ne bo spremenila z zaporednimi klici.


## Syntax

```powerquery
DateTimeZone.FixedUtcNow(

) as datetimezone
```

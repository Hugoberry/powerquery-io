# DateTimeZone.UtcNow


Vrne trenutni datum in uro v času UTC (časovni pas GMT).


## Syntax

```powerquery
DateTimeZone.UtcNow(

) as datetimezone
```


## Remarks

Vrne trenutni datum in uro v času UTC (časovni pas GMT).


## Examples

### Example #1
Pridobite trenutni datum in uro v UTC.
```powerquery
DateTimeZone.UtcNow()
```

Result: 
```powerquery
#datetimezone(2011, 8, 16, 23, 34, 37.745, 0, 0)
```

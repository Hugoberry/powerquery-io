# DateTimeZone.LocalNow


Vrne trenutni datum in uro v lokalnem časovnem pasu.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Vrne vrednost `datetimezone`, nastavljeno na trenutni datum in uro v sistemu. Vrnjena vrednost vsebuje podatke o časovnem pasu, ki predstavljajo lokalni časovni pas.

# BinaryFormat.Binary


Vrne dvojiško obliko, ki bere dvojiško vrednost.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Vrne dvojiško obliko, ki bere dvojiško vrednost. Če je določen parameter `length`, bo dvojiška vrednost vsebovala toliko bajtov. Če parameter `length` ni določen, bo dvojiška vrednost vsebovala preostanek bajtov. `length` je lahko določen kot število ali kot dvojiška oblika dolžine pred dvojiškimi podatki.

# BinaryFormat.ByteOrder


Vrne dvojiško obliko z vrstnim redom bajtov, ki ga določa funkcija.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Vrne dvojiško obliko z vrstnim redom bajtov, ki ga določa `binaryFormat`. Privzeti vrstni red bajtov je `ByteOrder.BigEndian`.

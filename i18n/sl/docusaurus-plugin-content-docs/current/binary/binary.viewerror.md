# Binary.ViewError


Ustvari spremenjen zapis o napaki, ki ne bo sprožil rezervnega ukrepa, če ga vrne rutina za obravnavo, ki je opredeljena v pogledu (prek pogleda Binary.View).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Ustvari spremenjen zapis o napaki iz `errorRecord`, ki ne bo sprožil rezervnega ukrepa, če ga vrne rutina za obravnavo, ki je opredeljena v pogledu (prek pogleda Binary.View).

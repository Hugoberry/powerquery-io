# HdInsight.Contents


Vrne tabelo za krmarjenje, ki vsebuje vsebnike, najdene v določenem računu iz trezorja shrambe Azure.


## Syntax

```powerquery
HdInsight.Contents(
    account as text
) as table
```


## Remarks

Vrne tabelo za krmarjenje, ki vsebuje vrstico vsakega vsebnika, najdenega na URL-ju računa (`account`), iz trezorja shrambe Azure. Vsaka vrstica vsebuje povezavo na zbirke dvojiških podatkov vsebnikov.

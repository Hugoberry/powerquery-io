# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

S priključkom za analitiko za Teams lahko pridobite vpoglede v svojo uporabo aplikacije Teams. Podatki so na voljo tako za osebno dejavnost v aplikaciji Teams kot tudi za za dejavnost v aplikaciji Teams, katere član ste.

Podatki so na voljo za preteklih 90 dni.

Za podrobnosti o vrstah podatkov, ki so na voljo, si oglejte to dokumentacijo s pomočjo:

-   **Uporaba aplikacije Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Dejavnost uporabnikov aplikacije Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

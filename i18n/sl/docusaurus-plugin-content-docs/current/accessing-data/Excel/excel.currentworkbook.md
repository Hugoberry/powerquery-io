# Excel.CurrentWorkbook


Vrne vsebino trenutnega Excelovega delovnega zvezka.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Vrne vsebino trenutnega Excelovega delovnega zvezka. Vrne tabele, imenovane obsege in dinamična polja strežnikov. Za razliko od `Excel.Workbook` ne vrne listov.

# Cube.ApplyParameter


Vrne kocko, ko zanjo uporabite parameter.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Vrne kocko, ko uporabite `parameter` z vrednostjo `arguments` za `cube`.

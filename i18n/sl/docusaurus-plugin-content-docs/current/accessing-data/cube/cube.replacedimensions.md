# Cube.ReplaceDimensions


Zamenja nabor dimenzij, ki jih vrne Cube.Dimensions.


## Syntax

```powerquery
Cube.ReplaceDimensions(
    cube as table,
    dimensions as any
) as table
```


## Remarks

Zamenja nabor dimenzij, ki jih vrne `Cube.Dimensions`. To funkcijo lahko na primer uporabite za dodajanje stolpca ID atributu razsežnosti, tako da lahko vir podatkov združuje na ID in ne na prikazano vrednost.

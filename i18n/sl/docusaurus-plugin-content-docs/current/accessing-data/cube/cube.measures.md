# Cube.Measures


Vrne tabelo z naborom razpoložljivih meritev.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Vrne tabelo z naborom razpoložljivih meritev v `cube`. Vsaka meritev je predstavljena kot funkcija. Meritve se lahko za kocko uporabijo s Cube.AddMeasureColumn.

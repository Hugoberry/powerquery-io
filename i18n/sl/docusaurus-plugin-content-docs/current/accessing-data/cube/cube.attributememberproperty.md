# Cube.AttributeMemberProperty


Vrne lastnost atributa dimenzije.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Vrne lastnost `propertyName` za atribut dimenzije `attribute`.

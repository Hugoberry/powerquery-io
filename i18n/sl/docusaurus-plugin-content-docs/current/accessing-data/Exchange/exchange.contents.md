# Exchange.Contents


Vrne kazalo vsebine iz računa Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Vrne kazalo vsebine iz Microsoft Exchangeevega računa `mailboxAddress`. Če parametra `mailboxAddress` ne navedete, bo uporabljen privzeti račun za poverilnice.

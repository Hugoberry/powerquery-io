# Hdfs.Contents


Vrne tabelo, ki vsebuje lastnosti in vsebino datotek in map, najdenih v določeni mapi iz datotečnega sistema Hadoop.


## Syntax

```powerquery
Hdfs.Contents(
    url as text
) as table
```


## Remarks

Vrne tabelo, ki vsebuje vrstico za vsako mapo in datoteko, najdeno na URL-ju mape, `url`, iz datotečnega sistema Hadoop. Vsaka vrstica vsebuje lastnosti mape ali datoteke in povezavo do vsebine.

# File.Contents


Vrne vsebino določene datoteke kot dvojiško vrednost.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Vrne vsebino datoteke, `path`, kot dvojiško vrednost. Parameter `options` je trenutno namenjen samo za notranjo uporabo.

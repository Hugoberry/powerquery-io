# Smartsheet.Tables


Vrne tabelo listov, poročil, map in delovnih prostorov iz vmesnika API storitve Smartsheet


## Syntax

```powerquery
Smartsheet.Tables(

) as table
```


## Remarks

Vrne ugnezdeno tabelo listov, poročil, map in delovnih prostorov, ki so na voljo v vmesniku API storitve Smartsheet.


## Examples

### Example #1
Vrne liste, mape, poročila in delovne prostore, ki so na voljo na zgornji ravni hierarhije storitve Smartsheet
```powerquery
Smartsheet.Tables()
```

Result: 
```powerquery
Tabela map, poročil in delovnih prostorov z zgornje ravni hierarhije storitve Smartsheet
```

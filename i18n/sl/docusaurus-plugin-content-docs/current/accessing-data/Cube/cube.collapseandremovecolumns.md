# Cube.CollapseAndRemoveColumns


Spremeni dimenzionalno granularnost konteksta filtra kocke s strnjevanjem atributov, preslikanih na navedene stolpce.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Spremeni dimenzionalno granularnost konteksta filtra za `cube` s strnjevanjem atributov, preslikanih na navedene stolpce `columnNames`. Stolpci se tudi odstranijo iz tabelarnega pogleda kocke.

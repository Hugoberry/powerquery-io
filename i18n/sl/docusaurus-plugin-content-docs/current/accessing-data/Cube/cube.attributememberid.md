# Cube.AttributeMemberId


Vrne enolični identifikator člana iz vrednosti lastnosti članov.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Vrne enolični identifikator člana iz vrednosti lastnosti člana. `attribute`. Vrne"null"za vse druge vrednosti.

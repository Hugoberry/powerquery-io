# Cube.Parameters


Vrne tabelo z naborom parametrov, ki jih lahko uporabite v kocki.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Vrne tabelo z naborom parametrov, ki jih lahko uporabite v kocki `cube`. Vsak parameter je funkcija, ki jo lahko prikličete, da dobite `cube` z uporabljenim parametrom in njegovimi argumenti.

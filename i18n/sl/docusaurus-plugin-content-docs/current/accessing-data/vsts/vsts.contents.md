# VSTS.Contents


Vnesite URL storitve Azure DevOps Analytics.


## Syntax

```powerquery
VSTS.Contents(
    url as text,
    optional options as record
) as binary
```


## Remarks

Vrne vsebino, preneseno z naslova URL storitve Azure DevOps Analytics, v obliki dvojiške vrednosti. Ta funkcija uporablja globalne poverilnice za vse organizacije, do katerih lahko dostopate.

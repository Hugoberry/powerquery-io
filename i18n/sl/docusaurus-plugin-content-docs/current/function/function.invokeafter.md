# Function.InvokeAfter


Prikliče navedeno funkcijo po poteku navedenega trajanja.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Vrne rezultata priklica funkcije `function` po poteku trajanja `delay`.



## Category
Function

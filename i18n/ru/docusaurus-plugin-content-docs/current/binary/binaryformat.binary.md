# BinaryFormat.Binary


Возвращает двоичный формат, который считывает двоичное значение.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Возвращает двоичный формат, который считывает двоичное значение. Если задан параметр `length`, двоичное значение будет содержать указанное число байт. Если параметр `length` не указан, двоичное значение будет содержать оставшиеся байты. `length` можно указать в виде числа или как двоичный формат длины, предшествующей двоичным данным.

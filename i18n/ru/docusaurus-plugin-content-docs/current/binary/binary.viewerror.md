# Binary.ViewError


Создает измененную запись об ошибке, которая не запускает откат, когда ошибка генерируется обработчиком, определенным в представлении (через Binary.View).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Создает на основе `errorRecord` измененную запись об ошибке, которая не запускает откат, когда ошибка генерируется обработчиком, определенным в представлении (через Binary.View).

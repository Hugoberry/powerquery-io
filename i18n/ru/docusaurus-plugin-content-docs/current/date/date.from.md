# Date.From


Создает дату из заданного значения.


## Syntax

```powerquery
Date.From(
    value as any,
    optional culture as text
) as date
```


## Remarks

Возвращает значение даты на основе заданного значения.

-   `value`: значение, которое нужно преобразовать в дату. Если заданное значение равно `null`, эта функция возвращает `null`. Если заданное значение относится к типу `date`, возвращается `value`. Значения следующих типов преобразуются в значение `date`:
    -   `text`: значение `date` из текстового представления. Подробности см. в разделе `Date.FromText`.
    -   `datetime`: компонент даты `value`.
    -   `datetimezone`: компонент даты локального эквивалента типа datetime для `value`.
    -   `number`: компонент даты в эквиваленте типа datetime числа с плавающей точкой, целая часть которого представляет собой количество дней до или после полуночи 30 декабря 1899 года, а дробная часть представляет собой время в этот день, деленное на 24. Например, полночь 31 декабря 1899 года будет представлена как 1,0; 6 утра 1 января 1900 года — как 2,25; полночь 29 декабря 1899 года — как -1,0; и 6 утра 29 декабря 1899 года — как -1,25. Базовое значение — полночь 30 декабря 1899 года. Минимальное значение — полночь 1 января 0100 года. Максимальное значение — последний момент 31 декабря 9999 года.
    -   Если `value` принадлежит к любому другому типу, будет возвращена ошибка.
-   `culture`: язык и региональные параметры указанного значения (например, "en-US").


## Examples

### Example #1
Преобразовать указанную дату и время в значение даты.
```powerquery
Date.From(#datetime(1899, 12, 30, 06, 45, 12))
```

Result: 
```powerquery
#date(1899, 12, 30)
```


### Example #2
Преобразовать указанное число в значение даты.
```powerquery
Date.From(43910)
```

Result: 
```powerquery
#date(2020, 3, 20)
```


### Example #3
Преобразуйте даты немецкого текста в столбце «Дата публикации» в значения дат.
```powerquery
let
    Source = #table(type table [Account Code = text, Posted Date = text, Sales = number],
    {
        {"US-2004", "20 Januar 2023", 580},
        {"CA-8843", "18 Juli, 2023", 280},
        {"PA-1274", "12 Januar, 2022", 90},
        {"PA-4323", "14 April 2023", 187},
        {"US-1200", "14 Dezember, 2022", 350},
        {"PTY-507", "4 Juni, 2023", 110}
    }),
    #"Filtered rows" = Table.TransformColumns(
        Source,
        {"Posted Date", each Date.From(_, "de-DE"), type date}
    )
in
    #"Filtered rows"
```

Result: 
```powerquery
#table(type table [Account Code = text, Posted Date = date, Sales = number],
{
    {"US-2004", #date(2023, 1, 20), 580},
    {"CA-8843", #date(2023, 7, 18), 280},
    {"PA-1274", #date(2022, 1, 12), 90},
    {"PA-4323", #date(2023, 4, 14), 187},
    {"US-1200", #date(2022, 12, 14), 350},
    {"PTY-507", #date(2023, 6, 4), 110}
})
```

# Lines.FromBinary


Преобразует двоичное значение в список текстовых значений, разделенных разрывами строк. Если указан стиль кавычек, разрывы строк могут отображаться между кавычками. Если значение includeLineSeparators равно true, то символы разрыва строк включаются в текст.


## Syntax

```powerquery
Lines.FromBinary(
    binary as binary,
    optional quoteStyle as any,
    optional includeLineSeparators as logical,
    optional encoding as TextEncoding.Type
) as list
```


## Remarks

Преобразует двоичное значение в список текстовых значений, разделенных разрывами строк.

-   `binary`. Двоичное значение для преобразования в список.
-   `quoteStyle`. Указывает, как обрабатываются разрывы строк. Значение `quoteStyle` может быть `null`. Значение по умолчанию — `QuoteStyle.None`.
-   `includeLineSeparators`. Указывает, следует ли включать символы разрыва строки в текст. Значение `includeLineSeparators` может быть `null`. Значение по умолчанию — `false`.
-   `encoding`. Указывает текстовое кодирование двоичного значения. Значение `encoding` может быть `null`. Значение по умолчанию: `65001` (UTF-8).

Если для `quoteStyle` указана запись (а `includeLineSeparators` и `encoding` равны `null`), могут быть предоставлены следующие поля записи:

-   `QuoteStyle`. Определяет обработку разрыва строк в кавычках.
    -   `QuoteStyle.Csv`: заключенные в кавычки разрывы строк рассматриваются как часть данных, а не как конец текущей строки.
    -   `QuoteStyle.None`: все разрывы строк рассматриваются как конец текущей строки, даже если они встречаются внутри заключенного в кавычки значения. Это значение используется по умолчанию, если параметр `CsvStyle` не указан.
-   `CsvStyle`: определяет, как обрабатываются кавычки. Не следует использовать с `QuoteStyle.None`.
    -   `CsvStyle.QuoteAfterDelimiter`: кавычки в поле имеют значение только сразу после `Delimiter`.
    -   `CsvStyle.QuoteAlways`. Кавычки в поле всегда учитываются независимо от того, где они находятся.
-   `Delimiter`: разделитель из одного символа. Следует использовать только с `CsvStyle.QuoteAfterDelimiter`.
-   `IncludeLineSeparators`: указывает, следует ли включать в текст символы разрыва строки. Значение по умолчанию — `false`.
-   `Encoding`. Текстовое кодирование двоичного значения. Значение по умолчанию — `65001` (UTF-8).

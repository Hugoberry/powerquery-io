# Value.Add


Возвращает сумму двух значений.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Возвращает сумму значений `value1` и `value2`. Можно указать необязательный параметр `precision`, по умолчанию используется `Precision.Double`.

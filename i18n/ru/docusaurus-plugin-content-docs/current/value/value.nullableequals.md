# Value.NullableEquals


Проверяет, равны ли два значения.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Возвращает null, если любой из аргументов `value1` и `value2` равен null; в противном случае эквивалентно Value.Equals.

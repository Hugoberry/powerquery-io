# Value.Subtract


Возвращает разность двух значений.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Возвращает разность `value1` и `value2`. Можно указать необязательный параметр `precision`, по умолчанию используется `Precision.Double`.

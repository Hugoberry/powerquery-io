# Value.Alternates


Выражает альтернативные планы запросов.


## Syntax

```powerquery
Value.Alternates(
    alternates as list
) as any
```


## Remarks

Представляет альтернативные планы запроса в рамках выражения плана запроса, полученного с помощью `Value.Expression(Value.Optimize(...))`. Не предназначено для других целей.

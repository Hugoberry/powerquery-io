# Variable.Value


Возвращает значение указанной переменной.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Возвращает значение указанной переменной `identifier`, определенной в текущей среде выполнения. Если переменная не определена, возникает ошибка.

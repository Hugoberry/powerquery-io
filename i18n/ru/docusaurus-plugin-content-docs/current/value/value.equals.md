# Value.Equals


Проверяет, равны ли два значения.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Возвращает значение true, если значение `value1` равно значению `value2`, в противном случае - false.



## Category
Values

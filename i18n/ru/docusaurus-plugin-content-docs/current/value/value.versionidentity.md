# Value.VersionIdentity


Возвращает идентификатор версии значения.


## Syntax

```powerquery
Value.VersionIdentity(
    value as any
) as any
```


## Remarks

Возвращает идентификатор версии `value` (или `null`, если версия отсутствует).

Action

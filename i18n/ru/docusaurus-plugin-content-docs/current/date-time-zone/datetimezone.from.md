# DateTimeZone.From


Создает значение datetimezone из заданного значения.


## Syntax

```powerquery
DateTimeZone.From(
    value as any,
    optional culture as text
) as datetimezone
```


## Remarks

Создает значение `datetimezone` на основе заданного значения.

-   `value`: значение, используемое для создания `datetimezone`.
-   `culture`: (необязательно) идентификатор языка и региональных параметров, которые следует использовать при преобразовании типов столбцов (например, "en-US").

В значение `datetimezone` можно преобразовать значения следующих типов:

-   `text`: преобразует текстовое представление в значение `datetimezone`. Подробности см. в разделе `DateTimeZone.FromText`.
-   `date`: возвращает значение `datetimezone`, содержащее `value` в качестве компонента даты, `00:00:00` в качестве компонента времени и смещение, соответствующее локальному часовому поясу.
-   `datetime`: возвращает значение `datetimezone`, содержащее `value` в качестве значения datetime, и смещение, соответствующее локальному часовому поясу.
-   `datetimezone`: возвращает `value`.
-   `time`: возвращает значение `datetimezone`, содержащее дату, эквивалентную дате автоматизации OLE для `0`, в качестве компонента даты, `value` в качестве компонента времени и смещение, соответствующее локальному часовом поясу. Дата автоматизации OLE состоит из числа с плавающей точкой, целая часть которого представляет собой количество дней до или после полуночи 30 декабря 1899 года, а дробная часть представляет собой время в этот день, деленное на 24. Например, полночь 31 декабря 1899 года будет представлена как 1,0; 6 утра 1 января 1900 года будет представлено как 2,25; полночь 29 декабря 1899 года будет представлена как -1,0; а 6 утра 29 декабря 1899 года будет представлено как -1,25. Базовое значение — полночь 30 декабря 1899 года. Минимальное значение — полночь 1 января 0100 года. Максимальное значение — последний момент 31 декабря 9999 года.
-   `number`: возвращает значение `datetimezone` со значением datetime, эквивалентным дате и времени даты автоматизации OLE, выраженной через `value`, и смещением, соответствующим локальному часовому поясу.
-   `null`: возвращает `null`.

Если `value` принадлежит к любому другому типу, будет возвращена ошибка.  
  
Значение смещения, соответствующее локальному часовому поясу, отличается при выполнении этой функции локально и при выполнении в сети. При локальном выполнении возвращается местный часовой пояс. При выполнении в сети возвращается часовой пояс UTC (+00:00).


## Examples

### Example #1
Преобразование текстового представления даты, времени и часового пояса в значение `datetimezone`.
```powerquery
DateTimeZone.From("2020-10-30T01:30:00-08:00")
```

Result: 
```powerquery
#datetimezone(2020, 10, 30, 01, 30, 00, -8, 00)
```


### Example #2
Преобразование текстового представления языка и региональных параметров для португальского языка (Бразилия) в значение `datetimezone`.
```powerquery
DateTimeZone.From("13 de agosto de 2025 15:43:00 -03:00", "pt-BR")
```

Result: 
```powerquery
#datetimezone(2025, 08, 13, 15, 43, 00, -3, 00)
```


### Example #3
Преобразование числа, представляющего дату и время 12:00 1 января 2025 года, в значение `datetimezone`. Часовой пояс, содержащийся в результате, зависит от того, выполняется ли пример локально или в сети.
```powerquery
DateTimeZone.From(45658.5)
```

Result: 
```powerquery
#datetimezone(2025, 01, 01, 12, 00, 00, 0, 00)
```

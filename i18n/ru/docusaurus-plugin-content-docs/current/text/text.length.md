# Text.Length


Возвращает число символов.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Возвращает число символов в тексте `text`.


## Examples

### Example #1
Определить, сколько символов содержится в тексте "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

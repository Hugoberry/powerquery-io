# Value.FromText


Создает строго типизированное значение из текстового представления.


## Syntax

```powerquery
Value.FromText(
    text as any,
    optional culture as text
) as any
```


## Remarks

Декодирование значения из текстового представления и его интерпретация в качестве значения соответствующего типа.

-   `text`: текст для интерпретации.
-   `culture`: (необязательно) язык и региональные параметры для интерпретации текста (например, "en-US").

Эта функция принимает текстовое значение и возвращает значение типа `number`, `logical`, `null`, `datetime`, `duration` или `text`. Пустое текстовое значение интерпретируется как значение `null`.


## Examples

### Example #1
Преобразование текста, представляющего число, в соответствующее числовое значение.
```powerquery
Value.FromText("12345.6789")
```

Result: 
```powerquery
12345.6789
```


### Example #2
Преобразование текста, представляющего процент, в соответствующее числовое значение.
```powerquery
Value.FromText("25.4%")
```

Result: 
```powerquery
0.254
```


### Example #3
Преобразование текста, представляющего сумму в евро во французском формате в соответствующее числовое значение.
```powerquery
Value.FromText("€1,190", "fr-FR")
```

Result: 
```powerquery
1.19
```


### Example #4
Преобразование текста, представляющего дату и время в немецком формате, в соответствующее значение даты и времени.
```powerquery
Value.FromText("24 Dez 2024 14:33:20", "de-DE")
```

Result: 
```powerquery
#datetime(2024, 12, 24, 14, 33, 20)
```

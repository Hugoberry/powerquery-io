# Function.InvokeAfter


Вызывает заданную функцию спустя указанный период времени.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Возвращает результат вызова `function` спустя период времени `delay`.



## Category
Function

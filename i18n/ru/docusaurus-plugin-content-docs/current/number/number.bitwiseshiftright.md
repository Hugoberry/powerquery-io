# Number.BitwiseShiftRight


Сдвигает заданные биты вправо.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Возвращает результат выполнения побитового сдвига вправо над `number1` на указанное число битов `number2`.

Number.Bytes

# Number.BitwiseAnd


Возвращает результат выполнения побитовой операции AND с двумя входными значениями.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Возвращает результат выполнения побитовой операции AND со значениями `number1` и `number2`.



## Category
Number.Bytes

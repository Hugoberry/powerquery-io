# Number.Log10


Возвращает десятичный логарифм числа.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Возвращает десятичный логарифм числа `number`. Если `number` имеет значение NULL, `Number.Log10` возвращает NULL.


## Examples

### Example #1
Получение десятичного логарифма для 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

# Number.Ln


Возвращает натуральный логарифм числа.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Возвращает натуральный логарифм числа `number`. Если `number` имеет значение NULL, то `Number.Ln` возвращает NULL.


## Examples

### Example #1
Получить натуральный логарифм числа 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

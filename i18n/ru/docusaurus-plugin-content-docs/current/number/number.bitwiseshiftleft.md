# Number.BitwiseShiftLeft


Сдвигает набор битов влево.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Возвращает результат выполнения побитового сдвига влево над `number1` на указанное число битов `number2`.

Number.Bytes

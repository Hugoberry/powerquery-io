# Number.RandomBetween


Возвращает случайное число между 2 чисел.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Возвращает случайное число, расположенное между `bottom` и `top`.


## Examples

### Example #1
Получить случайное число между 1 и 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

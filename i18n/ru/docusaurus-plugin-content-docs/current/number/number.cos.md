# Number.Cos


Возвращает косинус числа.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Возвращает косинус заданного угла.

-   `number`: угол в радианах.


## Examples

### Example #1
Найти косинус угла 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Найти косинус π радиан.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

# Number.BitwiseOr


Возвращает результат выполнения побитовой операции OR с двумя входными значениями.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Возвращает результат выполнения побитовой операции OR со значениями `number1` и `number2`.



## Category
Number.Bytes

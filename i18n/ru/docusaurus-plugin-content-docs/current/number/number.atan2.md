# Number.Atan2


Возвращает арктангенс частного от деления двух чисел.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Возвращает угол в радианах, тангенс которого равен частному `y`/`x` двух чисел `y` и `x`.

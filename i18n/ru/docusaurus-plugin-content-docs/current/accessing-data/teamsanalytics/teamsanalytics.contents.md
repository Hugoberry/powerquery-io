# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Соединитель аналитики для Teams позволяет получать сведения об использовании вами этого решения. Просматривайте данные о том, что вы делаете в Teams самостоятельно или в составе команды.

Информация доступна за прошлые 90 дней.

Сведения о доступных типах данных см. в следующей справочной документации.

-   **Использование Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Действия пользователя в Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

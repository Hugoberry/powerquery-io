# Cube.AttributeMemberProperty


Возвращает свойство атрибута измерения.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Возвращает свойство `propertyName` атрибута измерения `attribute`.

Cube

# Cube.AttributeMemberId


Возвращает уникальный идентификатор члена из значения свойства члена.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Возвращает уникальный идентификатор члена из значения свойства члена. `attribute`. Возвращает значение NULL для всех остальных значений.

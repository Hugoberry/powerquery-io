# File.Contents


Возвращает содержимое заданного файла в двоичном виде.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Возвращает содержимое файла, `path` в виде двоичного кода. Параметр `options` в настоящее время предназначен только для внутреннего использования.

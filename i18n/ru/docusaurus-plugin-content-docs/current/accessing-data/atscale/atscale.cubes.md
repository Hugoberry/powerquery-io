# AtScale.Cubes


Импорт или извлечение в режиме DirectQuery данных куба из AtScale.


## Syntax

```powerquery
AtScale.Cubes(
    server as Uri.Type,
    optional options as record
) as table
```


## Remarks

Возвращает данные куба из AtScale на сервере `server`. Можно указать необязательный параметр записи `options` для управления следующими параметрами:

-   `TypedMeasureColumns`: логическое значение, указывающее, будут ли в качестве типов добавленных столбцов мер использоваться типы, указанные в многомерной или табличной модели. Если задано значение false, для всех столбцов мер будет использоваться тип "number". Значение по умолчанию — false.
-   `CommandTimeout`: длительность выполнения запроса на стороне сервера до его отмены (в секундах). Значение по умолчанию зависит от драйвера.
-   `ConnectionTimeout`: длительность, контролирующая время ожидания до отмены попытки подключения к серверу (в секундах). Значение по умолчанию зависит от драйвера.

Параметр записи задается в формате \[параметр1 = значение1, параметр2 = значение2…\].


## Examples

### Example #1
Вывод списка данных куба в кубе AtScale.
```powerquery
AtScale.Cubes("https://contoso.atscale.com:10502/xmla/...")
```

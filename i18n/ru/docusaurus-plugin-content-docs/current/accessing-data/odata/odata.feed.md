# OData.Feed


Возвращает таблицу каналов OData, предлагаемых службой OData.


## Syntax

```powerquery
OData.Feed(
    serviceUri as text,
    optional headers as record,
    optional options as any
) as any
```


## Remarks

Возвращает таблицу каналов OData, предоставляемых службой OData из URI `serviceUri` (заголовки: `headers`). Для управления следующими вариантами можно использовать логическое значение, указывающее, должны ли использоваться одновременные подключения, или необязательный параметр записи, `options`:

-   `Query`: добавление параметров запроса в URL-адрес программными средствами без необходимости экранирования escape-символами.
-   `Заголовки`: указание этого значения в качестве записи добавит дополнительные заголовки в HTTP-запрос.
-   `ExcludedFromCacheKey`: если указать это значение в качестве списка, эти ключи HTTP-заголовков не будут участвовать в вычислении для кэширования данных.
-   `ApiKeyName`: если целевой сайт имеет понятие о ключе API, этот параметр можно использовать для указания имени (не значения) параметра ключа, который следует использовать в URL-адресе. Фактическое значение ключа указывается в учетных данных.
-   `Timeout`: указание этого значения в качестве длительности приведет к изменению времени ожидания HTTP-запроса. Значение по умолчанию — 600 секунд.
-   `EnableBatch`: логическое значение (true или false), которое разрешает или запрещает генерировать запрос $batch OData при превышении значения MaxUriLength (по умолчанию — false).
-   `MaxUriLength`: число, указывающее максимальную длину разрешенного универсального кода ресурса, отправляемого в службу OData. Если оно превышено и параметр EnableBatch имеет значение true, запрос будет направлен в конечную точку $batch OData, в противном случае произойдет сбой (значение по умолчанию: 2048).
-   `Concurrent`: логическое значение (true или false). Если задано значение true, запросы к службе отправляются параллельно. Если задано значение false, запросы к службе отправляются последовательно. Если значение не указано, оно определяется аннотацией службы AsynchronousRequestsSupported. Если служба не указывает, поддерживается ли AsynchronousRequestsSupported, запросы будут отправляться последовательно.
-   `ODataVersion`: число (3 или 4), указывающее версию протокола OData, используемую для этой службы OData. Если значение не указано, будут запрошены все поддерживаемые версии. Версия службы будет определена с помощью заголовка OData-Version, возвращаемого службой.
-   `FunctionOverloads`: логическое значение (true/false). При указании значения true перегрузки импорта функций будут указаны в навигаторе в качестве отдельных записей; если задано значение false, перегрузки импорта функции будут перечислены в навигаторе как одна функция объединения. Значение по умолчанию для V3: false. Значение по умолчанию для V4: true.
-   `MoreColumns`: логическое значение (true или false); если задано значение true, добавляется столбец "More Columns" для каждого канала сущности, содержащего открытые и полиморфные типы. Он будет содержать поля, не объявленные в базовом типе. Если задано значение false, это поле будет отсутствовать. Значение по умолчанию — false.
-   `IncludeAnnotations`: разделенный запятыми список имен терминов или шаблонов с указанием пространства имен, которые будут включены с подстановочным знаком "\*". По умолчанию никакие заметки не включаются.
-   `IncludeMetadataAnnotations`: разделенный запятыми список имен терминов или шаблонов с указанием пространства имен, которые будут включены в запросы документов с метаданными с подстановочным знаком "\*". По умолчанию включает те же заметки, что и IncludeAnnotations.
-   `OmitValues`: позволяет службе OData не записывать определенные значения в ответах. При наличии подтверждения со стороны службы эти значения будут получены из опущенных полей. Варианты включают в себя:
    -   `ODataOmitValues.Nulls`: позволяет службе OData пропускать значения null.
-   `Implementation`: указывает реализацию соединителя OData, которую следует использовать. Допустимые значения — "2.0" или null.


## Examples

### Example #1
Подключение к службе OData TripPin.
```powerquery
OData.Feed("https://services.odata.org/V4/TripPinService")
```

table

# List.Mode


Возвращает наиболее частое значение в списке.


## Syntax

```powerquery
List.Mode(
    list as list,
    optional equationCriteria as any
) as any
```


## Remarks

Возвращает элемент, который чаще всего встречается в `list`. Если список пуст, генерируется ошибка. Если несколько элементов появляются с одинаковой максимальной частотой, выбирается последний. Необязательное значение критерия сравнения, `equationCriteria`. Его можно указывать для управления проверкой равенства.


## Examples

### Example #1
Найти элемент, который наиболее часто появляется в списке `{"A", 1, 2, 3, 3, 4, 5}`.
```powerquery
List.Mode({"A", 1, 2, 3, 3, 4, 5})
```

Result: 
```powerquery
3
```


### Example #2
Найти элемент, который наиболее часто появляется в списке `{"A", 1, 2, 3, 3, 4, 5, 5}`.
```powerquery
List.Mode({"A", 1, 2, 3, 3, 4, 5, 5})
```

Result: 
```powerquery
5
```

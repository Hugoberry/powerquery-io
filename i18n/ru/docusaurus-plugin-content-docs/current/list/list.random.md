# List.Random


Возвращает список случайных чисел.


## Syntax

```powerquery
List.Random(
    count as number,
    optional seed as number
) as list
```


## Remarks

Возвращает список случайных чисел в диапазоне от 0 до 1 для заданного количества генерируемых значений и необязательного начального значения.

-   `count`: число случайных значений, которые нужно сгенерировать.
-   `seed`: *(необязательно)* числовое значение, используемое для затравки генератора случайных чисел. Если не указано, при каждом вызове функции создается уникальный список случайных чисел. Если указывать численное начальное значение, каждый вызов функции будет создавать один и тот же список случайных чисел для этого значения.


## Examples

### Example #1
Создать список из 3 случайных чисел.
```powerquery
List.Random(3)
```

Result: 
```powerquery
{0.992332, 0.132334, 0.023592}
```


### Example #2
Создать список из 3 случайных чисел с указанным начальным значением.
```powerquery
List.Random(3, 2)
```

Result: 
```powerquery
{0.883002, 0.245344, 0.723212}
```

# List.MaxN


Возвращает максимальные значения в списке. Необходимо указать число возвращаемых значений или условие фильтрации.


## Syntax

```powerquery
List.MaxN(
    list as list,
    countOrCondition as any,
    optional comparisonCriteria as any,
    optional includeNulls as logical
) as list
```


## Remarks

Возвращает максимальные значения в указанном списке. После сортировки строк можно указать необязательные параметры для дополнительной фильтрации результата.

-   `list`: список значений.
-   `countOrCondition`: указывает число возвращаемых значений или условие фильтрации. Если указано число, возвращается список из не более чем `countOrCondition` элементов в порядке убывания. Если указано условие, возвращаемый список включает все элементы, удовлетворяющие этому условию.
-   `comparisonCriteria`: (необязательно) функция, используемая для преобразования значений перед сравнением. Если этот параметр равен `null`, значения сравниваются без преобразования.
-   `includeNulls`: (необязательно) указывает, следует ли учитывать значения `null` при определении элемента с максимальным значением в списке. Значение по умолчанию — `true`.


## Examples

### Example #1
Поиск 5 наибольших значений в указанном списке.
```powerquery
List.MaxN({3, 4, 5, -1, 7, 8, 2}, 5)
```

Result: 
```powerquery
{8, 7, 5, 4, 3}
```


### Example #2
Поиск слов длиной более 3 символов.
```powerquery
List.MaxN(
    {"boy", "dog", "pony", "cat", "rabbit", "bat"},
    each Text.Length(_) > 3
)
```

Result: 
```powerquery
{"rabbit", "pony"}
```


### Example #3
Поиск трех поздних дат из списка дат в немецком формате.
```powerquery
let
    Source = {"12.02.2024", "15.05.2025", "10.10.2021", "16.01.2025", "30.12.2022"},
    MaxDate = List.MaxN(Source, 3, each Date.FromText(_, [Culture = "de-DE"]))
in
    MaxDate
```

Result: 
```powerquery
{
    "15.05.2025",
    "16.01.2025",
    "12.02.2024"
}
```

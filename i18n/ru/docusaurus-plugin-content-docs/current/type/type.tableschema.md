# Type.TableSchema


Возвращает таблицу, содержащую описание столбцов (схему) указанного типа таблиц.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Возвращает таблицу, описывающую столбцы `tableType`.

Описание результирующей таблицы см. в документации по `Table.Schema`.

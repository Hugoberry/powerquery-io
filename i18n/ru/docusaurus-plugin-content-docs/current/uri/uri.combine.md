# Uri.Combine


Возвращает абсолютный URI, представляющий собой сочетание базового URI и относительного URI входных данных.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Возвращает абсолютный URI, представляющие собой сочетание входных данных `baseUri` и `relativeUri`.

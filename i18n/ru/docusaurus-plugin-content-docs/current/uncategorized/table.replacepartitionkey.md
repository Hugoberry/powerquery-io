# Table.ReplacePartitionKey


Заменяет ключ раздела указанной таблицы.


## Syntax

```powerquery
Table.ReplacePartitionKey(
    table as table,
    partitionKey as list
) as table
```


## Remarks

Заменяет ключ раздела указанной таблицы.

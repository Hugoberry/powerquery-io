# Type.TablePartitionKey


Возвращает ключ раздела для указанного типа таблицы, если она содержит его.


## Syntax

```powerquery
Type.TablePartitionKey(
    tableType as type
) as list
```


## Remarks

Возвращает ключ раздела для указанного типа таблицы, если она содержит его.

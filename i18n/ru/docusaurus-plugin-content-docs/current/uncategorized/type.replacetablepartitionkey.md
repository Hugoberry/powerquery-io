# Type.ReplaceTablePartitionKey


Возвращает новый тип таблицы с ключом раздела, замененным на указанный ключ раздела.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Возвращает новый тип таблицы с ключом раздела, замененным на указанный ключ раздела.

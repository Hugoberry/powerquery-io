# List.LastN


Арнайы тізімдегі соңғы элемент немесе элементтер тізімін қайтарады. Таңдау бойынша, қанша мән қайтарылатынын көрсетуге немесе шартты нақтылауға болады.


## Syntax

```powerquery
List.LastN(
    list as list,
    optional countOrCondition as any
) as any
```


## Remarks

Арнайы тізімдегі соңғы элемент немесе элементтер тізімін қайтарады.

-   `list`: Тексерілетін тізім. Егер тізім бос болса, бос тізім қайтарылады.
-   `countOrCondition`: (Міндетті емес) Бірнеше элементті жинауды немесе элементтерді сүзуге қолдау көрсетеді. Бұл параметр міндетті емес деп көрсетілгенімен, егер бұл мән берілмесе немесе ол `null` болса, қате пайда болады. Бұл параметрді екі жолмен көрсетуге болады:
    -   Егер сан көрсетілсе, осыншама көп элементтер жойылады.
    -   Егер шарт көрсетілсе, тізімнің соңынан бастап шартқа сәйкес келетін барлық элементтер қайтарылады. Бір элемент шартқа сай келмесе, одан кейінгі элементтер қарастырылмайды.


## Examples

### Example #1
\{3, 4, 5, -1, 7, 8, 2\} тізіміндегі соңғы мәнді анықтау.
```powerquery
List.LastN({3, 4, 5, -1, 7, 8, 2}, 1)
```

Result: 
```powerquery
{2}
```


### Example #2
\{3, 4, 5, -1, 7, 8, 2\} тізіміндегі 0-ден үлкенірек соңғы мәндерді анықтау.
```powerquery
List.LastN({3, 4, 5, -1, 7, 8, 2}, each _ > 0)
```

Result: 
```powerquery
{7, 8, 2}
```

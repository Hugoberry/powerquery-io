# List.Split


Көрсетілген бет өлшемін пайдаланып, көрсетілген тізімді тізімдер тізіміне бөледі.


## Syntax

```powerquery
List.Split(
    list as list,
    pageSize as number
) as list
```


## Remarks

`list` тізімдер тізіміне бөледі, мұнда шығыс тізімінің бірінші элементі — бастапқы тізімнің алғашқы `pageSize` элементін қамтитын тізім, шығыс тізімінің келесі элементі — бастапқы тізімнің келесі `pageSize` элементін қамтитын тізім және т.б.

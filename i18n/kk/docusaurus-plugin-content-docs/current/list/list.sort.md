# List.Sort


Деректер тізімін көрсетілген шарттарға сай сұрыптайды.


## Syntax

```powerquery
List.Sort(
    list as list,
    optional comparisonCriteria as any
) as list
```


## Remarks

Көрсетілген қосымша критерийге байланысты, `list`, деректер тізімін сұрыптайды. `comparisonCriteria` қосымша параметрін салыстыру критерийі ретінде көрсетуге болады. Бұл келесі мәндерге ие бола алады:

-   Реттілікті басқару үшін, салыстыру критерийі “Реттілік” тізім мәні болуы мүмкін. (`Order.Descending`, `Order.Ascending`).
-   Сұрыптау үшін пайдаланылатын кілтті есептеу үшін, 1 аргумент функциясын пайдалануға болады.
-   Кілтті таңдау мен реттілікті басқарудың екеуі үшін де салыстыру критерийі кілт пен реттілікті қамтитын тізім болуы мүмкін (`{each 1 / _, Order.Descending}`).
-   Салыстыруды толығымен басқару үшін 2 аргумент функциясын пайдалануға болады (мысалы, Value.Compare). Бұл функцияға тізімнен екі элемент жіберіледі (кез келген екі элемент, кез келген реттілікте). Функция келесі мәндердің біреуін қайтаруы тиіс:
    -   `-1`: Бірінші элемент екінші элементтен кем.
    -   `0`: Элементтер тең.
    -   `1`: Бірінші элемент екінші элементтен артық.


## Examples

### Example #1
\{2, 3, 1\} тізімін сұрыптау.
```powerquery
List.Sort({2, 3, 1})
```

Result: 
```powerquery
{1, 2, 3}
```


### Example #2
\{2, 3, 1\} тізімін кему ретімен сұрыптау.
```powerquery
List.Sort({2, 3, 1}, Order.Descending)
```

Result: 
```powerquery
{3, 2, 1}
```


### Example #3
Value.Compare әдісін пайдаланып \{2, 3, 1\} тізімін кему ретімен сұрыптау.
```powerquery
List.Sort({2, 3, 1}, (x, y) => Value.Compare(1/x, 1/y))
```

Result: 
```powerquery
{3, 2, 1}
```

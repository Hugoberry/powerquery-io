# List.Skip


Тізімнің басында көрсетілген элементтер санын өткізіп жіберетін тізімді қайтарады.


## Syntax

```powerquery
List.Skip(
    list as list,
    optional countOrCondition as any
) as list
```


## Remarks

`list`тізімінің бірінші элементін өткізіп жіберетін тізімді қайтарады. Егер `list` бос тізім болса, бос тізім қайтарылады. Бұл функция төменде көрсетілгендей бірнеше мәнді өткізіп жіберуді қолдау үшін қосымша `countOrCondition` параметрін қабылдайды.

-   Егер сан көрсетілсе, осыншама көп элементтер өткізіп жіберіледі.
-   Егер шарт көрсетілсе, `list` басында барлық дәйекті сәйкес элементтер өткізіп жіберіледі.
-   Бұл параметр бос болса, әдепкі әрекет байқалады.


## Examples

### Example #1
\{1, 2, 3, 4, 5\} тізімінен бірінші 3 сан жоқ тізімді жасау.
```powerquery
List.Skip({1, 2, 3, 4, 5}, 3)
```

Result: 
```powerquery
{4, 5}
```


### Example #2
\{5, 4, 2, 6, 1\} тізімінен 3-тен кішірек саннан басталатын тізімді жасау.
```powerquery
List.Skip({5, 4, 2, 6, 1}, each _ > 3)
```

Result: 
```powerquery
{2, 6, 1}
```

# List.MinN


Тізімдегі ең кіші мәнді(дерді) қайтарады. Қайтарылатын мәндер санын немесе сүзу шартын көрсетуге болады.


## Syntax

```powerquery
List.MinN(
    list as list,
    countOrCondition as any,
    optional comparisonCriteria as any,
    optional includeNulls as logical
) as list
```


## Remarks

`list` тізіміндегі ең кіші мәнді(дерді) қайтарады. `countOrCondition` параметрі қайтарылатын мәндер санын немесе сүзу шартын көрсетеді. `comparisonCriteria` қосымша параметрі тізімдегі мәндерді салыстыру әдісін көрсетеді.

-   `list`: Мәндер тізімі.
-   `countOrCondition`: егер сан көрсетілген болса, кему ретімен берілген `countOrCondition` дейінгі элементтер тізімі қайтарылады. Егер шарт көрсетілген болса, басында шартқа сай болған элементтер тізімі қайтарылады. Бір элемент шартқа сай болмаса, басқа элементтер қарастырылмайды. Егер бұл параметрдің мәні null болса, тізімдегі бір ең кіші мән қайтарылады.
-   `comparisonCriteria`: *(Міндетті емес)* Тізімдегі элементтерді салыстыру жолын анықтау үшін қосымша `comparisonCriteria` мән көрсетіледі. Егер бұл параметрдің мәні null болса, әдепкі салыстыру құралы пайдаланылады.


## Examples

### Example #1
`{3, 4, 5, -1, 7, 8, 2}` тізіміндегі 5 ең кіші мәнді анықтау.
```powerquery
List.MinN({3, 4, 5, -1, 7, 8, 2}, 5)
```

Result: 
```powerquery
{-1, 2, 3, 4, 5}
```

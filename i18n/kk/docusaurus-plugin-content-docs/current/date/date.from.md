# Date.From


Осы мәннен күнді жасайды.


## Syntax

```powerquery
Date.From(
    value as any,
    optional culture as text
) as date
```


## Remarks

Берілген мәннен күн мәнін қайтарады.

-   `value`: Күнге түрлендіретін мән. Берілген мән `null` болса, бұл функция `null` мәнін қайтарады. Берілген мән `date` болса, `value` қайтарылады. Келесі түрлерге жататын мәндер `date` мәніне түрлендіріледі:
    -   `text`: мәтіндік көріністен `date` мәні. Мәліметтер алу үшін `Date.FromText` қараңыз.
    -   `datetime`: `value` күн құрамдасы.
    -   `datetimezone`: `value` жергілікті күн/уақыт баламасының күн құрамдасы.
    -   `number`: Бүтін сандық құрамдасы 1899 жылдың 30 желтоқсанына (түн ортасы) дейінгі немесе одан кейінгі күндер саны болып табылатын және бөлшектік құрамдасы сол күнгі 24-ке бөлінген уақытты білдіретін қалқымалы үтірлі санның күн/уақыт баламасының күн құрамдасы. Мысалы, түн ортасы, 31 желтоқсан, 1899 күні 1,0; 6:00 деп көрсетіледі, 1 қаңтар, 1900 2,25 деп көрсетіледі; түн ортасы, 29 желтоқсан, 1899 күні -1.0 және 6:00 деп көрсетіледі, 29 желтоқсан, 1899 күні -1,25 деп көрсетіледі. Негізгі мән — түн ортасы, 30 желтоқсан, 1899. Минималды мән — түн ортасы, 1 қаңтар, 0100. Максималды мән — 9999 жылдағы 31 желтоқсанның соңғы сәті.
    -   `value` қандай да бір басқа түрге жатса, қате қайтарылады.
-   `culture`: Берілген мәннің тілі (мысалы, "en-US").


## Examples

### Example #1
Көрсетілген күн мен уақытта күн мәніне түрлендіру.
```powerquery
Date.From(#datetime(1899, 12, 30, 06, 45, 12))
```

Result: 
```powerquery
#date(1899, 12, 30)
```


### Example #2
Көрсетілген санды күн мәніне түрлендіру.
```powerquery
Date.From(43910)
```

Result: 
```powerquery
#date(2020, 3, 20)
```


### Example #3
"Жарияланған күні" бағанындағы неміс мәтін күндерін күн мәндеріне түрлендіру.
```powerquery
let
    Source = #table(type table [Account Code = text, Posted Date = text, Sales = number],
    {
        {"US-2004", "20 Januar 2023", 580},
        {"CA-8843", "18 Juli, 2023", 280},
        {"PA-1274", "12 Januar, 2022", 90},
        {"PA-4323", "14 April 2023", 187},
        {"US-1200", "14 Dezember, 2022", 350},
        {"PTY-507", "4 Juni, 2023", 110}
    }),
    #"Filtered rows" = Table.TransformColumns(
        Source,
        {"Posted Date", each Date.From(_, "de-DE"), type date}
    )
in
    #"Filtered rows"
```

Result: 
```powerquery
#table(type table [Account Code = text, Posted Date = date, Sales = number],
{
    {"US-2004", #date(2023, 1, 20), 580},
    {"CA-8843", #date(2023, 7, 18), 280},
    {"PA-1274", #date(2022, 1, 12), 90},
    {"PA-4323", #date(2023, 4, 14), 187},
    {"US-1200", #date(2022, 12, 14), 350},
    {"PTY-507", #date(2023, 6, 4), 110}
})
```

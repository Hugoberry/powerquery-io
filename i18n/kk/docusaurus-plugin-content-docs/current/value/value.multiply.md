# Value.Multiply


Екі мәннің көбейтіндісін қайтарады.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1` мәнін `value2` мәніне көбейтудің нәтижесін қайтарады. `precision` міндетті емес параметрін көрсетуге болады, әдепкі мәні бойынша `Precision.Double` пайдаланылады.

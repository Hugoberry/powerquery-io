# Variable.ValueOrDefault


Айнымалы анықталмаса, көрсетілген айнымалының мәнін немесе әдепкі мәнді қайтарады.


## Syntax

```powerquery
Variable.ValueOrDefault(
    identifier as text,
    optional defaultValue as any
) as any
```


## Remarks

Ағымдағы бағалау ортасы анықтаған көрсетілген `identifier` айнымалының мәнін қайтарады. Айнымалы анықталмаса, қосымша `defaultValue` қайтарылады.

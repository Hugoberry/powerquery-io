# Value.Equals


Тең екі мәнді қайтарады.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

`value1` мәні `value2` мәніне тең болса шын мәнін, олай болмаса өтіркі мәнін қайтарады.

Values

# Value.Divide


Бірінші мәнді екіншісіне бөлудің нәтижесін қайтарады.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1` мәнін `value2` мәніне бөлудің нәтижесін қайтарады. `precision` міндетті емес параметрін көрсетуге болады, әдепкі мәні бойынша `Precision.Double` пайдаланылады.

# Value.NullableEquals


Тең екі мәнді қайтарады.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

`value1` немесе `value2` аргументттердің біреуінің мәні null болса, null мәнін қайтарады, олай болмаса, Value.Equals тең.

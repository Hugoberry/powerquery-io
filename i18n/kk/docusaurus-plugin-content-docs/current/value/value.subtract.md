# Value.Subtract


Екі мәннің айырмашылығын қайтарады.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1` және `value2` айырмашылығын қайтарады. `precision` міндетті емес параметрін көрсетуге болады, әдепкі мәні бойынша `Precision.Double` пайдаланылады.

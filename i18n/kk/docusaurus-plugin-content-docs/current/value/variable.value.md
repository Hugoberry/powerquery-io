# Variable.Value


Көрсетілген айнымалының мәнін қайтарады.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Ағымдағы бағалау ортасы анықтаған көрсетілген `identifier` айнымалының мәнін қайтарады. Айнымалы анықталмаса, қате пайда болады.

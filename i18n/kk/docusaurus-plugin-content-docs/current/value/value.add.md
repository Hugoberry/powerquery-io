# Value.Add


Екі мәннің қосындысын қайтарады.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1` және `value2` қосындысын қайтарады. `precision` міндетті емес параметрін көрсетуге болады, әдепкі мәні бойынша `Precision.Double` пайдаланылады.

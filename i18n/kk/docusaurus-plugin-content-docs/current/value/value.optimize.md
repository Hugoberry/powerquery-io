# Value.Optimize


Мән үшін оңтайландырылған өрнекті қайтару үшін Value.Expression сигнал береді.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Value.Expression ішінде пайдаланылғанда, егер `value` оңтайландыруға болатын сұрауды көрсетсе, бұл функция оңтайландырылған өрнектің қайтарылуы керектігін көрсетеді. Әйтпесе `value` әсерсіз өткізіледі.

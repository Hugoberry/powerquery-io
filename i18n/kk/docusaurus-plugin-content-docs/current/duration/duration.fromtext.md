# Duration.FromText


Мәтіндік өткен уақыт түрінен (к.у:м:с) ұзақтық мәнін қайтарады.


## Syntax

```powerquery
Duration.FromText(
    text as text
) as duration
```


## Remarks

Көрсетілген мәтіннен ұзақтық мәнін қайтарады, `text`. Бұл функция келесі пішімдерді талдай алады:

-   (-)сс:мм(:сс(.бб))
-   (-)ккк(.сс:мм(:сс(.бб)))

(Барлық ауқым қамтылған)

-   ккк: Күндердің саны.
-   сс: Сағаттардың саны, 0 мен 23 аралығы.
-   аа: Минуттардың саны, 0 мен 59 аралығы.
-   сс: Секундтардың саны, 0 мен 59 аралығы.
-   бб: Секунд бөлігі, 0 мен 9999999 аралығы.


## Examples

### Example #1
`"2.05:55:20"` мәнін `duration` мәніне түрлендіру.
```powerquery
Duration.FromText("2.05:55:20")
```

Result: 
```powerquery
#duration(2, 5, 55, 20)
```

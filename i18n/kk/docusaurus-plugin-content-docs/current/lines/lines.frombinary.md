# Lines.FromBinary


Екілік мәнді жол үзілімдерінде бөлінген мәтіндік мәндер тізіміне түрлендіреді. Егер тырнақша мәнері көрсетілген болса, онда жол үзілімдері тырнақшалар ішінде көрсетілуі мүмкін. Егер includeLineSeparators шын болса, онда мәтінге жол үзілімі таңбалары қосылады.


## Syntax

```powerquery
Lines.FromBinary(
    binary as binary,
    optional quoteStyle as any,
    optional includeLineSeparators as logical,
    optional encoding as TextEncoding.Type
) as list
```


## Remarks

Екілік мәнді жол үзілімдерінде мәтіндік мәндер тізіміне айналдырады.

-   `binary`: тізімге түрлендіру үшін екілік мән.
-   `quoteStyle`: Жол үзілімдерімен не істелгенін көрсетеді. `quoteStyle` мәні `бос мән` болуы мүмкін. Әдепкі мән: `QuoteStyle.None`.
-   `includeLineSeparators`: Мәтінде жол үзілімі таңбаларын қамтуды не қамтымауды көрсетеді. `includeLineSeparators` мәні `бос мән` болуы мүмкін. Әдепкі мән: `false`.
-   `encoding`: Екілік мәннің мәтіндік кодтауын көрсетеді. `encoding` мәні `бос мән` болуы мүмкін. Әдепкі мән: `65001` (UTF-8).

Егер `quoteStyle` (және `includeLineSeparators` және `encoding` `бос мән` болса) үшін жазба көрсетілсе, келесі жазу өрісін беруге болады:

-   `QuoteStyle`: Тырнақшаға алынған жол үзілімдері қалай өңделіп жатқанын көрсетеді.
    -   `QuoteStyle.Csv`: Дәйектелген жол үзілімдері ағымдағы жолдың соңы ретінде емес, деректердің бір бөлігі ретінде қарастырылады.
    -   `QuoteStyle.None`: Барлық жол үзілімдері дәйектелген мән ішінде пайда болса да, ағымдағы жолдың соңы ретінде қарастырылады. Егер `CsvStyle` параметрі көрсетілмесе, бұл мән әдепкі мән болып саналады.
-   `CsvStyle`: Тырнақшалардың қалай өңделетенін нақтылайды. `QuoteStyle.None` көмегімен пайдаланбау керек.
    -   `CsvStyle.QuoteAfterDelimiter` (әдепкі):Өрістегі тырнақшалар тек `Бөлгіштен` кейін келгенде ғана мәнге ие болады.
    -   `CsvStyle.QuoteAlways`:Өрістегі тырнақшалар қай жерде шықса да, әрқашан маңызды болады.
-   `Бөлгіш`: бір таңбалы бөлгіш. Тек `CsvStyle.QuoteAfterDelimiter` көмегімен ғана қолданылуы тиіс.
-   `IncludeLineSeparators`: Мәтінде жол үзілімі таңбаларын қамтуды не қамтымауды көрсетеді. Әдепкі мән: `false`.
-   `Кодтау`: Бинарлық мәнді мәтіндік кодтау. Әдепкі мән: `65001` (UTF-8).

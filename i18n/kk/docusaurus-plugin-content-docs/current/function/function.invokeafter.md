# Function.InvokeAfter


Көрсетілген ұзақтық өткен соң берілген функцияны шақырады.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Ұзақтық `delay` өткен соң `function` шақыру нәтижесін қайтарады.



## Category
Function

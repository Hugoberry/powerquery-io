# Type.ListItem


Тізім түріндегі элемент түрін береді.


## Syntax

```powerquery
Type.ListItem(
    type as type
) as type
```


## Remarks

`type` тізіміндегі элемент түрін береді.


## Examples

### Example #1
Элемент түрін `{number}` тізімінен табыңыз.
```powerquery
Type.ListItem(type {number})
```

Result: 
```powerquery
type number
```

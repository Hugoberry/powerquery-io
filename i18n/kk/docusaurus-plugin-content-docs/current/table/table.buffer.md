# Table.Buffer


Кестені жадқа буферге сақтайды, сөйтіп оны бағалау кезінде сыртқы өзгертулерден оқшаулайды.


## Syntax

```powerquery
Table.Buffer(
    table as table,
    optional options as record
) as table
```


## Remarks

Кестені жадқа буферге сақтайды, сөйтіп оны бағалау кезінде сыртқы өзгертулерден оқшаулайды. Буферге сақтау көлемі аз. Ол кез келген скалярлық ұяшық мәндерін есептеуді мәжбүрлейді, бірақ скалярлық емес мәндерді (жазбалар, тізімдер, кестелер және т.б.) сол күйінде қалдырады.

-   `table`: Жадыда буферге сақтайтын кесте.
-   `options`: (Міндетті емес) Келесі параметрлердің жазба мәндерін пайдалануға болады:
    -   `BufferMode`: орындалатын буферге сақтау түрін сипаттайтын буферге сақтау режимі. Бұл опция `BufferMode.Eager` немесе `BufferMode.Delayed` болуы мүмкін.

Бұл функцияны пайдалану сұрауларыңызды жылдамдатуы немесе жылдамдатпауы мүмкін. Кейбір жағдайларда бұл сұраныстардың баяу жұмыс істеуіне әкелуі мүмкін, себебі барлық деректерді оқу және оларды жадта сақтау шығындары қосылады, сондай-ақ буферлеу кейінгі кезеңдердегі оңтайландыруды болдырмайды. Деректерді буферге сақтау қажет болмаса, тек кейінгі оңтайландыруды тоқтату үшін `Table.StopFolding` пайдаланыңыз.


## Examples

### Example #1
Кез келген алдағы болатын операциялар SQL серверіне сұрау жасай алмайтындай SQL кестесінің барлық жолдарын жадқа жүктеу.
```powerquery
let
    Source = Sql.Database("SomeSQLServer", "MyDb"),
    MyTable = Source{[Item="MyTable"]}[Data],
    BufferMyTable = Table.Buffer(MyTable)
in
    BufferMyTable
```

Result: 
```powerquery
table
```

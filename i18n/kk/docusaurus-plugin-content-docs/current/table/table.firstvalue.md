# Table.FirstValue


Кестенің бірінші жолының бірінші бағанын немесе көрсетілген әдепкі мәнді қайтарады.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

`table` кестесінің бірінші жолының бірінші бағанын немесе көрсетілген әдепкі мәнді қайтарады.

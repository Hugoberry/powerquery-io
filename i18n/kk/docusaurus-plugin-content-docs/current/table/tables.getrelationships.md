# Tables.GetRelationships


Кестелер жиыны арасындағы қатынастарды алады.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Кестелер жиыны арасындағы қатынастарды алады. `tables` жиыны шарлау кестесіндегіге ұқсас құрылымға ие болады деп саналады. `dataColumn` анықтаған бағанда нақты деректер кестелері болады.

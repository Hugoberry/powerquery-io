# Number.BitwiseXor


Екі енгізбе арасында биттік "XOR" (Exclusive-OR) әрекетін орындаудың нәтижесін қайтарады.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` және `number2` арасында биттік "XOR" (Exclusive-OR) әрекетін орындаудың нәтижесін қайтарады.



## Category
Number.Bytes

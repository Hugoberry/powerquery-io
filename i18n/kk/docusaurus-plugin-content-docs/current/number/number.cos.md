# Number.Cos


Санның косинусын қайтарады.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Көрсетілген бұрыштың косинусын қайтарады.

-   `number`: Радианмен өлшенетін бұрыш.


## Examples

### Example #1
0 бұрышының косинусын анықтау.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
π радианның косинусын табу.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

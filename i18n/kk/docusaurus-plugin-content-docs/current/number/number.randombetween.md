# Number.RandomBetween


Екі сан арасындағы кездейсоқ санды қайтарады.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

`bottom` және `top` арасындағы кездейсоқ санды қайтарады.


## Examples

### Example #1
1 және 5 арасындағы кездейсоқ санды алу.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

# Number.Atan2


Екі сан бөліндісінің арктангенсін қайтарады.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Екі санның `y`/`x` тангенсі `y` және `x` сандарының үлесі болатын радианмен берілген бұрышын қайтарады.

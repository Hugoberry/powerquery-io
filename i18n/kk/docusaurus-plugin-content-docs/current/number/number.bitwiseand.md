# Number.BitwiseAnd


Екі енгізбе арасында биттік "And" әрекетін орындаудың нәтижесін қайтарады.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` және `number2` арасында биттік "And" әрекетін орындаудың нәтижесін қайтарады.

Number.Bytes

# Number.Tan


Санның тангенсін қайтарады.


## Syntax

```powerquery
Number.Tan(
    number as number
) as number
```


## Remarks

`number` тангенсін қайтарады.


## Examples

### Example #1
1 бұрышының тангенсін анықтау.
```powerquery
Number.Tan(1)
```

Result: 
```powerquery
1.5574077246549023
```

# Number.Abs


Санның абсолютті мәнін қайтарады.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

`number` абсолюттік мәнін қайтарады. Егер `number` null болса, `Number.Abs` null мәнін қайтарады.

-   `number`: абсолюттік мән есептелетін `number`.


## Examples

### Example #1
\-3 санының абсолютті мәні.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

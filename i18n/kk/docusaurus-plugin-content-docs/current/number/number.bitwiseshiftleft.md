# Number.BitwiseShiftLeft


Биттер жиынын солға жылжытады.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` солға қарай көрсетілген `number2` биттер санына биттік жылжытуды орындаудың нәтижесін қайтарады.



## Category
Number.Bytes

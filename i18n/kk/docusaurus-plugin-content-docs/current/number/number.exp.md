# Number.Exp


e мәнін көрсетілген дәрежеге шығарады.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

e санын `number` дәрежесіне шығарудың нәтижесін қайтарады (экспоненциалдық функция).

-   `number`: экспоненциалдық функция есептелетін `number`. Егер `number` null болса, `Number.Exp` null мәнін қайтарады.


## Examples

### Example #1
e мәнін 3 дәрежесіне шығару.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.Factorial


Санның факториалын қайтарады.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

`number` санының факториалын қайтарады.


## Examples

### Example #1
10 факториалын анықтау.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

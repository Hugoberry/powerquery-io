# Number.BitwiseOr


Екі енгізбе арасында биттік "Or" әрекетін орындаудың нәтижесін қайтарады.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` және `number2` арасында биттік "Or" әрекетін орындаудың нәтижесін қайтарады.

Number.Bytes

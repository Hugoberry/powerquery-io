# Number.Log10


Санның ондық логарифмін қайтарады.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Санның ондық логарифмін қайтарады, `number`. Егер `number` нөл болса, `Number.Log10` нөл мәнін қайтарады.


## Examples

### Example #1
2 санының ондық логарифмін алу.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

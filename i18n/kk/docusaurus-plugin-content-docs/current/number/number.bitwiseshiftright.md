# Number.BitwiseShiftRight


Биттер жиынын оңға жылжытады.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` оң жаққа қарай көрсетілген `number2` биттер санына биттік жылжытуды орындаудың нәтижесін қайтарады.

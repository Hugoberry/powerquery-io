# Number.Ln


Санның натурал логарифмін қайтарады.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

`number` санының натурал логарифмін қайтарады. Егер `number` мәні "null" болса, `Number.Ln` "null" мәнін қайтарады.


## Examples

### Example #1
15 санының натурал логарифмін алу.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

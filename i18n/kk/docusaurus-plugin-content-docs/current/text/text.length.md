# Text.Length


Таңбалар санын қайтарады.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

`text` мәтініндегі таңбалар санын қайтарады.


## Examples

### Example #1
"Сәлем Әлем" мәтініндегі таңбалар санын анықтау.
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

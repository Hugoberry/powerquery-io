# Text.InferNumberType


Мәтінде кодталған сан үшін нақтыланған сан түрін (Int64.Type, Double.Type және т.б.) алады.


## Syntax

```powerquery
Text.InferNumberType(
    text as text,
    optional culture as text
) as type
```


## Remarks

`text` нақтыланған сан түрін (Int64.Type, Double.Type және т.б.) алады. Егер `text` сан болмаса, қате шығарылады. Сонымен қатар міндетті емес `culture` мәні берілуі мүмкін (мысалы, "en-US").

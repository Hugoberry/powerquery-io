# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Берілген `text` кері өзгертеді.


## Examples

### Example #1
"123" мәтінін кері өзгерту.
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

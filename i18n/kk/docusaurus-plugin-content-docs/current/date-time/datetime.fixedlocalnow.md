# DateTime.FixedLocalNow


Жергілікті уақыт белдеуіндегі ағымдағы күнді және уақытты қайтарады. Бұл мән бекітілген және келесі шақыруларда өзгермейді.


## Syntax

```powerquery
DateTime.FixedLocalNow(

) as datetime
```


## Remarks

`datetime` мәндер жиынын жүйедегі ағымдағы күнге және уақытқа қайтарады. Бұл мән бекітілген және келесі шақыруларда өзгертілмейді, өрнекті орындау барысында әр түрлі мәндерді қайтаруы мүмкін DateTime.LocalNow функциясынан басқаша.

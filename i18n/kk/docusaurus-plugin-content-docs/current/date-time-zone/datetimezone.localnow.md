# DateTimeZone.LocalNow


Жергілікті уақыт белдеуіндегі ағымдағы күнді және уақытта қайтарады.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Жүйедегі ағымдағы күнге және уақытқа орнатылған `datetimezone` мәнін қайтарады. Қайтарылған мән жергілікті уақыт белдеуін білдіретін уақыт белдеуі туралы ақпаратты қамтиды.

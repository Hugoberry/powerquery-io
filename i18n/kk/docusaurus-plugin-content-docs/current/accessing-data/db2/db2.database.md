# DB2.Database


Db2 дерекқорында қолжетімді SQL кестелері мен көріністердің кестесін қайтарады.


## Syntax

```powerquery
DB2.Database(
    server as text,
    database as text,
    optional options as record
) as table
```


## Remarks

`server` деп аталатын дерекқор нұсқасында `database` серверіндегі Db2 дерекқорында бар SQL кестелері мен көріністерінің кестесін қайтарады. Портты қос нүктемен бөлу арқылы сервермен бірге қосымша көрсетуге болады. Қосымша жазба параметрі, `options`, келесі параметрлерді басқару үшін көрсетілуі мүмкін:

-   `CreateNavigationProperties` : Логикалық мән (true/false), ол қайтарылатын мәндерде навигация сипаттарын жасау немесе жасамау керектігін көрсетеді (әдепкі мән - true).
-   `NavigationPropertyNameGenerator` : Навигация сипаттарының атауларын жасау үшін пайдаланылатын функция.
-   `Query` : Деректерді шығаруға пайдаланылатын жергілікті SQL сұрауы. Сұрау бірнеше нәтиже жиынтығын шығарса, біріншісі ғана қайтарылады.
-   `CommandTimeout` : Бас тартылғанға дейін серверлік сұраудың қанша уақыт орындалатынын басқаратын ұзақтық. Әдепкі мәні он минут болады.
-   `ConnectionTimeout` : Сервермен байланыс орнату әрекетінен бас тартуға дейінгі күту мерзімін басқаратын ұзақтық. Әдепкі мәні драйверге тәуелді.
-   `HierarchicalNavigation` : Логикалық мән (true/false), ол кестелерді олардың схема атаулары бойынша топтап көру немесе көрмеу керектігін анықтайды (әдепкі мән - false).
-   `Implementation` : Пайдаланылатын ішкі дерекқор провайдері орындалуын көрсетеді. Жарамды мәндер: "IBM" және "Microsoft".
-   `BinaryCodePage` : Db2 FOR BIT екілік деректерін таңбалар жолдарына кодын ашуға арналған CCSID (кодталған таңбалар жиынтығының идентификаторы) саны. Қолданылуы: орындау = “Microsoft”. Түрлендіруді ажырату үшін 0 мәніне орнатыңыз (әдепкі). Дерекқорды кодтау негізінде түрлендіру үшін, 1 мәніне орнатыңыз. Бағдарлама кодтауына түрлендіру үшін басқа CCSID санын орнатыңыз.
-   `PackageCollection` : SQL нұсқауларын өңдеу үшін қажет ортақ жиынтықтарды пайдалануды қосу үшін жиынтықтар жинағы үшін жол мәнін көрсетеді (әдепкі мән - "NULLID"). Қолданылады: орындау = "Microsoft".
-   `UseDb2ConnectGateway` : Қосылымның Db2 жалғау шлюзі арқылы жасалып жатқанын-жатпағанын көрсетеді. Іске асыру = "Microsoft" үшін қолданылады.

Жазба параметрі, мысалы, \[1опция = 1мән, 2опция = 2мән...\] немесе \[Сұрау = "... таңдау"\] ретінде көрсетіледі.

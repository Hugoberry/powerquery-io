# SharePoint.Files


SharePoint сайтындағы құжаттарды қамтитын кестені қайтарады.


## Syntax

```powerquery
SharePoint.Files(
    url as text,
    optional options as record
) as table
```


## Remarks

Көрсетілген `url` SharePoint сайтында және ішкі қалталарда табылған әр құжат үшін жолды қамтитын кестені қайтарады. Әр жол қалтаның немесе файлдың сипаттарын және оның контентіне сілтемені қамтиды. Келесі параметрлерді басқару үшін `options` көрсетілуі мүмкін:

-   `ApiVersion` : Осы сайтқа пайдаланылатын SharePoint API нұсқасын көрсететін (14 немесе 15) саны немесе "Авто" мәтіні. Көрсетілмеген кезде, API нұсқасы 14 пайдаланылады. "Авто" көрсетілген кезде сервер нұсқасы мүмкін болған жағдайда автоматты түрде анықталады, керісінше жағдайда нұсқаның әдепкі мәні 14 болады. Ағылшын тілінде емес SharePoint сайттары үшін кемінде 15-нұсқа қажет.

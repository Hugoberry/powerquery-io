# HdInsight.Containers


Azure қоймасындағы көрсетілген тіркелгіден табылған бөлімді қамтитын шарлау кестесін береді.


## Syntax

```powerquery
HdInsight.Containers(
    account as text
) as table
```


## Remarks

Azure сақтау қоймасынан URL, `account`, тіркелгісінде табылған әр бөлікке арналған жолды қамтитын шарлау кестесін береді. Әр жолда бөліктің блоб файлдарына сілтеме бар.

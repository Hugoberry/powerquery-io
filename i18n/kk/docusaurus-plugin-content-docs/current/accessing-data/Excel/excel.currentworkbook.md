# Excel.CurrentWorkbook


Ағымдағы Excel жұмыс кітабының контентін қайтарады.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Ағымдағы Excel жұмыс кітабының мазмұнын қайтарады. Ол кестелерді, аталған ауқымдарды және динамикалық массивтерді қайтарады. `Excel.Workbook` кодынан айырмашылығы, ол парақтарды қайтармайды.

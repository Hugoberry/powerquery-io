# Cube.CollapseAndRemoveColumns


Көрсетілген бағандармен салыстырылған төлсипаттарды тасалау арқылы текше үшін сүзгі мәтінмәнінің өлшемділік түйіршіктілігін өзгертеді.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

`columnNames` көрсетілген бағандарымен салыстырылған төлсипаттарды тасалау арқылы `cube` үшін сүзгі мәтінмәнінің өлшемділік түйіршіктілігін өзгертеді. Сондай-ақ, бағандар текшенің кестелік көрінісінен жойылады.

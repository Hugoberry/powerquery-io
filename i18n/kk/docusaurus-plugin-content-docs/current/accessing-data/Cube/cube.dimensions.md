# Cube.Dimensions


Қол жетімді өлшемділіктер жиынын қамтитын кестені қайтарады.


## Syntax

```powerquery
Cube.Dimensions(
    cube as table
) as table
```


## Remarks

`cube` ішіндегі қол жетімді өлшемділіктер жиынын қамтитын кестені қайтарады. Әр өлшемділік — өлшемділік төлсипаттарын қамтитын кесте және әр өлшемділік төлсипаты өлшемділік кестесінде баған ретінде көрсетіледі. Өлшемделіктерді текшеде Cube.AddAndExpandDimensionColumn арқылы кеңейтуге болады.

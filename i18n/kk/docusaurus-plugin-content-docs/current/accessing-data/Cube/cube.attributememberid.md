# Cube.AttributeMemberId


Бірегей мүше идентификаторын мүшелер сипаты мәнінен қайтарады.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Бірегей мүше идентификаторын мүше сипаты мәнінен қайтарады. `attribute`. Басқа мәндер үшін нөл мәнін қайтарады.

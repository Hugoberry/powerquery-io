# Cube.Parameters


Текшеге қолдануға болатын параметрлер жиынтығы бар кестені қайтарады.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

`cube` үшін қолдануға болатын параметрлер жиынтығы бар кестені қайтарады. Әрбір параметр қолданылған параметрімен және оның аргументтерімен `cube` алу үшін қолдануға болатын функция болып табылады.

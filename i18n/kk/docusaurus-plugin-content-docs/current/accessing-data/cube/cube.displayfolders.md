# Cube.DisplayFolders


Нысандардың (мысалы, өлшемділіктер және өлшемдер) көрсетілетін қалталар иерархиясын білдіретін кестелердің кірістірілген дарағын қайтарады.


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

`cube` ішінде пайдалануға қолжетімді нысандардың (мысалы, өлшемділіктер және өлшемдер) көрсетілетін қалталар иерархиясын білдіретін кестелердің кірістірілген дарағын қайтарады.

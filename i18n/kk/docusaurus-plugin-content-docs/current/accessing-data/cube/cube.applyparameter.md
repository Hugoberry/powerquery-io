# Cube.ApplyParameter


Параметрді қолданғаннан кейін текшені қайтарады.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

`cube` үшін `arguments` бар `parameter` параметрін қолданғаннан кейін текшені қайтарады.

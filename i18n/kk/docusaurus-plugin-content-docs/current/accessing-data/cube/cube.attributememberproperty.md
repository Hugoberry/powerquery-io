# Cube.AttributeMemberProperty


Өлшем атрибутының сипатын қайтарады.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

`attribute` өлшем атрибутының `propertyName` сипатын қайтарады.

Cube

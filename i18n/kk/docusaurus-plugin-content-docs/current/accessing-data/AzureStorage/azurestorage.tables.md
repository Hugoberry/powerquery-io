# AzureStorage.Tables


Azure қоймасындағы көрсетілген тіркелгідегі кестелерді қамтитын шарлау кестесін қайтарады.


## Syntax

```powerquery
AzureStorage.Tables(
    account as text,
    optional options as record
) as table
```


## Remarks

Azure қоймасынан `account` тіркелгі URL мекенжайы бойынша табылған әр кесте үшін жол бар навигациялық кестені қайтарады. Әрбір жолда Azure кестесіне сілтеме бар. Қосымша сипаттарды көрсету үшін `options` деген міндетті емес жазба параметрін көрсетуге болады. Жазба келесі өрістерді қамтуы мүмкін:

-   `Timeout` : Серверге сұраудан бас тартуға дейінгі күту уақытын басқаратын ұзақтық. Әдепкі мәні деректер көзіне тәуелді.

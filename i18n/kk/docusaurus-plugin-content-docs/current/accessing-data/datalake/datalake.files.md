# DataLake.Files


Azure Data Lake Storage тіркелгісінің URL мекенжайын енгізіңіз.


## Syntax

```powerquery
DataLake.Files(
    url as text,
    optional options as record
) as table
```


## Remarks

Azure Data Lake Storage Gen1 қоймасынан `url` бойынша табылған әрбір файл үшін жол бар кестені қайтарады. Әрбір жолда файлдың сипаттары және оның контентіне сілтеме болады.

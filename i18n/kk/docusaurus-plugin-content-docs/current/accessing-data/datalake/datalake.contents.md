# DataLake.Contents


Azure Data Lake Storage Gen1 тіркелгісінің URL мекенжайын енгізіңіз.


## Syntax

```powerquery
DataLake.Contents(
    url as text,
    optional options as record
) as table
```


## Remarks

Azure Data Lake Storage Gen1 қоймасынан `url` бойынша табылған әрбір қалта мен файл үшін жол бар кестені қайтарады. Әрбір жолда қалтаның немесе файлдың сипаттары және оның контентіне сілтеме болады.

# Vertica.Database


Деректерді Vertica жүйесінен импорттау


## Syntax

```powerquery
Vertica.Database(
    server as text,
    database as text,
    optional options as record
) as table
```


## Remarks

`Database` параметрі арқылы көрсетілген дерекқордағы `server` параметрі арқылы көрсетілген серверде қолжетімді схемалар кестесін қайтарады. Қосымша сипаттарды көрсету үшін `options` қосымша жазба параметрі берілуі мүмкін. Жазбада келесі өрістер болуы мүмкін:

-   `ConnectionTimeout`: Серверге қосылу әрекетін тоқтатуға дейінгі күту уақытын басқаратын ұзақтық. Әдепкі мәні драйверге тәуелді болады.
-   `CommandTimeout` : Сервер жақтағы сұраудың бас тартқанша қанша уақыт орындалатынын басқаратын ұзақтық. Әдепкі мәні драйверге тәуелді болады.

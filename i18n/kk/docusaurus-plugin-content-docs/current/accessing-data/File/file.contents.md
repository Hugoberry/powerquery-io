# File.Contents


Көрсетілген файлдың мазмұнын екілік түрде қайтарады.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

`path` файлының мазмұнын бинарлық мән ретінде қайтарады. `options` параметрі тек ішкі қолданысқа арналған.

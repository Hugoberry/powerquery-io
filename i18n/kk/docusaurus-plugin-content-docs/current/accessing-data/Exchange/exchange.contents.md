# Exchange.Contents


Microsoft Exchange тіркелгісінен мазмұн кестесін қайтарады.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

`mailboxAddress` Microsoft Exchange тіркелгісінен мазмұнды қайтарады. Егер `mailboxAddress` көрсетілмесе, тіркелгі деректері үшін әдепкі тіркелгі пайдаланылады.

# HdInsight.Files


Azure қоймасындағы көрсетілген бөліктен табылған блоб файлдарының сипаттары мен мазмұндарын қамтитын кестені береді.


## Syntax

```powerquery
HdInsight.Files(
    account as text,
    containerName as text
) as table
```


## Remarks

Azure қоймасындағы URL мекенжайынан, `account`, табылған әр блоб файлының жолын қамтитын кестені береді. Әр жолда файлдың сипаттары мен олардың мазмұнына сілтеме бар.

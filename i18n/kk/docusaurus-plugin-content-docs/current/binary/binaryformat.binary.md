# BinaryFormat.Binary


Екілік мәнді оқитын екілік пішімді қайтарады.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Екілік мәнді оқитын екілік пішімді қайтарады. Егер `length` көрсетілген болса, екілік мән сонша байтты қамтиды. Егер `length` көрсетілмеген болса, екілік мән қалған байттарды қамтиды. `length` сан ретінде немесе екілік деректердің алдында келетін ұзындықтағы екілік пішім ретінде көрсетуге болады.

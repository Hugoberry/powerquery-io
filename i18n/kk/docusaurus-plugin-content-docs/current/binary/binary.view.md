# Binary.View


Сұрау және әрекет операциялары үшін пайдаланушы анықтаған өңдегіштер арқылы екілік мәнді жасайды немесе кеңейтеді.


## Syntax

```powerquery
Binary.View(
    binary as binary,
    handlers as record
) as binary
```


## Remarks

Көрініске операция қолданылғанда `handlers` ішінде көрсетілген функциялар операцияның әдепкі әрекетінің орнына пайдаланылатын `binary` көрінісін қайтарады.

`binary` көрсетілген болса, барлық өңдегіш функциялар міндетті емес болып табылады. `binary` көрсетілмеген болса, `GetStream` өңдегіш функция қажет. Операция үшін өңдегіш функция көрсетілмеген болса, оның орнына `binary` дегенге операцияның әдепкі әрекеті қолданылады (`GetExpression` жағдайын қоспағанда).

Өңдегіш функциялар `binary` қатысты операцияны қолдану нәтижесіне (немесе `GetExpression` жағдайында нәтижесіндегі көрініске) семантикалық түрде баламалы.

Өңдегіш функция қате тудырса, көрініске операцияның әдепкі әрекеті қолданылады.

`Binary.View` дегенді деректер көзін қысқартуды (M сұрауларының көз операцияларына өтуі, мысалы, файл бөлімін жүктеп алу үшін) жүзеге асыру үшін пайдалануға болады.

`Binary.View` толығырақ сипаттамасын жарияланған Power Query теңшелетін қосқыш құжаттамасынан қараңыз.


## Examples

### Example #1
Ұзындықты анықтау үшін деректерге қатынасуды қажет етпейтін негізгі көріністі жасайды.
```powerquery
Binary.View(
    null,
    [
        GetLength = () => 12,
        GetStream = () => Text.ToBinary("hello world!")
    ]
)
```

Result: 
```powerquery
Text.ToBinary("hello world!")
```

# Binary.Split


Көрсетілген бет өлшемін пайдаланып, көрсетілген екілік файлдарды екілік файлдар тізіміне бөледі.


## Syntax

```powerquery
Binary.Split(
    binary as binary,
    pageSize as number
) as list
```


## Remarks

`binary` жазбаларын екілік файлдар тізіміне бөледі, онда шығыс тізімнің бірінші элементі – бастапқы екілік файлдан алынған алғашқы `pageSize` байттан тұратын екілік файл. Шығыс тізімнің келесі элементі – бастапқы екілік файлдан алынған келесі `pageSize` байттан тұратын екілік файл. Солай жалғаса береді.

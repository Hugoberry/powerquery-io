# Binary.ViewError


Көріністе (екілік көрініс арқылы) анықталған өңдегіш берген кезде резервтік функцияны іске қоспайтын өзгертілген қате жазбасын жасайды.


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

`errorRecord` дегеннен көріністе (екілік көрініс арқылы) анықталған өңдегіш берген кезде резервтік функцияны іске қоспайтын өзгертілген қате жазбасын жасайды.

# BinaryFormat.ByteOrder


Функция арқылы көрсетілген байттар реті бар екілік пішімді қайтарады.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

`binaryFormat` арқылы көрсетілген байттар реті бар екілік пішімді қайтарады. Әдепкі байттар реті — `ByteOrder.BigEndian`.

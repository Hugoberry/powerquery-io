# Opdag sproget
Power Query M-formelsproget er optimeret til at bygge meget fleksible forespørgsler til datasammensætning. Det er et funktionelt sprog, der skelner mellem store og små bogstaver, og som minder om F#. Power Query-formelsproget bruges i en række Microsoft-produkter såsom Power BI Desktop, Excel og Analysis Services.

Denne side fungerer som en reference for Power Query-funktioner og giver hurtig og direkte adgang til detaljerede oplysninger og praktiske eksempler for hver funktion.
:::note
Bemærk venligst, at forfatteren ikke gør krav på nogen ophavsret til de materialer, der præsenteres på denne side. Oplysningerne er indsamlet og stillet til rådighed i håbet om, at de vil være nyttige for dem, der ønsker at udvide deres viden om og anvendelse af Power Query.
:::

Søgefunktionaliteten på denne hjemmeside skulle forenkle processen med at opdage det brede udvalg af Power Query-funktioner. Sørg for at prøve den (Ctrl+K).

![Søgefunktionalitet leveret af Algolia](/img/search.png)

For dem, der er interesserede i dybere udforskning eller implementeringsdetaljer, kan yderligere oplysninger findes i følgende GitHub-repository: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Dette repository kan indeholde yderligere eksempler, opdateringer og ressourcer, der er relevante for udvikling og brug af Power Query.

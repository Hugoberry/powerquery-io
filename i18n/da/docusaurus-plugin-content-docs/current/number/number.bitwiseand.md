# Number.BitwiseAnd


Returnerer resultatet af at udføre en bitvis "And"-handling mellem de to input.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerer resultatet af at udføre en bitvis "And"-handling mellem `number1` og `number2`.



## Category
Number.Bytes

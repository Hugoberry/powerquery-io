# Number.BitwiseOr


Returnerer resultatet af at udføre en bitvis "Or"-handling mellem de to input.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerer resultatet af at udføre en bitvis "Or"-handling mellem `number1` og `number2`.



## Category
Number.Bytes

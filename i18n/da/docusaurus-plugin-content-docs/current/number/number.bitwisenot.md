# Number.BitwiseNot


Returnerer en byte, hvor de enkelte bit er det modsatte af inputtet.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Returnerer resultatet af at udføre en bitvis "Not"-handling for `number`.



## Category
Number.Bytes

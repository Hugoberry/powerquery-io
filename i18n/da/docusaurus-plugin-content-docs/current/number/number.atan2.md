# Number.Atan2


Returnerer arcus tangens til divisionen af de to tal.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Returnerer vinklen i radianer, hvis tangens er kvotienten `y`/`x` af de to tal `y` og `x`.

Number.Trigonometry

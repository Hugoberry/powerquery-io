# Number.Log10


Returnerer logaritmen med grundtallet 10 for tallet.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Returnerer logaritmen med grundtallet 10 for et tal, `number`. Hvis `number` er null, returnerer `Number.Log10` null.


## Examples

### Example #1
Hent logaritmen med grundtallet 10 for 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

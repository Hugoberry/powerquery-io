# Number.BitwiseXor


Returnerer resultatet af at udføre en bitvis "XOR" (Exclusive-OR) mellem de to input.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerer resultatet af at udføre en bitvis "XOR" (Exclusive-OR) mellem `number1` og `number2`.

Number.Bytes

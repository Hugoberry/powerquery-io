# Number.BitwiseShiftLeft


Skifter bitsættet til venstre.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerer resultatet af at udføre et bitvis skift til venstre på `number1` med det angivne antal bit `number2`.

Number.Bytes

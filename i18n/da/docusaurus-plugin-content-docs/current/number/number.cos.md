# Number.Cos


Returnerer cosinus til tallet.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Returnerer cosinus til den angivne vinkel.

-   `number`: En vinkel, der måles i radianer.


## Examples

### Example #1
Find cosinus af vinklen 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Find cosinus for π radianer.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

# Number.BitwiseShiftRight


Skifter bitsættet til højre.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerer resultatet af at udføre et bitvis skift til højre på `number1` med det angivne antal bit `number2`.

Number.Bytes

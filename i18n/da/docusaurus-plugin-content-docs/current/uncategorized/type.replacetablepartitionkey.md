# Type.ReplaceTablePartitionKey


Returnerer en ny tabeltype, hvor partitionsnøglen er erstattet af den angivne partitionsnøgle.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Returnerer en ny tabeltype, hvor partitionsnøglen er erstattet af den angivne partitionsnøgle.

# Variable.Value


Returnerer værdien af den angivne variabel.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Returnerer værdien af den angivne variabel `identifier` defineret af det aktuelle evalueringsmiljø. Hvis variablen ikke er defineret, udløses der en fejl.

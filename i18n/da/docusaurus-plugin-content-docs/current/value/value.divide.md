# Value.Divide


Returnerer resultatet af at dividere første værdi med den anden.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Returnerer resultatet af at dividere `value1` med `value2`. Der kan angives en valgfri parameter, `precision`. `Precision.Double` bruges som standard.

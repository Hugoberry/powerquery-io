# Value.Equals


Returnerer, om de to værdier er ens.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Returnerer true, hvis værdien `value1` er lig med værdien `value2`. Ellers returneres false.

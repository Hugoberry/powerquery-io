# Value.Multiply


Returnerer produktet af de to værdier.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Returnerer produktet af multiplicering af `value1` med `value2`. Der kan angives en valgfri parameter, `precision`. `Precision.Double` bruges som standard.

# Text.Length


Returnerer antallet af tegn.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Returnerer antallet af tegn i strengen `text`.


## Examples

### Example #1
Find ud af, hvor mange tegn der er i teksten "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

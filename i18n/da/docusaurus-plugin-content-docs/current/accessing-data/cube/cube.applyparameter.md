# Cube.ApplyParameter


Returnerer en kube efter at have anvendt en parameter for den.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Returnerer en kube efter at have anvendt `parameter` med `arguments` for `cube`.

# Cube.Parameters


Returnerer en tabel, der indeholder det sæt parametre, der kan anvendes til kuben.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Returnerer en tabel, der indeholder det sæt parametre, der kan anvendes til `cube`. Hver parameter er en funktion, der kan kaldes for at anvende `cube` med parameteren og dens argumenter.

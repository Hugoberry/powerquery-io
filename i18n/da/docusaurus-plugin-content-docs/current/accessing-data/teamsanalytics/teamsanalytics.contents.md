# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Teams Analytics-forbindelseskomponenten gør det muligt for dig at få indsigt i din brug af Teams. Der er tilgængelige data til både din personlige aktivitet i Teams og aktiviteten i Teams, som du er medlem af.

Data er tilgængelige for de sidste 90 dage.

Oplysninger om de tilgængelige typer data finder du i følgende hjælp-dokumentation:

-   **Teams-brug:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Teams-brugeraktivitet:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

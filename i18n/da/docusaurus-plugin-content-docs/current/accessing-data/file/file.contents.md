# File.Contents


Returnerer indholdet af den angivne fil som binært.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Returnerer indholdet af filen, `path`, som binært. Parameteren `options` er i øjeblikket kun beregnet til intern brug.

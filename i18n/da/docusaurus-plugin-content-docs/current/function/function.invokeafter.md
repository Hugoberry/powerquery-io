# Function.InvokeAfter


Starter den givne funktion, når den angivne varighed overskrides.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Returnerer resultatet af start af `function`, når varigheden `delay` overskrides.



## Category
Function

# BinaryFormat.Binary


Returnerer et binært format, der læser en binær værdi.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Returnerer et binært format, der læser en binær værdi. Hvis `length` er angivet, indeholder den binære værdi dette antal byte. Hvis `length` ikke er angivet, indeholder den binære værdi de resterende byte. `length` kan angives som enten et tal eller som et binært format af den længde, der står foran de binære data.

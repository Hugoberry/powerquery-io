# Uri.Combine


Returnerer en absolut URI, der er en kombination af udgangs-URI'en for input og den relative URI.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Returnerer en absolut URI, der er en kombination af `baseUri` for input og `relativeUri`.

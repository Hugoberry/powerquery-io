# Uri.Combine


Retourneert een absolute URI die de combinatie is van de basis-URI van de invoer en een relatieve URI.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Retourneert een absolute URI die de combinatie is van de `baseUri` van de invoer en een `relativeUri`.

# Table.ViewError


Hiermee maakt u een gewijzigde foutrecord die geen terugval activeert wanneer deze wordt gegenereerd door een beheerder die is gedefinieerd in een weergave (via Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Hiermee maakt u een gewijzigde foutrecord vanuit `errorRecord` waaruit geen terugval wordt geactiveerd wanneer deze wordt gegenereerd door een beheerder die is gedefinieerd in een weergave (via Table.View).

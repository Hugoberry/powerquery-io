# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Met de Teams Analytics-connector kunt u inzicht krijgen in uw gebruik van Teams. Gegevens zijn beschikbaar voor zowel uw persoonlijke activiteiten in Teams als de activiteit in Teams waarvan u lid bent.

Gegevens zijn beschikbaar van de voorgaande 90 dagen.

Raadpleeg voor meer informatie over de beschikbare gegevenstypen de volgende Help-documentatie:

-   **Teams-gebruik** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Teams-gebruikersactiviteit:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

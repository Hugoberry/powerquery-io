# Cube.ApplyParameter


Retourneert een kubus nadat er een parameter op is toegepast.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Retourneert een kubus nadat `parameter` met `arguments` op `cube` is toegepast.

Cube

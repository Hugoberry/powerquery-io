# Cube.MeasureProperty


Hiermee wordt een eigenschap van een meetwaarde (celeigenschap) geretourneerd.


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Hiermee wordt de eigenschap `propertyName` van de meetwaarde `measure` geretourneerd.



## Category
Cube

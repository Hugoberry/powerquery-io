# Github.Tables


Voer de naam van de GitHub-opslagplaats en de naam van de opslagplaats in.


## Syntax

```powerquery
Github.Tables(
    RepositoryOwner as text,
    Repository as text
) as table
```


## Remarks

Hiermee wordt een tabel met de relevante GitHub-gegevens geretourneerd.

# Type.ReplaceFacets


Hiermee worden de facetten van een type vervangen.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Hiermee worden de facetten van `type` vervangen door de facetten in de record `facets`.

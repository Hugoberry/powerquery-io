# Type.TableSchema


Hiermee wordt een tabel geretourneerd met een beschrijving van de kolommen (oftewel het schema) van de opgegeven tabeltype.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Hiermee wordt een tabel geretourneerd die de kolommen van `tableType` beschrijft.

Raadpleeg de documentatie voor`Table.Schema` voor een beschrijving van de tabel die wordt gemaakt.

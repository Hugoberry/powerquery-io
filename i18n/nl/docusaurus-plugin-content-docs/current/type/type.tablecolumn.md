# Type.TableColumn


Retourneert het type van een kolom in een tabel.


## Syntax

```powerquery
Type.TableColumn(
    tableType as type,
    column as text
) as type
```


## Remarks

Retourneert het type van de kolom `column` in het tabeltype `tableType`.

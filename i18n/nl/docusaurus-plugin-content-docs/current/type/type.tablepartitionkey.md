# Type.TablePartitionKey


Retourneert de partitiesleutel voor het opgegeven tabeltype als deze er een heeft.


## Syntax

```powerquery
Type.TablePartitionKey(
    tableType as type
) as list
```


## Remarks

Retourneert de partitiesleutel voor het opgegeven tabeltype als deze er een heeft.

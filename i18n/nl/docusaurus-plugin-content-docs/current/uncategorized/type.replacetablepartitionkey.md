# Type.ReplaceTablePartitionKey


Retourneert een nieuw tabeltype waarbij de partitiesleutel wordt vervangen door de opgegeven partitiesleutel.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Retourneert een nieuw tabeltype waarbij de partitiesleutel wordt vervangen door de opgegeven partitiesleutel.

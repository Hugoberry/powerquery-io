# Number.Log10


Hiermee retourneert u de logaritme met grondtal 10 van het getal.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Hiermee retourneert u de logaritme met grondtal 10 van een getal `number`. Als `number` null is, wordt met `Number.Log10` null geretourneerd.


## Examples

### Example #1
De logaritme met grondtal 10 van 2 ophalen.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

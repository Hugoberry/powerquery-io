# Number.BitwiseShiftRight


Verschuift de bitset naar rechts.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retourneert het resultaat van een bitwise-verschuiving naar rechts op `number1` conform het aantal opgegeven bits `number2`.

Number.Bytes

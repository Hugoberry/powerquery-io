# Number.Atan2


Retourneert de arctangens van de deling van de twee getallen.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Retourneert de hoek, in radialen, waarvan de tangens het quotiënt `y`/`x` van de twee getallen `y` is en `x`.

Number.Trigonometry

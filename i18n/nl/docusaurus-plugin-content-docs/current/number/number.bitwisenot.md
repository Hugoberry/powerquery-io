# Number.BitwiseNot


Retourneert een byte waar elke bit het tegenovergestelde van de invoer is.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Retourneert het resultaat van de uitvoering van een bitwise "Not"-bewerking op `number`.



## Category
Number.Bytes

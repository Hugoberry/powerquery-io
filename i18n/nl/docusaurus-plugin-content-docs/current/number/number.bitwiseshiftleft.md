# Number.BitwiseShiftLeft


Verschuift de bitset naar links.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retourneert het resultaat van een bitwise-verschuiving naar links op `number1` conform het aantal opgegeven bits `number2`.

Number.Bytes

# Ontdek de taal
De Power Query M-formuletaal is geoptimaliseerd voor het bouwen van zeer flexibele query's voor het samenvoegen van gegevens. Het is een functionele, hoofdlettergevoelige taal die lijkt op F#. De Power Query-formuletaal wordt gebruikt in een aantal Microsoft-producten zoals Power BI Desktop, Excel en Analysis Services.

Deze site dient als naslagwerk voor Power Query-functies en biedt snelle en directe toegang tot gedetailleerde informatie en praktische voorbeelden voor elke functie.
:::note
Houd er rekening mee dat de auteur geen enkel auteursrecht claimt op het materiaal dat op deze site wordt gepresenteerd. De informatie is verzameld en beschikbaar gesteld in de hoop dat het nuttig zal zijn voor diegenen die hun kennis en toepassing van Power Query willen uitbreiden.
:::

De zoekfunctionaliteit op deze website zou het ontdekkingsproces van het brede scala aan Power Query-functies moeten vereenvoudigen. Probeer het zeker uit (Ctrl+K).

![Zoekfunctionaliteit geleverd door Algolia](/img/search.png)

Voor degenen die geïnteresseerd zijn in diepere verkenning of implementatiedetails, is meer informatie te vinden in de volgende GitHub-repository: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Deze repository kan aanvullende voorbeelden, updates en bronnen bevatten die relevant zijn voor de ontwikkeling en het gebruik van Power Query.

# Text.Length


Retourneert het aantal tekens.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Retourneert het aantal tekens uit de tekst `text`.


## Examples

### Example #1
Uitzoeken uit hoeveel tekens de tekst "Hallo wereld" bestaat.
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Hiermee wordt de opgegeven `text` omgekeerd.


## Examples

### Example #1
Hiermee wordt de tekst '123' omgekeerd.
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

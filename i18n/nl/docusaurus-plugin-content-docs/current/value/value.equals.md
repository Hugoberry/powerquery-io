# Value.Equals


Retourneert of twee waarden gelijk zijn.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Retourneert 'true' wanneer de waarde `value1` gelijk is aan de waarde `value2` en 'false' als dit niet het geval is.

Values

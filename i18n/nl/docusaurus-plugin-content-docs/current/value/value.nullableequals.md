# Value.NullableEquals


Retourneert of twee waarden gelijk zijn.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Retourneert null als een van de argumenten `value1` of `value2` null is, anders gelijk aan Value.Equals.



## Category
Values

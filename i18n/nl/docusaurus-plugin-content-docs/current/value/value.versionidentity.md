# Value.VersionIdentity


Retourneert de versie-identiteit van de waarde.


## Syntax

```powerquery
Value.VersionIdentity(
    value as any
) as any
```


## Remarks

Retourneert de versie-identiteit van de `value`, of `null` als er geen versie is.

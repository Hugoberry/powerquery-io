# Number.Atan2


दो संख्याओं के विभाजन का आर्कटेंजेंट लौटाता है.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

यह रेडियन में वह कोण लौटाता है, जिसका टैनजेंट दो संख्याओं `y` और `x` का भागफल `y`/`x` होता है.

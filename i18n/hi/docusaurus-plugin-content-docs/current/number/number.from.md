# Number.From


दिए गए मान से एक संख्या बनाता है.


## Syntax

```powerquery
Number.From(
    value as any,
    optional culture as text
) as number
```


## Remarks

दिए गए `value` से एक `संख्या` मान वापस करता है.एक वैकल्पिक `culture` भी प्रदान किया जा सकता है (उदाहरण के लिए, "en-US"). यदि दिया गया `value` `नल` है, तो `Number.From` `नल` वापस करता है. यदि दिया गया `value` `संख्या` है, तो `value` लौटाया जाता है. निम्न प्रकार के मानों को एक `संख्या` मान में रूपांतरित किया जा सकता है:

-   `पाठ`: पाठ प्रस्तुतिकरण से एक `संख्या` मान. सामान्य पाठ फ़ॉर्मेंट संभाले जाते हैं ("15", "3,423.10", "5.0E-10"). विवरण के लिए `Number.FromText` देखें.
-   `तार्किक`: `सत्य` के लिए 1, `गलत` के लिए 0.
-   `तिथिसमय`: एक दोहरी-परिशुद्धता फ़्लोटिंग पॉइंट संख्या जिसमें समतुल्य OLE स्वचालन तिथि शामिल होती है.
-   `datetimezone`: एक दोहरी-परिशुद्धता फ़्लोटिंग पॉइंट संख्या जिसमें `value` के स्थानीय तिथि और समय के समतुल्य OLE स्वचालन तिथि शामिल होती है.
-   `तिथि`: एक दोहरी-परिशुद्धता फ़्लोटिंग पॉइंट संख्या जिसमें समतुल्य OLE स्वचालन तिथि शामिल होती है.
-   `समय`: आंशिक दिनों में व्यक्त.
-   `अवधि`: पूर्णांक और आंशिक दिनों में व्यक्त.

/यदि `value` किसी भी अन्य प्रकार का है, तो एक त्रुटि लौटाई जाती है.


## Examples

### Example #1
`"4"` का `number` मान प्राप्त करें.
```powerquery
Number.From("4")
```

Result: 
```powerquery
4
```


### Example #2
`#datetime(2020, 3, 20, 6, 0, 0)` का `number` मान प्राप्त करें.
```powerquery
Number.From(#datetime(2020, 3, 20, 6, 0, 0))
```

Result: 
```powerquery
43910.25
```


### Example #3
`"12.3%"` का मान `संख्या` प्राप्त करें.
```powerquery
Number.From("12.3%")
```

Result: 
```powerquery
0.123
```

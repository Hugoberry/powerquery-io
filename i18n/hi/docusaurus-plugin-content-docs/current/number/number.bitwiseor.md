# Number.BitwiseOr


दो इनपुट के बीच बिटवाइज़ "Or" के निष्पादन का परिणाम लौटाता है.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` और `number2` के बीच बिटवाइज़ "Or" के निष्पादन का परिणाम लौटाता है.

# Number.BitwiseShiftLeft


बिट सेट को बाएँ शिफ़्ट करता है.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

बिट `number2` की संख्या निर्दिष्ट करके, `number1` पर बिटवाइज़ बाएँ शिफ़्ट करें के निष्पादन का परिणाम लौटाता है.

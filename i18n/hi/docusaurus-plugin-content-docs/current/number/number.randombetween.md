# Number.RandomBetween


दो संख्याओं के बीच की यादृच्छिक संख्या लौटाता है.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

`bottom` और `top` के बीच की यादृच्छिक संख्या लौटाता है.


## Examples

### Example #1
1 और 5 के बीच की यादृच्छिक संख्या प्राप्त करें.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

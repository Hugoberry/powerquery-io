# Number.BitwiseShiftRight


बिट सेट को दाएँ शिफ़्ट करता है.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

बिट `number2` की संख्या निर्दिष्ट करके, `number1` पर बिटवाइज़ दाएँ शिफ़्ट करें के निष्पादन का परिणाम लौटाता है.

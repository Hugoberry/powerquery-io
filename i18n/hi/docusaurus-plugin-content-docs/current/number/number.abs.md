# Number.Abs


संख्या का निरपेक्ष मान लौटाता है.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

`number` का निरपेक्ष मान लौटाता है. यदि `number` नल है, तो `Number.Abs` नल लौटाता है.

-   `number`: एक ऐसी `संख्या` जिसके लिए निरपेक्ष मान का परिकलन किया जाना है.


## Examples

### Example #1
\-3 का निरपेक्ष मान.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

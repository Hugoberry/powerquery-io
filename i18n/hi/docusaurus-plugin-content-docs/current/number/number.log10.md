# Number.Log10


संख्या का आधार-10 लघुगणक लौटाता है.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

संख्या, `number` का आधार-10 लघुगणक लौटाता है. अगर `number` नल है, तो `Number.Log10` नल लौटाता है.


## Examples

### Example #1
2 का आधार-10 लघुगणक प्राप्त करें.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

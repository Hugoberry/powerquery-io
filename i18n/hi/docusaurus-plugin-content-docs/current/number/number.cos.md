# Number.Cos


संख्या का कोसिन लौटाता है.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

निर्दिष्ट कोण का कोसाइन लौटाता है.

-   `number`: एक कोण, जिसे रेडियन में मापा जाता है.


## Examples

### Example #1
0 कोण का कोसिन प्राप्त करें.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
π रेडियन का कोसाइन ज्ञात कीजिए.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

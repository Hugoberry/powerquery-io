# Number.BitwiseAnd


दो इनपुट के बीच बिटवाइज़ "And" कार्रवाई के निष्पादन का परिणाम लौटाता है.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1` और `number2` के बीच बिटवाइज़ "And" कार्रवाई के निष्पादन का परिणाम लौटाता है.

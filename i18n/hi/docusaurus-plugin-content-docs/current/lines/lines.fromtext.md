# Lines.FromText


एक पाठ मान को पंक्ति विराम पर विभाजित होने वाली पाठ मानों की सूची में रूपांतरित करता है. यदि includeLineSeparators true है, तो फिर पंक्ति विराम वर्णों को पाठ में शामिल किया जाता है.


## Syntax

```powerquery
Lines.FromText(
    text as text,
    optional quoteStyle as any,
    optional includeLineSeparators as logical
) as list
```


## Remarks

किसी पाठ मान को पंक्ति विरामों पर विभाजित पाठ मानों की एक सूची में रूपांतरित करता है.

-   `text`: पाठ मानों की एक सूची में रूपांतरित करने के लिए पाठ मान.
-   `quoteStyle`: पंक्ति विरामों को कैसे हैंडल करें यह निर्दिष्ट करता है. `quoteStyle` का मान `null` हो सकता है. डिफ़ॉल्ट मान `QuoteStyle.None` है.
-   `includeLineSeparators`: यह निर्दिष्ट करता है कि क्या पाठ में पंक्ति विराम वर्णों को शामिल किया जाए. `includeLineSeparators` का मान `null` हो सकता है. डिफ़ॉल्ट मान `FALSE` है.

यदि `quoteStyle` के लिए कोई रेकॉर्ड निर्दिष्ट किया गया हो (और `includeLineSeparators` `null`हो), तो निम्न रेकॉर्ड फील्ड्स प्रदान किए जा सकते हैं:

-   `QuoteStyle`: कोट किए गए पंक्ति विराम कैसे हैंडल किए जाते हैं, यह निर्दिष्ट करता है.
    -   `QuoteStyle.Csv`: कोट किए गए पंक्ति विरामों को डेटा के भाग के रूप में माना जाता है, वर्तमान पंक्ति के अंत के रूप में नहीं.
    -   `QuoteStyle.None`: सभी पंक्ति विरामों को वर्तमान पंक्ति का अंत माना जाता है, भले ही वे किसी कोट किए गए मान के अंदर आते हों. यदि `CsvStyle` विकल्प निर्दिष्ट न किया गया हो, तो यही मान डिफ़ॉल्ट है.
-   `CsvStyle`: कोट कैसे हैंडल किए जाते हैं, यह निर्दिष्ट करता है. `QuoteStyle.None` के साथ उपयोग नहीं किया जाना चाहिए.
    -   `CsvStyle.QuoteAfterDelimiter`: किसी फ़ील्ड में कोट केवल तभी महत्वपूर्ण होते हैं जब वे `Delimiter` के ठीक बाद में हों.
    -   `CsvStyle.QuoteAlways`: किसी फ़ील्ड में कोट हमेशा महत्वपूर्ण होते हैं, चाहे वे कहीं भी दिखाई दें.
-   `Delimiter`: कोई एकल वर्ण का डिलिमिटर. केवल `CsvStyle.QuoteAfterDelimiter` के साथ उपयोग किया जाना चाहिए.
-   `IncludeLineSeparators`: यह निर्दिष्ट करता है कि क्या पाठ में पंक्ति विराम वर्णों को शामिल किया जाए. डिफ़ॉल्ट मान `FALSE` है.

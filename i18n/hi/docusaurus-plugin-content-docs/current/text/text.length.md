# Text.Length


वर्णों की संख्‍या लौटाता है.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

पाठ `text` के वर्णों की संख्या लौटाता है.


## Examples

### Example #1
खोजें कि पाठ "Hello World" में कितने वर्ण हैं.
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

# List.LastN


निर्दिष्ट सूची के अंतिम आइटम या आइटम्स की सूची लौटाता है. वैकल्पिक रूप से यह निर्दिष्ट किया जा सकता है कि कितने मान लौटाए जाएँ या कोई पात्रता शर्त हो.


## Syntax

```powerquery
List.LastN(
    list as list,
    optional countOrCondition as any
) as any
```


## Remarks

निर्दिष्ट सूची का अंतिम आइटम या आइटम्स की सूची लौटाता है.

-   `list`: जांची जाने वाली सूची. अगर सूची खाली है, तो एक खाली सूची लौटाई जाती है.
-   `countOrCondition`: (वैकल्पिक) कई आइटम्स एकत्र करने या आइटम्स फ़िल्टर करने का समर्थन करता है. हालांकि यह पैरामीटर वैकल्पिक के रूप में सूचीबद्ध है, लेकिन अगर यह मान प्रदान नहीं किया गया है या यह `null` है, तो एक त्रुटि होती है. यह पैरामीटर दो तरीकों से निर्दिष्ट किया जा सकता है:
    -   अगर कोई संख्या निर्दिष्ट की जाती है, तो उतनी ही संख्या तक आइटम लौटाए जाते हैं.
    -   अगर कोई शर्त निर्दिष्ट की जाती है, तो सूची के अंत से शुरू करते हुए, शर्त को पूरा करने वाले सभी आइटम लौटा दिए जाते हैं. एक बार जब कोई आइटम शर्त पूरी करने में विफल हो जाता है, तो और किसी आइटम पर विचार नहीं किया जाता.


## Examples

### Example #1
सूची \{3, 4, 5, -1, 7, 8, 2\} का अंतिम मान प्राप्त करें.
```powerquery
List.LastN({3, 4, 5, -1, 7, 8, 2}, 1)
```

Result: 
```powerquery
{2}
```


### Example #2
सूची \{3, 4, 5, -1, 7, 8, 2\} के वे अंतिम मान प्राप्त करें जो 0 से बड़े हैं.
```powerquery
List.LastN({3, 4, 5, -1, 7, 8, 2}, each _ > 0)
```

Result: 
```powerquery
{7, 8, 2}
```

# List.MinN


सूची के न्यूनतम मान लौटाता है. लौटाए जाने वाले मानों की संख्या या फ़िल्टर करने की शर्त को निर्दिष्ट किया जा सकता है.


## Syntax

```powerquery
List.MinN(
    list as list,
    countOrCondition as any,
    optional comparisonCriteria as any,
    optional includeNulls as logical
) as list
```


## Remarks

सूची के न्यूनतम मान(मानों) को लौटाता है.`list`. पैरामीटर `countOrCondition` लौटाए जाने वाले मानों की संख्या या फ़िल्टर करने की शर्त निर्दिष्ट करता है. वैकल्पिक पैरामीटर `comparisonCriteria` निर्दिष्ट करता है कि सूची के मानों की तुलना कैसे करनी है.

-   `list`: मानों की सूची.
-   `countOrCondition`: अगर कोई संख्या निर्दिष्ट की गई है, तो अ से ज्ञ में `countOrCondition` आइटम तक की सूची लौटाई जाती है. अगर कोई शर्त निर्दिष्ट हो, तो प्रारंभिक रूप से शर्त को पूरा करने वाले आइटम्स की सूची को लौटाया जाता है. एक बार आइटम द्वारा शर्त को पूरा न करने पर, आगे किसी भी आइटम पर विचार नहीं किया जाता है. अगर यह पैरामीटर नल है, तो सूची का एकल सबसे छोटा मान लौटाया जाता है.
-   `comparisonCriteria`: *(वैकल्पिक)* सूची के आइटम की तुलना करने का तरीका निर्धारित करने के लिए एक वैकल्पिक `comparisonCriteria` मान निर्दिष्ट किया जा सकता है. अगर यह पैरामीटर नल है, तो डिफ़ॉल्ट तुलनाकर्ता का उपयोग किया जाता है.


## Examples

### Example #1
सूची `{3, 4, 5, -1, 7, 8, 2}` के 5 सबसे छोटे मान प्राप्त करें.
```powerquery
List.MinN({3, 4, 5, -1, 7, 8, 2}, 5)
```

Result: 
```powerquery
{-1, 2, 3, 4, 5}
```

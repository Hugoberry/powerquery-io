# भाषा को जानें
Power Query M फॉर्मूला भाषा अत्यधिक लचीली डेटा मैशअप क्वेरीज़ बनाने के लिए अनुकूलित है। यह F# के समान एक फंक्शनल, केस-संवेदनशील भाषा है। Power Query फॉर्मूला भाषा का उपयोग Power BI Desktop, Excel और Analysis Services जैसे कई Microsoft उत्पादों में किया जाता है।

यह साइट Power Query फ़ंक्शंस के लिए एक संदर्भ के रूप में कार्य करती है, जो प्रत्येक फ़ंक्शन के लिए विस्तृत जानकारी और व्यावहारिक उदाहरणों तक त्वरित और सीधी पहुंच प्रदान करती है।
:::note
कृपया ध्यान दें, लेखक इस साइट पर प्रस्तुत सामग्री पर किसी भी कॉपीराइट अधिकार का दावा नहीं करता है। जानकारी इस आशा में एकत्र और प्रदान की गई है कि यह उन लोगों के लिए उपयोगी होगी जो Power Query के अपने ज्ञान और अनुप्रयोग का विस्तार करना चाहते हैं।
:::

इस वेबसाइट पर खोज कार्यक्षमता Power Query फ़ंक्शंस की विस्तृत श्रृंखला की खोज प्रक्रिया को सरल बनाती है। इसे ज़रूर आज़माएं (Ctrl+K)।

![Algolia द्वारा प्रदान की गई खोज कार्यक्षमता](/img/search.png)

जो लोग गहन अन्वेषण या कार्यान्वयन विवरण में रुचि रखते हैं, उनके लिए निम्नलिखित GitHub रिपॉजिटरी में अधिक जानकारी मिल सकती है: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io)। इस रिपॉजिटरी में Power Query विकास और उपयोग से संबंधित अतिरिक्त उदाहरण, अपडेट और संसाधन हो सकते हैं।

# Function.InvokeAfter


निर्दिष्ट अवधि के गुज़र जाने के बाद दिए गए फ़ंक्शन को इनवोक करता है.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

अवधि `delay` के गुज़र जाने के बाद `function` इनवोक करने का परिणाम लौटाता है.

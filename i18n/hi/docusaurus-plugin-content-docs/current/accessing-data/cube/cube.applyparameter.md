# Cube.ApplyParameter


क्यूब पर पैरामीटर लागू करने के बाद उसे लौटाता है.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

`cube` पर `arguments` के साथ `parameter` लागू करने के बाद क्यूब लौटाता है.

# Cube.AttributeMemberProperty


आयाम विशेषता का कोई गुण वापस करता है.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

आयाम विशेषता `attribute` का गुण `propertyName` वापस करता है.

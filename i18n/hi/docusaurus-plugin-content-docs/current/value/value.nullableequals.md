# Value.NullableEquals


लौटाता है कि क्या दो मान बराबर हैं या नहीं.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

अगर कोई भी तर्क `value1` या `value2` नल है, तो नल लौटाता है; अन्यथा यह Value.Equals के समतुल्य होता है.

# Value.Add


दो मानों का योग लौटाता है.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1` और `value2` का योग लौटाता है. एक वैकल्पिक पैरामीटर, `precision`, भी निर्दिष्ट किया जा सकता है, डिफ़ॉल्ट रूप से `Precision.Double` का उपयोग किया जाता है.

# Variable.Value


यह निर्दिष्ट चर का मान लौटाता है.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

यह वर्तमान मूल्यांकन परिवेश द्वारा परिभाषित निर्दिष्ट चर `identifier` का मान लौटाता है. अगर चर परिभाषित नहीं है, तो एक त्रुटि होगी.

# Table.ViewError


एक संशोधित त्रुटि रिकॉर्ड बनाता है जो किसी दृश्य पर (Table.View के माध्यम से) परिभाषित हैंडलर द्वारा रेज़ किए जाने पर फ़ॉलबैक को ट्रिगर नहीं करता है.


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

`errorRecord` से एक संशोधित त्रुटि रिकॉर्ड बनाता है जो किसी दृश्य पर (Table.View के माध्यम से) परिभाषित हैंडलर द्वारा रेज़ किए जाने पर फ़ॉलबैक को ट्रिगर नहीं करता है.

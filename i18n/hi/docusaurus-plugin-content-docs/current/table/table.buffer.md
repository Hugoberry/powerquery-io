# Table.Buffer


मूल्यांकन के दौरान तालिका को बाहरी परिवर्तनों से पृथक करते हुए मेमोरी में उसे बफ़र करता है.


## Syntax

```powerquery
Table.Buffer(
    table as table,
    optional options as record
) as table
```


## Remarks

एक तालिका को मेमोरी में बफ़र करता है, और मूल्यांकन के दौरान उसे बाहरी बदलावों से अलग रखता है. बफ़रिंग कम है. यह किसी भी स्केलर कक्ष मान के मूल्यांकन को बाध्य करता है, लेकिन गैर-स्केलर मानों (रिकॉर्ड, सूचियाँ, तालिकाएँ, आदि) को यथानुपात छोड़ देता है.

-   `table`: मेमोरी में बफ़र करने के लिए तालिका.
-   `options`: (वैकल्पिक) निम्न विकल्पों के रिकॉर्ड मानों का उपयोग किया जा सकता है:
    -   `BufferMode`: बफ़र मोड, जो यह बताता है कि किस प्रकार की बफ़रिंग की जानी है. यह विकल्प या तो `BufferMode.Eager` या `BufferMode.Delayed` हो सकता है.

इस फ़ंक्शन का उपयोग करने से आपकी क्वेरीज़ तेज़ चल भी सकती हैं और नहीं भी. कुछ मामलों में, जोड़े गए के कारण यह आपकी क्वेरी को अधिक धीरे-धीरे चलने योग्य बना सकता है सभी डेटा को पढ़ने और उसे मेमोरी में स्टोर करने की लागत, साथ ही यह तथ्य कि बफरिंग डाउनस्ट्रीम फोल्डिंग को रोकती है. अगर डेटा को करने की आवश्यकता नहीं है बफ़र किया गया है लेकिन आप केवल डाउनस्ट्रीम फ़ोल्डिंग को रोकना चाहते हैं, इसके बजाय `Table.StopFolding` का उपयोग करें.


## Examples

### Example #1
SQL तालिका की सभी पंक्तियों को मेमोरी में लोड करना, ताकि कोई भी डाउनस्ट्रीम कार्रवाइयाँ SQL सर्वर पर क्वेरी न कर सकें.
```powerquery
let
    Source = Sql.Database("SomeSQLServer", "MyDb"),
    MyTable = Source{[Item="MyTable"]}[Data],
    BufferMyTable = Table.Buffer(MyTable)
in
    BufferMyTable
```

Result: 
```powerquery
table
```

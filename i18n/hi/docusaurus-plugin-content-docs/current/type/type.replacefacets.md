# Type.ReplaceFacets


किसी प्रकार के फ़ैसिट बदल देता है.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

`type` प्रकार के फ़ैसिट को रिकॉर्ड `facets` में शामिल फ़ैसिट के साथ बदल देता है.

# Number.Cos


Zwraca cosinus liczby.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Zwraca cosinus odpowiadający określonemu kątowi.

-   `number`: kąt mierzony w radianach.


## Examples

### Example #1
Znajdź cosinus kąta 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Znajdź cosinus radianów π.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

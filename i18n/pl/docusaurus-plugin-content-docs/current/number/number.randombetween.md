# Number.RandomBetween


Zwraca liczbę losową z zakresu między dwiema liczbami.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Zwraca liczbę losową z zakresu od `bottom` do `top`.


## Examples

### Example #1
Utwórz liczbę losową z zakresu od 1 do 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

# Number.BitwiseShiftLeft


Wykonuje przesunięcie bitów w lewo.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Zwraca wynik przesunięcia bitów w lewo w wartości `number1` o określoną liczbę bitów `number2`.



## Category
Number.Bytes

# Number.BitwiseOr


Zwraca wynik wykonania bitowej opcji OR na dwóch wartościach wejściowych.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Zwraca wynik wykonania bitowej opcji OR na wartościach `number1` i `number2`.



## Category
Number.Bytes

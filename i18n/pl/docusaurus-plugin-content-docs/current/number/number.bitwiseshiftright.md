# Number.BitwiseShiftRight


Wykonuje przesunięcie bitów w prawo.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Zwraca wynik przesunięcia bitów w prawo w wartości `number1` o określoną liczbę bitów `number2`.



## Category
Number.Bytes

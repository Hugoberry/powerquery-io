# Number.BitwiseXor


Zwraca wynik wykonania bitowej opcji XOR (OR wyłączne) na dwóch wartościach wejściowych.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Zwraca wynik wykonania bitowej opcji XOR (OR wyłączne) na wartościach `number1` i `number2`.



## Category
Number.Bytes

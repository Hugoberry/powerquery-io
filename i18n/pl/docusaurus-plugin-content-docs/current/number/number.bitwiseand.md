# Number.BitwiseAnd


Zwraca wynik wykonania bitowej opcji AND na dwóch wartościach wejściowych.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Zwraca wynik wykonania bitowej opcji AND na wartościach `number1` i `number2`.

Number.Bytes

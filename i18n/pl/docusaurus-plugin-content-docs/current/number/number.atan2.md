# Number.Atan2


Zwraca arcus tangens ilorazu dwóch liczb.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Zwraca kąt w radianach, którego tangens jest ilorazem `y`/`x` dwóch liczb `y` i `x`.

Number.Trigonometry

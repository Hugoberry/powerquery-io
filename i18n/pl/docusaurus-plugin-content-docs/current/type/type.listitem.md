# Type.ListItem


Zwraca typ elementu z typu listy.


## Syntax

```powerquery
Type.ListItem(
    type as type
) as type
```


## Remarks

Zwraca typ elementu z listy `type`.


## Examples

### Example #1
Znajdź typ elementu na liście `{number}`.
```powerquery
Type.ListItem(type {number})
```

Result: 
```powerquery
type number
```

# Type.ReplaceTablePartitionKey


Zwraca nowy typ tabeli, w którym klucz partycji został zastąpiony określonym kluczem partycji.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

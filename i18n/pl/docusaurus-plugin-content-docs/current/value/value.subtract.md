# Value.Subtract


Zwraca różnicę dwóch wartości.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Zwraca różnicę wartości `value1` i `value2`. Można określić opcjonalny parametr `precision`; domyślnie jest używana wartość `Precision.Double`.

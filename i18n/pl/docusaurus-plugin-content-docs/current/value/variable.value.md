# Variable.Value


Zwraca wartość określonej zmiennej.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Zwraca wartość określonej zmiennej `identifier` zdefiniowanej przez bieżące środowisko oceny. Jeśli zmienna nie jest zdefiniowana, zgłaszany jest błąd.

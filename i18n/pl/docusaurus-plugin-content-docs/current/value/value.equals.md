# Value.Equals


Zwraca informację, czy dwie wartości są równe.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Zwraca wartość true, jeśli wartość `value1` jest równa wartości `value2`; w przeciwnym razie zwraca wartość false.

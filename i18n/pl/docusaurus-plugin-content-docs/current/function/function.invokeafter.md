# Function.InvokeAfter


Wywołuje daną funkcję po upływie podanego okresu.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Zwraca wynik wywołania funkcji `function` po upływie okresu `delay`.



## Category
Function

# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Łącznik Teams Analytics umożliwia uzyskiwanie wglądu w użycie usługi Teams. Dostępne dane obejmują zarówno osobistą aktywność w usłudze Teams, jak również aktywność w zespołach Teams, do których należysz.

Dostępne są dane z poprzednich 90 dni.

Aby uzyskać szczegółowe informacje na temat typów dostępnych danych, zapoznaj się z następującą dokumentacją pomocy:

-   **Użycie usługi Teams:** https://docs.microsoft.com/pl-pl/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Aktywność użytkownika w usłudze Teams:** https://docs.microsoft.com/pl-pl/microsoftteams/teams-analytics-and-reports/user-activity-report

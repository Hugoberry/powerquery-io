# Cube.MeasureProperty


Zwraca właściwości miary (właściwość komórki).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Zwraca właściwość `propertyName` miary `measure`.



## Category
Cube

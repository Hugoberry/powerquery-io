# Cube.ApplyParameter


Zwraca moduł po zastosowaniu do niego parametru.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Zwraca moduł po zastosowaniu parametru `parameter` z wartością `arguments` do `cube`.

Cube

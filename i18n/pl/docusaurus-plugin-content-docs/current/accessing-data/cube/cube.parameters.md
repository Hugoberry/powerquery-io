# Cube.Parameters


Zwraca tabelę zawierającą zestaw parametrów, które można zastosować do modułu.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Zwraca tabelę zawierającą zestaw parametrów, które można zastosować do `cube`. Każdy parametr jest funkcją, która może zostać wywołana w celu pobrania `cube` z zastosowanym parametrem i jego argumentami.

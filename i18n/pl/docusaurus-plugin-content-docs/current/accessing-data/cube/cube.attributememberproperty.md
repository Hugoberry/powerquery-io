# Cube.AttributeMemberProperty


Zwraca właściwość atrybutu wymiaru.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Zwraca właściwość `propertyName` atrybutu wymiaru `attribute`.

Cube

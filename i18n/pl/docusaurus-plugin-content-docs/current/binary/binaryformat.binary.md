# BinaryFormat.Binary


Zwraca format binarny odczytujący wartość binarną.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Zwraca format binarny odczytujący wartość binarną. W przypadku określenia parametru `length` wartość binarna będzie zawierać liczbę bajtów równą wartości tego parametru. W przypadku nieokreślenia parametru `length` wartość binarna będzie zawierać pozostałe bajty. Parametr `length` można określić jako liczbę lub format binarny długości poprzedzający dane binarne.

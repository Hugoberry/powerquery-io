# List.MinN


ส่งกลับค่าต่ำสุดในรายการ สามารถระบุจำนวนค่าที่จะส่งกลับหรือเงื่อนไขการกรองได้


## Syntax

```powerquery
List.MinN(
    list as list,
    countOrCondition as any,
    optional comparisonCriteria as any,
    optional includeNulls as logical
) as list
```


## Remarks

ส่งกลับค่าต่ำสุดในรายการ, `list` พารามิเตอร์ `countOrCondition` จะระบุจำนวนค่าเพื่อส่งกลับหรือเงื่อนไขการกรอง. พารามิเตอร์ที่เลือกได้ `comparisonCriteria` จะระบุวิธีเปรียบเทียบค่าในรายการ.

-   `list`: รายการของค่า
-   `countOrCondition`: ถ้าระบุตัวเลข จะมีการส่งกลับรายการที่มีข้อมูลสูงสุด `countOrCondition` รายการตามลำดับจากน้อยไปหามาก ถ้าระบุเงื่อนไข จะมีการส่งกลับรายการข้อมูลที่ตรงกับเงื่อนไขตั้งแต่แรก. เมื่อรายการใดรายการหนึ่งไม่เป็นไปตามเงื่อนไข จะไม่มีการพิจารณารายการถัดไป. ถ้าพารามิเตอร์นี้เป็น null ค่าที่น้อยที่สุดค่าเดียวในรายการจะถูกส่งกลับ
-   `comparisonCriteria`: *(ไม่บังคับ)* สามารถระบุค่า `comparisonCriteria` ที่เลือกได้เพื่อกําหนดวิธีการเปรียบเทียบข้อมูลในรายการ ถ้าพารามิเตอร์เป็น null จะมีการใช้ตัวเปรียบเทียบเริ่มต้น


## Examples

### Example #1
หา 5 ค่าเล็กสุดในรายการ `{3, 4, 5, -1, 7, 8, 2}`
```powerquery
List.MinN({3, 4, 5, -1, 7, 8, 2}, 5)
```

Result: 
```powerquery
{-1, 2, 3, 4, 5}
```

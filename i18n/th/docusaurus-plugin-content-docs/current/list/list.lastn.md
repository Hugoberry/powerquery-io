# List.LastN


ส่งกลับรายการของรายการสุดท้ายหรือรายการในรายการที่ระบุ สามารถเลือกระบุจำนวนค่าที่จะส่งกลับหรือเงื่อนไขที่เหมาะสมหรือไม่ก็ได้


## Syntax

```powerquery
List.LastN(
    list as list,
    optional countOrCondition as any
) as any
```


## Remarks

ส่งกลับรายการของรายการสุดท้ายหรือรายการในรายการที่ระบุ

-   `list`: รายการที่จะตรวจสอบ หากรายการว่างเปล่า จะส่งกลับรายการว่างเปล่า
-   `countOrCondition`: (ไม่บังคับ) สนับสนุนการรวบรวมหลายรายการหรือการกรองรายการ แม้ว่าพารามิเตอร์นี้จะเป็นพารามิเตอร์ที่ไม่บังคับ แต่จะเกิดข้อผิดพลาดขึ้น หากไม่ได้ระบุค่านี้หรือเป็น `null` พารามิเตอร์นี้สามารถระบุได้ด้วยสองวิธี:
    -   หากระบุหมายเลข จะส่งกลับรายการสูงสุดตามจำนวนดังกล่าว
    -   หากระบุเงื่อนไข จะส่งกลับรายการทั้งหมดที่ตรงตามเงื่อนไข โดยเริ่มจากจุดสิ้นสุดของรายการ เมื่อรายการไม่ตรงตามเงื่อนไข จะไม่มีการพิจารณารายการเพิ่มเติม


## Examples

### Example #1
ค้นหาค่าสุดท้ายในรายการ \{3, 4, 5, -1, 7, 8, 2\}
```powerquery
List.LastN({3, 4, 5, -1, 7, 8, 2}, 1)
```

Result: 
```powerquery
{2}
```


### Example #2
ค้นหาค่าสุดท้ายในรายการ \{3, 4, 5, -1, 7, 8, 2\} ที่มากกว่า 0
```powerquery
List.LastN({3, 4, 5, -1, 7, 8, 2}, each _ > 0)
```

Result: 
```powerquery
{7, 8, 2}
```

# BinaryFormat.Binary


ส่งกลับรูปแบบไบนารีที่อ่านค่าไบนารี


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

ส่งกลับรูปแบบไบนารีที่อ่านค่าไบนารี ถ้ามีการระบุ `length` ค่าไบนารีจะมีหลายไบต์ ถ้าไม่ได้ระบุ `length` ค่าไบนารีจะมีไบต์ที่เหลือ สามารถระบุ `length` เป็นตัวเลข หรือเป็นรูปแบบไบนารีของความยาวที่อยู่ก่อนหน้าข้อมูลไบนารี

# Binary.ViewError


สร้างระเบียนข้อผิดพลาดที่ปรับเปลี่ยนจะไม่ทริกเกอร์การย้อนกลับเมื่อยกระดับโดยตัวจัดการที่กําหนดในมุมมอง (ผ่าน Binary.View)


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

สร้างระเบียนข้อผิดพลาดที่ปรับเปลี่ยนจาก `errorRecord` ซึ่งจะไม่ทริกเกอร์การย้อนกลับเมื่อยกระดับโดยตัวจัดการที่กําหนดในมุมมอง (ผ่าน Binary.View)

# ค้นพบภาษานี้
ภาษาสูตร Power Query M ได้รับการปรับให้เหมาะสมสำหรับการสร้างคิวรีการผสานข้อมูลที่ยืดหยุ่นสูง เป็นภาษาเชิงฟังก์ชันที่แยกความแตกต่างระหว่างตัวพิมพ์ใหญ่และตัวพิมพ์เล็ก คล้ายกับ F# ภาษาสูตร Power Query ถูกใช้ในผลิตภัณฑ์ของ Microsoft หลายรายการ เช่น Power BI Desktop, Excel และ Analysis Services

ไซต์นี้เป็นแหล่งอ้างอิงสำหรับฟังก์ชัน Power Query โดยให้การเข้าถึงข้อมูลโดยละเอียดและตัวอย่างการใช้งานจริงสำหรับแต่ละฟังก์ชันอย่างรวดเร็วและตรงไปตรงมา
:::note
โปรดทราบว่าผู้เขียนไม่ได้อ้างสิทธิ์ในลิขสิทธิ์ใด ๆ ต่อเนื้อหาที่นำเสนอบนไซต์นี้ ข้อมูลถูกรวบรวมและจัดเตรียมไว้โดยหวังว่าจะเป็นประโยชน์สำหรับผู้ที่ต้องการขยายความรู้และการประยุกต์ใช้ Power Query
:::

ฟังก์ชันการค้นหาบนเว็บไซต์นี้ควรช่วยให้กระบวนการค้นพบฟังก์ชัน Power Query ที่หลากหลายง่ายขึ้น อย่าลืมลองใช้งาน (Ctrl+K)

![ฟังก์ชันการค้นหาให้บริการโดย Algolia](/img/search.png)

สำหรับผู้ที่สนใจการสำรวจเชิงลึกหรือรายละเอียดการนำไปใช้งาน สามารถดูข้อมูลเพิ่มเติมได้ในที่เก็บ GitHub ต่อไปนี้: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io) ที่เก็บนี้อาจมีตัวอย่างเพิ่มเติม การอัปเดต และทรัพยากรที่เกี่ยวข้องกับการพัฒนาและการใช้งาน Power Query

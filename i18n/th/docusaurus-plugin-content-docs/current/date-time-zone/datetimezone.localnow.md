# DateTimeZone.LocalNow


ส่งกลับวันที่และเวลาในโซนเวลาท้องถิ่น


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

ส่งกลับค่า `datetimezone` เพื่อตั้งค่าวันที่และเวลาปัจจุบันในระบบ ค่าที่ส่งกลับมีข้อมูลโซนเวลาที่แสดงโซนเวลาท้องถิ่น

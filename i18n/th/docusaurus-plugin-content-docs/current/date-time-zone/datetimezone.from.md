# DateTimeZone.From


สร้างโซนวันที่เวลาจากค่าที่กำหนด


## Syntax

```powerquery
DateTimeZone.From(
    value as any,
    optional culture as text
) as datetimezone
```


## Remarks

สร้าง `datetimezone` จากค่าที่กําหนด

-   `value`: ค่าที่ใช้ในการสร้าง `datetimezone`
-   `culture`:(เพิ่มเติม) วัฒนธรรมที่จะใช้เมื่อแปลงค่า (ตัวอย่างเช่น "en-US")

ค่าของประเภทต่อไปนี้สามารถแปลงเป็นค่า `datetimezone` ได้:

-   `text`: ส่งกลับค่า `datetimezone` จากข้อความสำหรับแสดงแทน โปรดดูรายละเอียดที่ `DateTimeZone.FromText`
-   `date`: ส่งกลับ `datetimezone` โดยมี `value` เป็นส่วนประกอบของวันที่ `12:00:00 AM` เป็นส่วนประกอบของเวลา และค่าออฟเซ็ตที่สอดคล้องกับโซนเวลาท้องถิ่น
-   `datetime`: ส่งกลับ `datetimezone` โดยมี `value` เป็นวันที่เวลา และค่าออฟเซ็ตที่สอดคล้องกับโซนเวลาท้องถิ่น
-   `datetimezone`: ส่งกลับ `value`
-   `time`: ส่งกลับ `datetimezone` โดยมีวันที่เทียบเท่ากับ OLE Automation Date ของ `0` เป็นส่วนประกอบวันที่ `value` เป็นส่วนประกอบเวลา และออฟเซ็ตที่สอดคล้องกับโซนเวลาท้องถิ่น OLE Automation Date ประกอบด้วยเลขทศนิยมลอยตัว ซึ่งมีองค์ประกอบจำนวนเต็มคือจำนวนวันก่อนหรือหลังเที่ยงคืนของวันที่ 30 ธันวาคม 1899 และองค์ประกอบเศษส่วนแสดงเวลาในวันนั้นหารด้วย 24 ตัวอย่างเช่น เที่ยงคืนของวันที่ 31 ธันวาคม 1899 แสดงด้วย 1.0; 6.00 น. ของวันที่ 1 มกราคม 1900 แสดงด้วย 2.25; เที่ยงคืนของวันที่ 29 ธันวาคม 1899 แสดงด้วย -1.0; และ 6.00 น. ของวันที่ 29 ธันวาคม 1899 แสดงด้วย -1.25 ค่าฐานคือเที่ยงคืนของวันที่ 30 ธันวาคม 1899 ค่าต่ำสุดคือเที่ยงคืนของวันที่ 1 มกราคม 0100 ค่าสูงสุดคือวินาทีสุดท้ายของวันที่ 31 ธันวาคม 9999
-   `number`: ส่งกลับ `datetimezone` ที่มีวันที่เวลาที่เทียบเท่ากับ OLE Automation Date ที่แสดงโดย `value` และออฟเซตที่สอดคล้องกับโซนเวลาท้องถิ่น
-   `null`: ส่งกลับ `null`

หาก `value` เป็นชนิดอื่น จะส่งกลับข้อผิดพลาด  
  
ค่าของออฟเซตที่สอดคล้องกับโซนเวลาท้องถิ่นจะแตกต่างกันเมื่อเรียกใช้ฟังก์ชันนี้ภายในเครื่องตรงกันข้ามกับการเรียกใช้แบบออนไลน์ เมื่อเรียกใช้ภายในเครื่อง โซนเวลาท้องถิ่นจะถูกส่งกลับ เมื่อเรียกใช้แบบออนไลน์ โซนเวลา UTC (+00:00) จะถูกส่งกลับ


## Examples

### Example #1
แปลงการแสดงข้อความของวันที่ เวลา และเขตเวลาเป็นค่า `datetimezone`
```powerquery
DateTimeZone.From("2020-10-30T01:30:00-08:00")
```

Result: 
```powerquery
#datetimezone(2020, 10, 30, 01, 30, 00, -8, 00)
```


### Example #2
แปลงการแสดงข้อความของวันที่ เวลา และเขตเวลาในภาษาโปรตุเกสของบราซิลเป็นค่า `datetimezone`
```powerquery
DateTimeZone.From("13 de agosto de 2025 15:43:00 -03:00", "pt-BR")
```

Result: 
```powerquery
#datetimezone(2025, 08, 13, 15, 43, 00, -3, 00)
```


### Example #3
แปลงตัวเลขที่แสดงวันที่ 1 มกราคม 2025 เวลา 12:00 น. เป็นค่า `datetimezone` เขตเวลาในผลลัพธ์จะขึ้นอยู่กับว่าตัวอย่างถูกเรียกใช้ภายในเครื่องหรือออนไลน์
```powerquery
DateTimeZone.From(45658.5)
```

Result: 
```powerquery
#datetimezone(2025, 01, 01, 12, 00, 00, 0, 00)
```

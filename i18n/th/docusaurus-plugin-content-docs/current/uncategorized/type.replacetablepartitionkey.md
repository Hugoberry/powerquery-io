# Type.ReplaceTablePartitionKey


ส่งกลับชนิดตารางใหม่ด้วยคีย์พาร์ติชันที่แทนที่ด้วยคีย์พาร์ติชันที่ระบุ


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

ส่งกลับชนิดตารางใหม่ด้วยคีย์พาร์ติชันที่แทนที่ด้วยคีย์พาร์ติชันที่ระบุ

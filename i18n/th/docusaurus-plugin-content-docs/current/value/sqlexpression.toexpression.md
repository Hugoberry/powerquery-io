# SqlExpression.ToExpression


แปลงแบบสอบถาม SQL ที่ให้มาเป็นโค้ด M ฟังก์ชันนี้มีไว้สําหรับใช้ภายในเท่านั้น


## Syntax

```powerquery
SqlExpression.ToExpression(
    sql as text,
    environment as record
) as text
```


## Remarks

แปลงคิวรี `sql` ที่ระบุเป็นโค้ด M ด้วยตัวระบุที่พร้อมใช้งานซึ่งกําหนดโดย `environment` ฟังก์ชันนี้มีไว้สําหรับใช้ภายในเท่านั้น

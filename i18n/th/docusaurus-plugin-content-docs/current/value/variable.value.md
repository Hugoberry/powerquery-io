# Variable.Value


ส่งกลับค่าของตัวแปรที่ระบุ


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

ส่งกลับค่าของตัวแปรที่ระบุ `identifier` ที่กำหนดโดยสภาพแวดล้อมการประเมินปัจจุบัน ถ้าไม่ได้กําหนดตัวแปร ข้อผิดพลาดจะเกิดขึ้น

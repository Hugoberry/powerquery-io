# Value.Add


ส่งกลับผลรวมของสองค่า


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

ส่งกลับผลรวมของ `value1` และ `value2` พารามิเตอร์ `precision` ที่เลือกได้อาจถูกระบุไว้ ตามค่าเริ่มต้น จะมีการใช้ `Precision.Double`

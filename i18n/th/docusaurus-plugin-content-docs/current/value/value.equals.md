# Value.Equals


ส่งกลับว่าค่าสองค่าเท่ากันหรือไม่


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

ส่งกลับ True ถ้าค่า `value1` เท่ากับค่า `value2` และ False ถ้าไม่ใช่

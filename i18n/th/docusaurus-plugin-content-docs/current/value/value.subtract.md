# Value.Subtract


ส่งกลับผลต่างของสองค่า


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

ส่งกลับผลต่างของ `value1` และ `value2` พารามิเตอร์ `precision` ที่เลือกได้อาจถูกระบุไว้ ตามค่าเริ่มต้น จะมีการใช้ `Precision.Double`

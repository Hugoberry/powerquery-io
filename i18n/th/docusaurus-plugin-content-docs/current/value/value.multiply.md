# Value.Multiply


ส่งกลับผลคูณของสองค่า


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

ส่งกลับผลคูณของการคูณ `value1` ด้วย `value2` พารามิเตอร์ `precision` ที่เลือกได้อาจถูกระบุไว้ ตามค่าเริ่มต้น จะมีการใช้ `Precision.Double`

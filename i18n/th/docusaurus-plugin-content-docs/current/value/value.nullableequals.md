# Value.NullableEquals


ส่งกลับว่าค่าสองค่าเท่ากันหรือไม่


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

ส่งคืนค่า null หากอาร์กิวเมนต์ `value1` หรือ `value2` เป็นค่า null มิเช่นนั้นจะเทียบเท่ากับ Value.Equals

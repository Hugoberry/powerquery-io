# Table.FirstValue


ส่งคืนคอลัมน์แรกของแถวแรกจากตาราง หรือค่าเริ่มต้นตามที่ระบุไว้


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

ส่งคืนคอลัมน์แรกของแถวแรกจากตาราง `table` หรือค่าเริ่มต้นตามที่ระบุไว้

# Type.TableSchema


ส่งคืนค่าตารางที่ประกอบด้วยคำอธิบายเกี่ยวกับคอลัมน์็ (เช่น Schema) สำหรับชนิดตารางที่ระบุไว้เฉพาะ


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

ส่งคืนค่าตารางที่อธิบายเกี่ยวกับคอลัมน์ `tableType`

ดูเอกสารประกอบเกี่ยวกับ `Table.Schema` สำหรับคำอธิบายตารางที่แสดงผลลัพธ์

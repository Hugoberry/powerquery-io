# Number.Abs


ส่งกลับค่าสัมบูรณ์ของจำนวน


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

ส่งคืนค่าสัมบูรณ์ของ `number` ถ้า `number` เป็น null `ตัวเลข.Abs` จะส่งคืนค่าเป็น null

-   `number`: `ตัวเลข` ซึ่งจะมีการคำนวณค่าสัมบูรณ์


## Examples

### Example #1
ค่าสัมบูรณ์ของ -3
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

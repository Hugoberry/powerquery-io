# Number.Log10


ส่งกลับลอการิทึมฐาน 10 ของตัวเลข


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

ส่งคืนลอการิทึมฐาน 10 ของตัวเลข `number` ถ้า `number` เป็น null `Number.Log10` จะส่งกลับ null


## Examples

### Example #1
รับลอการิทึมฐาน 10 ของ 2
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

# Number.Atan2


ส่งกลับค่าอาร์กแทนเจนต์ของการหารสองจำนวน


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

ส่งกลับค่ามุมเป็นหน่วยเรเดียน โดยแทนเจนต์คือผลหาร `y`/`x` ของตัวเลขสองตัวคือ `y` และ `x`

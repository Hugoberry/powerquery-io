# Number.BitwiseXor


ส่งกลับผลลัพธ์ของการดำเนินการในระดับบิต "XOR" (Exclusive-OR) ระหว่างค่าที่ป้อนสองรายการ


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

ส่งกลับผลลัพธ์ของการดำเนินการในระดับบิต "XOR" (Exclusive-OR) ระหว่าง `number1` กับ `number2`

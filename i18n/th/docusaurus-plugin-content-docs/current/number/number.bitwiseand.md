# Number.BitwiseAnd


ส่งกลับผลลัพธ์ของการดำเนินการในระดับบิต "And" ระหว่างค่าที่ป้อนสองรายการ


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

ส่งกลับผลลัพธ์ของการดำเนินการในระดับบิต "And" ระหว่าง `number1` กับ `number2`

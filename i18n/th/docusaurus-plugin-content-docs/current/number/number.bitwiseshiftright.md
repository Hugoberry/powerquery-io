# Number.BitwiseShiftRight


เลื่อนชุดบิตที่กำหนดไปทางขวา


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

ส่งกลับผลลัพธ์ของการดำเนินการเลื่อนบิตไปทางขวาใน `number1` ตามจำนวนบิต `number2` ที่ระบุ

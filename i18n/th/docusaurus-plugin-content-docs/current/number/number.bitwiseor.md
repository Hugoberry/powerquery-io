# Number.BitwiseOr


ส่งกลับผลลัพธ์ของการดำเนินการในระดับบิต "Or" ระหว่างค่าที่ป้อนสองรายการ


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

ส่งกลับผลลัพธ์ของการดำเนินการในระดับบิต "Or" ระหว่าง `number1` กับ `number2`

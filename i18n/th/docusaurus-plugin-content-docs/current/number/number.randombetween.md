# Number.RandomBetween


ส่งกลับตัวเลขสุ่มระหว่างสองตัวเลข


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

ส่งกลับตัวเลขสุ่มระหว่าง `bottom` ถึง `top`


## Examples

### Example #1
รับตัวเลขสุ่มระหว่าง 1 ถึง 5
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

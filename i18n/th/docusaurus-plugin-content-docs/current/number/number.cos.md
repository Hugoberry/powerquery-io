# Number.Cos


ส่งกลับค่าโคไซน์ของตัวเลข


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

ส่งกลับค่าโคไซน์ของมุมที่ระบุ

-   `number`: มุม วัดเป็นเรเดียน


## Examples

### Example #1
หาค่าโคไซน์ของมุม 0
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
ค้นหาโคไซน์ของ π เรเดียน
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

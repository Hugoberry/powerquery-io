# Function.InvokeAfter


เรียกฟังก์ชันที่กำหนดไว้หลังผ่านระยะเวลาที่ระบุไว้


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

ส่งกลับผลลัพธ์ของการเรียก `function` หลังผ่านระยะเวลา `delay`

# Cube.AttributeMemberProperty


ส่งกลับคุณสมบัติของแอตทริบิวต์มิติ


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

ส่งกลับคุณสมบัติ `propertyName` ของแอตทริบิวต์มิติ `attribute`



## Category
Cube

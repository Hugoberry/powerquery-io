# Cube.MeasureProperty


ส่งกลับคุณสมบัติของหน่วยวัด (คุณสมบัติเซลล์)


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

ส่งกลับคุณสมบัติ `propertyName` ของหน่วยวัด `measure`

Cube

# Cube.ApplyParameter


ส่งคืนคิวบ์หลังจากกำหนดใช้พารามิเตอร์


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

ส่งคืนคิวบ์หลังจากกำหนดใช้ `parameter` ด้วย `arguments` เป็น `cube`

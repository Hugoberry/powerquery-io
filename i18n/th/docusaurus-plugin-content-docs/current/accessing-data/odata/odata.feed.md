# OData.Feed


ส่งกลับตารางของตัวดึงข้อมูล OData ที่เสนอโดยบริการ OData


## Syntax

```powerquery
OData.Feed(
    serviceUri as text,
    optional headers as record,
    optional options as any
) as any
```


## Remarks

ส่งกลับตารางของฟีด OData ที่นำเสนอโดยบริการ OData จาก URI `serviceUri`, ส่วนหัว `headers` อาจมีการระบุค่าบูลีนที่ระบุว่าจะใช้การเชื่อมต่อพร้อมกัน หรือพารามิเตอร์ระเบียนตัวเลือก `options` เพื่อควบคุมตัวเลือกดังต่อไปนี้:

-   `Query`: เพิ่มพารามิเตอร์การค้นหาลงใน URL โดยอัตโนมัติโดยไม่ต้องกังวลเรื่องการหลีกเลี่ยงอักขระพิเศษ
-   `ส่วนหัว` : การระบุค่านี้เป็นระเบียนจะให้ส่วนหัวเพิ่มเติมสำหรับคำขอ HTTP
-   `ExcludedFromCacheKey`: การระบุค่านี้ในรูปแบบรายการจะเป็นการตัดคีย์ส่วนหัว HTTP เหล่านี้ออกจากการเป็นส่วนหนึ่งของการคำนวณสำหรับข้อมูลการแคช
-   `ApiKeyName`: ถ้าไซต์เป้าหมายมีเครื่องหมายของคีย์ API คุณสามารถใช้พารามิเตอร์นี้เพื่อระบุชื่อ (ไม่ใช่ค่า) ของพารามิเตอร์ของคีย์ที่ต้องใช้ใน URL ได้ จะมีการแสดงค่าคีย์จริงไว้ในข้อมูลประจำตัว
-   `Timeout` : การระบุค่านี้เป็นระยะเวลาจะเปลี่ยนระยะหมดเวลาสำหรับคำขอ HTTP ค่าเริ่มต้นคือ 600 วินาที
-   `EnableBatch` : ค่าตรรกะ (จริง/เท็จ) ที่ใช้กำหนดว่าจะอนุญาตให้สร้างคำขอ OData $batch หรือไม่ หากความยาว MaxUriLength เกินกำหนด (ค่าเริ่มต้นคือเท็จ)
-   `MaxUriLength`: ตัวเลขที่ระบุความยาวสูงสุดของ URI ที่อนุญาตให้ส่งไปยังบริการ OData หากเกินและ EnableBatch เป็นจริง คำขอจะถูกส่งไปยังจุดสิ้นสุด OData $batch มิฉะนั้นจะล้มเหลว (ค่าเริ่มต้นคือ 2048).
-   `พร้อมกัน` : ตรรกะ (จริง/เท็จ) เมื่อกำหนดเป็นจริง คำขอไปยังบริการจะถูกส่งแบบพร้อมกัน เมื่อกำหนดเป็นเท็จ คำขอจะถูกส่งแบบเรียงตามลำดับ. เมื่อไม่ได้ระบุ ค่าจะถูกกำหนดโดยคำอธิบายประกอบ AsynchronousRequestsSupported ของบริการ หากบริการไม่ได้ระบุว่ารองรับ AsynchronousRequestsSupported หรือไม่ คำขอจะถูกส่งแบบเรียงตามลำดับ
-   `ODataVersion` : ตัวเลข (3 หรือ 4) ที่ระบุเวอร์ชันโปรโตคอล OData ที่จะใช้สำหรับบริการ OData นี้ เมื่อไม่ได้ระบุ จะแจ้งขอเวอร์ชันที่รองรับทั้งหมด เวอร์ชันของบริการจะถูกกำหนดโดยส่วนหัว OData-Version ที่บริการส่งกลับ
-   `FunctionOverloads`: ค่าตรรกะ (จริง/เท็จ) ตรรกะ (จริง/เท็จ) เมื่อตั้งค่าเป็นจริง การโอเวอร์โหลดการนําเข้าฟังก์ชันจะแสดงรายการในตัวนําทางเป็นรายการแยกต่างหาก เมื่อตั้งค่าเป็นเท็จ การโอเวอร์โหลดการนําเข้าฟังก์ชันจะแสดงเป็นฟังก์ชันยูเนียนหนึ่งฟังก์ชันในตัวนําทาง ค่าเริ่มต้นสำหรับ V3: เท็จ ค่าเริ่มต้นสำหรับ V4: จริง
-   `MoreColumns` : ค่าตรรกะ (จริง/เท็จ) เมื่อตั้งค่าเป็นจริง จะเพิ่มคอลัมน์ "คอลัมน์เพิ่มเติม" ให้กับฟีดเอนทิตีแต่ละรายการที่มีประเภทแบบเปิดและประเภทแบบโพลีมอร์ฟิก คอลัมน์นี้จะประกอบด้วยฟิลด์ที่ไม่ได้ประกาศในชนิดฐาน. เมื่อเป็นเท็จ จะไม่มีฟิลด์นี้. ค่าเริ่มต้นเป็นเท็จ
-   `IncludeAnnotations` : รายการคั่นด้วยจุลภาคของชื่อเทอมที่มีคุณสมบัติตาม Namespace หรือรูปแบบที่จะรวม โดยใช้ "\*" เป็นอักขระตัวแทน โดยค่าเริ่มต้น จะไม่มีการรวมอนุกรมประกอบใดๆ
-   `IncludeMetadataAnnotations` : รายการคั่นด้วยจุลภาคของชื่อเทอมที่มีคุณสมบัติตาม Namespace หรือรูปแบบที่จะรวมไว้ในคำขอเอกสารเมตาดาต้า โดยใช้ "\*" เป็นอักขระตัวแทน โดยค่าเริ่มต้น จะรวมอนุกรมประกอบเดียวกับ IncludeAnnotations
-   `OmitValues` : อนุญาตให้บริการ OData ไม่เขียนค่าบางอย่างออกมาในคำตอบ หากได้รับการยอมรับโดยบริการ เราจะอนุมานค่าดังกล่าวจากฟิลด์ที่ถูกละไว้ ตัวเลือกประกอบด้วย:
    -   `ODataOmitValues.Nulls` : อนุญาตให้บริการ OData ละเว้นค่าที่เป็น null
-   `Implementation` : ระบุการใช้งานของตัวเชื่อมต่อ OData ที่จะใช้ ค่าที่ถูกต้องคือ "2.0" หรือ null


## Examples

### Example #1
เชื่อมต่อกับบริการ TripPin OData
```powerquery
OData.Feed("https://services.odata.org/V4/TripPinService")
```

Result: 
```powerquery
table
```

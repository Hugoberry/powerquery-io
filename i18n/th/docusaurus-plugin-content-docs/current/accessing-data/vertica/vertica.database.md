# Vertica.Database


นำเข้าข้อมูลจาก Vertica


## Syntax

```powerquery
Vertica.Database(
    server as text,
    database as text,
    optional options as record
) as table
```


## Remarks

ส่งกลับตาราง Schema ที่พร้อมใช้งานบนเซิร์ฟเวอร์ที่มีชื่อตามพารามิเตอร์ `เซิร์ฟเวอร์` ในฐานข้อมูลที่มีชื่อตามพารามิเตอร์ `ฐานข้อมูล` อาจมีการมอบพารามิเตอร์ระเบียนแบบไม่บังคับที่เรีกยว่า `ตัวเลือก` เพื่อระบุคุณสมบัติเพิ่มเติมได้ ระเบียนสามารถประกอบด้วยเขตข้อมูลต่อไปนี้:

-   `ConnectionTimeout`: ระยะเวลาที่ควบคุมระยะเวลาในการรอก่อนที่จะละทิ้งความพยายามที่จะทำการเชื่อมต่อไปยังเซิร์ฟเวอร์ ค่าเริ่มต้นจะขึ้นอยู่กับโปรแกรมควบคุม
-   `CommandTimeout` : ระยะเวลาที่ควบคุมระยะเวลาที่คิวรีฝั่งเซิร์ฟเวอร์ได้รับอนุญาตให้เรียกใช้ก่อนที่จะถูกยกเลิก ค่าเริ่มต้นจะขึ้นอยู่กับโปรแกรมควบคุม

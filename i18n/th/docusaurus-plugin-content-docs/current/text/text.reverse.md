# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

ย้อนกลับ `text` ที่ระบุ


## Examples

### Example #1
ย้อนกลับข้อความ "123"
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

# Function.InvokeAfter


A megadott időtartam elteltével meghívja az adott függvényt.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

`delay` időtartam elteltével visszaadja a(z) `function` függvény meghívásának eredményét.

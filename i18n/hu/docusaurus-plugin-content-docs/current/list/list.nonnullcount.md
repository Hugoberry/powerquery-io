# List.NonNullCount


A listán szereplő nem null értékű elemek számát adja vissza.


## Syntax

```powerquery
List.NonNullCount(
    list as list
) as number
```


## Remarks

A(z) `list` listán szereplő nem null értékű elemek számát adja vissza.

List.Information

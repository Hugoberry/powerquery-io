# Type.TableColumn


Egy táblában szereplő oszlop típusát adja vissza.


## Syntax

```powerquery
Type.TableColumn(
    tableType as type,
    column as text
) as type
```


## Remarks

A(z) `tableType` táblatípusban szereplő `column` oszlop típusát adja vissza.

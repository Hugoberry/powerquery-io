# Type.TableSchema


Egy, a megadott táblatípus oszlopainak leírását (a sémát) tartalmazó táblát ad vissza.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Egy, a(z) `tableType` oszlopait leíró táblát ad vissza.

Az eredményül kapott tábla leírása a `Table.Schema` dokumentációjában található.

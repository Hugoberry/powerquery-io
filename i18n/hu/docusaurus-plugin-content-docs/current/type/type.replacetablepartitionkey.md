# Type.ReplaceTablePartitionKey


Egy új táblatípust ad vissza, amelynek partíciókulcsát a megadott partíciókulcs váltja fel.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```

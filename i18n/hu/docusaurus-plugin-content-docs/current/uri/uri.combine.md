# Uri.Combine


Egy abszolút URI-azonosítót ad vissza, amelyet a bemeneti alap URI és relatív URI egyesítésével állít elő.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Egy abszolút URI-azonosítót ad vissza, amelyet a bemeneti `baseUri` és `relativeUri` egyesítésével állít elő.

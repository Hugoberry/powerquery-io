# DateTimeZone.LocalNow


Az aktuális dátumot és időt adja vissza a helyi időzónában.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Egy olyan `datetimezone` típusú értéket ad vissza, amely a rendszer aktuális dátumát és idejét tartalmazza. A visszaadott érték a helyi időzónát jelölő időzónaadatokat tartalmaz.

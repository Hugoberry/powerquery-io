# File.Contents


A megadott fájl tartalmát adja vissza bináris formában.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

A(z) `path` fájl tartalmát adja vissza binárisként. A(z) `options` paraméter jelenleg csak belső használatra szolgál.

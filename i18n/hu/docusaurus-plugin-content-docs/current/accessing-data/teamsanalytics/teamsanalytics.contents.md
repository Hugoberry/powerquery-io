# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

A Teams Analytics-összekötő révén betekintést nyerhet a Teams használati információiba. Adatokat kaphat a Teamsben végzett személyes tevékenységeire, valamint az olyan Teams-csatornákra vonatkozóan is, amelyeknek Ön a tagja.

Az elmúlt 90 napra vonatkozóan érhetők el adatok.

Az elérhető adatok típusairól a következő súgódokumentációban talál információt:

-   **Teams-használat:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Teams-felhasználói tevékenység:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

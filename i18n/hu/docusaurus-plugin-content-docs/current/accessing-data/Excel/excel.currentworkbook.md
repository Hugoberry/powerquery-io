# Excel.CurrentWorkbook


Az aktuális Excel-munkafüzet tartalmát adja vissza.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Az aktuális Excel-munkafüzet tartalmát adja vissza. Táblákat, névvel ellátott tartományokat és dinamikus tömböket ad vissza. Ellentétben az `Excel.Workbook` utasítással, nem ad vissza lapokat.

# Exchange.Contents


Egy tartalomjegyzéket ad vissza egy Microsoft Exchange-fiókból.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Egy tartalomjegyzéket ad vissza a(z) `mailboxAddress` Microsoft Exchange-fiókból. Ha a(z) `mailboxAddress` nincs megadva, a rendszer a azonosító adatok alapértelmezett fiókját használja.

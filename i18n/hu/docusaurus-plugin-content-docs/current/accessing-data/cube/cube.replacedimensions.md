# Cube.ReplaceDimensions


Lecseréli a Cube.Dimensions által visszaadott dimenziókészletet.


## Syntax

```powerquery
Cube.ReplaceDimensions(
    cube as table,
    dimensions as any
) as table
```


## Remarks

Lecseréli a `Cube.Dimensions` által visszaadott dimenziókészletet. Ezzel a függénnyel például azonosító oszlop adható hozzá egy dimenzió attribútumhoz, így az adatforrás a megjelenített érték helyett az azonosító alapján csoportosíthat.

# Cube.AttributeMemberProperty


Egy dimenzióattribútum tulajdonságát adja vissza.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

A(z) `attribute` dimenzióattribútum `propertyName` tulajdonságát adja vissza.

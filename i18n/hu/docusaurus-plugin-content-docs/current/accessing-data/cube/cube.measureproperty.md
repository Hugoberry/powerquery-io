# Cube.MeasureProperty


Egy mérték egyik tulajdonságát adja vissza (cellatulajdonság).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

A(z) `measure` mérték `propertyName` tulajdonságát adja vissza.

Cube

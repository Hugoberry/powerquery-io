# Cube.Parameters


Egy, az adatkockára alkalmazható paraméterkészletet tartalmazó táblát ad vissza.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Egy táblát ad vissza, amely tartalmazza a következőre alkalmazható paraméterek készletét: `cube`. Minden paraméter egy meghívható függvény, amellyel lekérhető a(z) `cube`az alkalmazott paraméterrel és argumentumokkal.

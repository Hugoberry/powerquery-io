# Cube.AttributeMemberId


A tagok tulajdonságértékének egyedi tagazonosítóját adja vissza.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

A tagok tulajdonságértékének egyedi tagazonosítóját adja vissza. `attribute`. Egyéb értékek esetén null értéket ad vissza.

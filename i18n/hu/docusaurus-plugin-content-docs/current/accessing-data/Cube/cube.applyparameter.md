# Cube.ApplyParameter


Egy paraméter alkalmazása után egy adatkockát ad vissza.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

A(z) `parameter` és `arguments` `cube`\-ra való alkalmazása után egy adatkockát ad vissza.

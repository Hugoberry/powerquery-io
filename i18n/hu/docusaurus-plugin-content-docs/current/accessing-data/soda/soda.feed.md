# Soda.Feed


A megadott URL-címen található tartalomból álló táblát ad vissza a SODA 2.0 API által definiált formátumban.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

A megadott `url` URL-címen található tartalomból álló táblát ad vissza a SODA 2.0 API által definiált formátumban. Az URL-címnek olyan érvényes, a SODA szabványnak megfelelő forrásra kell mutatnia, amely a .csv kiterjesztésre végződik.

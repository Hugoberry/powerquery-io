# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Megfordítja a megadott `text` elemet.


## Examples

### Example #1
Az „123” szöveg megfordítása.
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

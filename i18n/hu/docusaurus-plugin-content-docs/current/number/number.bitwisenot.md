# Number.BitwiseNot


Egy olyan bájtot ad vissza, amelyben mindegyik bit ellentétes a bemenetben szereplővel.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

A(z) `number` értéken elvégzett bitenkénti „Negálás” művelet eredményét adja vissza.

Number.Bytes

# Number.BitwiseOr


A két bemenet közötti bitenkénti „Vagy” művelet eredményét adja vissza.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

A(z) `number1` és `number2` közötti bitenkénti „Vagy” művelet eredményét adja vissza.

Number.Bytes

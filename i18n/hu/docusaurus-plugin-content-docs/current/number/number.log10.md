# Number.Log10


A szám 10-es alapú logaritmusát adja vissza.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

A(z) `number` szám 10-es alapú logaritmusát adja vissza. Ha a(z) `number` érték null, a `Number.Log10` függvény null értéket ad vissza.


## Examples

### Example #1
A 2-es szám 10-es alapú logaritmusának lekérése.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

# Number.Sin


Visszaadja a szám szinuszát.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

A(z) `number` szinuszát adja vissza.


## Examples

### Example #1
A 0 radiános szög szinuszának meghatározása
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

# Number.Ln


A szám természetes alapú logaritmusát adja vissza.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

A(z) `number` szám természetes algoritmusát adja vissza. Ha a(z) `number` értéke null, akkor a `Number.Ln` null értéket ad vissza.


## Examples

### Example #1
A 15 természetes alapú logaritmusának kiszámítása
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

# Number.Abs


A szám abszolút értékét adja vissza.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

`number` Abszolút értékét adja vissza. Ha a(z) `number` nullértékű, a `Number.Abs` nullértéket ad vissza.

-   `number`: Egy `number` érték, amelyhez a rendszer abszolút értéket számít.


## Examples

### Example #1
A -3 abszolút értéke
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

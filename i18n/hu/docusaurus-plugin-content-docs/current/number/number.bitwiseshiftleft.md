# Number.BitwiseShiftLeft


Balra eltolja a bitkészletet.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

A(z) `number1` értéken elvégzett, a megadott `number2` bittel való bitenkénti balra eltolási művelet eredményét adja vissza.

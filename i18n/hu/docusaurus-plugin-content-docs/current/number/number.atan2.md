# Number.Atan2


A két szám hányadosának arkusz tangensét adja vissza.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Azt a szöget adja vissza radiánban, amelynek tangense a megadott két szám (`y` és `x`) `y`/`x` hányadosa.

# Number.Factorial


Visszaadja a szám faktoriálisát.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

A(z) `number` szám faktoriálisát adja vissza.


## Examples

### Example #1
A 10 faktoriálisának meghatározása
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

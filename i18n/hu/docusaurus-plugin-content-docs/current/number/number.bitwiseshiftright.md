# Number.BitwiseShiftRight


Jobbra eltolja a bitkészletet.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

A(z) `number1` értéken elvégzett, a megadott `number2` bittel való bitenkénti jobbra eltolási művelet eredményét adja vissza.

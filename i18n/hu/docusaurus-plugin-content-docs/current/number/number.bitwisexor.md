# Number.BitwiseXor


A két bemenet közötti bitenkénti „XOR” (kizáró vagy) művelet eredményét adja vissza.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

A(z) `number1` és `number2` közötti bitenkénti „XOR” (kizáró vagy) művelet eredményét adja vissza.

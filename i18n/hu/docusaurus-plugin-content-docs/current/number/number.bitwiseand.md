# Number.BitwiseAnd


A két bemenet közötti bitenkénti „És” művelet eredményét adja vissza.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

A(z) `number1` és `number2` közötti bitenkénti „És” művelet eredményét adja vissza.

Number.Bytes

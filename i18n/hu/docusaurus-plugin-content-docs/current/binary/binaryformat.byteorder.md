# BinaryFormat.ByteOrder


Egy függvény által meghatározott bájtsorrendű bináris formátumot ad vissza.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

A(z) `binaryFormat` által meghatározott bájtsorrendű bináris formátumot ad vissza. Az alapértelmezett bájtsorrend a következő: `ByteOrder.BigEndian`.

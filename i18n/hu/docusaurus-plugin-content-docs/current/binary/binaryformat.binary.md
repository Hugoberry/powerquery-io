# BinaryFormat.Binary


Bináris értéket olvasó bináris formátumot ad vissza.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Bináris értéket olvasó bináris formátumot ad vissza. Ha a(z) `length` meg van adva, a bináris érték ennyi bájtot fog tartalmazni. Ha a(z) `length` nincs megadva, a bináris érték a fennmaradó bájtokat fogja tartalmazni. A(z) `length` megadható számként, illetve a bináris adatok előtti hosszúság bináris formátumaként.

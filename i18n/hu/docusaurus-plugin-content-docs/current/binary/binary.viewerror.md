# Binary.ViewError


Létrehoz egy módosított hibarekordot, amely nem vált ki átadást, ha egy nézetben (a Binary.View használatával) definiált kezelő váltja ki.


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Létrehoz egy módosított hibarekordot a(z) `errorRecord` elemből, amely nem vált ki átadást, ha egy nézetben (a Binary.View használatával) definiált kezelő váltja ki.

# Value.VersionIdentity


Az érték verzióazonosítóját adja vissza.


## Syntax

```powerquery
Value.VersionIdentity(
    value as any
) as any
```


## Remarks

A(z) `value` verzióazonosítóját adja vissza, vagy `null` értéket, ha nem rendelkezik verzióval.

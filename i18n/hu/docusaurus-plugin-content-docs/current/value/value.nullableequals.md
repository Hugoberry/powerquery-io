# Value.NullableEquals


Azt adja vissza, hogy két érték egyenlő-e.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Null értéket ad vissza, ha a(z) `value1` vagy `value2` argumentumok bármelyike null értékű, egyéb esetben pedig a Value.Equals értékét adja vissza.

# SqlExpression.ToExpression


A megadott SQL-lekérdezést M-kóddá konvertálja. Ez a függvény csak belső használatra készült.


## Syntax

```powerquery
SqlExpression.ToExpression(
    sql as text,
    environment as record
) as text
```


## Remarks

A megadott `sql`\-lekérdezést M-kódra konvertálja, a(z) `environment` által meghatározott elérhető azonosítókkal. Ez a függvény csak belső használatra készült.

# Variable.Value


A megadott változó értékének visszaadása.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Az aktuális kiértékelési környezet által definiált `identifier` megadott változó értékét adja vissza. Ha a változó nincs definiálva, hiba keletkezik.

# Value.Divide


Az első érték második értékkel való osztásának eredményét adja vissza.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

A(z) `value1` érték `value2` értékkel való osztásának eredményét adja vissza. Megadható egy nem kötelező `precision` paraméter, a függvény alapértelmezés szerint a `Precision.Double` beállítást használja.

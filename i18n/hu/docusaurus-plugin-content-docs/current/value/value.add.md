# Value.Add


A két érték összegét adja vissza.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

A(z) `value1` és `value2` értékek összegét adja vissza. Megadható egy nem kötelező `precision` paraméter, a függvény alapértelmezés szerint a `Precision.Double` beállítást használja.

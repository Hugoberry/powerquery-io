# Value.Multiply


A két érték szorzatát adja vissza.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

A(z) `value1` és `value2` értékek szorzatát adja vissza. Megadható egy nem kötelező `precision` paraméter, a függvény alapértelmezés szerint a `Precision.Double` beállítást használja.

# Value.Equals


Azt adja vissza, hogy két érték egyenlő-e.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Igaz értéket ad vissza, ha a(z) `value1` érték egyenlő a(z) `value2` értékkel, egyéb esetben pedig hamis értéket ad vissza.

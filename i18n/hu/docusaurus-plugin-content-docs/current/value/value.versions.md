# Value.Versions


Az érték elérhető verzióit tartalmazó navigációs táblázatot ad vissza.


## Syntax

```powerquery
Value.Versions(
    value as any
) as table
```


## Remarks

A(z) `value` elérhető verzióit tartalmazó navigációs táblázatot ad vissza.

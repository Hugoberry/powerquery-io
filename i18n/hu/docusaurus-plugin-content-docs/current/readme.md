# Ismerje meg a nyelvet
A Power Query M képletnyelv rendkívül rugalmas adatösszevonási lekérdezések készítésére van optimalizálva. Funkcionális, kis- és nagybetűket megkülönböztető nyelv, amely az F#-hoz hasonló. A Power Query képletnyelvet számos Microsoft-termékben használják, például a Power BI Desktopban, az Excelben és az Analysis Servicesben.

Ez az oldal a Power Query függvények referenciájaként szolgál, gyors és közvetlen hozzáférést biztosítva a részletes információkhoz és gyakorlati példákhoz minden függvény esetében.
:::note
Kérjük, vegye figyelembe, hogy a szerző nem tart igényt semmilyen szerzői jogra az ezen az oldalon bemutatott anyagokkal kapcsolatban. Az információkat abban a reményben gyűjtöttük össze és tesszük elérhetővé, hogy hasznosak lesznek azok számára, akik bővíteni szeretnék a Power Query ismereteiket és alkalmazását.
:::

A webhely keresési funkciója egyszerűsíti a Power Query függvények széles körének felfedezési folyamatát. Mindenképpen próbálja ki (Ctrl+K).

![Az Algolia által biztosított keresési funkció](/img/search.png)

Azok számára, akiket érdekel a mélyebb feltárás vagy a megvalósítási részletek, további információk találhatók a következő GitHub-tárolóban: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Ez a tároló további példákat, frissítéseket és a Power Query fejlesztéséhez és használatához kapcsolódó erőforrásokat tartalmazhat.

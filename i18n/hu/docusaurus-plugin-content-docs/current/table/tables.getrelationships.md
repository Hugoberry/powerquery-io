# Tables.GetRelationships


Lekéri a táblák egy készlete közötti kapcsolatokat.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Lekéri a táblák egy készlete közötti kapcsolatokat. A(z) `tables` készletről feltételezhető, hogy a navigációs táblákhoz hasonló struktúrával rendelkezik. A(z) `dataColumn` által meghatározott oszlop tartalmazza a tényleges adattáblákat.

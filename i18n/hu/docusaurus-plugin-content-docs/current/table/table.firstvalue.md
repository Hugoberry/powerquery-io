# Table.FirstValue


A tábla első sorának első oszlopát adja vissza vagy egy meghatározott alapértelmezett értéket.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

A(z) `table` tábla első sorának első oszlopát adja vissza vagy egy meghatározott alapértelmezett értéket.

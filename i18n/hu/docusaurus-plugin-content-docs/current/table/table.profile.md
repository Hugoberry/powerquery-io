# Table.Profile


Egy tábla oszlopainak profilját adja vissza.


## Syntax

```powerquery
Table.Profile(
    table as table,
    optional additionalAggregates as list
) as table
```


## Remarks

A(z) `table` oszlopainak profilját adja vissza.

Az egyes oszlopok esetében a következo adatokat adja vissza (ha lehetséges):

-   minimum
-   maximum
-   átlag
-   szórás
-   szám
-   null szám
-   eltérok darabszáma

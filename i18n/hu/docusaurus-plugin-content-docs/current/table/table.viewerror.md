# Table.ViewError


Létrehoz egy módosított hibarekordot, amely nem vált ki átadást, ha egy nézetben (a Table.View segítségével) definiált kezelő váltja ki.


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Létrehoz egy módosított hibarekordot (`errorRecord`), amely nem vált ki átadást, ha egy nézetben (a Table.View segítségével) definiált kezelő váltja ki.

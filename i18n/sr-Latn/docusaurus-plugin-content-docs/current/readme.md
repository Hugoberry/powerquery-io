# Otkrijte jezik
Jezik formula Power Query M optimizovan je za izradu veoma fleksibilnih upita za objedinjavanje podataka. To je funkcionalni jezik osetljiv na velika i mala slova, sličan F#. Jezik formula Power Query koristi se u nizu Microsoft proizvoda kao što su Power BI Desktop, Excel i Analysis Services.

Ovaj sajt služi kao referenca za Power Query funkcije, nudeći brz i direktan pristup detaljnim informacijama i praktičnim primerima za svaku funkciju.
:::note
Imajte na umu da autor ne polaže nikakva autorska prava na materijale prikazane na ovom sajtu. Informacije se prikupljaju i pružaju u nadi da će biti korisne onima koji žele da prošire svoje znanje i primenu Power Query-ja.
:::

Funkcija pretrage na ovom veb-sajtu trebalo bi da pojednostavi proces otkrivanja širokog spektra Power Query funkcija. Obavezno je isprobajte (Ctrl+K).

![Funkciju pretrage obezbeđuje Algolia](/img/search.png)

Za one koji su zainteresovani za dublje istraživanje ili detalje implementacije, više informacija može se pronaći u sledećem GitHub repozitorijumu: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Ovaj repozitorijum može sadržati dodatne primere, ažuriranja i resurse relevantne za razvoj i upotrebu Power Query-ja.

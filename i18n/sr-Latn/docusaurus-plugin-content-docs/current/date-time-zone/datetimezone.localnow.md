# DateTimeZone.LocalNow


Vraća trenutni datum i vreme u lokalnoj vremenskoj zoni.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Vraća vrednost `datetimezone` podešenu na trenutni datum i vreme na sistemu. Vraćena vrednost sadrži informacije o vremenskoj zoni koje se odnose na lokalnu vremensku zonu.

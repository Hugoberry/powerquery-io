# Text.Length


Vraća broj znakova.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Vraća broj znakova u tekstu `text`.


## Examples

### Example #1
Otkrivanje koliko se znakova nalazi u tekstu „Hello World“.
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

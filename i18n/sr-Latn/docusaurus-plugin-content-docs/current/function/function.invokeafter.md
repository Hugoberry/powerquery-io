# Function.InvokeAfter


Poziva datu funkciju nakon što je prosleđeno navedeno trajanje.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Vraća rezultat `function` nakon što je trajanje `delay` prosleđeno.



## Category
Function

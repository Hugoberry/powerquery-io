# Value.Add


Vraća zbir dve vrednosti.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vraća zbir `value1` i `value2`. Može se navesti opcionalni parametar `precision`. Podrazumevano se koristi `Precision.Double`.

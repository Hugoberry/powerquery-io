# Value.NullableEquals


Navodi da li su dve vrednosti jednake.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Vraća null ako je bilo koji od argumenata `value1` ili `value2` null, u suprotnom je ekvivalentno Value.Equals.

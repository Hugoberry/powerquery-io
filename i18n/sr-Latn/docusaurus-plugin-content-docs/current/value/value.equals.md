# Value.Equals


Navodi da li su dve vrednosti jednake.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Vraća „true“ ako je vrednost `value1` jednaka vrednosti `value2`. U suprotnom vraća „false“.

# Variable.Value


Vraća vrednost navedene promenljive.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Vraća vrednost navedene promenljive `identifier` definisane u trenutnom okruženju procene. Ako promenljiva nije definisana, javlja se greška.

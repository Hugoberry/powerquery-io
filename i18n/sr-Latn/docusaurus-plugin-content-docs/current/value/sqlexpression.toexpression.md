# SqlExpression.ToExpression


Konvertuje navedeni SQL upit u M kôd. Ova funkcija je namenjena samo za internu upotrebu.


## Syntax

```powerquery
SqlExpression.ToExpression(
    sql as text,
    environment as record
) as text
```


## Remarks

Konvertuje navedeni `sql` upit u M kôd, sa dostupnim identifikatorima koje definiše `environment`. Ova funkcija je namenjena samo za internu upotrebu.

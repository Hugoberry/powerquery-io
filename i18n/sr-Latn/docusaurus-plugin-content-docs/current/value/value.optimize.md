# Value.Optimize


Signali Value.Expression za vraćanje optimizovanog izraza za vrednost.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Kada se koristi u okviru Value.Expression, ako `value` predstavlјa upit koji može da se optimizuje, ova funkcija ukazuje na to da treba da se vrati optimizovani izraz. U suprotnom, `value` se prosleđuje bez efekta.

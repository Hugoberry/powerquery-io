# Value.Divide


Vraća rezultat deljenja prve vrednosti drugom.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vraća rezultat deljenja vrednosti `value1` vrednošću `value2`. Može se navesti opcionalni parametar `precision`. Podrazumevano se koristi `Precision.Double`.

# Cube.Measures


Vraća tabelu koja sadrži skup dostupnih mera.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Vraća tabelu koja sadrži skup dostupnih mera u okviru `cube`. Svaka mera je predstavljena kao funkcija. Mere mogu biti primenjene na kocku pomoću Cube.AddMeasureColumn.

# Cube.AttributeMemberProperty


Vraća svojstvo atributa dimenzije.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Vraća svojstvo `propertyName` atributa dimenzije `attribute`.

# Cube.AttributeMemberId


Vraća jedinstveni identifikator člana iz vrednosti svojstava članova.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Vraća jedinstveni identifikator člana iz vrednosti svojstava članova. `attribute`. Vraća praznu vrednost za sve ostale vrednosti.

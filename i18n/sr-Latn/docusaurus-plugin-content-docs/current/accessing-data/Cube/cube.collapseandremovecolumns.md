# Cube.CollapseAndRemoveColumns


Menja dimenzionu granularnost konteksta filtera za kocku skupljanjem atributa mapiranih na navedene kolone.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Menja dimenzionu granularnost konteksta filtera za `cube` skupljanjem atributa mapiranih na navedene kolone `columnNames`. Kolone se takođe uklanjaju iz tabelarnog prikaza kocke.

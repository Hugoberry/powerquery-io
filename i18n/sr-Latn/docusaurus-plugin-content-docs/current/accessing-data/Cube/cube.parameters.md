# Cube.Parameters


Vraća tabelu sa skupom parametara koji mogu da se primene na kocku.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Vraća tabelu sa skupom parametara koji mogu da se primene na `cube`. Svaki parametar je funkcija koja može da se aktivira da bi se primenio `cube` sa parametrom i argumentima.

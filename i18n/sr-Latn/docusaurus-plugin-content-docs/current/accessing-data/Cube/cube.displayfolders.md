# Cube.DisplayFolders


Vraća ugnežđeno stablo tabela koje predstavlja hijerarhiju objekata (na primer, dimenzije i mere) prikazane fascikle.


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Vraća ugnežđeno stablo tabela koje predstavlja hijerarhiju objekata (na primer, dimenzije i mere) prikazane fascikle koja se može koristiti u `cube`.

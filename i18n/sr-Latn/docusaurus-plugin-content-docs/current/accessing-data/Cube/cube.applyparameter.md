# Cube.ApplyParameter


Vraća kocku nakon primene parametra.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Vraća kocku nakon primene `parameter` sa `arguments` na `cube`.

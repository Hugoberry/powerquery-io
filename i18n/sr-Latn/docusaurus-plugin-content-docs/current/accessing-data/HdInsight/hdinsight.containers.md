# HdInsight.Containers


Vraća navigacionu tabelu koja sadrži kontejnere pronađene na navedenom nalogu iz Azure bezbednog skladišta.


## Syntax

```powerquery
HdInsight.Containers(
    account as text
) as table
```


## Remarks

Vraća navigacionu tabelu koja sadrži red za svaki kontejner pronađen na URL adresi naloga, `account`, iz Azure bezbednog skladišta. Svaki red sadrži vezu do blob objekata kontejnera.

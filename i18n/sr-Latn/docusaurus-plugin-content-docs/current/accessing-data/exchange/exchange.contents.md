# Exchange.Contents


Vraća sadržaj iz Microsoft Exchange naloga.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Vraća tabelu sadržaja sa Microsoft Exchange naloga `mailboxAddress`. Ako se `mailboxAddress` ne navede, koristiće se podrazumevani nalog za akreditiv.

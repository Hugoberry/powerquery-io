# File.Contents


Vraća sadržaj navedene datoteke u binarnom obliku.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Vraća sadržaje datoteke `path` u binarnom obliku. Parametar `options` je trenutno namenjen samo za interno upotrebu.

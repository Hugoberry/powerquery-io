# Hdfs.Files


Vraća tabelu koja sadrži svojstva i sadržaj datoteka pronađenih u navedenoj fascikli i potfasciklama sa Hadoop sistema datoteka.


## Syntax

```powerquery
Hdfs.Files(
    url as text
) as table
```


## Remarks

Vraća tabelu koja sadrži red za svaku datoteku pronađenu na URL adresi fascikle, `url`, kao i u potfasciklama sa Hadoop sistema datoteka. Svaki red sadrži svojstva datoteke i vezu do njenog sadržaja.

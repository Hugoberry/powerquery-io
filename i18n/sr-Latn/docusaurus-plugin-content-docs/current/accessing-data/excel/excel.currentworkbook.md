# Excel.CurrentWorkbook


Vraća sadržaj trenutne Excel radne sveske.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Vraća sadržaj trenutne Excel radne sveske. Vraća tabele, imenovane opsege i dinamičke nizove. Za razliku od funkcije `Excel.Workbook`, ona ne vraća listove.

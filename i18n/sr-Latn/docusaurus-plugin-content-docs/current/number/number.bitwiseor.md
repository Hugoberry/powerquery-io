# Number.BitwiseOr


Vraća rezultat izvršavanja operacije „Or“ na nivou bita između dva unosa.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vraća rezultat izvršavanja operacije „Or“ na nivou bita između `number1` i `number2`.

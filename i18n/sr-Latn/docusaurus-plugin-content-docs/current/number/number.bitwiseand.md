# Number.BitwiseAnd


Vraća rezultat izvršavanja operacije „And“ na nivou bita između dva unosa.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vraća rezultat izvršavanja operacije „And“ na nivou bita između `number1` i `number2`.

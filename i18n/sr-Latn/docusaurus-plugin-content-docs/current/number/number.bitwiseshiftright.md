# Number.BitwiseShiftRight


Pomera skup bitova udesno.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vraća rezultat izvršavanja pomeranja udesno na nivou bita na `number1`, za navedeni broj bitova `number2`.

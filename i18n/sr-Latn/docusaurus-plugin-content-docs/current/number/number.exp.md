# Number.Exp


Podiže e na dati stepen.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Vraća rezultat podizanja e na stepen `number` (eksponencijalna funkcija).

-   `number`: `number` za koji se izračunava eksponencijalna funkcija. Ako je `number` bez vrednosti, `Number.Exp` vraća rezultat bez vrednosti.


## Examples

### Example #1
Podizanje e na treći stepen.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.Ln


Vraća prirodni logaritam broja.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Vraća prirodni logaritam broja, `number`. Ako je `number` bez vrednosti, `Number.Ln` vraća rezultat bez vrednosti.


## Examples

### Example #1
Izračunavanje prirodnog logaritma broja 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

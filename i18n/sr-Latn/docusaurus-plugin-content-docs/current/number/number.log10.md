# Number.Log10


Vraća logaritam broja sa osnovom 10.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Vraća logaritam broja, `number`, sa osnovom 10. Ako je `number` bez vrednosti, `Number.Log10` vraća rezultat bez vrednosti.


## Examples

### Example #1
Izračunavanje logaritma broja 2 sa osnovom 10.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

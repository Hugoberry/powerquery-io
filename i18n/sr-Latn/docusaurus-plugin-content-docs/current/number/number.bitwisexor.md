# Number.BitwiseXor


Vraća rezultat izvršavanja operacije „XOR“ (isključivo OR) na nivou bita između dva unosa.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vraća rezultat izvršavanja operacije „XOR“ (isključivo OR) na nivou bita između `number1` i `number2`.

Number.Bytes

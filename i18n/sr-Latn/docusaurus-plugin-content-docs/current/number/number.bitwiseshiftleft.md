# Number.BitwiseShiftLeft


Pomera skup bitova ulevo.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vraća rezultat izvršavanja pomeranja ulevo na nivou bita na `number1`, za navedeni broj bitova `number2`.

Number.Bytes

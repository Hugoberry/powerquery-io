# Number.Atan2


Vraća arkus tangens za deljenje dva broja.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Vraća ugao u radijanima čiji je tangens količnik `y`/`x` dva broja `y` i `x`.

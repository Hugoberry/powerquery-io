# Number.Sin


Vraća sinus broja.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Vraća sinus za `number`.


## Examples

### Example #1
Pronalaženje sinusa ugla 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

# Number.Abs


Vraća apsolutnu vrednost broja.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Vraća apsolutnu vrednost za `number`. Ako je `number` bez vrednosti, `Number.Abs` vraća rezultat bez vrednosti.

-   `number`: `number` za koji se izračunava apsolutna vrednost.


## Examples

### Example #1
Apsolutna vrednost za -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

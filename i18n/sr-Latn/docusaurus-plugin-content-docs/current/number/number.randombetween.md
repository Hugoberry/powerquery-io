# Number.RandomBetween


Vraća nasumičan broj između dva broja.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Vraća nasumičan broj između `bottom` i `top`.


## Examples

### Example #1
Dobijanje nasumičnog broja između 1 i 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

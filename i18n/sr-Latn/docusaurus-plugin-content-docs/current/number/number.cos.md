# Number.Cos


Vraća kosinus broja.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Vraća kosinus navedenog ugla.

-   `number`: Ugao izražen radijanima.


## Examples

### Example #1
Pronalaženje kosinusa ugla 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Pronađite kosinus π radijana.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

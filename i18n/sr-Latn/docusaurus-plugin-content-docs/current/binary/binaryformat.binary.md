# BinaryFormat.Binary


Vraća binarni format koji čita binarnu vrednost.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Vraća binarni format koji čita binarnu vrednost. Ako je navedena `length`, binarna vrednost će sadržati toliko bajtova. Ako nije navedena `length`, binarna vrednost će sadržati preostale bajtove. `length` može se navesti kao broj ili kao binarni format dužine koja prethodi binarnim podacima.

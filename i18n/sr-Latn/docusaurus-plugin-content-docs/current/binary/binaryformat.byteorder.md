# BinaryFormat.ByteOrder


Vraća binarni format sa rasporedom bajtova koji navodi funkcija.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Vraća binarni format sa rasporedom bajtova koji navodi `binaryFormat`. Podrazumevani raspored bajtova je `ByteOrder.BigEndian`.

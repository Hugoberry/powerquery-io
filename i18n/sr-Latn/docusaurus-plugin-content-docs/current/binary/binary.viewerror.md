# Binary.ViewError


Kreira izmenjeni zapis o grešci koji neće aktivirati vraćanje kada ga podiže rukovalac definisan u prikazu (putem binarnog prikaza).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Kreira izmenjeni zapis o grešci iz `errorRecord` koji neće pokrenuti vraćanje kada ga podiže rukovalac definisan u prikazu (putem binarnog prikaza).

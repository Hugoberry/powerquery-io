# Type.TableSchema


Vraća tabelu koja sadrži opis kolona (tj. šemu) navedenog tipa tabele.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Vraća tabelu koja opisuje kolone za `tableType`.

Pogledajte dokumentaciju za `Table.Schema` da biste videli opis date tabele.

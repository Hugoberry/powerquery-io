# Tables.GetRelationships


Preuzima relacije u skupu tabela.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Preuzima relacije u skupu tabela. Za skup `tables` se pretpostavlja da ima sličnu strukturu kao navigaciona tabela. Kolona koju definiše `dataColumn` sadrži stvarne tabele sa podacima.

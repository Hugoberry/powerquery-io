# Table.ViewError


Kreira izmenjeni zapis o grešci koji neće aktivirati vraćanje kada ga podiže rukovalac definisan u prikazu (putem table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Kreira izmenjeni zapis o grešci iz `errorRecord` koji neće pokrenuti vraćanje kada ga podiže rukovalac definisan u prikazu (putem tabele.View).

# Table.Profile


Vraća profil kolona tabele.


## Syntax

```powerquery
Table.Profile(
    table as table,
    optional additionalAggregates as list
) as table
```


## Remarks

Vraća profil za kolone u `table`.

Sledeće informacije se vraćaju za svaku kolonu (kada je primenjivo):

-   minimalno
-   maksimalno
-   prosek
-   standardna devijacija
-   broj
-   broj bez vrednosti
-   posebno brojanje

# Table.FirstValue


Vraća prvu kolonu prvog reda tabele ili navedenu podrazumevanu vrednost.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Vraća prvu kolonu prvog reda tabele `table` ili navedenu podrazumevanu vrednost.

Table.Row operations

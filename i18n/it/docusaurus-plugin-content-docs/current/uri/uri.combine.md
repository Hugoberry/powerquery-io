# Uri.Combine


Restituisce un URI assoluto che rappresenta la combinazione dell'URI di base e dell'URI relativo di input.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Restituisce un URI assoluto che rappresenta la combinazione di `baseUri` e `relativeUri` di input.

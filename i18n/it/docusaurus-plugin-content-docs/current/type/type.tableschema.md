# Type.TableSchema


Restituisce una tabella contenente una descrizione delle colonne, ovvero lo schema, del tipo di tabella specificato.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Restituisce una tabella che descrive le colonne di `tableType`.

Per una descrizione della tabella risultante, vedere la documentazione per `Table.Schema`.

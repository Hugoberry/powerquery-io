# Number.BitwiseAnd


Restituisce il risultato dell'esecuzione di un'operazione "And" bit per bit tra i due input.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Restituisce il risultato dell'esecuzione di un'operazione "And" bit per bit tra `number1` e `number2`.



## Category
Number.Bytes

# Number.BitwiseShiftRight


Scorre i set di bit verso destra.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Restituisce il risultato dell'esecuzione di uno scorrimento bit per bit verso destra su `number1`, in base al numero di bit specificato `number2`.

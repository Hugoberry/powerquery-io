# Number.RandomBetween


Restituisce un numero casuale compreso tra due numeri.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Restituisce un numero casuale compreso tra `bottom` e `top`.


## Examples

### Example #1
Ottenere un numero casuale compreso tra 1 e 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

# Number.Atan2


Restituisce l'arcotangente della divisione dei due numeri.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Restituisce l'angolo, in radianti, la cui tangente è il quoziente `y`/`x` dei due numeri `y` e `x`.

# Number.Cos


Restituisce il coseno del numero.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Restituisce il coseno dell'angolo specificato.

-   `number`: angolo misurato in radianti.


## Examples

### Example #1
Trovare il coseno dell'angolo 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Trova il coseno di π radianti.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

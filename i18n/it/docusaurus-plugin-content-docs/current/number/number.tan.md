# Number.Tan


Restituisce la tangente del numero.


## Syntax

```powerquery
Number.Tan(
    number as number
) as number
```


## Remarks

Restituisce la tangente di `number`.


## Examples

### Example #1
Trovare la tangente dell'angolo 1.
```powerquery
Number.Tan(1)
```

Result: 
```powerquery
1.5574077246549023
```

# Number.BitwiseOr


Restituisce il risultato dell'esecuzione di un'operazione "Or" bit per bit tra i due input.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Restituisce il risultato dell'esecuzione di un'operazione "Or" bit per bit tra `number1` e `number2`.



## Category
Number.Bytes

# Number.BitwiseNot


Restituisce un byte per ogni bit che è l'opposto dell'input.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Restituisce il risultato dell'esecuzione di un'operazione "Not" bit per bit su `number`.



## Category
Number.Bytes

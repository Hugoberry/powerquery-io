# Webtrends.Tables


Immettere l'ID profilo associato all'account Webtrends.


## Syntax

```powerquery
Webtrends.Tables(
    ProfileId as text,
    optional startDate as date,
    optional endDate as date
) as table
```


## Remarks

Restituisce una tabella con i dati Webtrends pertinenti.

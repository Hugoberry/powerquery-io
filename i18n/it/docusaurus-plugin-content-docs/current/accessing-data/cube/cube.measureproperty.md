# Cube.MeasureProperty


Restituisce una proprietà di una misura (proprietà della cella).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Restituisce la proprietà `propertyName` della misura `measure`.

Cube

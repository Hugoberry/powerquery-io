# Cube.ApplyParameter


Restituisce un cubo dopo avervi applicato un parametro.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Restituisce un cubo dopo aver applicato `parameter` con `arguments` a `cube`.

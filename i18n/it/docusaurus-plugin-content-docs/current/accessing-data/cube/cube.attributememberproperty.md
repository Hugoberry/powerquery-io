# Cube.AttributeMemberProperty


Restituisce una proprietà di un attributo dimensione.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Restituisce la proprietà `propertyName` dell'attributo dimensione `attribute`.

Cube

# File.Contents


Restituisce il contenuto del file specificato come binario.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Restituisce il contenuto del file, `path`, come binario. Il parametro `options` è attualmente destinato solo all'uso interno.

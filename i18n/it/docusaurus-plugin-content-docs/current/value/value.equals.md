# Value.Equals


Restituisce un valore che indica se due valori sono uguali.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Restituisce true se il valore `value1` è uguale al valore `value2`, in caso contrario false.

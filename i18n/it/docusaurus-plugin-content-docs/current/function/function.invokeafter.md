# Function.InvokeAfter


Richiama la funzione specificata una volta trascorsa la durata specificata.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Restituisce il risultato della richiamata di `function` una volta trascorsa la durata `delay`.



## Category
Function

# Function.IsDataSource


Restituisce se una determinata funzione è considerata un'origine dati o meno.


## Syntax

```powerquery
Function.IsDataSource(
    function as function
) as logical
```


## Remarks

Restituisce se la funzione `function` è considerata un'origine dati o meno.

# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Inverte il testo `text` specificato.


## Examples

### Example #1
Inverte il testo "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

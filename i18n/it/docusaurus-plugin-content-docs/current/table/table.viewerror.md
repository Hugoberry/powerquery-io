# Table.ViewError


Crea un record di errore modificato che non attiva un fallback quando viene generato da un gestore definito in una vista (tramite Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Crea un record di errore modificato da `errorRecord` che non attiva un fallback quando viene generato da un gestore definito in una vista (tramite Table.View).

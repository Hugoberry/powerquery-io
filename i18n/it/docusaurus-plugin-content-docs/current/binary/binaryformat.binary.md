# BinaryFormat.Binary


Restituisce un formato binario che legge un valore binario.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Restituisce un formato binario che legge un valore binario. Se `length` viene specificato, il valore binario conterrà lo stesso numero di byte. Se `length` non viene specificato, il valore binario conterrà i byte rimanenti. `length` può essere specificato come numero o come formato binario della lunghezza che precede i dati binari.

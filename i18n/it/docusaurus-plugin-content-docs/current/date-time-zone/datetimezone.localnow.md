# DateTimeZone.LocalNow


Restituisce la data e l'ora correnti nel fuso orario locale.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Restituisce un valore `datetimezone` impostato sulla data e sull'ora correnti del sistema. Il valore restituito contiene le informazioni del fuso orario che rappresentano il fuso orario locale.

# Table.ReplacePartitionKey


Sostituisce la chiave di partizione della tabella specificata.


## Syntax

```powerquery
Table.ReplacePartitionKey(
    table as table,
    partitionKey as list
) as table
```


## Remarks

Sostituisce la chiave di partizione della tabella specificata.

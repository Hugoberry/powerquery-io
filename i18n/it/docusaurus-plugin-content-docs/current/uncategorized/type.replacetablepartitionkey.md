# Type.ReplaceTablePartitionKey


Restituisce un nuovo tipo di tabella con la chiave di partizione sostituita dalla chiave di partizione specificata.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Restituisce un nuovo tipo di tabella con la chiave di partizione sostituita dalla chiave di partizione specificata.

# DateTime.FixedLocalNow


Pateikiama vietinės laiko juostos dabartinė data ir laikas. Ši reikšmė yra fiksuota ir nepasikeis per vėlesnius iškvietimus.


## Syntax

```powerquery
DateTime.FixedLocalNow(

) as datetime
```


## Remarks

Pateikiamas `datetime` reikšmių rinkinys, skirtas dabartinei sistemos datai ir laikui. Ši reikšmė yra fiksuota ir nepasikeis per vėlesnius iškvietimus, skirtingai nei DateTime.LocalNow, kuri gali pateikti skirtingas reikšmes vykdant išraišką.

# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

„Teams“ analizės jungtis leidžia gauti įžvalgų apie „Teams“ naudojimą. Prieinami tiek jūsų asmeninės veiklos „Teams“, tiek „Teams“, kurių narys esate, veiklos duomenys.

Prieinami ankstesnių 90 dienų duomenys.

Išsamesnės informacijos apie turimus duomenis ieškokite šioje žinyno dokumentacijoje:

-   **„Teams“ naudojimas:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **„Teams“ vartotojo veikla:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

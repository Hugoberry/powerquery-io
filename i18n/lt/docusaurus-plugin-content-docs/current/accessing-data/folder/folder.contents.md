# Folder.Contents


Pateikiama lentelė su failų ir aplankų, rastų nurodytame aplanke, ypatybėmis ir turiniu.


## Syntax

```powerquery
Folder.Contents(
    path as text,
    optional options as record
) as table
```


## Remarks

Pateikiama lentelė, kurioje yra kiekvienam aplankui ir failui, rastam aplanke `path`, skirta eilutė. Kiekvienoje eilutėje yra aplanko arba failo ypatybės ir turinio saitas. Parametras `options` šiuo metu skirtas tik vidiniam naudojimui.

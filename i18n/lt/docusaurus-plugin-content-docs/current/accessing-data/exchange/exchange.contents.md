# Exchange.Contents


Pateikiamas turinys iš „Microsoft Exchange“ abonemento.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Pateikiama turinio iš „Microsoft Exchange“ paskyros `mailboxAddress` lentelė. Jei `mailboxAddress` nenurodyta, bus naudojami numatytosios paskyros kredencialai.

# Hdfs.Files


Pateikiama lentelė su failų, rastų nurodytame aplanke ir poaplankiuose iš „Hadoop“ failų sistemos, ypatybėmis ir turiniu.


## Syntax

```powerquery
Hdfs.Files(
    url as text
) as table
```


## Remarks

Pateikiama lentelė, kurioje yra kiekvienam failui, rastam naudojant aplanko URL, `url`, ir poaplankiams iš „Hadoop“ failų sistemos skirta eilutė. Kiekvienoje eilutėje yra failo ypatybės ir jo turinio saitas.

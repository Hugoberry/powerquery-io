# HdInsight.Containers


Pateikiama naršymo lentelė, kurioje yra konteineriai, rasti nurodytame „Azure“ saugyklos abonemente.


## Syntax

```powerquery
HdInsight.Containers(
    account as text
) as table
```


## Remarks

Pateikiama naršymo lentelė, kurioje yra po eilutę kiekvienam konteineriui, rastam „Azure“ saugyklos abonemento URL `account`. Kiekvienoje eilutėje yra konteinerio didelio dvejetainio objekto saitas.

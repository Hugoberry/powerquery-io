# HdInsight.Files


Pateikiama lentelė, kurioje yra „Azure“ saugyklos nurodytame konteineryje rastų didelių dvejetainių objektų ypatybės ir turinys.


## Syntax

```powerquery
HdInsight.Files(
    account as text,
    containerName as text
) as table
```


## Remarks

Pateikiama lentelė, kurioje yra po eilutę kiekvienam didelio dvejetainio objekto failui, rastam „Azure“ saugyklos konteinerio URL `account`. Kiekvienoje eilutėje yra failo ypatybės ir jo turinio saitas.

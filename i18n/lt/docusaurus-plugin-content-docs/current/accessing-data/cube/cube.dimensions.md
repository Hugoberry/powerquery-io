# Cube.Dimensions


Pateikiama lentelė, kurioje yra galimų dimensijų rinkinys.


## Syntax

```powerquery
Cube.Dimensions(
    cube as table
) as table
```


## Remarks

Pateikiama lentelė, kurioje yra `cube` galimų dimensijų rinkinys. Kiekviena dimensija yra lentelė, kurioje yra dimensijos atributų rinkinys, ir dimensijų lentelėje yra kiekvienam dimensijos atributui skirtas stulpelis. Dimensijas galima išplėsti kube naudojant Cube.AddAndExpandDimensionColumn.

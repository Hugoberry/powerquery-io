# Cube.DisplayFolders


Pateikiamas įdėtasis lentelių medis, nurodantis objektų (pvz., dimensijų ir matų) aplankų hierarchijos rodymo tvarką.


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Pateikiamas įdėtasis lentelių medis, nurodantis objektų (pvz., dimensijų ir matų), kuriuos galima naudoti `cube`, aplankų hierarchijos rodymo tvarką.

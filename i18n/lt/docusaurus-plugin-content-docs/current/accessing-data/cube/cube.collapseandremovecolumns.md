# Cube.CollapseAndRemoveColumns


Pakeičiamas kubo filtro konteksto dimensijų detalumo lygis sutraukiant atributus, susietus su nurodytais stulpeliais.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Pakeičiamas `cube` filtro konteksto dimensijų detalumo lygis sutraukiant atributus, susietus su nurodytais stulpeliais `columnNames`. Stulpeliai taip pat pašalinami iš kubo lentelės rodinio.

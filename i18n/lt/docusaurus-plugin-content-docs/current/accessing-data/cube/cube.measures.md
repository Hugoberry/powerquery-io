# Cube.Measures


Pateikiama lentelė, kurioje yra galimų matų rinkinys.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Pateikiama lentelė, kurioje yra `cube` galimų matų rinkinys. Kiekvienas matas pateikiamas kaip funkcija. Matus galima taikyti kubui naudojant Cube.AddMeasureColumn.

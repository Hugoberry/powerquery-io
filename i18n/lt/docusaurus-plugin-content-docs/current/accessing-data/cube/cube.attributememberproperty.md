# Cube.AttributeMemberProperty


Pateikiama dimensijos atributo ypatybė.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Pateikiama dimensijos atributo `attribute` ypatybė `propertyName`.

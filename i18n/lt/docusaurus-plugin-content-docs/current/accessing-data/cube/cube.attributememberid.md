# Cube.AttributeMemberId


Pateikiamas unikalus nario identifikatorius iš nario ypatybės vertės.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Pateikiamas unikalus nario identifikatorius iš nario ypatybės vertės. `attribute`. Naudojant bet kurias kitas vertes pateikiamas nulis.

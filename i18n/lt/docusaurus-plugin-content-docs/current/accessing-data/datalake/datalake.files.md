# DataLake.Files


Įveskite savo „Azure Data Lake Storage“ paskyros URL.


## Syntax

```powerquery
DataLake.Files(
    url as text,
    optional options as record
) as table
```


## Remarks

Pateikiama lentelė, kurioje yra kiekvieno failo, rasto „Azure Data Lake Storage Gen1“ naudojant `URL`, eilutė. Kiekvienoje eilutėje yra failo ypatybės ir saitas į jo turinį.

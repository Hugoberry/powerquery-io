# DataLake.Contents


Įveskite savo „Azure Data Lake Storage Gen1“ paskyros URL.


## Syntax

```powerquery
DataLake.Contents(
    url as text,
    optional options as record
) as table
```


## Remarks

Pateikiama lentelė, kurioje yra kiekvieno aplanko ir failo, rastų „Azure Data Lake Storage Gen1“ naudojant `URL`, eilutė. Kiekvienoje eilutėje yra aplanko ir failo ypatybės bei saitas į jų turinį.

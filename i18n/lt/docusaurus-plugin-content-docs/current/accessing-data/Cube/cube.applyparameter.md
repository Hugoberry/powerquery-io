# Cube.ApplyParameter


Pritaikius parametrą pateikia kubą.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Pritaikius `parameter` su `arguments` `cube` pateikia kubą.

# Cube.Parameters


Pateikiama lentelė, kurioje yra parametrų rinkinys, galimas taikyti kubui.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Pateikiama lentelė, kurioje yra parametrų rinkinys, galimas taikyti `cube`. Kiekvienas parametras yra funkcija, kurią galima iškviesti norint gauti `cube` su pritaikytais parametru ir argumentais.

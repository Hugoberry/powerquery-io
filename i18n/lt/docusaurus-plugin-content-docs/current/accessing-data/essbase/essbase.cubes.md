# Essbase.Cubes


„Essbase“ egzemplioriuje pateikiami pagal „Essbase“ serverį sugrupuoti kubai.


## Syntax

```powerquery
Essbase.Cubes(
    url as text,
    optional options as record
) as table
```


## Remarks

Pateikiama pagal „Essbase“ serverį sugrupuotų kubų lentelė iš „Essbase“ egzemplioriaus APS serveryje `url`. Galima nurodyti pasirinktinį įrašo parametrą `options` ir valdyti šias parinktis:

-   `CommandTimeout` : Trukmė, kontroliuojanti serverio užklausos vykdymo laiką prieš ją atšaukiant. Numatytoji reikšmė yra dešimt minučių.

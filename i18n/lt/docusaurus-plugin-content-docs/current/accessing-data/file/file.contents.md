# File.Contents


Nurodyto failo turinys pateikiamas kaip dvejetainiai duomenys.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Grąžina failo, `path`, turinį kaip dvejetainį. `options` parametras šiuo metu skirtas tik vidiniam naudojimui.

# DateTimeZone.LocalNow


Pateikiama vietinės laiko juostos dabartinė data ir laikas.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Pateikiamas `datetimezone` reikšmių rinkinys, skirtas dabartinei sistemos datai ir laikui. Pateiktoje reikšmėje yra laiko juostos informacija, nurodanti vietinę laiko juostą.

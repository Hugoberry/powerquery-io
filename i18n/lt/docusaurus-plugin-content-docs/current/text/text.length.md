# Text.Length


Pateikiamas simbolių skaičius.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Pateikiamas simbolių tekste `text` skaičius.


## Examples

### Example #1
Sužinokite, kiek simbolių yra tekste „Hello World“.
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

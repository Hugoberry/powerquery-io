# Type.ListItem


Pateikiamas elemento tipas iš sąrašo tipo.


## Syntax

```powerquery
Type.ListItem(
    type as type
) as type
```


## Remarks

Pateikiamas elemento tipas iš sąrašo `type`.


## Examples

### Example #1
Raskite elemento tipą sąraše `{number}`.
```powerquery
Type.ListItem(type {number})
```

Result: 
```powerquery
type number
```

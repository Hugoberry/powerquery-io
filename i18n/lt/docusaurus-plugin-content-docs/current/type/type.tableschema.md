# Type.TableSchema


Pateikiama lentelė su nurodyto lentelės tipo stulpelių aprašu (t. y. schema).


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Pateikiama lentelė, apibūdinanti `tableType` stulpelius.

Pateiktos lentelės aprašą žr. `Table.Schema` dokumentacijoje.

# Value.Add


Pateikiama dviejų reikšmių suma.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Pateikiama `value1` ir `value2` suma. Galima nurodyti pasirenkamą parametrą `precision`; pagal numatytuosius parametrus naudojamas `Precision.Double`.

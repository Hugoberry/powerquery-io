# Value.Optimize


Duoda ženklą Value.Expression, kad pateiktų optimizuotą reikšmės reiškinį.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Kai naudojama reiškinyje Value.Expression, jei `value` reiškia užklausą, kurią galima optimizuoti, ši funkcija nurodo, kad turi būti pateiktas optimizuotas reiškinys. Priešingu atveju `value` bus perduota be jokio poveikio.

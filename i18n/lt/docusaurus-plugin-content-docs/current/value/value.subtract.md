# Value.Subtract


Pateikiamas dviejų reikšmių skirtumas.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Pateikiamas `value1` ir `value2` skirtumas. Galima nurodyti pasirenkamą parametrą `precision`; pagal numatytuosius parametrus naudojamas `Precision.Double`.

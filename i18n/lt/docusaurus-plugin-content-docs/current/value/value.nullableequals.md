# Value.NullableEquals


Nurodoma, ar dvi reikšmės yra lygios.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Pateikiama neapibrėžta reikšmė, jei argumentas `value1` arba `value2` yra neapibrėžtas; priešingu atveju atitinka Value.Equals.

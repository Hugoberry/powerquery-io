# Value.Divide


Pateikiamas pirmosios reikšmės padalijimo iš antrosios rezultatas.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Pateikiamas `value1` padalijimo iš `value2` rezultatas. Galima nurodyti pasirenkamą parametrą `precision`; pagal numatytuosius parametrus naudojamas `Precision.Double`.

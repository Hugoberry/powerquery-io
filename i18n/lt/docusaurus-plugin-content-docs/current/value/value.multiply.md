# Value.Multiply


Pateikiamas dviejų reikšmių rezultatas.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Pateikiamas `value1` dauginimo iš `value2` rezultatas. Galima nurodyti pasirenkamą parametrą `precision`; pagal numatytuosius parametrus naudojamas `Precision.Double`.

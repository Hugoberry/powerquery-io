# Value.Alternates


Išreiškiami alternatyvūs užklausų planai.


## Syntax

```powerquery
Value.Alternates(
    alternates as list
) as any
```


## Remarks

Išreiškia alternatyvius užklausų planus užklausų plano išraiškoje, gautoje naudojant `Value.Expression(Value.Optimize(...))`. Neskirta naudoti kitais tikslais.

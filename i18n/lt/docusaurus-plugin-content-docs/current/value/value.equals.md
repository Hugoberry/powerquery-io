# Value.Equals


Nurodoma, ar dvi reikšmės yra lygios.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Pateikiama „true“, jei reikšmė `value1` yra lygi reikšmei `value2`; priešingu atveju pateikiama „false“.

# Variable.ValueOrDefault


Pateikiama nurodyto kintamojo reikšmė arba numatytoji reikšmė, jei kintamasis neapibrėžtas.


## Syntax

```powerquery
Variable.ValueOrDefault(
    identifier as text,
    optional defaultValue as any
) as any
```


## Remarks

Pateikiama nurodyto kintamojo `identifier` reikšmė, apibrėžto dabartinėje vertinimo aplinkoje. Jei kintamasis neapibrėžtas, pateikiamas pasirinktinis `defaultValue`.

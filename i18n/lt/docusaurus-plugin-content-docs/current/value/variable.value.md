# Variable.Value


Pateikiama nurodyto kintamojo reikšmė.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Pateikiama nurodyto kintamojo `identifier` reikšmė, apibrėžto dabartinėje vertinimo aplinkoje. Jei kintamasis neapibrėžtas, pateikiama klaida.

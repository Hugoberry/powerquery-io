# Pažinkite kalbą
Power Query M formulių kalba optimizuota itin lanksčioms duomenų jungimo užklausoms kurti. Tai funkcinė, didžiosioms ir mažosioms raidėms jautri kalba, panaši į F#. Power Query formulių kalba naudojama daugelyje „Microsoft“ produktų, tokių kaip „Power BI Desktop“, „Excel“ ir „Analysis Services“.

Ši svetainė yra Power Query funkcijų žinynas, suteikiantis greitą ir tiesioginę prieigą prie išsamios informacijos ir praktinių pavyzdžių kiekvienai funkcijai.
:::note
Atkreipkite dėmesį, kad autorius nereiškia jokių autorių teisių į šioje svetainėje pateiktą medžiagą. Informacija renkama ir teikiama tikintis, kad ji bus naudinga tiems, kurie nori praplėsti savo žinias ir Power Query taikymą.
:::

Šios svetainės paieškos funkcija turėtų supaprastinti plataus Power Query funkcijų spektro atradimo procesą. Būtinai išbandykite ją (Ctrl+K).

![Paieškos funkciją teikia „Algolia“](/img/search.png)

Tiems, kurie domisi gilesniu tyrinėjimu ar diegimo detalėmis, daugiau informacijos galima rasti šioje „GitHub“ saugykloje: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Šioje saugykloje gali būti papildomų pavyzdžių, naujinių ir išteklių, susijusių su Power Query kūrimu ir naudojimu.

# BinaryFormat.ByteOrder


Pateikiamas dvejetainis formatas, baitų eilę nurodo funkcija.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Pateikiamas dvejetainis formatas, baitų eilę nurodo `binaryFormat`. Numatytoji baitų eilė: `ByteOrder.BigEndian`.

# Binary.Split


Nurodyta dvejetainis elementas išskaidomas į dvejetainių sąrašą naudojant nurodytą puslapio formatą.


## Syntax

```powerquery
Binary.Split(
    binary as binary,
    pageSize as number
) as list
```


## Remarks

`binary` išskaido į dvejetainių sąrašą, kuriame pirmasis išvesties sąrašo elementas yra dvejetainis su pirmaisiais (-ųjų) šaltinio dvejetainio elemento `pageSize` baitais (-ų), antrasis išvesties sąrašo elementas yra dvejetainis elementas su kitais (-ų) šaltinio dvinario elemento `pageSize` baitais (-ų) ir t. t.

# BinaryFormat.Binary


Pateikiamas dvejetainis formatas, kuris perskaito dvejetainę reikšmę.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Pateikiamas dvejetainis formatas, kuris perskaito dvejetainę reikšmę. Jei nurodyta `length`, dvejetainė reikšmė turės daug baitų. Jei `length` nenurodyta, dvejetainė reikšmė turės likusius baitus. `length` galima nurodyti arba kaip skaičių, arba kaip ilgio dvejetainį formatą, kuris nurodomas prieš dvejetainius duomenis.

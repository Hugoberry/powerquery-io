# Function.InvokeAfter


Praėjus nurodytai trukmei iškviečiama duota funkcija.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Praėjus trukmei `delay` pateikiamas `function` iškvietimo rezultatas.

Function

# Uri.Combine


Pateikiamas absoliutusis URI, kuris yra įvesties pagrindinio URI ir santykinio URI derinys.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Pateikiamas absoliutusis URI, kuris yra įvesties `baseUri` ir `relativeUri` derinys.

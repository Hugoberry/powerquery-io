# Table.ViewError


Sukuriamas modifikuotas klaidos įrašas, kuris nesuaktyvins atsarginio įrašo, kai jį pateikia rodinyje apibrėžta apdorojimo programa (per Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Sukuriamas modifikuotas klaidos įrašas iš `errorRecord`, kuris nesuaktyvins atsarginio įrašo, kai jį pateikia rodinyje apibrėžta apdorojimo programa (per Table.View).

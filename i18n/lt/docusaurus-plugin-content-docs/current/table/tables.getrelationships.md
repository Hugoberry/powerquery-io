# Tables.GetRelationships


Gaunami ryšiai tarp lentelių rinkinio.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Gaunami ryšiai tarp lentelių rinkinio. Laikoma, kad rinkinio `tables` struktūra yra panaši į naršymo lentelės struktūrą. `dataColumn` apibrėžtame stulpelyje yra faktinės duomenų lentelės.

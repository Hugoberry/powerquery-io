# Table.FirstValue


Pateikiamas lentelės pirmosios eilutės pirmasis stulpelis arba nurodyta numatytoji reikšmė.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Pateikiamas lentelės `table` pirmosios eilutės pirmasis stulpelis arba nurodyta numatytoji reikšmė.

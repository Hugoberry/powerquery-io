# Number.Atan2


Pateikiamas dviejų skaičių dalybos arktangentas.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Pateikiamas kampas radianais, kurio tangentas yra dalmuo `y`/`x` dviejų skaičių `y` ir `x`.

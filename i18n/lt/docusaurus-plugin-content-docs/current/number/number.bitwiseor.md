# Number.BitwiseOr


Pateikiamas bitų „Or“ operacijos tarp dviejų įvesčių vykdymo rezultatas.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Pateikiamas bitų „Or“ operacijos tarp `number1` ir `number2` vykdymo rezultatas.

Number.Bytes

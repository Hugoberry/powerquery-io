# Number.BitwiseXor


Pateikiamas bitų „XOR“ („Exclusive-OR“) operacijos tarp dviejų įvesčių vykdymo rezultatas.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Pateikiamas bitų „XOR“ („Exclusive-OR“) operacijos tarp `number1` ir `number2` vykdymo rezultatas.

Number.Bytes

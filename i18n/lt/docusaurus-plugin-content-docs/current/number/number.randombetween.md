# Number.RandomBetween


Pateikiamas atsitiktinis skaičius iš dviejų skaičių.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Pateikiamas atsitiktinis skaičius iš `bottom` ir `top`.


## Examples

### Example #1
Gaukite atsitiktinį skaičių nuo 1 iki 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

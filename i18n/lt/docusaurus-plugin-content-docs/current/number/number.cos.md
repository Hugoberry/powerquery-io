# Number.Cos


Pateikiamas skaičiaus kosinusas.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Grąžina nurodyto kampo kosinusą.

-   `number`: radianais matuojamas kampas.


## Examples

### Example #1
Raskite kampo 0 kosinusą.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Raskite π radianų kosinuso reikšmę.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

# Number.BitwiseNot


Pateikiamas baitas, kuriame kiekvienas bitas yra priešingas įvesčiai.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Pateikiamas bitų „Not“ operacijos vykdymo `number` rezultatas.



## Category
Number.Bytes

# Number.Exp


Pakelia e nurodytu laipsniu.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Pateikiamas `number` laipsniu pakelto e rezultatas (eksponentinė funkcija).

-   `number`: `number`, kurio eksponentinė funkcija turi būti skaičiuojama. Jei `number` yra neapibrėžta, `Number.Exp` pateikia neapibrėžtą reikšmę.


## Examples

### Example #1
Pakelkite e 3 laipsniu.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

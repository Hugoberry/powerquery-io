# Number.Permutations


Pateikiamas perstatų skaičius.


## Syntax

```powerquery
Number.Permutations(
    setSize as number,
    permutationSize as number
) as number
```


## Remarks

Pateikiamas skaičius perstatų, kurias galima sugeneruoti iš elementų skaičiaus, `setSize`, su nurodytu perstatos dydžiu, `permutationSize`.


## Examples

### Example #1
Raskite skaičių perstatų iš 5 elementų grupėse iš 3.
```powerquery
Number.Permutations(5, 3)
```

Result: 
```powerquery
60
```

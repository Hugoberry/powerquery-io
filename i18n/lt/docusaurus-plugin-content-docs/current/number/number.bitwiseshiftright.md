# Number.BitwiseShiftRight


Nustatyti bitai perstumiami į dešinę.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Pateikiamas bitų perstūmimo į dešinę vykdymo `number1` pagal nurodytą bitų `number2` skaičių rezultatas.

# Number.Abs


Pateikiama absoliučioji skaičiaus reikšmė.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Pateikiama absoliučioji `number` reikšmė. Jei `number` yra neapibrėžta, `Number.Abs` pateikia neapibrėžtą reikšmę.

-   `number`: `number`, kurio absoliučioji reikšmė turi būti skaičiuojama.


## Examples

### Example #1
Absoliučioji -3 reikšmė.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Number.Sin


Pateikiamas skaičiaus sinusas.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Pateikiamas `number` sinusas.


## Examples

### Example #1
Raskite kampo 0 sinusą.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

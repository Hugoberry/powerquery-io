# Number.BitwiseShiftLeft


Nustatyti bitai perstumiami į kairę.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Pateikiamas bitų perstūmimo į kairę vykdymo `number1` pagal nurodytą bitų `number2` skaičių rezultatas.

Number.Bytes

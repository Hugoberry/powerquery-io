# Number.Ln


Pateikiamas natūrinis skaičiaus logaritmas.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Pateikiamas natūrinis skaičiaus `number` logaritmas. Jeigu `number` yra neapibrėžta, `Number.Ln` pateikia neapibrėžtą reikšmę.


## Examples

### Example #1
Gaukite natūrinį skaičiaus 15 logaritmą.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

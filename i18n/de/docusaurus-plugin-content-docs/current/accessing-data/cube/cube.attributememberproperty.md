# Cube.AttributeMemberProperty


Gibt eine Eigenschaft eines Dimensionsattributs zurück.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Gibt die Eigenschaft "`propertyName`" des Dimensionsattributs "`attribute`" zurück.



## Category
Cube

# Cube.ApplyParameter


Gibt einen Cube zurück, nachdem ein Parameter darauf angewendet wurde.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Gibt einen Cube zurück, nachdem '`parameter`' mit '`arguments`' auf '`cube`' angewendet wurde.

Cube

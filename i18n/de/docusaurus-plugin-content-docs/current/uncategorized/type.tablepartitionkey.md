# Type.TablePartitionKey


Gibt den Partitionsschlüssel für den angegebenen Tabellentyp zurück, sofern vorhanden.


## Syntax

```powerquery
Type.TablePartitionKey(
    tableType as type
) as list
```


## Remarks

Gibt den Partitionsschlüssel für den angegebenen Tabellentyp zurück, sofern vorhanden.

# Function.InvokeAfter


Ruft die angegebene Funktion auf, nachdem die angegebene Dauer verstrichen ist.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Gibt das Ergebnis des Aufrufs von '`function`' nach dem Ablauf der Dauer `delay` zurück.



## Category
Function

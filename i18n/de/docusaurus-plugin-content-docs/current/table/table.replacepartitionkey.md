# Table.ReplacePartitionKey


Ersetzt den Partitionsschlüssel der angegebenen Tabelle.


## Syntax

```powerquery
Table.ReplacePartitionKey(
    table as table,
    partitionKey as list
) as table
```


## Remarks

Ersetzt den Partitionsschlüssel der angegebenen Tabelle.

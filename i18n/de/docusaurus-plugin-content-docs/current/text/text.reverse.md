# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Kehrt die Angabe von "`text`" um.


## Examples

### Example #1
Kehrt den Text "123" um.
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

# Text.Length


Gibt die Zeichenanzahl zurück.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Gibt die Anzahl von Zeichen im Text "`text`" zurück.


## Examples

### Example #1
Ermittelt die Anzahl von Zeichen im Text "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

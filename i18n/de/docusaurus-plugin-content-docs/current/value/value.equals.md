# Value.Equals


Gibt zurück, ob zwei Werte gleich sind.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Gibt "true" zurück, wenn der Wert `value1` gleich dem Wert `value2` ist. Andernfalls wird "false" zurückgegeben.

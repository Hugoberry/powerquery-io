# Value.VersionIdentity


Gibt die Versionskennung des Werts zurück.


## Syntax

```powerquery
Value.VersionIdentity(
    value as any
) as any
```


## Remarks

Gibt die Versionsidentität des `value` zurück oder `null`, wenn keine Version vorhanden ist.

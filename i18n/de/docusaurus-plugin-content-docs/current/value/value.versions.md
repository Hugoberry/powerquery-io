# Value.Versions


Gibt eine Navigationstabelle zurück, die die verfügbaren Versionen des Werts enthält.


## Syntax

```powerquery
Value.Versions(
    value as any
) as table
```


## Remarks

Gibt eine Navigationstabelle zurück, die die verfügbaren Versionen des `value` enthält.

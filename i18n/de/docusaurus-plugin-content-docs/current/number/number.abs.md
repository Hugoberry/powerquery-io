# Number.Abs


Gibt den absoluten Wert der Zahl zurück.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Gibt den absoluten Wert von "`number`" zurück. Ist "`number`" NULL, gibt `Number.Abs` NULL zurück.

-   `number`: Ein `number`\-Wert, dessen absoluter Wert berechnet werden soll.


## Examples

### Example #1
Absoluter Wert von -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

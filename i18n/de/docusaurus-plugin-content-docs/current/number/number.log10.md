# Number.Log10


Gibt den Logarithmus der Zahl zur Basis 10 zurück.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Gibt den Logarithmus einer Zahl (`number`) zur Basis 10 zurück. Ist `number` null, gibt `Number.Log10` null zurück.


## Examples

### Example #1
Ermittelt den Logarithmus von 2 zur Basis 10.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

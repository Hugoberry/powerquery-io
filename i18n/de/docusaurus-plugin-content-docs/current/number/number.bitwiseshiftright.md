# Number.BitwiseShiftRight


Nimmt eine Verschiebung nach rechts um die festgelegten Bits vor.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Gibt für "`number1`" das Ergebnis einer bitweisen Verschiebung nach rechts um die angegebene Anzahl von Bits (`number2`) zurück.

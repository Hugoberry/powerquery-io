# Number.BitwiseXor


Gibt das Ergebnis der Ausführung eines bitweisen XOR-Vorgangs (ausschließendes ODER) zwischen den beiden Eingaben zurück.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Gibt das Ergebnis der Ausführung eines bitweisen XOR-Vorgangs (ausschließendes ODER) zwischen "`number1`" und "`number2`" zurück.

Number.Bytes

# Number.BitwiseNot


Gibt ein Byte zurück, bei dem jedes Bit das Gegenteil der Eingabe ist.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Gibt das Ergebnis der Ausführung eines bitweisen NICHT-Vorgangs für "`number`" zurück.



## Category
Number.Bytes

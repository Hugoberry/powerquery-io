# Number.Atan2


Gibt den Arkustangens der Division der beiden Zahlen zurück.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Gibt den Winkel im Bogenmaß zurück, dessen Tangens der Quotient `y`/`x` der beiden Zahlen `y` und `x` ist.

Number.Trigonometry

# Number.Cos


Gibt den Kosinus der Zahl zurück.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Gibt den Kosinus des angegebenen Winkels zurück.

-   `number`: Ein Winkel, gemessen im Bogenmaß.


## Examples

### Example #1
Ermittelt den Kosinus des Winkels 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Ermitteln Sie den Kosinus des Bogenmaßes π.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

# Number.BitwiseOr


Gibt das Ergebnis der Ausführung eines bitweisen ODER-Vorgangs zwischen den beiden Eingaben zurück.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Gibt das Ergebnis der Ausführung eines bitweisen ODER-Vorgangs zwischen "`number1`" und "`number2`" zurück.

Number.Bytes

# Type.ReplaceTablePartitionKey


Gibt einen neuen Tabellentyp zurück, bei dem der Partitionsschlüssel durch den angegebenen Partitionsschlüssel ersetzt wird.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Gibt einen neuen Tabellentyp zurück, bei dem der Partitionsschlüssel durch den angegebenen Partitionsschlüssel ersetzt wird.

# Type.ReplaceFacets


Ersetzt die Facets eines Typs.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Ersetzt die Facets von `type` durch die Facets, die im Datensatz `facets` enthalten sind.

# Type.TableSchema


Gibt eine Tabelle mit einer Beschreibung der Spalten (d. h. das Schema) des angegebenen Tabellentyps zurück.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Gibt eine Tabelle mit einer Beschreibung der Spalten von „`tableType`“ zurück.

Eine Beschreibung der resultierenden Tabelle finden Sie in der Dokumentation zu `Table.Schema`.

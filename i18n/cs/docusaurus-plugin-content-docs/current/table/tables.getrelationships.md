# Tables.GetRelationships


Získá relace mezi sadou tabulek.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Získá relace mezi sadou tabulek. U sady `tables` se předpokládá struktura podobná struktuře navigační tabulky. Sloupec definovaný pomocí `dataColumn` obsahuje skutečné tabulky dat.

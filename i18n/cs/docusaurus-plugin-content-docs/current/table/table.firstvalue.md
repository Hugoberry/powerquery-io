# Table.FirstValue


Vrátí první sloupec prvního řádku tabulky nebo zadanou výchozí hodnotu.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Vrátí první sloupec prvního řádku tabulky `table` nebo zadanou výchozí hodnotu.

Table.Row operations

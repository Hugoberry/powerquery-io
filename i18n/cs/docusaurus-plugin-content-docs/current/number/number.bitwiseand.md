# Number.BitwiseAnd


Vrátí výsledek provedení bitové operace And mezi dvěma vstupy.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrátí výsledek provedení bitové operace And mezi hodnotami `number1` a `number2`.



## Category
Number.Bytes

# Number.Exp


Umocní konstantu e daným exponentem.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Vrátí výsledek umocnění čísla konstanty e exponentem `number` (exponenciální funkce).

-   `number`: Hodnota `number`, pro kterou bude vypočtena exponenciální funkce. Pokud je hodnota `number` null, funkce `Number.Exp` vrátí hodnotu null.


## Examples

### Example #1
Umocní konstantu e exponentem 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.BitwiseShiftRight


Posune sadu bitů doprava.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrátí výsledek bitového posunu hodnoty `number1` směrem doprava o zadaný počet bitů `number2`.



## Category
Number.Bytes

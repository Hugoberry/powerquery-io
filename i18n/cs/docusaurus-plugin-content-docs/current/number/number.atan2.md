# Number.Atan2


Vrátí arkus tangens podílu dvou čísel.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Vrátí úhel v radiánech, jehož tangens je podíl `y`/`x` dvou čísel `y` a `x`.

Number.Trigonometry

# Number.Cos


Vrátí kosinus čísla.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Vrací kosinus určeného úhlu.

-   `number`: Úhel měřený v radiánech.


## Examples

### Example #1
Vrátí cosinus úhlu o velikosti 0 stupňů.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Najdi kosinus π radiánů.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

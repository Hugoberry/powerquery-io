# Number.RandomBetween


Vrátí náhodné číslo v rozsahu určeném dvěma čísly.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Vrátí náhodné číslo v rozsahu určeném čísly `bottom` a `top`.


## Examples

### Example #1
Vrátí náhodné číslo v intervalu 1 až 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

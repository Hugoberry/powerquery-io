# Number.BitwiseNot


Vrátí bajt, ve kterém je každý bit protikladem vstupního bitu.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Vrátí výsledek provedení bitové operace Not s hodnotou `number`.



## Category
Number.Bytes

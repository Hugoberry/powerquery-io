# Number.BitwiseXor


Vrátí výsledek provedení bitové operace XOR (exkluzivní disjunkce OR) mezi dvěma vstupy.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrátí výsledek provedení bitové operace XOR (exkluzivní disjunkce OR) mezi hodnotami `number1` a `number2`.



## Category
Number.Bytes

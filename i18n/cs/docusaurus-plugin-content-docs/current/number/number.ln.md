# Number.Ln


Vrátí přirozený logaritmus čísla.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Vrátí přirozený logaritmus čísla `number`. Pokud je hodnota `number` null, funkce `Number.Ln` vrátí hodnotu null.


## Examples

### Example #1
Vrátí přirozený logaritmus čísla 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

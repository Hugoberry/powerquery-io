# Number.Log10


Vrátí dekadický logaritmus (se základem 10) čísla.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Vrátí dekadický logaritmus (se základem 10) čísla `number`. Pokud je hodnota `number` null, funkce `Number.Log10` vrátí hodnotu null.


## Examples

### Example #1
Vrátí dekadický logaritmus (se základem 10) čísla 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

# Number.Sin


Vrátí sinus čísla.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Vrátí sinus hodnoty `number`.


## Examples

### Example #1
Vrátí sinus úhlu 0 stupňů.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

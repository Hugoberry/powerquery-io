# Number.Abs


Vrátí absolutní hodnotu čísla.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Vrátí absolutní hodnotu čísla `number`. Pokud je hodnota `number` null, funkce `Number.Abs` vrátí hodnotu null.

-   `number`: Hodnota `number`, jejíž absolutní hodnota se vypočítá.


## Examples

### Example #1
Absolutní hodnota čísla -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

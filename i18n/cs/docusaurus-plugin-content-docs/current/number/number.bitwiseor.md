# Number.BitwiseOr


Vrátí výsledek provedení bitové operace Or mezi dvěma vstupy.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrátí výsledek provedení bitové operace Or mezi hodnotami `number1` a `number2`.



## Category
Number.Bytes

# Number.BitwiseShiftLeft


Posune sadu bitů doleva.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Vrátí výsledek bitového posunu hodnoty `number1` směrem doleva o zadaný počet bitů `number2`.



## Category
Number.Bytes

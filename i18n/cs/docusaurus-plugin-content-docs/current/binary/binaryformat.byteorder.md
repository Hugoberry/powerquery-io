# BinaryFormat.ByteOrder


Vrátí binární formát s pořadím bajtů zadaným funkcí.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Vrátí binární formát s pořadím bajtů zadaným parametrem `binaryFormat`. Výchozí pořadí bajtů je `ByteOrder.BigEndian`.

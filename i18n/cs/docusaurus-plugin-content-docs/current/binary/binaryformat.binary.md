# BinaryFormat.Binary


Vrátí binární formát, který čte binární hodnotu.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Vrátí binární formát, který čte binární hodnotu. Je-li zadán parametr `length`, bude binární hodnota obsahovat přesně tolik bajtů. Pokud parametr `length` zadán není, bude binární hodnota obsahovat zbylé bajty. Parametr `length` lze zadat jako číslo nebo v binárním formátu o délce, která předchází binární data.

# Binary.ViewError


Vytvoří upravený záznam o chybě, který při vyvolání obslužnou rutinou definovanou v zobrazení (přes Binary.View) neaktivuje náhradní řešení.


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Vytvoří z `errorRecord` upravený záznam o chybě, který při vyvolání obslužnou rutinou definovanou v zobrazení (přes Binary.View) neaktivuje náhradní řešení.

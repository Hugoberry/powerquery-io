# Variable.Value


Vrátí hodnotu zadané proměnné.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Vrátí hodnotu zadané proměnné `identifier` definované aktuálním vyhodnocovacím prostředím. Pokud proměnná není definována, je vyvolána chyba.

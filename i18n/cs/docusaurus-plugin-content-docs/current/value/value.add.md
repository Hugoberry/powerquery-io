# Value.Add


Vrátí součet dvou hodnot.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vrátí součet hodnoty `value1` s hodnotou `value2`. Lze zadat volitelný parametr `precision`. Ve výchozím nastavení se používá hodnota `Precision.Double`.

# Value.Divide


Vrátí výsledek dělení první hodnoty druhou.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vrátí výsledek dělení hodnoty `value1` hodnotou `value2`. Lze zadat volitelný parametr `precision`. Ve výchozím nastavení se používá hodnota `Precision.Double`.

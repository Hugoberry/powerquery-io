# Value.Optimize


Signalizuje, že Value.Expression vrátí optimalizovaný výraz pro hodnotu.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Pokud `value` představuje dotaz, který by se dá optimalizovat, při použití s Value.Expression tato funkce indikuje, že se má vrátit optimalizovaný výraz. Jinak se `value` předá bez efektu.

Expression

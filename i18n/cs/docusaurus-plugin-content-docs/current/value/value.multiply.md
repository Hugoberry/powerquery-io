# Value.Multiply


Vrátí součin dvou hodnot.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vrátí součin hodnot `value1` a `value2`. Lze zadat volitelný parametr `precision`. Ve výchozím nastavení se používá hodnota `Precision.Double`.

# Value.Subtract


Vrátí rozdíl dvou hodnot.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Vrátí rozdíl hodnot `value1` a `value2`. Lze zadat volitelný parametr `precision`. Ve výchozím nastavení se používá hodnota `Precision.Double`.

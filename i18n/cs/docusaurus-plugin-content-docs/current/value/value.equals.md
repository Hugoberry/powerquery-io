# Value.Equals


Zjistí, zda jsou si dvě hodnoty rovny.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Pokud je hodnota `value1` rovna hodnotě `value2`, vrátí hodnotu True. Jinak vrátí hodnotu False.

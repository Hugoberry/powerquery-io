# Function.InvokeAfter


Vyvolá danou funkci po uplynutí zadané doby.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Vrátí výsledek vyvolání funkce `function` po uplynutí doby `delay`.



## Category
Function

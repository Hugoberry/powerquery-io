# Function.IsDataSource


Vrátí informaci o tom, jestli se konkrétní funkce považuje za zdroj dat, nebo ne.


## Syntax

```powerquery
Function.IsDataSource(
    function as function
) as logical
```


## Remarks

Vrátí informaci o tom, jestli se `function` považuje za zdroj dat, nebo ne.

# Type.ReplaceFacets


Nahradí omezující vlastnosti typu.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Nahradí omezující vlastnosti pro: `type` omezujícími vlastnostmi obsaženými v záznamu `facets`.

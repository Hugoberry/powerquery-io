# Type.TableSchema


Vrací tabulku obsahující popis sloupců (tj. schéma) zadaného typu tabulky.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Vrací tabulku popisující sloupce `tableType`.

V dokumentaci pro `Table.Schema` vyhledejte popis výsledné tabulky.

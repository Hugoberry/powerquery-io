# Uri.Combine


Vrátí absolutní identifikátor URI, který je kombinací základního identifikátoru URI vstupu a relativního identifikátoru URI.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Vrátí absolutní identifikátor URI, který je kombinací identifikátoru `baseUri` vstupu a identifikátoru `relativeUri`.

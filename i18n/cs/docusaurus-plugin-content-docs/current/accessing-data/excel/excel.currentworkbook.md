# Excel.CurrentWorkbook


Vrátí obsah aktuálního excelového sešitu.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Vrátí obsah aktuálního excelového sešitu. Vrátí tabulky, pojmenované oblasti a dynamická pole. Na rozdíl od `Excel.Workbook` nevrací listy.

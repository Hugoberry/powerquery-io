# HdInsight.Contents


Vrátí navigační tabulku obsahující kontejnery nalezené v zadaném účtu trezoru úložiště služby Azure.


## Syntax

```powerquery
HdInsight.Contents(
    account as text
) as table
```


## Remarks

Vrátí navigační tabulku obsahující řádek pro každý kontejner nalezený na adrese URL účtu `account` trezoru úložiště služby Azure. Každý řádek obsahuje odkaz na objekty blob kontejneru.

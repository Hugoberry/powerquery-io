# Cube.DisplayFolders


Vrátí vnořenou stromovou strukturu tabulek reprezentující hierarchii zobrazovaných složek objektů (například dimenzí a měr).


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Vrátí vnořenou stromovou strukturu tabulek reprezentující hierarchii zobrazovaných složek objektů (například dimenzí a měr) k použití v `cube`.

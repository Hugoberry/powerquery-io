# Cube.AttributeMemberId


Vrací jedinečný identifikátor členu z hodnoty vlastnosti členů.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Vrací jedinečný identifikátor členu z hodnoty vlastnosti členu. `attribute`. Pro všechny ostatní hodnoty vrací hodnotu null.

# Exchange.Contents


Vrátí tabulku s obsahem z účtu Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Vrátí tabulku obsahu z účtu Microsoft Exchange `mailboxAddress`. Pokud účet `mailboxAddress` není zadaný, použije se výchozí účet pro příslušné pověření.

# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Konektor analytiky Teams umožňuje získat přehledy o využití Teams. Data jsou k dispozici pro vaši osobní aktivitu v Teams i pro aktivitu v Teams, kde které jste členem.

Data jsou k dispozici za uplynulých 90 dnů.

Podrobnosti o dostupných typech dat najdete v následující dokumentaci nápovědy:

-   **Využití Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Aktivita uživatele Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

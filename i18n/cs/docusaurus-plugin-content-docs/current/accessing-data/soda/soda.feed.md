# Soda.Feed


Vrátí tabulku z obsahu na zadané adrese URL formátovaného podle rozhraní API SODA 2.0.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

Vrátí tabulku z obsahu na zadané adrese URL `url` formátovaného podle rozhraní API SODA 2.0. Adresa URL musí odkazovat na platný zdroj kompatibilní s rozhraním SODA, který má příponu CSV.

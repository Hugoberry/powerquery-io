# Cube.ApplyParameter


Vrátí datovou krychli po použití parametru.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Vrátí datovou krychli po použití `parameter` s `arguments` na `cube`.

Cube

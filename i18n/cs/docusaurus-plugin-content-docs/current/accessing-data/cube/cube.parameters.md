# Cube.Parameters


Vrátí tabulku obsahující sadu parametrů, které jde použít na datovou krychli.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Vrátí tabulku obsahující sadu parametrů, které jde použít na `cube`. Každý parametr je funkce, která se může vyvolat. Výsledkem je `cube` s použitým parametrem a jeho argumenty.

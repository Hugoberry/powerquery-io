# Cube.Measures


Vrací tabulku obsahující sadu dostupných měr.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Vrací tabulku obsahující sadu dostupných měr v rámci `cube`. Každá míra je reprezentována jako funkce. Míry lze v datové krychli použít příkazem Cube.AddMeasureColumn.

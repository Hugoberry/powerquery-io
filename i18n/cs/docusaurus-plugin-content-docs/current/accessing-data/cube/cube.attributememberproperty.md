# Cube.AttributeMemberProperty


Vrátí vlastnost atributu dimenze.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Vrátí vlastnost `propertyName` atributu dimenze `attribute`.

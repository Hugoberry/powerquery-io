# Cube.ReplaceDimensions


Nahradí sadu dimenzí vrácenou objektem Cube.Dimensions.


## Syntax

```powerquery
Cube.ReplaceDimensions(
    cube as table,
    dimensions as any
) as table
```


## Remarks

Nahradí sadu dimenzí vrácenou objektem `Cube.Dimensions`. Tuto funkci lze například použít k přidání sloupce ID do atributu dimenze, aby zdroj dat mohl provést seskupení podle ID, a ne podle zobrazené hodnoty.

# Hdfs.Files


Vrátí tabulku obsahující vlastnosti a obsah souborů nalezených v zadané složce systému souborů Hadoop a jejích podsložkách.


## Syntax

```powerquery
Hdfs.Files(
    url as text
) as table
```


## Remarks

Vrátí tabulku obsahující řádek pro každý soubor nalezený na drese URL `url` složky systému souborů Hadoop a v jejích podložkách. Každý řádek obsahuje vlastnosti souboru a odkaz na jeho obsah.

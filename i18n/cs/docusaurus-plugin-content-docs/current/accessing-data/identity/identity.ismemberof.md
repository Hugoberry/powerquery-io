# Identity.IsMemberOf


Určuje, jestli je identita členem kolekce identit.


## Syntax

```powerquery
Identity.IsMemberOf(
    identity as record,
    collection as record
) as logical
```


## Remarks

Určuje, jestli je identita členem kolekce identit.

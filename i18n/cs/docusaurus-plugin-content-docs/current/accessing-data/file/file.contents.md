# File.Contents


Vrátí obsah určeného souboru jako binární hodnotu.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Vrátí obsah souboru `path`jako binární. Parametr `options` je aktuálně určen pouze pro interní použití.

# DateTimeZone.LocalNow


Vrátí aktuální datum a čas v místním časovém pásmu.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Vrací hodnotu `datetimezone` nastavenou na aktuální datum a čas v systému. Vrácená hodnota obsahuje údaj o časovém pásmu, který představuje místní časové pásmo.

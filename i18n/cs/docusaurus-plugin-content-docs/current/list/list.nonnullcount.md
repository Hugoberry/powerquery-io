# List.NonNullCount


Vrátí počet položek seznamu, které nemají hodnotu null.


## Syntax

```powerquery
List.NonNullCount(
    list as list
) as number
```


## Remarks

Vrátí počet položek seznamu `list`, které nemají hodnotu null.

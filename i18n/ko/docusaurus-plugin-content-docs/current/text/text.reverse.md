# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

제공한 `text`을(를) 반전시킵니다.


## Examples

### Example #1
텍스트 "123"을 반전시킵니다.
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

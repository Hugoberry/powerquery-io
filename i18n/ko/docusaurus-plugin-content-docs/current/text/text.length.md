# Text.Length


문자 수를 반환합니다.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

`text` 텍스트의 문자 수를 반환합니다.


## Examples

### Example #1
"Hello World" 텍스트의 문자 수를 찾습니다.
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

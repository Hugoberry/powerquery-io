# Number.Cos


숫자의 코사인을 반환합니다.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

지정된 각도의 코사인을 반환합니다.

-   `number`: 라디안으로 측정된 각도입니다.


## Examples

### Example #1
각도 0의 코사인을 구합니다.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
π 라디안의 코사인을 구합니다.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

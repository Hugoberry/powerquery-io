# Number.Abs


숫자의 절대값을 반환합니다.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

`number`의 절대값을 반환합니다. `number`이(가) null인 경우 `Number.Abs`는 null을 반환합니다.

-   `number`: 절대값을 계산할 `number`입니다.


## Examples

### Example #1
\-3의 절대값입니다.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

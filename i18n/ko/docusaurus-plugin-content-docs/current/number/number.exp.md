# Number.Exp


e를 지정된 지수로 거듭제곱합니다.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

e를 `number`제곱한 결과(지수 함수)를 반환합니다.

-   `number`: 지수 함수를 계산할 `number`입니다. `number`이(가) Null인 경우 `Number.Exp`는 Null을 반환합니다.


## Examples

### Example #1
e를 3제곱합니다.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.Ln


숫자의 자연 로그를 반환합니다.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

숫자 `number`의 자연 로그를 반환합니다. `number`이(가) null인 경우 `Number.Ln`은 null을 반환합니다.


## Examples

### Example #1
15의 자연 로그를 가져옵니다.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

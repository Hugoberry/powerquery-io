# Number.BitwiseShiftLeft


비트 집합을 왼쪽으로 이동합니다.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1`에 대해 지정된 비트 수 `number2`만큼 왼쪽으로 비트 시프트를 수행한 결과를 반환합니다.

# Number.BitwiseXor


두 입력 간의 비트 "XOR"(배타적 OR) 연산을 수행한 결과를 반환합니다.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

`number1`과(와) `number2` 간의 비트 "XOR"(배타적 OR) 연산을 수행한 결과를 반환합니다.

# Tables.GetRelationships


테이블 집합 간의 관계를 가져옵니다.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

테이블 집합 간의 관계를 가져옵니다. `tables` 집합의 구조는 탐색 테이블의 구조와 유사한 것으로 간주됩니다. `dataColumn`에 의해 정의된 열은 실제 데이터 테이블을 포함합니다.

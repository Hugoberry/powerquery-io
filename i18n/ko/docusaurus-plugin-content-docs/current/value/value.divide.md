# Value.Divide


첫 번째 값을 두 번째 값으로 나눈 결과를 반환합니다.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1`을(를) `value2`(으)로 나눈 결과를 반환합니다. 선택적으로 `precision` 매개 변수를 지정할 수 있습니다. 기본적으로 `Precision.Double`이 사용됩니다.

# Value.Multiply


두 값의 곱을 반환합니다.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1`을(를) `value2`(으)로 곱한 값을 반환합니다. 선택적으로 `precision` 매개 변수를 지정할 수 있습니다. 기본적으로 `Precision.Double`이 사용됩니다.

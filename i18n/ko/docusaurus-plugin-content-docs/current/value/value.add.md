# Value.Add


두 값의 합계를 반환합니다.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1`과(와) `value2`의 합계를 반환합니다. 선택적으로 `precision` 매개 변수를 지정할 수 있습니다. 기본적으로 `Precision.Double`이 사용됩니다.

# Cube.ApplyParameter


큐브에 매개 변수를 적용한 후 큐브를 반환합니다.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

`parameter`과(와) `arguments`을(를) `cube`에 적용한 후 큐브를 반환합니다.

Cube

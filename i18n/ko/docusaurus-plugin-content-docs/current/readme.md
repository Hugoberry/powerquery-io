# 언어 알아보기
Power Query M 수식 언어는 매우 유연한 데이터 매시업 쿼리를 구축하는 데 최적화되어 있습니다. F#과 유사한 함수형이며 대소문자를 구분하는 언어입니다. Power Query 수식 언어는 Power BI Desktop, Excel, Analysis Services 등 다양한 Microsoft 제품에서 사용됩니다.

이 사이트는 Power Query 함수에 대한 참조 자료로서, 각 함수에 대한 자세한 정보와 실용적인 예제에 빠르고 직접적으로 접근할 수 있도록 제공합니다.
:::note
저자는 이 사이트에 제시된 자료에 대해 어떠한 저작권도 주장하지 않음을 알려드립니다. 이 정보는 Power Query에 대한 지식과 활용을 넓히고자 하는 분들에게 유용하기를 바라는 마음으로 수집되어 제공됩니다.
:::

이 웹사이트의 검색 기능은 다양한 Power Query 함수의 탐색 과정을 간소화합니다. 꼭 사용해 보세요 (Ctrl+K).

![Algolia에서 제공하는 검색 기능](/img/search.png)

더 깊은 탐구나 구현 세부 사항에 관심이 있는 분들은 다음 GitHub 저장소에서 추가 정보를 찾을 수 있습니다: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). 이 저장소에는 Power Query 개발 및 사용과 관련된 추가 예제, 업데이트 및 리소스가 포함되어 있을 수 있습니다.

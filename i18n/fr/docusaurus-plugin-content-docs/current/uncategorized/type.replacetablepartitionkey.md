# Type.ReplaceTablePartitionKey


Retourne un nouveau type de table avec la clé de partition remplacée par la clé de partition spécifiée.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Retourne un nouveau type de table avec la clé de partition remplacée par la clé de partition spécifiée.

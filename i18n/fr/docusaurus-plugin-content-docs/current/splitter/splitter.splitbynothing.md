# Splitter.SplitByNothing


Retourne une fonction qui n'effectue pas de fractionnement, son argument étant retourné sous la forme d'une liste d'éléments unique.


## Syntax

```powerquery
Splitter.SplitByNothing(

) as function
```


## Remarks

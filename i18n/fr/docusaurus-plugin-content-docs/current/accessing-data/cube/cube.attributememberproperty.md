# Cube.AttributeMemberProperty


Retourne une propriété d'un attribut de dimension.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Retourne la propriété `propertyName` de l'attribut de dimension `attribute`.

Cube

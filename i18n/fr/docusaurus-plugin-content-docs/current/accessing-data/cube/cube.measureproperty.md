# Cube.MeasureProperty


Retourne une propriété d'une mesure (propriété de cellule).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Retourne la propriété `propertyName` de la mesure `measure`.

Cube

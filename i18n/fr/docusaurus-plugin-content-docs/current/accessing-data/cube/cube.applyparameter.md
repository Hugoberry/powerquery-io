# Cube.ApplyParameter


Retourne un cube après application d'un paramètre à celui-ci.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Retourne un cube après application de `parameter` avec `arguments` à `cube`.

Cube

# AzureDevOpsServer.AnalyticsViews


Entrez les noms de l'organisation et du projet.


## Syntax

```powerquery
AzureDevOpsServer.AnalyticsViews(
    url as text,
    project as text,
    optional options as record
) as table
```


## Remarks

Retourne une table de vues Analytics offertes par Azure DevOps.

# Uri.Combine


Retourne un URI absolu qui est la combinaison de l'URI de base d'entrée et de l'URI relatif.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Retourne un URI absolu qui est la combinaison de l'`baseUri` d'entrée et de `relativeUri`.

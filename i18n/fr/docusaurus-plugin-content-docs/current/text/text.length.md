# Text.Length


Retourne le nombre de caractères.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Retourne le nombre de caractères dans le texte `text`.


## Examples

### Example #1
Indiquez combien de caractères sont dans le texte "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

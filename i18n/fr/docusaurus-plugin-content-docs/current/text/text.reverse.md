# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Inverse le `text` fourni.


## Examples

### Example #1
Inversez le texte "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

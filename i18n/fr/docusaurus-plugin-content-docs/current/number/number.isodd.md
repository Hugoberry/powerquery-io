# Number.IsOdd


Indique si la valeur est impaire.


## Syntax

```powerquery
Number.IsOdd(
    number as number
) as logical
```


## Remarks

Indique si la valeur est impaire. Retourne `true` si `number` est un nombre impair, sinon `false`.


## Examples

### Example #1
Vérifie si 625 est un nombre impair.
```powerquery
Number.IsOdd(625)
```

Result: 
```powerquery
true
```


### Example #2
Vérifie si 82 est un nombre impair.
```powerquery
Number.IsOdd(82)
```

Result: 
```powerquery
false
```

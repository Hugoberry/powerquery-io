# Number.Abs


Retourne la valeur absolue du nombre.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Retourne la valeur absolue de `number`. Si `number` a la valeur null, `Number.Abs` retourne null.

-   `number` : `number` dont la valeur absolue doit être calculée.


## Examples

### Example #1
Valeur absolue de -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

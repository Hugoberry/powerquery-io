# Number.BitwiseAnd


Retourne le résultat d'une opération au niveau du bit "And" entre les deux entrées.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retourne le résultat d'une opération au niveau du bit "And" entre `number1` et `number2`.



## Category
Number.Bytes

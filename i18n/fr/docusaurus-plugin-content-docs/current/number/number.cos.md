# Number.Cos


Retourne le cosinus du nombre.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Retourne le cosinus de l'angle spécifié.

-   `number` : angle, mesuré en radians.


## Examples

### Example #1
Recherche le cosinus de l'angle 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Recherchez le cosinus de π radians.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

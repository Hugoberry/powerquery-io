# Number.Ln


Retourne le logarithme népérien du nombre.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Retourne le logarithme népérien d'un nombre, `number`. Si `number` a la valeur null, `Number.Ln` retourne null.


## Examples

### Example #1
Obtient le logarithme népérien de 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

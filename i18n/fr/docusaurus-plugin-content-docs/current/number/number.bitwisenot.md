# Number.BitwiseNot


Retourne un octet où chaque bit est l'inverse de l'entrée.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Retourne le résultat d'une opération au niveau du bit "Not" sur `number`.



## Category
Number.Bytes

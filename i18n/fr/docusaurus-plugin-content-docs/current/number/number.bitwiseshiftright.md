# Number.BitwiseShiftRight


Déplace l'ensemble de bits à droite.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retourne le résultat d'un déplacement au niveau du bit vers la droite sur `number1`, en fonction du nombre de bits spécifié `number2`.

Number.Bytes

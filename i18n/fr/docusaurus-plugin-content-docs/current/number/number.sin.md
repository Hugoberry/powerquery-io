# Number.Sin


Retourne le sinus du nombre.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Retourne le sinus de `number`.


## Examples

### Example #1
Recherche le sinus de l'angle 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

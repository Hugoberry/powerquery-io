# Number.Atan2


Renvoie l'arc tangente de la division des deux nombres.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Renvoie l'angle, en radians, dont la tangente est le quotient `y`/`x` des deux nombres `y` et `x`.

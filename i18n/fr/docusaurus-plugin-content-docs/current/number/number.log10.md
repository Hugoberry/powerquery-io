# Number.Log10


Retourne le logarithme de base 10 du nombre.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Retourne le logarithme de base 10 d'un nombre, `number`. Si `number` a la valeur Null, `Number.Log10` retourne Null.


## Examples

### Example #1
Obtient le logarithme de base 10 de 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

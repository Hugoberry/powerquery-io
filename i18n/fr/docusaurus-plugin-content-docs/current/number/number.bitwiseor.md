# Number.BitwiseOr


Retourne le résultat d'une opération au niveau du bit « Or » entre les deux entrées.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retourne le résultat d'une opération au niveau du bit « Or » entre `number1` et `number2`.



## Category
Number.Bytes

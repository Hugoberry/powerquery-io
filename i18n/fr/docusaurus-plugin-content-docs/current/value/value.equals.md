# Value.Equals


Détermine si deux valeurs sont égales.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Retourne true si la valeur `value1` est égale à la valeur `value2`, sinon retourne false.

Values

# Value.NullableEquals


Détermine si deux valeurs sont égales.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Retourne NULL si l'un des arguments `value1` ou `value2` est NULL ; sinon, équivalent à Value.Equals.



## Category
Values

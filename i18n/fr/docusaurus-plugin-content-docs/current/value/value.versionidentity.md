# Value.VersionIdentity


Renvoie l'identité de version de la valeur.


## Syntax

```powerquery
Value.VersionIdentity(
    value as any
) as any
```


## Remarks

Renvoie l'identifiant de version de `value`, ou `null` s'il ne possède pas de version.

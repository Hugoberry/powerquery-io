# Type.ReplaceFacets


Remplace les facettes d'un type.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Remplace les facettes de `type` par les facettes contenues dans l'enregistrement `facets`.

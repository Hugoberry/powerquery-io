# Table.ReplacePartitionKey


Remplace la clé de partition de la table spécifiée.


## Syntax

```powerquery
Table.ReplacePartitionKey(
    table as table,
    partitionKey as list
) as table
```


## Remarks

Remplace la clé de partition de la table spécifiée.

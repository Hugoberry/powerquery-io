# Uri.Combine


Returnează un identificator URI absolut care reprezintă combinaţia dintre identificatorul URI de intrare de bază şi identificatorul URI relativ.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Returnează un identificator URI absolut care este combinaţia dintre `baseUri` de intrare şi `relativeUri`.

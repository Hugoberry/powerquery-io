# Type.ReplaceFacets


Înlocuiește fațetele unui tip.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Înlocuiește fațetele pentru `type` cu fațetele cuprinse în înregistrarea `facets`.

# Type.TableSchema


Returnează un tabel ce conține o descriere a coloanelor (de ex., schema) tipului de tabel specificat.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Returnează un tabel care descrie coloanele din `tableType`.

Consultați documentația `Table.Schema` pentru o descriere a tabelului rezultat.

# Type.ReplaceTablePartitionKey


Returnează un nou tip de tabel cu cheia de partiție înlocuită de cheia de partiție specificată.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Returnează un nou tip de tabel cu cheia de partiție înlocuită de cheia de partiție specificată.

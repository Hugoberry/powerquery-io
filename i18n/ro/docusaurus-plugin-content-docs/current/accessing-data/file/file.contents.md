# File.Contents


Returnează conţinutul fişierului specificat ca binar.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Returnează conținutul fișierului, `path`, ca Binary. Parametrul `options` este destinat în prezent doar utilizării interne.

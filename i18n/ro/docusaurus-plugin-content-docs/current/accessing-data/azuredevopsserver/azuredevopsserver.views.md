# AzureDevOpsServer.Views


Introduceți numele organizației și al proiectului.


## Syntax

```powerquery
AzureDevOpsServer.Views(
    url as text,
    project as text,
    areaPath as text,
    optional options as record
) as table
```


## Remarks

Returnează un tabel de fluxuri OData oferite de Azure DevOps.

# Cube.AttributeMemberProperty


Returnează o proprietate a unui atribut de dimensiune.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Returnează proprietatea `propertyName` a atributului de dimensiune `attribute`.

Cube

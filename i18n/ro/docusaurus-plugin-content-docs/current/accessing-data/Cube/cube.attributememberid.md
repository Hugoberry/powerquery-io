# Cube.AttributeMemberId


Returnează identificatorul de membru unic din valoarea de proprietate a membrilor.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Returnează identificatorul de membru unic dintr-o valoare de proprietate a membrilor. `attribute`. Returnează nul pentru orice alte valori.

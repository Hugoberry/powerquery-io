# Cube.CollapseAndRemoveColumns


Modifică granularitatea dimensională a contextului filtru pentru cub prin restrângerea atributelor mapate în coloanele specificate.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Modifică granularitatea dimensională a contextului filtru pentru `cube` prin restrângerea atributelor mapate în coloanele specificate `columnNames`. De asemenea, coloanele sunt eliminate din vizualizarea tabelară a cubului.

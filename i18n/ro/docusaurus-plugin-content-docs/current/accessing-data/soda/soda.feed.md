# Soda.Feed


Returnează un tabel din conţinut la adresa URL specificată formatată conform interfeţei API SODA 2.0.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

Returnează un tabel din conţinut la adresa URL specificată `url` formatată conform interfeţei API SODA 2.0. Adresa URL trebuie să indice la o sursă compatibilă cu SODA validă care se termină cu o extensie .csv.

# Exchange.Contents


Returnează un table de conţinut de la un cont Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Returnează un cuprins din contul Microsoft Exchange `mailboxAddress`. Dacă nu se specifică `mailboxAddress`, se va utiliza contul implicit pentru acreditare.

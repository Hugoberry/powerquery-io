# Excel.CurrentWorkbook


Returnează conținutul registrului de lucru Excel curent.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Returnează conținutul registrului de lucru Excel curent. Returnează tabele, zone denumite și matrice dinamice. Spre deosebire de `Excel.Workbook`, nu returnează foi.

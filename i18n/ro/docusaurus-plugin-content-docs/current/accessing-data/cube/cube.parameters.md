# Cube.Parameters


Returnează un tabel care conține setul de parametri ce se pot aplica la cub.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Returnează un tabel care conține setul de parametri ce se pot aplica la `cube`. Fiecare parametru este o funcție care poate fi invocată pentru a obține `cube` cu parametrul și argumentele sale aplicate.

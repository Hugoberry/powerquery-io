# Cube.ApplyParameter


Returnează un cub după aplicarea unui parametru la acesta.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Returnează un cub după aplicarea `parameter` cu `arguments` la `cube`.

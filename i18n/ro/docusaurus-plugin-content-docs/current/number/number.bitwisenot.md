# Number.BitwiseNot


Returnează un octet în care fiecare bit este opusul datelor introduse.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Returnează rezultatul efectuării operaţiunii „Not” la nivel de bit pe `number`.



## Category
Number.Bytes

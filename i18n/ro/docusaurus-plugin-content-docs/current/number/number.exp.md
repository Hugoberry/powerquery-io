# Number.Exp


Ridică e la puterea dată.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Returnează rezultatul ridicării e la puterea `number` (funcția exponențială).

-   `number`: o valoare `number` pentru care urmează să fie calculată funcția exponențială. Dacă `number` este nul, `Number.Exp` returnează nul.


## Examples

### Example #1
Ridicaţi e la puterea 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.Sin


Returnează sinusul numărului.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Returnează sinusul `number`.


## Examples

### Example #1
Aflaţi sinusul unghiului 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

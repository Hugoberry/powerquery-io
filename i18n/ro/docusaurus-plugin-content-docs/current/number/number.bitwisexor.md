# Number.BitwiseXor


Returnează rezultatul efectuării operaţiunii „XOR” (Exclusive-OR) la nivel de bit între cele două date introduse.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnează rezultatul efectuării operaţiunii „XOR” (Exclusive-OR) la nivel de bit între `number1` şi `number2`.

Number.Bytes

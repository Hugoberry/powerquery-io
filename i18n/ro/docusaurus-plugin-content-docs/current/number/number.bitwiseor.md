# Number.BitwiseOr


Returnează rezultatul efectuării operaţiunii „Or” la nivel de bit între cele două date introduse.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnează rezultatul efectuării operaţiunii „Or” la nivel de bit între `number1` şi `number2`.

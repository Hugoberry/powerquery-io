# Number.BitwiseShiftLeft


Deplasează setul de biţi spre stânga.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnează rezultatul efectuării unei deplasări spre stânga la nivel de bit pe `number1`, cu numărul specificat de biţi `number2`.

# Number.BitwiseShiftRight


Deplasează setul de biţi spre dreapta.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnează rezultatul efectuării unei deplasări spre dreapta la nivel de bit pe `number1`, cu numărul specificat de biţi `number2`.

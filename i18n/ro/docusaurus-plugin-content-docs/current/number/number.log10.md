# Number.Log10


Returnează logaritmul în baza 10 al numărului.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Returnează logaritmul în baza 10 al unui număr, `number`. Dacă `number` este nul, `Number.Log10` returnează nul.


## Examples

### Example #1
Aflați logaritmul în baza 10 pentru 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

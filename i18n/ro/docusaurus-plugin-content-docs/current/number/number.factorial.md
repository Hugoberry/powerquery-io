# Number.Factorial


Returnează produsul factorial al numărului.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

Returnează produsul factorial al numărului `number`.


## Examples

### Example #1
Găsiţi produsul factorial pentru 10.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

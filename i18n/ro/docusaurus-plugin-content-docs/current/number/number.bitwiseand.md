# Number.BitwiseAnd


Returnează rezultatul efectuării unei operaţiuni „And” la nivel de bit între cele două date introduse.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnează rezultatul efectuării operaţiunii „And” la nivel de bit între `number1` şi `number2`.

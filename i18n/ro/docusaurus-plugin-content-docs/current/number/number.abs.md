# Number.Abs


Returnează valoarea absolută a numărului.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Returnează valoarea absolută a `number`. Dacă `number` este nul, `Number.Abs` returnează nul.

-   `number`: o valoare `number` pentru care urmează să fie calculată valoarea absolută.


## Examples

### Example #1
Valoarea absolută -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Number.Cos


Returnează cosinusul numărului.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Returnează cosinusul unghiului specificat.

-   `number`: un unghi, măsurat în radiani.


## Examples

### Example #1
Aflaţi cosinusul unghiului 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Calculați cosinusul unghiului de π radiani.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

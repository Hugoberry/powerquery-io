# Number.Ln


Returnează logaritmul natural al numărului.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Returnează logaritmul natural al unui număr, `number`. Dacă `number` este nul, `Number.Ln` returnează nul.


## Examples

### Example #1
Obţineţi logaritmul natural pentru 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

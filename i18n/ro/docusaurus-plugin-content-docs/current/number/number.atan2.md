# Number.Atan2


Returnează arctangenta împărţirii a două numere.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Returnează unghiul, în radiani, a cărui tangentă este câtul `y`/`x` a celor două numere `y` și `x`.

Number.Trigonometry

# Value.Divide


Returnează rezultatul împărţirii primei valori la cea de-a doua.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Returnează rezultatul împărţirii `value1` la `value2`. Un parametru `precision` opţional poate fi specificat; în mod implicit, se utilizează `Precision.Double`.

# Value.Subtract


Returnează diferenţa celor două valori.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Returnează diferenţa dintre `value1` şi `value2`. Un parametru `precision` opţional poate fi specificat; în mod implicit, se utilizează `Precision.Double`.

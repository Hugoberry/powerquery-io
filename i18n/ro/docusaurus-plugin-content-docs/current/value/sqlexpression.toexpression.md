# SqlExpression.ToExpression


Convertește interogarea SQL furnizată în cod M. Această funcție este destinată numai utilizării interne.


## Syntax

```powerquery
SqlExpression.ToExpression(
    sql as text,
    environment as record
) as text
```


## Remarks

Convertește interogarea `sql` furnizată în cod M, cu identificatorii disponibili definiți de `environment`. Această funcție este destinată numai utilizării interne.

# Value.Multiply


Returnează produsul celor două valori.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Returnează produsul înmulţirii `value1` cu `value2`. Un parametru `precision` opţional poate fi specificat; în mod implicit, se utilizează `Precision.Double`.

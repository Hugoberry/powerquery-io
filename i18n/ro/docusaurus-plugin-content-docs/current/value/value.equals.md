# Value.Equals


Returnează dacă două valori sunt egale.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Returnează true dacă valoarea `value1` este egală cu valoarea `value2`; în caz contrar, returnează false.

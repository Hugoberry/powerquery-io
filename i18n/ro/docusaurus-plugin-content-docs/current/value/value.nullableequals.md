# Value.NullableEquals


Returnează dacă două valori sunt egale.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Returnează null dacă oricare argument `value1` sau `value2` este nul; în caz contrar, este echivalent cu Value.Equals.

Values

# Variable.Value


Returnează valoarea variabilei specificate.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Returnează valoarea variabilei specificate `identifier` definită de mediul de evaluare curent. Dacă variabila nu este definită, se declanșează o eroare.

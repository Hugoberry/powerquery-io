# Value.Add


Returnează suma celor două valori.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Returnează suma dintre `value1` şi `value2`. Un parametru `precision` opţional poate fi specificat; în mod implicit, se utilizează `Precision.Double`.

# Table.FirstValue


Returnează prima coloană a primului rând al tabelului sau o valoare implicită specificată.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Returnează prima coloană a primului rând al tabelului `table` sau o valoare implicită specificată.



## Category
Table.Row operations

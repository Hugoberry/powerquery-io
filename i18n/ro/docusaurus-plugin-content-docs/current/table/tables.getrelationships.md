# Tables.GetRelationships


Obține relațiile dintr-un set de tabele.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Obține relațiile dintr-un set de tabele. Se presupune că setul `tables` are o structură similară cu cea a unui tabel de navigare. Coloana definită de `dataColumn` conține tabelele de date propriu-zise.

# BinaryFormat.ByteOrder


Returnează un format binar cu ordinea de octeţi specificată de o funcţie.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Returnează un format binar cu ordinea de octeţi specificată de `binaryFormat`. Ordinea de octeţi implicită este `ByteOrder.BigEndian`.

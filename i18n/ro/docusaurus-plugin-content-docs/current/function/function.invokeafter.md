# Function.InvokeAfter


Invocă funcția dată după expirarea duratei specificate.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Returnează rezultatul invocării `function` după ce trece durata `delay`.



## Category
Function

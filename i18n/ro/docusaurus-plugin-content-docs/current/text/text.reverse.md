# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Inversează `text` furnizat.


## Examples

### Example #1
Inversați textul „123”.
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

# Text.Length


Returnează numărul de caractere.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Returnează numărul de caractere din textul `text`.


## Examples

### Example #1
Aflaţi câte caractere sunt în textul „Hello World”.
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

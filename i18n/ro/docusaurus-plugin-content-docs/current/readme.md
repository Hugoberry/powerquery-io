# Descoperiți limbajul
Limbajul de formule Power Query M este optimizat pentru construirea de interogări de combinare a datelor extrem de flexibile. Este un limbaj funcțional, sensibil la majuscule și minuscule, asemănător cu F#. Limbajul de formule Power Query este utilizat într-o serie de produse Microsoft, precum Power BI Desktop, Excel și Analysis Services.

Acest site servește drept referință pentru funcțiile Power Query, oferind acces rapid și direct la informații detaliate și exemple practice pentru fiecare funcție.
:::note
Vă rugăm să rețineți că autorul nu revendică niciun drept de autor asupra materialelor prezentate pe acest site. Informațiile sunt colectate și furnizate în speranța că vor fi utile celor care doresc să-și extindă cunoștințele și aplicarea Power Query.
:::

Funcționalitatea de căutare de pe acest site web ar trebui să simplifice procesul de descoperire a gamei largi de funcții Power Query. Asigurați-vă că o încercați (Ctrl+K).

![Funcționalitate de căutare oferită de Algolia](/img/search.png)

Pentru cei interesați de o explorare mai aprofundată sau de detalii de implementare, mai multe informații pot fi găsite în următorul depozit GitHub: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Acest depozit poate conține exemple suplimentare, actualizări și resurse relevante pentru dezvoltarea și utilizarea Power Query.

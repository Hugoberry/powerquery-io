# Table.ViewError


Crea un registre d'error modificat que no activarà una restricció quan el llança un controlador definit en una visualització (a través de Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Crea un registre d'error modificat des de `errorRecord` que no activarà una restricció quan el llança un controlador definit en una visualització (a través de Table.View).

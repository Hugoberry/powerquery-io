# Table.Profile


Retorna un perfil de les columnes d'una taula.


## Syntax

```powerquery
Table.Profile(
    table as table,
    optional additionalAggregates as list
) as table
```


## Remarks

Retorna un perfil de les columnes de `table`.

La informació següent es retorna per a cada columna (quan correspon):

-   mínim
-   màxim
-   mitjana
-   desviació estàndard
-   recompte
-   recompte nul
-   recompte diferent

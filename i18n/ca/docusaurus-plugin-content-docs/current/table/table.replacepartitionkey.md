# Table.ReplacePartitionKey


Substitueix la clau de partició de la taula especificada.


## Syntax

```powerquery
Table.ReplacePartitionKey(
    table as table,
    partitionKey as list
) as table
```


## Remarks

Substitueix la clau de partició de la taula especificada.

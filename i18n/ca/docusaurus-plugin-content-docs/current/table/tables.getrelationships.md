# Tables.GetRelationships


Obté les relacions entre un conjunt de taules.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Obté les relacions entre un conjunt de taules. Es considera que el conjunt `tables` té una estructura similar a la d'una taula de navegació. La columna definida per `dataColumn` conté les taules de dades reals.

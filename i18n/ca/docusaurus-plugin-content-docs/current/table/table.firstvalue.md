# Table.FirstValue


Retorna la primera columna de la primera fila de la taula o un valor per defecte especificat.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Retorna la primera columna de la primera fila de la taula `table` o un valor per defecte especificat.



## Category
Table.Row operations

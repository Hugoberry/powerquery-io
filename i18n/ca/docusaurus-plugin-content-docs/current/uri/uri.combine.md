# Uri.Combine


Retorna un URI absolut que és la combinació de l'URI base d'entrada i l'URI relatiu.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Retorna un URI absolut que és la combinació de l'`baseUri` d'entrada i `relativeUri`.

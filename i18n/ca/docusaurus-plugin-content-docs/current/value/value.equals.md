# Value.Equals


Retorna si dos valors són iguals.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Retorna el valor `value1` és igual que el valor `value2` i el valor false en cas contrari.

Values

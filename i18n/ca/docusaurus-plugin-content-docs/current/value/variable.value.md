# Variable.Value


Retorna el valor de la variable especificada.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Retorna el valor de la variable especificada `identifier` definida per l'entorn d'avaluació actual. Si la variable no està definida, es genera un error.

# Value.Optimize


Indica l'element Value.Expression per retornar l'expressió optimitzada per a un valor.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Quan s'utilitza a l'element Value.Expression, si el valor `value` representa una consulta que es pot optimitzar, aquesta funció indica que s'ha de retornar l'expressió optimitzada. En cas contrari, el valor `value` es passarà sense cap efecte.

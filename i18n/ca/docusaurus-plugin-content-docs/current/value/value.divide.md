# Value.Divide


Retorna el resultat de dividir el primer valor pel segon.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Retorna el resultat de dividir `value1` per `value2`. Es pot especificar un paràmetre opcional `precision`, s'utilitza `Precision.Double` per defecte.

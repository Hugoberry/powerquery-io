# Value.Subtract


Retorna la diferència dels dos valors.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Retorna la diferència de `value1` i `value2`. Es pot especificar un paràmetre opcional `precision`, s'utilitza `Precision.Double` per defecte.

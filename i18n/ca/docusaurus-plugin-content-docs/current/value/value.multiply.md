# Value.Multiply


Retorna el producte dels dos valors.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Retorna el producte de multiplicar `value1` per `value2`. Es pot especificar un paràmetre opcional `precision`, s'utilitza `Precision.Double` per defecte.

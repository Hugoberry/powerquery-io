# Value.NullableEquals


Retorna si dos valors són iguals.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Returns null if either argument `value1` or `value2` is null, otherwise equivalent to Value.Equals.



## Category
Values

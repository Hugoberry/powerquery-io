# Function.InvokeAfter


Invoca la funció determinada després de passar la durada especificada.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Retorna el resultat d'invocar `function` després de passar la durada `delay`.



## Category
Function

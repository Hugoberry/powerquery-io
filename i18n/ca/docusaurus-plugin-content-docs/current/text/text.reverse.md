# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Reverteix el text proporcionat (`text`).


## Examples

### Example #1
Reverteix el text "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

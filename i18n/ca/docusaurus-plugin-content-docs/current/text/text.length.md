# Text.Length


Retorna el nombre de caràcters.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Retorna el nombre de caràcters del text `text`.


## Examples

### Example #1
Troba quants caràcters hi ha al text "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

# Number.IsEven


Indica si el valor és parell.


## Syntax

```powerquery
Number.IsEven(
    number as number
) as logical
```


## Remarks

Indica si el valor, `number`, és parell i retorna `true` si és parell o `false` en cas contrari.


## Examples

### Example #1
Comprova si 625 és un nombre parell.
```powerquery
Number.IsEven(625)
```

Result: 
```powerquery
false
```


### Example #2
Comprova si 82 és un nombre parell.
```powerquery
Number.IsEven(82)
```

Result: 
```powerquery
true
```

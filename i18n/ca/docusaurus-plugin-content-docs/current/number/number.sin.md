# Number.Sin


Retorna el sinus del nombre.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Retorna el sinus de `number`.


## Examples

### Example #1
Troba el sinus de l'angle 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

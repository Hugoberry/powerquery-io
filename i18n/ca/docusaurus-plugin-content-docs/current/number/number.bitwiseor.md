# Number.BitwiseOr


Retorna el resultat de fer un bit a bit "Or" entre les dues entrades.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna el resultat de fer un bit a bit "Or" entre `number1` i `number2`.



## Category
Number.Bytes

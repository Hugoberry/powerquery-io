# Number.BitwiseShiftRight


Desplaça el conjunt de bits a la dreta.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna el resultat de fer un desplaçament bit a bit a la dreta a `number1`, en el nombre especificat de bits `number2`.



## Category
Number.Bytes

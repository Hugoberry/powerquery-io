# Number.BitwiseXor


Retorna el resultat de fer un bit a bit "XOR" (OR exclusiu) entre les dues entrades.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna el resultat de fer un bit a bit "XOR" (OR exclusiu) entre `number1` i `number2`.



## Category
Number.Bytes

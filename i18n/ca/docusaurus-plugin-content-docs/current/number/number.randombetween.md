# Number.RandomBetween


Retorna un nombre aleatori entre dos nombres.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Retorna un nombre aleatori entre `bottom` i `top`.


## Examples

### Example #1
Obté un nombre aleatori entre 1 i 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

# Number.Abs


Retorna el valor absolut del nombre.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Retorna el valor absolut de `number`. Si `number` és nul, `Number.Abs` retorna el valor nul.

-   `number`: `number` per al qual s'ha de calcular el valor absolut.


## Examples

### Example #1
Valor absolut de -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

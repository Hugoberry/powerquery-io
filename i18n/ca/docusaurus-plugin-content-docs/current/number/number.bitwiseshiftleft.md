# Number.BitwiseShiftLeft


Desplaça el conjunt de bits a l'esquerra.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna el resultat de fer un desplaçament bit a bit a l'esquerra a `number1`, en el nombre especificat de bits `number2`.



## Category
Number.Bytes

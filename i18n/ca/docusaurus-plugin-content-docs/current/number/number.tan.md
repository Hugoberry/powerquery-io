# Number.Tan


Retorna la tangent del nombre.


## Syntax

```powerquery
Number.Tan(
    number as number
) as number
```


## Remarks

Retorna la tangent de `number`.


## Examples

### Example #1
Troba la tangent de l'angle 1.
```powerquery
Number.Tan(1)
```

Result: 
```powerquery
1.5574077246549023
```

# Number.Log10


Retorna el logaritme de base 10 del nombre.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Retorna el logaritme de base 10 d'un nombre, `number`. Si `number` és nul, `Number.Log10` retorna el valor nul.


## Examples

### Example #1
Obté el logaritme de base 10 de 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

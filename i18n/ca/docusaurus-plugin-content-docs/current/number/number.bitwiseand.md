# Number.BitwiseAnd


Retorna el resultat de fer una operació bit a bit "And" entre les dues entrades.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna el resultat de fer una operació bit a bit "And" entre `number1` i `number2`.



## Category
Number.Bytes

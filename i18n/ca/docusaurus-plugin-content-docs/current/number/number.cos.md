# Number.Cos


Retorna el cosinus del nombre.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Retorna el cosinus de l'angle especificat.

-   `number`: angle mesurat en radians.


## Examples

### Example #1
Troba el cosinus de l'angle 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Calcula el cosinus de π radians.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

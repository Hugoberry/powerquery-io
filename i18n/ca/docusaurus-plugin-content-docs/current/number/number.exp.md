# Number.Exp


Eleva e a la potència donada.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Retorna el resultat d'elevar e a la potència de `number` (funció exponencial).

-   `number`: `number` per al qual s'ha de calcular la funció exponencial. Si `number` és nul, `Number.Exp` retorna el valor nul.


## Examples

### Example #1
Eleva e a la potència de 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

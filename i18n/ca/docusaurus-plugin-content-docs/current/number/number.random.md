# Number.Random


Retorna un nombre aleatori.


## Syntax

```powerquery
Number.Random(

) as number
```


## Remarks

Retorna un nombre aleatori entre 0 i 1.


## Examples

### Example #1
Obté un nombre aleatori.
```powerquery
Number.Random()
```

Result: 
```powerquery
0.919303
```

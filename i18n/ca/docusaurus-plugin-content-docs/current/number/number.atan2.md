# Number.Atan2


Retorna l'arctangent de la divisió dels dos nombres.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Retorna l'angle, en radians, la tangent del quocient `y`/`x` dels dos nombres `y` i `x`.

Number.Trigonometry

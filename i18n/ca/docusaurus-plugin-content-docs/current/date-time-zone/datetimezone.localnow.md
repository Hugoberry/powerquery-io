# DateTimeZone.LocalNow


Retorna la data i hora actuals al fus horari local.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Retorna un conjunt de valors `datetimezone` a la data i hora actuals al sistema. El valor retornat conté informació de fus horari que representa el fus horari local.

# DateTime.FixedLocalNow


Retorna la data i l'hora actuals al fus horari local. Aquest valor és fix i no canviarà amb crides successives.


## Syntax

```powerquery
DateTime.FixedLocalNow(

) as datetime
```


## Remarks

Retorna un conjunt de valors `datetime` a la data i hora actuals al sistema. Aquest valor és fix i no canviarà amb crides successives, a diferència de DateTime.LocalNow que pot retornar valors diferents en el transcurs de l'execució d'una expressió.

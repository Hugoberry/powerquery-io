# BinaryFormat.Binary


Retorna un format binari que llegeix un valor binari.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Retorna un format binari que llegeix un valor binari. Si s'especifica `length`, el valor binari contindrà els mateixos bytes. Si no s'especifica `length`, el valor binari contindrà els bytes restants. El valor `length` es pot especificar com a nombre o com a format binari de la longitud que precedeix les dades binàries.

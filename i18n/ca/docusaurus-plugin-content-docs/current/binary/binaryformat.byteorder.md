# BinaryFormat.ByteOrder


Retorna un format binari amb l'ordre de bytes especificat per una funció.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Retorna un format binari amb l'ordre de bytes especificat per `binaryFormat`. L'ordre de bytes per defecte és `ByteOrder.BigEndian`.

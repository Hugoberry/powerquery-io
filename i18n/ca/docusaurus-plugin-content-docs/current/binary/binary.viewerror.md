# Binary.ViewError


Crea un registre d'error modificat que no activarà una restricció quan el llanci un controlador definit en una visualització (a través de Binary.View).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Crea un registre d'error modificat des de `errorRecord`que no activarà una restricció quan el llanci un controlador definit en una visualització (a través de Binary.View).

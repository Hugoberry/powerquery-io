# BinaryFormat.7BitEncodedUnsignedInteger


Un format binari que llegeix un enter sense signe de 64 bits que s'ha codificat mitjançant una codificació de longitud variable de 7 bits.


## Syntax

```powerquery
BinaryFormat.7BitEncodedUnsignedInteger(
    binary as binary
) as any
```

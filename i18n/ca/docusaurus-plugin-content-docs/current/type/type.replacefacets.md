# Type.ReplaceFacets


Substitueix les facetes d'un tipus.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Substitueix les facetes de `type` per les facetes que conté el registre `facets`.

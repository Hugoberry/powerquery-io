# Type.ReplaceTablePartitionKey


Retorna un nou tipus de taula amb la clau de partició substituïda per la clau de partició especificada.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Retorna un nou tipus de taula amb la clau de partició substituïda per la clau de partició especificada.

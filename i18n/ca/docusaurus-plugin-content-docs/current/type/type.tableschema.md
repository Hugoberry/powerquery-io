# Type.TableSchema


Retorna una taula que conté una descripció de les columnes (p. ex. l'esquema) del tipus de taula especificat.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Retorna una taula que descriu les columnes de `tableType`.

Consulteu la documentació de `Table.Schema` per obtenir una descripció de la taula resultant.

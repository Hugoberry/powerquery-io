# Exchange.Contents


Retorna una taula de continguts des d'un compte del Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Retorna una taula de contingut del compte del Microsoft Exchange `mailboxAddress`. Si `mailboxAddress` no s'especifica, s'utilitzarà el compte per defecte per a la credencial.

# Cube.Parameters


Retorna una taula que conté el conjunt de paràmetres que es pot aplicar al cub.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Retorna una taula que conté el conjunt de paràmetres que es pot aplicar a `cube`. Cada paràmetre és una funció que es pot invocar per obtenir `cube` amb el paràmetre i els seus arguments aplicats.

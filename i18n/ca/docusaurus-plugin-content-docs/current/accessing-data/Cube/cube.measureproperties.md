# Cube.MeasureProperties


Retorna una taula que conté el conjunt de propietats disponibles per a les mesures que s'amplien al cub.


## Syntax

```powerquery
Cube.MeasureProperties(
    cube as table
) as table
```


## Remarks

Retorna una taula que conté el conjunt de propietats disponibles per a les mesures que s'amplien al cub.

# Cube.AttributeMemberProperty


Retorna una propietat d'un atribut de dimensió.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Retorna la propietat `propertyName` de l'atribut de dimensió `attribute`.

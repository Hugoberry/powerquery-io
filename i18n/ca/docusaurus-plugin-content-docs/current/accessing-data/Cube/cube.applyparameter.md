# Cube.ApplyParameter


Retorna un cub després d'aplicar-li un paràmetre.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Retorna un cub després d'aplicar `parameter` amb `arguments` a `cube`.

Cube

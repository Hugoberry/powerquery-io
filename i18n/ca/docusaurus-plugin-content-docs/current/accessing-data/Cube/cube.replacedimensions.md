# Cube.ReplaceDimensions


Substitueix el conjunt de dimensions que retorna Cube.Dimensions.


## Syntax

```powerquery
Cube.ReplaceDimensions(
    cube as table,
    dimensions as any
) as table
```


## Remarks

Substitueix el conjunt de dimensions que retorna `Cube.Dimensions`. Per exemple, aquesta funció es pot utilitzar per afegir una columna ID a un atribut de dimensió, de manera que l'origen de dades pugui agrupar-se a l'ID en lloc del valor mostrat.

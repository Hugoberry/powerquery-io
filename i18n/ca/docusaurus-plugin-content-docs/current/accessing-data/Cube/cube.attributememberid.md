# Cube.AttributeMemberId


Torna l'identificador de membre exclusiu del valor de propietat de membres.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Torna l'identificador de membre exclusiu d'un valor de propietat de membre. `attribute`. Torna un valor nul per a la resta de valors.

Cube

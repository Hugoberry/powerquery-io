# Dynamics365BusinessCentral.EnvironmentContents


Introduïu el nom de l'entorn i l'empresa del Dynamics 365 Business Central.


## Syntax

```powerquery
Dynamics365BusinessCentral.EnvironmentContents(
    optional environment as text,
    optional company as text
) as table
```


## Remarks

Retorna una taula amb les dades pertinents del Dynamics 365 Business Central.

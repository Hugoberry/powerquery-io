# Webtrends.Tables


Introduïu l'ID del perfil associat amb el compte del Webtrends.


## Syntax

```powerquery
Webtrends.Tables(
    ProfileId as text,
    optional startDate as date,
    optional endDate as date
) as table
```


## Remarks

Retorna una taula amb les dades rellevants del Webtrends.

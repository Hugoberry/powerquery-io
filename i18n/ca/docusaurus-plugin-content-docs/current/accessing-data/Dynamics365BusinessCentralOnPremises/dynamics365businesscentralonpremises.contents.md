# Dynamics365BusinessCentralOnPremises.Contents


Introduïu l'URL de l'extrem del vostre servei OData del Dynamics 365 Business Central (local).


## Syntax

```powerquery
Dynamics365BusinessCentralOnPremises.Contents(
    url as text,
    optional company as text
) as table
```


## Remarks

Retorna una taula amb les dades pertinents del Dynamics 365 Business Central (local).

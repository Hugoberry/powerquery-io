# Hdfs.Files


Retorna una taula que conté les propietats i els continguts dels fitxers i les carpetes que hi ha a la carpeta i les subcarpetes especificades des d'un sistema de fitxers Hadoop.


## Syntax

```powerquery
Hdfs.Files(
    url as text
) as table
```


## Remarks

Retorna una taula que conté una fila per a cada fitxer que hi ha a l'URL de la carpeta, `url`, i les subcarpetes des d'un sistema de fitxers Hadoop. Cada fila conté propietats del fitxer i un enllaç al seu contingut.

# Hdfs.Contents


Retorna una taula que conté les propietats i els continguts dels fitxers i les carpetes que hi ha a la carpeta especificada des d'un sistema de fitxers Hadoop.


## Syntax

```powerquery
Hdfs.Contents(
    url as text
) as table
```


## Remarks

Retorna una taula que conté una fila per a cada carpeta i cada fitxer que hi ha a l'URL la carpeta, `url`, des d'un sistema de fitxers Hadoop. Cada fila conté propietats de la carpeta o del fitxer i un enllaç al seu contingut.

# DynamicsNav.Contents


Introduïu l'URL de l'extrem del vostre servei OData del Dynamics NAV.


## Syntax

```powerquery
DynamicsNav.Contents(
    url as text,
    optional company as text
) as table
```


## Remarks

Mostra una taula amb les dades pertinents del Dynamics NAV.

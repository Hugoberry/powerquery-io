# Cube.CollapseAndRemoveColumns


Canvia la granularitat dimensional del context de filtre del cub reduint els atributs assignats a les columnes específiques.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Canvia la granularitat dimensional del context de filtre del `cube` reduint els atributs assignats a les columnes específiques `columnNames`. Les columnes també se suprimeixen de la vista tubular del cub.

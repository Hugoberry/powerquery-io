# Cube.DisplayFolders


Retorna un arbre de taules imbricat que representa la jerarquia de carpetes de visualització dels objectes (per exemple, dimensions i mesures).


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Retorna un arbre de taules allotjat que representa la jerarquia de carpetes de visualització dels objectes (per exemple, dimensions i mesures) que es pot utilitzar a `cube`.

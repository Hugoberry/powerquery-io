# Cube.Measures


Retorna una taula que conté el conjunt de mesures disponibles.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Retorna una taula que conté el conjunt de mesures disponibles dins de `cube`. Cada mesura es representa com una funció. Les mesures es poden aplicar al cub utilitzant Cube.AddMeasureColumn.

# Cube.Properties


Torna una taula que conté el conjunt de propietats disponibles per a les dimensions que s'amplien al cub.


## Syntax

```powerquery
Cube.Properties(
    cube as table
) as table
```


## Remarks

Torna una taula que conté el conjunt de propietats disponibles per a les dimensions que s'amplien al cub.

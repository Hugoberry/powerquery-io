# Cube.MeasureProperty


Retorna una propietat d'una mesura (propietat de cel·la).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Retorna la propietat `propertyName` de la mesura `measure`.

Cube

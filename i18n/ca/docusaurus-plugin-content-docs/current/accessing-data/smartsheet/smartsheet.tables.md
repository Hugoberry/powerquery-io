# Smartsheet.Tables


Retorna una taula de fulls, informes, carpetes i àrees de treball de l'API de Smartsheet


## Syntax

```powerquery
Smartsheet.Tables(

) as table
```


## Remarks

Retorna una taula incrustada de fulls, informes, carpetes i àrees de treball disponibles de l'API de Smartsheet.


## Examples

### Example #1
Retorna fulls, carpetes, informes i àrees de treball disponibles al nivell superior de la jerarquia de l'Smartsheet
```powerquery
Smartsheet.Tables()
```

Result: 
```powerquery
Una taula de carpetes, informes i àrees de treball del nivell superior de la jerarquia de l'Smartsheet
```

# VSTS.AnalyticsViews


Introduïu el nom de l'organització i el del projecte.


## Syntax

```powerquery
VSTS.AnalyticsViews(
    url as text,
    project as text,
    optional options as record
) as table
```


## Remarks

Retorna una taula de visualitzacions de l'Analytics que ofereix l'Azure DevOps.

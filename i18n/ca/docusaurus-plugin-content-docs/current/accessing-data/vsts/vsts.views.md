# VSTS.Views


Introduïu el nom de l'organització i el del projecte.


## Syntax

```powerquery
VSTS.Views(
    url as text,
    project as text,
    areaPath as text,
    optional options as record
) as table
```


## Remarks

Retorna una taula dels canals de continguts de l'OData que ofereix l'Azure DevOps.

# List.NonNullCount


Retorna el nombre d'elements de la llista que siguin nuls.


## Syntax

```powerquery
List.NonNullCount(
    list as list
) as number
```


## Remarks

Retorna el nombre d'elements de la llista `list` que no siguin nuls.

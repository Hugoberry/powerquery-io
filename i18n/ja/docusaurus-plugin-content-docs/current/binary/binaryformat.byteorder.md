# BinaryFormat.ByteOrder


関数で指定されたバイト順でバイナリ形式を返します。


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

`binaryFormat` で指定されたバイト順でバイナリ形式を返します。既定のバイト順は `ByteOrder.BigEndian` です。

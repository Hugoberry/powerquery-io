# Value.NullableEquals


2 つの値が等しいかどうかを示す値を返します。


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

引数 `value1` または `value2` が null 値であるか、Value.Equals に等しい場合は、null 値を返します。

Values

# Value.Add


2 つの値の合計を返します。


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1` と `value2` の合計を返します。省略可能な `precision` パラメーターを指定できます。既定では `Precision.Double` が使用されます。

# Value.Multiply


2 つの値の積を返します。


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1` に `value2` を掛けた積を返します。省略可能な `precision` パラメーターを指定できます。既定では `Precision.Double` が使用されます。

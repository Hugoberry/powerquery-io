# Value.Divide


最初の値を 2 番目の値で除算した結果を返します。


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

`value1` を `value2` で除算した結果を返します。省略可能な `precision` パラメーターを指定できます。既定では `Precision.Double` が使用されます。

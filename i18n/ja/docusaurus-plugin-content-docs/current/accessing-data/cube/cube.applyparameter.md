# Cube.ApplyParameter


パラメーターを適用後、キューブを返します。


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

`arguments` を含む `parameter` を `cube` に適用後、キューブを返します。

Cube

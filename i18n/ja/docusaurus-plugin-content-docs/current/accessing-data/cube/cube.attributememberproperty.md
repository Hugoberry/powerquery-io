# Cube.AttributeMemberProperty


ディメンション属性のプロパティを返します。


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

ディメンション属性 `attribute` のプロパティ `propertyName` を返します。



## Category
Cube

# Cube.Parameters


キューブに適用できるパラメーターのセットを含むテーブルを返します。


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

`cube` に適用できるパラメーターのセットを含むテーブルを返します。各パラメーターは、そのパラメーターとパラメーターの引数が適用されている `cube` を取得するために呼び出すことができる関数です。

# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

指定された `text` を反転します。


## Examples

### Example #1
テキスト "123" を反転します。
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

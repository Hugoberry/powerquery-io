# Text.Length


文字の数を返します。


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

テキスト `text` 内の文字の数を返します。


## Examples

### Example #1
テキスト "Hello World" 内の文字の数を調べます。
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

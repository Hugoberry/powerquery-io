# 言語を知る
Power Query M 数式言語は、柔軟性の高いデータマッシュアップクエリの構築に最適化されています。これは F# に似た、関数型で大文字と小文字を区別する言語です。Power Query 数式言語は、Power BI Desktop、Excel、Analysis Services など、多くの Microsoft 製品で使用されています。

このサイトは Power Query 関数のリファレンスとして機能し、各関数の詳細な情報と実用的な例に素早く直接アクセスできます。
:::note
著者は本サイトに掲載されている資料に対していかなる著作権も主張しないことにご注意ください。情報は、Power Query の知識と活用を広げたい方々のお役に立つことを願って収集・提供されています。
:::

このウェブサイトの検索機能により、幅広い Power Query 関数の発見プロセスが簡素化されます。ぜひお試しください（Ctrl+K）。

![Algolia によって提供される検索機能](/img/search.png)

より深い探求や実装の詳細に関心のある方は、次の GitHub リポジトリで詳細情報を確認できます: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io)。このリポジトリには、Power Query の開発と使用に関連する追加の例、更新、リソースが含まれている場合があります。

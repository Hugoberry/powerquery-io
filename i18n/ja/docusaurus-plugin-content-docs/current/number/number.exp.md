# Number.Exp


e を指定された数値でべき乗します。


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

e を `number` (指数関数) でべき乗した結果を返します。

-   `number`: 指数関数を計算する対象の `number`。`number` が null の場合、`Number.Exp` は null を返します。


## Examples

### Example #1
e を 3 でべき乗します。
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.Abs


数値の絶対値を返します。


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

`number` の絶対値を返します。`number` が null の場合、`Number.Abs` は null を返します。

-   `number`: 絶対値を計算する対象の `number`。


## Examples

### Example #1
\-3 の絶対値。
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Number.Ln


数値の自然対数を返します。


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

数値 `number` の自然対数を返します。`number` が NULL の場合、`Number.Ln` は NULL を返します。


## Examples

### Example #1
15 の自然対数を取得します。
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

# Number.Cos


数値のコサインを返します。


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

指定された角度の余弦を返します。

-   `number`: ラジアン単位の角度。


## Examples

### Example #1
角度 0 のコサインを求めます。
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
π ラジアンの余弦を求めます。
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

# Type.ReplaceTablePartitionKey


指定したパーティション キーで置き換えられたパーティション キーで、新しいテーブル型を返します。


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

指定したパーティション キーで置き換えられたパーティション キーで、新しいテーブル型を返します。

# Descubra a linguagem
A linguagem de fórmulas Power Query M está otimizada para criar consultas de combinação de dados altamente flexíveis. É uma linguagem funcional, sensível a maiúsculas e minúsculas, semelhante ao F#. A linguagem de fórmulas Power Query é utilizada em vários produtos da Microsoft, como o Power BI Desktop, o Excel e o Analysis Services.

Este site serve de referência para as funções do Power Query, oferecendo acesso rápido e direto a informações detalhadas e exemplos práticos para cada função.
:::note
Tenha em atenção que o autor não reivindica quaisquer direitos de autor sobre os materiais apresentados neste site. As informações são recolhidas e disponibilizadas na esperança de que sejam úteis para quem pretende expandir o seu conhecimento e a aplicação do Power Query.
:::

A funcionalidade de pesquisa neste website deverá simplificar o processo de descoberta da vasta gama de funções do Power Query. Não deixe de a experimentar (Ctrl+K).

![Funcionalidade de pesquisa fornecida pela Algolia](/img/search.png)

Para quem tiver interesse numa exploração mais aprofundada ou em detalhes de implementação, é possível encontrar mais informações no seguinte repositório do GitHub: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Este repositório pode conter exemplos adicionais, atualizações e recursos relevantes para o desenvolvimento e a utilização do Power Query.

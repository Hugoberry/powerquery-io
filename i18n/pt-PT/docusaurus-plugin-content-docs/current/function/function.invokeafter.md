# Function.InvokeAfter


Invoca a função indicada após a duração especificada ter passado.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Devolve o resultado da invocação de `function` após a duração `delay` ter passado.

Function

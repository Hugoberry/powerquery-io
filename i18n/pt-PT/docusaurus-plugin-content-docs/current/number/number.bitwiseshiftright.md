# Number.BitwiseShiftRight


Desvia os bits definidos para a direita.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devolve o resultado da execução de um desvio bit a bit para a direita em `number1` pelo número especificado de bits `number2`.

Number.Bytes

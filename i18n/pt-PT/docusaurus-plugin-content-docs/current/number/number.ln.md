# Number.Ln


Devolve o logaritmo natural do número.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Devolve o logaritmo natural de um número, `number`. Se `number` for nulo, `Number.Ln` devolverá um valor nulo.


## Examples

### Example #1
Obter o logaritmo natural de 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

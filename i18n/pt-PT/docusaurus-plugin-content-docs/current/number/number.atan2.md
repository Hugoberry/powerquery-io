# Number.Atan2


Devolve o arco de tangente da divisão dos dois números.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Devolve o ângulo, em radianos, cuja tangente é o quociente `y`/`x` dos dois números `y` e `x`.

# Number.BitwiseXor


Devolve o resultado da execução de uma operação "XOR" (Exclusive-OR) bit a bit entre as duas entradas.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devolve o resultado da execução de uma operação "XOR" (Exclusive-OR) bit a bit entre `number1` e `number2`.

Number.Bytes

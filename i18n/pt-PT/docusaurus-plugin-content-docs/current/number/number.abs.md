# Number.Abs


Devolve o valor absoluto do número.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Devolve o valor absoluto de `number`. Se `number` for nulo, `Number.Abs` devolverá um valor nulo.

-   `number`: um `number` para o qual o valor absoluto deve ser calculado.


## Examples

### Example #1
Valor absoluto de -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

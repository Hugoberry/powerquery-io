# Number.BitwiseAnd


Devolve o resultado da execução de uma operação "And" bit a bit entre duas entradas.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devolve o resultado da execução de uma operação "And" bit a bit entre `number1` e `number2`.



## Category
Number.Bytes

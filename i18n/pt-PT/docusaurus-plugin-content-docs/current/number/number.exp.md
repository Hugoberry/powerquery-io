# Number.Exp


Eleva e à potência especificada.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Devolve o valor de elevar e à potência de `number` (função exponencial).

-   `number`: um `number` para o qual a função exponencial deve ser calculada. Se `number` for nulo, `Number.Exp` devolverá um valor nulo.


## Examples

### Example #1
Elevar e à potência de 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.BitwiseShiftLeft


Desvia os bits definidos para a esquerda.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devolve o resultado da execução de um desvio bit a bit para a esquerda em `number1` pelo número especificado de bits `number2`.

Number.Bytes

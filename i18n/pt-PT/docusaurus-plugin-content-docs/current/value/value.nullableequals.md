# Value.NullableEquals


Devolve se dois valores são iguais.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Devolve null se um dos argumentos, `value1` ou `value2`, for null; caso contrário, é equivalente a Value.Equals.

Values

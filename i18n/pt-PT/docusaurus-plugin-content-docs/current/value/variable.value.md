# Variable.Value


Devolve o valor da variável especificada.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Devolve o valor da variável especificada `identifier` definida pelo ambiente de avaliação atual. Se a variável não estiver definida, é gerado um erro.

# Value.Equals


Devolve se dois valores são iguais.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Devolve true se o valor `value1` for igual ao valor `value2`; caso contrário, devolve false.

Values

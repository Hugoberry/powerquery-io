# Uri.Combine


Devolve um URI absoluto que é a combinação do URI base e do URI relativo de entrada.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Devolve um URI absoluto que é a combinação do `baseUri` e `relativeUri` de entrada.

# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Inverte o `text` fornecido.


## Examples

### Example #1
Inverter o texto "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

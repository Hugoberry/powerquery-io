# Cube.ApplyParameter


Devolve um cubo após aplicar-lhe um parâmetro.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Devolve um cubo após aplicar `parameter` com `arguments` a `cube`.

# Cube.AttributeMemberProperty


Devolve uma propriedade de um atributo de dimensão.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Devolve a propriedade `propertyName` do atributo de dimensão `attribute`.

Cube

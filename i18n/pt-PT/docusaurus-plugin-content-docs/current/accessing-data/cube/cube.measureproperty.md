# Cube.MeasureProperty


Devolve uma propriedade de uma medida (propriedade de célula).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Devolve a propriedade `propertyName` do atributo de dimensão `measure`.

Cube

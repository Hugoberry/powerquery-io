# Exchange.Contents


Devolve uma tabela com o conteúdo de uma conta do Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Devolve um índice da conta do Microsoft Exchange `mailboxAddress`. Se `mailboxAddress` não for especificada, será utilizada a conta predefinida da credencial.

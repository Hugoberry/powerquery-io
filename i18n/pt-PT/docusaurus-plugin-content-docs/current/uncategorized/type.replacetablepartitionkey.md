# Type.ReplaceTablePartitionKey


Devolve um novo tipo de tabela com a chave de partição substituída pela chave de partição especificada.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Devolve um novo tipo de tabela com a chave de partição substituída pela chave de partição especificada.

# Type.TablePartitionKey


Retorna a chave de partição para o tipo de tabela fornecido, se ele tiver uma.


## Syntax

```powerquery
Type.TablePartitionKey(
    tableType as type
) as list
```


## Remarks

Retorna a chave de partição para o tipo de tabela fornecido, se ele tiver uma.

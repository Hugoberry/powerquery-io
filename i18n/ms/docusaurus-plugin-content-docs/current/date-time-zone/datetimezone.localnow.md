# DateTimeZone.LocalNow


Mengembalikan tarikh & masa semasa dalam zon waktu tempatan.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Mengembalikan nilai `datetimezone` yang disetkan kepada tarikh dan masa semasa pada sistem. Nilai yang dikembalikan mengandungi maklumat zon waktu yang mewakili zon waktu tempatan.

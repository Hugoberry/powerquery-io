# Number.BitwiseShiftRight


Menganjak set bit ke kanan.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Mengembalikan hasil daripada melaksanakan anjakan bit ke kanan pada `number1`, sebanyak bilangan bit yang ditentukan `number2`.

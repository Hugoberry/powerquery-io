# Number.Atan2


Mengembalikan lengkok tangen bagi pembahagian dua nombor.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Mengembalikan sudut, dalam radian, yang tangennya ialah hasil bahagi `y`/`x` daripada dua nombor `y` dan `x`.

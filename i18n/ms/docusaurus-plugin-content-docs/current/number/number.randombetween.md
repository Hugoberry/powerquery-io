# Number.RandomBetween


Mengembalikan nombor rawak antara dua nombor.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Mengembalikan nombor rawak antara `bottom` dan `top`.


## Examples

### Example #1
Dapatkan nombor rawak antara 1 dan 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

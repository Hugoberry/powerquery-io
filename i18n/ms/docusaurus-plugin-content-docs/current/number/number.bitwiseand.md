# Number.BitwiseAnd


Mengembalikan hasil daripada melaksanakan operasi bit "Dan" antara dua input.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Mengembalikan hasil daripada melaksanakan operasi bit "Dan" antara `number1` dan `number2`.

Number.Bytes

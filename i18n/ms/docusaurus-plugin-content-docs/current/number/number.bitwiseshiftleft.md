# Number.BitwiseShiftLeft


Menganjak set bit ke kiri.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Mengembalikan hasil daripada melaksanakan anjakan bit ke kiri pada `number1`, sebanyak bilangan bit yang ditentukan `number2`.

# Number.Abs


Mengembalikan nilai mutlak bagi nombor.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Mengembalikan nilai mutlak bagi `number`. Jika `number` adalah nol, `Number.Abs` mengembalikan nol.

-   `number`: `number` untuk yang mana nilai mutlak perlu dikira.


## Examples

### Example #1
Nilai mutlak -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

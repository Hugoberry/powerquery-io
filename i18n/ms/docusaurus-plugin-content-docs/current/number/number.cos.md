# Number.Cos


Mengembalikan kosinus bagi nombor.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Mengembalikan kosinus bagi sudut yang ditentukan.

-   `number`: Sudut, diukur dalam radian.


## Examples

### Example #1
Cari kosinus bagi sudut 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Cari kosinus π radian.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

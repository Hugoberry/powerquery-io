# Number.BitwiseOr


Mengembalikan hasil daripada melaksanakan bit "Atau" antara dua input.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Mengembalikan hasil daripada melaksanakan bit "Atau" antara `number1` dan `number2`.

Number.Bytes

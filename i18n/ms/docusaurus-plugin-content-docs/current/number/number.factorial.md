# Number.Factorial


Mengembalikan faktorial bagi nombor.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

Mengembalikan faktorial bagi nombor `number`.


## Examples

### Example #1
Cari faktorial bagi 10.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

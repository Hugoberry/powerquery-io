# Number.IsEven


Menunjukkan sama ada nilai genap.


## Syntax

```powerquery
Number.IsEven(
    number as number
) as logical
```


## Remarks

Menunjukkan sama ada nilai, `number`, ialah genap dengan mengembalikan `true` jika ia genap, `false` sebaliknya.


## Examples

### Example #1
Semak sama ada 625 ialah nombor genap.
```powerquery
Number.IsEven(625)
```

Result: 
```powerquery
false
```


### Example #2
Semak sama ada 82 ialah nombor genap.
```powerquery
Number.IsEven(82)
```

Result: 
```powerquery
true
```

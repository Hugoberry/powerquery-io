# Number.Exp


Menguasakan e kepada kuasa yang ditentukan.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Mengembalikan hasil daripada menguasakan e kepada kuasa `number` (fungsi eksponen).

-   `number`: `number` untuk yang mana fungsi eksponen perlu dikira. Jika `number` adalah nol, `Number.Exp` mengembalikan nol.


## Examples

### Example #1
Kuasakan e kepada kuasa 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

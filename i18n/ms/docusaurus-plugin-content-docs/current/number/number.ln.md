# Number.Ln


Mengembalikan logaritma asli bagi nombor.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Mengembalikan logaritma asli bagi nombor, `number`. Jika `number` adalah nol `Number.Ln` mengembalikan nol.


## Examples

### Example #1
Dapatkan logaritma asli bagi 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

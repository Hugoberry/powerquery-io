# Number.BitwiseNot


Mengembalikan bait yang mana setiap bit ialah bertentangan input.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Mengembalikan hasil daripada melaksanakan operasi bit "Not" pada `number`.



## Category
Number.Bytes

# Number.Log10


Mengembalikan logaritma asas 10 bagi nombor.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Mengembalikan logaritma asas 10 bagi nombor, `number`. Jika `number` ialah nol `Number.Log10`, mengembalikan nol.


## Examples

### Example #1
Dapatkan logaritma asas 10 bagi 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

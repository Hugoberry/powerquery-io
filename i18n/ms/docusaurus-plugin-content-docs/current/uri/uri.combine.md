# Uri.Combine


Mengembalikan URI mutlak yang merupakan gabungan URI asas input dan URI relatif.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Mengembalikan URI mutlak yang merupakan gabungan input `baseUri` dan `relativeUri`.

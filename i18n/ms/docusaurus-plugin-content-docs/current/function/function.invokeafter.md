# Function.InvokeAfter


Kerahkan fungsi yang diberi selepas tempoh yang ditentukan telah dihantar.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Kembalikan hasil kerahan `function` selepas tempoh `delay` telah dihantar.



## Category
Function

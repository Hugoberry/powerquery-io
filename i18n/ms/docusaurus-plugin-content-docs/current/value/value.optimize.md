# Value.Optimize


Memberi isyarat Value. Expression untuk mengembalikan ungkapan yang dioptimumkan untuk nilai.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Apabila digunakan dalam Value.Expression, jika `value` mewakili pertanyaan yang boleh dioptimumkan, fungsi ini menunjukkan bahawa ungkapan yang dioptimumkan perlu dikembalikan. Jika tidak, `value` akan dihantar tanpa kesan.

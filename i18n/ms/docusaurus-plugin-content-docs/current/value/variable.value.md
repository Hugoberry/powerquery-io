# Variable.Value


Mengembalikan nilai pemboleh ubah yang ditentukan.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Mengembalikan nilai pemboleh ubah yang ditentukan `identifier` ditakrifkan oleh persekitaran penilaian semasa. Jika pemboleh ubah tidak ditakrifkan, ralat akan dibangkitkan.

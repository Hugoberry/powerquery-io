# Value.Multiply


Mengembalikan hasil daripada dua nilai.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Mengembalikan hasil daripada mendarab `value1` dengan `value2`. Parameter `precision` pilihan boleh ditentukan, `Precision.Double` digunakan secara lalai.

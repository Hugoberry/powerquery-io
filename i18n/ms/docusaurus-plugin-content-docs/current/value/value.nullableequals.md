# Value.NullableEquals


Mengembalikan sama ada dua nilai adalah sama.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Mengembalikan nol jika mana-mana argumen `value1` atau `value2` adalah nol, sebaliknya bersamaan dengan Value.Equals.

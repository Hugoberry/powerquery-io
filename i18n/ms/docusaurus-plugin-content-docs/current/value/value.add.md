# Value.Add


Mengembalikan jumlah dua nilai.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Mengembalikan jumlah `value1` dan `value2`. Parameter `precision` pilihan boleh ditentukan, `Precision.Double` digunakan secara lalai.

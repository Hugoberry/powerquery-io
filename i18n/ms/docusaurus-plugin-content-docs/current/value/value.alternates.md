# Value.Alternates


Melahirkan pelan pertanyaan alternatif.


## Syntax

```powerquery
Value.Alternates(
    alternates as list
) as any
```


## Remarks

Melahirkan pelan pertanyaan alternatif dalam ungkapan pelan pertanyaan yang diperoleh melalui `Value.Expression(Value.Optimize(...))`. Tidak bertujuan untuk kegunaan lain.

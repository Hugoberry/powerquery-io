# Value.Equals


Mengembalikan sama ada dua nilai adalah sama.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Mengembalikan benar jika nilai `value1` adalah sama dengan nilai `value2`, palsu jika sebaliknya.

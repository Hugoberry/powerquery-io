# Value.Divide


Mengembalikan hasil daripada membahagi nilai pertama dengan nilai kedua.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Mengembalikan hasil daripada membahagi `value1` dengan `value2`. Parameter `precision` pilihan boleh ditentukan, `Precision.Double` digunakan secara lalai.

# Value.VersionIdentity


Mengembalikan identiti versi bagi nilai.


## Syntax

```powerquery
Value.VersionIdentity(
    value as any
) as any
```


## Remarks

Mengembalikan identiti versi `value`, atau `null` jika ia tidak mempunyai versi.

# Value.Subtract


Mengembalikan perbezaan dua nilai.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Mengembalikan perbezaan untuk `value1` dan `value2`. Parameter `precision` pilihan boleh ditentukan, `Precision.Double` digunakan secara lalai.

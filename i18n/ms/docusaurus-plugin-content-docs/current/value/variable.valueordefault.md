# Variable.ValueOrDefault


Mengembalikan nilai pemboleh ubah yang ditentukan atau nilai lalai jika pemboleh ubah tidak ditakrifkan.


## Syntax

```powerquery
Variable.ValueOrDefault(
    identifier as text,
    optional defaultValue as any
) as any
```


## Remarks

Mengembalikan nilai pemboleh ubah yang ditentukan `identifier` ditakrifkan oleh persekitaran penilaian semasa. Jika pemboleh ubah tidak ditakrifkan, `defaultValue` pilihan akan dikembalikan.

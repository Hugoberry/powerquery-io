# Binary.ViewError


Mencipta rekod ralat diubah suai yang tidak akan mencetuskan sandaran apabila dikembalikan oleh pengendali yang ditentukan pada pandangan (melalui Binary.View).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Mencipta rekod ralat diubah suai daripada `errorRecord` yang tidak akan mencetuskan sandaran apabila dipaparkan oleh pengendali yang ditentukan pada pandangan (melalui Binary.View).

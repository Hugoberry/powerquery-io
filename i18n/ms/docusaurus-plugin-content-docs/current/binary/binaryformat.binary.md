# BinaryFormat.Binary


Mengembalikan format perduaan yang membaca nilai perduaan.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Mengembalikan format perduaan yang membaca nilai perduaan. Jika `length` ditentukan, nilai perduaan akan mengandungi bait sebanyak itu. Jika `length` tidak ditentukan, nilai perduaan akan mengandungi baki bait. `length` boleh ditentukan sama ada sebagai nombor atau sebagai format perduaan bagi panjang yang mendahului data perduaan.

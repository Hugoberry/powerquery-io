# BinaryFormat.ByteOrder


Mengembalikan format perduaan dengan tertib bait yang ditentukan oleh fungsi.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Mengembalikan format perduaan dengan tertib bait yang ditentukan oleh `binaryFormat`. Tertib bait lalai ialah `ByteOrder.BigEndian`.

# Essbase.Cubes


Mengembalikan kiub dalam tika Essbase yang dikumpulkan oleh pelayan Essbase.


## Syntax

```powerquery
Essbase.Cubes(
    url as text,
    optional options as record
) as table
```


## Remarks

Mengembalikan jadual kiub yang dikumpulkan oleh pelayan Essbase daripada tika Essbase di pelayan APS `url`. Parameter rekod pilihan, `options`, boleh ditentukan untuk mengawal opsyen berikut:

-   `CommandTimeout` : Tempoh yang mengawal berapa lama pertanyaan bahagian pelayan dibenarkan berjalan sebelum ia dibatalkan. Nilai lalai ialah sepuluh minit.

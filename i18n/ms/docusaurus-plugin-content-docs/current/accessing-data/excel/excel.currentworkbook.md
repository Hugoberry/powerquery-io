# Excel.CurrentWorkbook


Mengembalikan kandungan buku kerja Excel semasa.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Mengembalikan kandungan buku kerja Excel semasa. Ia mengembalikan jadual, julat bernama dan tatasusunan dinamik. Tidak suka `Excel.Workbook`, ia tidak mengembalikan helaian.

# Folder.Contents


Mengembalikan jadual yang mengandungi sifat dan kandungan fail dan folder yang ditemui dalam folder yang ditentukan.


## Syntax

```powerquery
Folder.Contents(
    path as text,
    optional options as record
) as table
```


## Remarks

Mengembalikan jadual yang mengandungi baris untuk setiap folder dan fail yang ditemui dalam `path` folder. Setiap baris mengandungi sifat folder atau fail dan pautan ke kandungannya. Parameter `options` bertujuan untuk kegunaan dalaman sahaja buat masa ini.

# Exchange.Contents


Mengembalikan jadual kandungan daripada akaun Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Mengembalikan jadual kandungan daripada akaun Microsoft Exchange `mailboxAddress`. Jika `mailboxAddress` tidak ditentukan, akaun lalai bagi kelayakan akan digunakan.

# Soda.Feed


Mengembalikan jadual daripada kandungan pada URL yang ditentukan yang diformatkan menurut API SODA 2.0.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

Mengembalikan jadual daripada kandungan pada URL `url` yang ditentukan yang diformatkan menurut API SODA 2.0. URL mesti menuding kepada sumber mematuhi SODA yang sah yang berakhir dengan sambungan .csv.

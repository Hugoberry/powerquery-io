# Cube.Dimensions


Mengembalikan jadual yang mengandungi set dimensi yang tersedia.


## Syntax

```powerquery
Cube.Dimensions(
    cube as table
) as table
```


## Remarks

Mengembalikan jadual yang mengandungi set dimensi yang tersedia dalam `cube`. Setiap dimensi ialah jadual yang mengandungi set atribut dimensi dan setiap atribut dimensi diwakili sebagai lajur dalam jadual dimensi. Dimensi boleh dikembangkan dalam kiub menggunakan Cube.AddAndExpandDimensionColumn.

# HdInsight.Files


Kembalikan jadual yang mengandungi sifat dan kandungan blob yang ditemui dalam bekas yang ditentukan daripada ruang simmpanan storan Azure.


## Syntax

```powerquery
HdInsight.Files(
    account as text,
    containerName as text
) as table
```


## Remarks

Kembalikan jadual yang mengandungi bari bagi setiap fail blob yang ditemui pada URL bekas, `account`, daripada ruang simpanan storan Azure. Setiap baris mengandungi sifat fail dan pautan kepada kandungannya.

# Cube.DisplayFolders


Mengembalikan pohon jadual tersarang yang mewakili hierarki folder paparan bagi objek (contohnya, dimensi dan ukuran).


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Mengembalikan pohon jadual tersarang yang mewakili hierarki folder paparan bagi objek (contohnya, dimensi dan ukuran) yang tersedia untuk digunakan dalam `cube`.

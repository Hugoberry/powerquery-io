# Cube.MeasureProperty


Mengembalikan sifat ukuran (sifat sel).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Mengembalikan sifat `propertyName` atribut dimensi `measure`.

Cube

# Cube.Parameters


Mengembalikan jadual yang mengandungi set parameter yang boleh digunakan pada kuib.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Mengembalikan jadual yang mengandungi set parameter yang boleh digunakan pada `cube`. Setiap parameter merupakan fungsi yang boleh dimohon untuk mendapatkan `cube` yang berparameter dan argumennya dikenakan.

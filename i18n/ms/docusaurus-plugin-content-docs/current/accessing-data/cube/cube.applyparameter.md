# Cube.ApplyParameter


Mengembalikan kiub selepas menggunakan parameter padanya.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Mengembalikan kiub selepas menggunakan `parameter` dengan `arguments` ke `cube`.

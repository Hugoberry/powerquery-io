# Cube.AttributeMemberProperty


Mengembalikan sifat bagi atribut dimensi.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Mengembalikan sifat `propertyName` atribut dimensi `attribute`.

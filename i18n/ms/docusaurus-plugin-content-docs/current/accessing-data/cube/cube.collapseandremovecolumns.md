# Cube.CollapseAndRemoveColumns


Mengubah kebutiran dimensi bagi konteks penapis untuk kiub dengan meruntuhkan atribut yang dipetakan pada lajur yang ditentukan.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Mengubah kebutiran dimensi bagi konteks penapis untuk `cube` dengan meruntuhkan atribut yang dipetakan pada lajur `columnNames` yang ditentukan. Lajur juga dialih keluar daripada pandangan jadual bagi kiub.

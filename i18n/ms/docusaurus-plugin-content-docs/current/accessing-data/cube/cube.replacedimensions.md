# Cube.ReplaceDimensions


Menggantikan set dimensi yang dikembalikan oleh Cube.Dimensions.


## Syntax

```powerquery
Cube.ReplaceDimensions(
    cube as table,
    dimensions as any
) as table
```


## Remarks

Menggantikan set dimensi yang dikembalikan oleh `Cube.Dimensions`. Sebagai contoh, fungsi ini boleh digunakan untuk menambah lajur ID pada atribut dimensi, supaya sumber data boleh dikumpulkan pada ID dan bukannya pada nilai yang dipaparkan.

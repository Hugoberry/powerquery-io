# Cube.AttributeMemberId


Kembalikan pengecam ahli unik daripada nilai sifat ahli.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Kembalikan pengecam ahli unik daripada nilai sifat ahli. `attribute`. Kembalikan nol bagi sebarang nilai yang lain.

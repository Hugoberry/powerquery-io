# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Penyambung Analitis Teams membolehkan anda mendapatkan cerapan ke dalam penggunaan Teams anda. Data tersedia untuk kedua-dua aktiviti peribadi anda dalam Teams dan juga aktiviti dalam Teams anda ialah ahlinya.

Data tersedia untuk tempoh 90 hari sebelumnya.

Untuk butiran tentang jenis data yang tersedia, sila rujuk dokumentasi bantuan yang berikut:

-   **Penggunaan Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Aktiviti Pengguna Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

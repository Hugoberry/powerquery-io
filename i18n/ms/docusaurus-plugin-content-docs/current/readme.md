# Terokai bahasanya
Bahasa formula Power Query M dioptimumkan untuk membina pertanyaan gabungan data yang sangat fleksibel. Ia merupakan bahasa berfungsi yang sensitif huruf besar-kecil, serupa dengan F#. Bahasa Formula Power Query digunakan dalam beberapa produk Microsoft seperti Power BI Desktop, Excel dan Analysis Services.

Laman ini berfungsi sebagai rujukan untuk fungsi Power Query, menawarkan akses pantas dan terus kepada maklumat terperinci serta contoh praktikal bagi setiap fungsi.
:::note
Sila ambil perhatian, penulis tidak menuntut sebarang hak cipta ke atas bahan yang dipaparkan di laman ini. Maklumat dikumpulkan dan disediakan dengan harapan ia akan berguna bagi mereka yang ingin meluaskan pengetahuan dan penggunaan Power Query.
:::

Fungsi carian di laman web ini sepatutnya memudahkan proses penemuan pelbagai jenis fungsi Power Query. Pastikan anda mencubanya (Ctrl+K).

![Fungsi carian disediakan oleh Algolia](/img/search.png)

Bagi mereka yang berminat dengan penerokaan lebih mendalam atau butiran pelaksanaan, maklumat lanjut boleh didapati dalam repositori GitHub berikut: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Repositori ini mungkin mengandungi contoh tambahan, kemas kini dan sumber yang berkaitan dengan pembangunan dan penggunaan Power Query.

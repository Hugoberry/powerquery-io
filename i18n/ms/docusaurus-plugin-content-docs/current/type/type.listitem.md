# Type.ListItem


Kembalikan jenis item daripada jenis senarai.


## Syntax

```powerquery
Type.ListItem(
    type as type
) as type
```


## Remarks

Kembalikan jenis item daripada senarai `type`.


## Examples

### Example #1
Cari jenis item daripada senarai `{number}`.
```powerquery
Type.ListItem(type {number})
```

Result: 
```powerquery
type number
```

# Type.ReplaceTablePartitionKey


Mengembalikan jenis jadual baharu dengan kunci petak yang digantikan oleh kunci petak yang ditentukan.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Mengembalikan jenis jadual baharu dengan kunci petak yang digantikan oleh kunci petak yang ditentukan.

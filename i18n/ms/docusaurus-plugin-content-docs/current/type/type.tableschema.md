# Type.TableSchema


Mengembalikan jadual yang mengandungi perihalan lajur (iaitu skema) bagi jenis jadual yang ditentukan.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Mengembalikan jadual yang menerangkan lajur bagi `tableType`.

Rujuk dokumentasi untuk `Table.Schema` untuk penerangan bagi jadual yang terhasil.

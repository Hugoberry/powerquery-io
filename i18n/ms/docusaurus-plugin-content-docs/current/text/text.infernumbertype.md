# Text.InferNumberType


Mentaabir jenis nombor bergranul (Int64.Type, Double.Type, dan sebagainya) bagi nombor yang dikodkan dalam teks.


## Syntax

```powerquery
Text.InferNumberType(
    text as text,
    optional culture as text
) as type
```


## Remarks

Mentaabir jenis nombor bergranul (Int64.Type, Double.Type, dan sebagainya) bagi `text`. Ralat dibangkitkan jika `text` bukan nombor. `culture` pilihan mungkin juga diberikan (contohnya, "en-US").

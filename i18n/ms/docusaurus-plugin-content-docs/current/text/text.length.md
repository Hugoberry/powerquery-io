# Text.Length


Mengembalikan bilangan aksara.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Mengembalikan bilangan aksara dalam teks `text`.


## Examples

### Example #1
Cari bilangan aksara yang ada dalam teks "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

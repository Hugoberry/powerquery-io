# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Menterbalikkan `text` yang diberikan.


## Examples

### Example #1
Terbalikkan teks "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

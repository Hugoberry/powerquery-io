# Table.ViewError


Mencipta rekod ralat diubah suai yang tidak akan mencetuskan sandaran apabila dipaparkan oleh pengendali yang ditentukan pada pandangan (melalui Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Mencipta rekod ralat diubah suai daripada `errorRecord` yang tidak akan mencetuskan sandaran apabila dipaparkan oleh pengendali yang ditentukan pada pandangan (melalui Table.View).

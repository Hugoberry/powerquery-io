# Tables.GetRelationships


Dapatkan perhubungan di antara set jadual.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Dapatkan hubungan di antara set jadual. Set `tables` dianggarkan mempunyai struktur yang sama dengan jadual navigasi. Lajur yang ditakrifkan oleh `dataColumn` mengandungi jadual data yang sebenar.

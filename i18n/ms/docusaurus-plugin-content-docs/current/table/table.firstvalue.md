# Table.FirstValue


Mengembalikan lajur pertama daripada baris pertama jadual atau nilai lalai yang dinyatakan.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Mengembalikan lajur pertama daripada baris pertama jadual `table` atau nilai lalai yang dinyatakan.

Table.Row operations

# Table.Profile


Mengembalikan profil lajur jadual.


## Syntax

```powerquery
Table.Profile(
    table as table,
    optional additionalAggregates as list
) as table
```


## Remarks

Mengembalikan profil untuk lajur dalam `table`.

Maklumat berikut dikembalikan untuk setiap lajur (jika berkenaan):

-   minimum
-   maksimum
-   purata
-   sisihan standard
-   kiraan
-   kiraan nol
-   kiraan berbeza

# Number.Log10


傳回數字以 10 為底數的對數。


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

傳回數字 `number` 以 10 為底數的對數。若 `number` 為 Null，`Number.Log10` 會傳回 Null。


## Examples

### Example #1
取得 2 以 10 為底數的對數。
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

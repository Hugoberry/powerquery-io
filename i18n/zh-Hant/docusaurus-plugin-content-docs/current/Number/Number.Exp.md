# Number.Exp


求 e 的指定次方。


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

傳回 e 的 `number` 次方 (指數函數) 結果。

-   `number`: 要計算其指數函數的 `number`。如果 `number` 是 Null，`Number.Exp` 會傳回 Null。


## Examples

### Example #1
取 e 的 3 次方。
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

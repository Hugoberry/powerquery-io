# Number.Abs


傳回數字的絕對值。


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

傳回 `number` 的絕對值。如果 `number` 是 Null，`Number.Abs` 會傳回 Null。

-   `number`: 要計算其絕對值的 `number`。


## Examples

### Example #1
\-3 的絕對值。
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Value.Subtract


傳回兩個值的差額。


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

傳回 `value1` 與 `value2` 的差額。可指定選擇性 `precision` 參數，預設使用 `Precision.Double`。

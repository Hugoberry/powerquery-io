# Cube.ApplyParameter


在對其套用參數之後，傳回一個 Cube。


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

在將含有 `arguments` 的 `parameter` 套用至 `cube` 之後，傳回一個 Cube。

Cube

# Value.Divide


傳回第一個值除以第二個值的結果。


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

傳回 `value1` 除以 `value2` 的結果。可指定選擇性 `precision` 參數，預設使用 `Precision.Double`。

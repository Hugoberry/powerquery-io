# Table.ViewError


建立修改的錯誤記錄，其中在由檢視上定義 (透過 Table.View) 的處理常式引發時，不會觸發後援。


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

從 `errorRecord` 建立修改的錯誤記錄，其中在由檢視上定義 (透過 Table.View) 的處理常式引發時，不會觸發後援。

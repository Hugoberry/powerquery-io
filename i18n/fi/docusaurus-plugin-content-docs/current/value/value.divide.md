# Value.Divide


Palauttaa ensimmäisen arvon toisella arvolla jakamisen tuloksen.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Palauttaa luvun `value1` luvulla `value2` jakamisen tuloksen. Valinnainen parametri `precision` voidaan määrittää. Oletusarvon mukaan käytetään kohdetta `Precision.Double`.

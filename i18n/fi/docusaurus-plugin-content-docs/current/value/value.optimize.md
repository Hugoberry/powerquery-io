# Value.Optimize


Antaa Value.Expression-asetuksen palauttaa arvon optimoidun lausekkeen.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Kun sitä käytetään Value.Expression-funktiossa ja `value` edustaa optimoitavaa kyselyä, tämä funktio osoittaa, että optimoitu lauseke on palautettava. Muuten `value` välitetään ilman vaikutusta.

Expression

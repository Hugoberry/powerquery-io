# Value.NullableEquals


Palauttaa tiedon siitä, ovatko kaksi arvoa yhtä suuret.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Palauttaa tyhjän arvon, jos jompikumpi argumenteista `value1` tai `value2` on tyhjä, muuten vastaa Value.Equals-arvoa.

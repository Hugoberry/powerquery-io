# Value.Multiply


Palauttaa kahden arvon tulon.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Palauttaa arvon `value1` arvolla `value2` kertomisen tulon. Valinnainen parametri `precision` voidaan määrittää. Oletusarvon mukaan käytetään kohdetta `Precision.Double`.

# Value.Alternates


Ilmaisee vaihtoehtoisia kyselysuunnitelmia.


## Syntax

```powerquery
Value.Alternates(
    alternates as list
) as any
```


## Remarks

Ilmaisee vaihtoehtoisia kyselysuunnitelmia kyselysuunnitelmalausekkeen sisällä, joka on saatu käyttämällä `Value.Expression(Value.Optimize(...))`. Ei ole tarkoitettu muuhun käyttöön.

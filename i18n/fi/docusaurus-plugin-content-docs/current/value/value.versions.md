# Value.Versions


Palauttaa siirtymistaulukon, joka sisältää arvon käytettävissä olevat versiot.


## Syntax

```powerquery
Value.Versions(
    value as any
) as table
```


## Remarks

Palauttaa siirtymistaulukon, joka sisältää kohteen `value` käytettävissä olevat versiot.

# Value.Subtract


Palauttaa kahden arvon eron.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Palauttaa kohteiden `value1` ja `value2` eron. Valinnainen parametri `precision` voidaan määrittää. Oletusarvon mukaan käytetään kohdetta `Precision.Double`.

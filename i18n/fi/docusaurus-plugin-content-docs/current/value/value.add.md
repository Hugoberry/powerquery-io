# Value.Add


Palauttaa kahden arvon summan.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Palauttaa kohteiden `value1` ja `value2` summan. Valinnainen parametri `precision` voidaan määrittää. Oletusarvon mukaan käytetään kohdetta `Precision.Double`.

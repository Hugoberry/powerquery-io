# Value.Equals


Palauttaa tiedon siitä, ovatko kaksi arvoa yhtä suuret.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Palauttaa arvon true, jos arvo `value1` on yhtä suuri kuin arvo `value2`, ja muutoin arvon false.

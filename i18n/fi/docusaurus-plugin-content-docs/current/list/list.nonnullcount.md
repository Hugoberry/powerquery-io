# List.NonNullCount


Palauttaa luettelon muiden kuin tyhjäarvoisten kohteiden määrän.


## Syntax

```powerquery
List.NonNullCount(
    list as list
) as number
```


## Remarks

Palauttaa luettelon `list` muiden kuin tyhjäarvoisten kohteiden määrän.

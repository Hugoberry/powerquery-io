# Function.InvokeAfter


Käynnistää määritetyn funktion, kun määritetty kesto on kulunut.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Palauttaa tulokset kohteen `function` käynnistämisestä, kun kesto `delay` on kulunut.

Function

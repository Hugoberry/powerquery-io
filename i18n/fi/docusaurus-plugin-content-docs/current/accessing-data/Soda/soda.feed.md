# Soda.Feed


Palauttaa taulukon määritetyn URL-osoitteen sisällöstä muotoiltuna SODA 2.0 -ohjelmointirajapinnan mukaisesti.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

Palauttaa taulukon määritetyn URL-osoitteen `url` sisällöstä muotoiltuna SODA 2.0 -ohjelmointirajapinnan mukaisesti. URL-osoitteen on osoitettava kelvolliseen SODA-yhteensopivaan lähteeseen, joka päättyy .csv-tiedostotunnisteeseen.

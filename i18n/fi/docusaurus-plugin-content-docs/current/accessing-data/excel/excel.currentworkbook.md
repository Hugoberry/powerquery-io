# Excel.CurrentWorkbook


Palauttaa nykyisen Excel-työkirjan sisällön.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Palauttaa nykyisen Excel-työkirjan sisällön. Palauttaa taulukot, nimetyt alueet ja dynaamiset matriisit.Toisin kuin `Excel.Workbook`, se ei palauta taulukoita.

# Parquet.Document


Palauttaa Parquet-tiedoston sisällön taulukkona.


## Syntax

```powerquery
Parquet.Document(
    binary as binary,
    optional options as record
) as any
```


## Remarks

Palauttaa Parquet-tiedoston sisällön taulukkona. Vaihtoehtoihin sisältyvät seuraavat:

-   `TypeMapping`: Tekstiarvo, joka hallinnoi yhdistämismäärityksen oletustyyppiä tiedostoja kirjoitettaessa ja luettaessa. Oletusarvo on tyhjä ja pyrkii vastaamaan alkuperäistä tyyppiä mahdollisimman hyvin. SQL-arvo tuottaa SQL Serverin kanssa yhteensopivimpia tuloksia.

# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Teamsin Analytics-liittimen avulla voit saada merkityksellisiä tietoja Teamsin käytöstäsi. Tiedot ovat käytettävissä sekä henkilökohtaiseen toimintaasi Teamsissa että toimintaan Teamsissa, jonka jäsen olet.

Tiedot ovat käytettävissä edelliseltä 90 päivältä.

Tietoja käytettävissä olevista tietotyypeistä tietoja on seuraavassa ohjeessa:

-   **Teamsin käyttö:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Teamsin käyttäjätoiminta:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

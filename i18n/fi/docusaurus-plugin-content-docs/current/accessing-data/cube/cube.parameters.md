# Cube.Parameters


Palauttaa taulukon, joka sisältää joukon parametreja, joita voi käyttää kuutiolle.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Palauttaa taulukon, joka sisältää joukon parametreja, joita voi käyttää kohteelle `cube`. Kukin parametri on funktio, joka voidaan käynnistää, jotta saadaan `cube`, kun parametri ja sen argumentit ovat käytössä.

# Cube.AttributeMemberProperty


Palauttaa dimensiomääritteen ominaisuuden.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Palauttaa dimensioattribuutin `attribute` ominaisuuden `propertyName`.

# Cube.AttributeMemberId


Palauttaa yksilöivän jäsentunnuksen jäsenten ominaisuuden arvosta.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Palauttaa yksilöivän jäsentunnuksen jäsenen ominaisuuden arvosta. `attribute`. Palauttaa tyhjäarvon mille tahansa muille arvoille.

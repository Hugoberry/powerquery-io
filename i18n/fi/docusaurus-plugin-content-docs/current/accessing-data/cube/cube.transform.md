# Cube.Transform


Ottaa käyttöön kuutiofunktioiden luettelon.


## Syntax

```powerquery
Cube.Transform(
    cube as table,
    transforms as list
) as table
```


## Remarks

Ottaa käyttöön kuutiofunktioiden luettelon `transforms` kohteessa `cube`.

Cube

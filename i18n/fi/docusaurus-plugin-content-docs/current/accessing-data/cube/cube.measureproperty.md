# Cube.MeasureProperty


Palauttaa mittayksikön ominaisuuden (solun ominaisuuden).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Palauttaa mittayksikön `measure` ominaisuuden `propertyName`.

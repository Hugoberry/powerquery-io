# Exchange.Contents


Palauttaa sisällysluettelon Microsoft Exchange -tilistä.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Palauttaa sisällysluettelon Microsoft Exchange -tililtä `mailboxAddress`. Jos kohdetta `mailboxAddress` ei määritetä, käytetään tunnistetiedon oletustiliä.

# File.Contents


Palauttaa määritetyn tiedoston sisällön binaarimuodossa.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Palauttaa tiedoston sisällön binaarimuodossa `path`. `options`\-parametri on tällä hetkellä tarkoitettu vain sisäiseen käyttöön.

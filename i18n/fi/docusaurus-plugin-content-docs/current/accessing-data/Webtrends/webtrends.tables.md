# Webtrends.Tables


Anna Webtrends-tiliisi liittyvä profiilitunnus.


## Syntax

```powerquery
Webtrends.Tables(
    ProfileId as text,
    optional startDate as date,
    optional endDate as date
) as table
```


## Remarks

Palauttaa olennaisia Webtrends-tietoja sisältävän taulukon.

# Cube.ApplyParameter


Palauttaa kuution parametrin sille käyttämisen jälkeen.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Palauttaa kuution sen jälkeen, kun kohdetta `parameter` ja kohdetta `arguments` käytettiin kohteelle `cube`.

# Cube.Measures


Palauttaa taulukon, joka sisältää käytettävissä olevien mittayksiköiden joukon.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Palauttaa taulukon, joka sisältää kohteessa `cube` käytettävissä olevien mittayksiköiden joukon. Kukin mittayksikkö on esitetty funktiona. Mittayksiköitä voi käyttää kuutiossa käyttämällä menetelmää Cube.AddMeasureColumn.

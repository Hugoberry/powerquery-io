# Cube.CollapseAndRemoveColumns


Muuttaa suodatinkontekstin dimension askelväliä kuutiossa kutistamalla määritettyihin sarakkeisiin yhdistetyt määritteet.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Muuttaa suodatinkontekstin dimension askelväliä kuutiossa `cube` kutistamalla määritettyihin sarakkeisiin `columnNames` yhdistetyt määritteet. Sarakkeet poistetaan myös kuution taulukkonäkymästä.

# Cube.DisplayFolders


Palauttaa sisäkkäisen taulukoiden puun, joka edustaa objektien näyttökansiohierarkiaa (esimerkiksi dimensioita ja mittareita).


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Palauttaa sisäkkäisen taulukoiden puun, joka edustaa `cube`käytettävien objektien näyttökansiohierarkiaa (esimerkiksi dimensioita ja mittareita).

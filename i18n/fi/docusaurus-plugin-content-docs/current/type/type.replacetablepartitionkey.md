# Type.ReplaceTablePartitionKey


Palauttaa uuden taulukkotyypin, jonka osion avain on korvattu määritetyllä osion avaimella.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Palauttaa uuden taulukkotyypin, jonka osion avain on korvattu määritetyllä osion avaimella.

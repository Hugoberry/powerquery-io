# Type.TableSchema


Palauttaa taulukon, joka sisältää määritetyn taulukkotyypin sarakkeiden kuvauksen (eli rakenteen).


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Palauttaa taulukon, joka kuvaa kohteen `tableType` sarakkeet.

Kohteen `Table.Schema` dokumentaatiossa on tuloksena olevan taulukon kuvaus.

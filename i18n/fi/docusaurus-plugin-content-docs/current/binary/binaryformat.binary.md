# BinaryFormat.Binary


Palauttaa binaarimuodon, joka lukee binaariarvon.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Palauttaa binaarimuodon, joka lukee binaariarvon. Jos `length` on määritetty, binaariarvo sisältää kyseisen määrän tavuja. Jos `length` ei ole määritetty, binaariarvo sisältää jäljellä olevat tavut. `length` voidaan määrittää joko lukuna tai binaaritietoja edeltävän pituuden binaarimuodossa.

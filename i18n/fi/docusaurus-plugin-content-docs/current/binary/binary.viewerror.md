# Binary.ViewError


Luo muokatun virhetietueen, joka ei käynnistä varatoimintoa, kun näkymässä määritetty käsittelijä käynnistää sen (Binary.View-toiminnon kautta).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Luo muokatun virhetietueen kohteesta `errorRecord`, josta ei voi käynnistää varatoimintoa, kun näkymässä määritetty käsittelijä käynnistää sen (Binary.View-toiminnon kautta).

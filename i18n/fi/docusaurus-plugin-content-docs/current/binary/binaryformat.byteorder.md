# BinaryFormat.ByteOrder


Palauttaa binaarimuodon, jonka tavujärjestyksen määrittää funktio.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Palauttaa binaarimuodon, jonka tavujärjestyksen määrittää `binaryFormat`. Oletustavujärjestys on `ByteOrder.BigEndian`.

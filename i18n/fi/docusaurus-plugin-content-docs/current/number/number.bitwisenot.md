# Number.BitwiseNot


Palauttaa tavun, jossa kukin bitti on syötteen vastakohta.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Palauttaa bittitason Not-toiminnon kohteelle `number` suorittamisen tuloksen.



## Category
Number.Bytes

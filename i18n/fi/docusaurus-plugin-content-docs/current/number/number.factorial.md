# Number.Factorial


Palauttaa luvun kertoman.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

Palauttaa luvun `number` kertoman.


## Examples

### Example #1
Selvitä luvun 10 kertoma.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

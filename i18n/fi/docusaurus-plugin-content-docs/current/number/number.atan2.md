# Number.Atan2


Palauttaa kahden luvun jakamisen arkustangentin.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Palauttaa radiaaneina kulman, jonka tangentti on lukujen `y` ja `x` osamäärä `y` / `x`.

# Number.BitwiseAnd


Palauttaa bittitason And-toiminnon kahden syötteen välillä suorittamisen tuloksen.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Palauttaa bittitason And-toiminnon kohteiden `number1` ja `number2` välillä suorittamisen tuloksen.

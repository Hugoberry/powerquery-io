# Number.Sin


Palauttaa luvun sinin.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Palauttaa kohteen `number` sinin.


## Examples

### Example #1
Selvitä kulman 0 sini.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

# Number.BitwiseXor


Palauttaa bittitason XOR (Exclusive-OR) -toiminnon kahden syötteen välillä suorittamisen tuloksen.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Palauttaa bittitason XOR (Exclusive-OR) toiminnon kohteiden `number1` ja `number2` välillä suorittamisen tuloksen.

Number.Bytes

# Number.BitwiseShiftLeft


Siirtää bittijoukkoa vasemmalle.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Palauttaa bittitason määritetyn bittien määrän `number2` verran vasemmalle kohteessa `number1` siirtämisen tuloksen.

Number.Bytes

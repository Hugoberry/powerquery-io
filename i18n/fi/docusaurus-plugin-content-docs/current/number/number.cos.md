# Number.Cos


Palauttaa luvun kosinin.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Palauttaa määritetyn kulman kosinin.

-   `number`: Kulma radiaaneina mitattuna.


## Examples

### Example #1
Selvitä kulman 0 kosini.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Laske π-radiaanin kosini.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

# Number.Log10


Palauttaa luvun kymmenkantaisen (base 10) logaritmin.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Palauttaa luvun `number` kymmenkantaisen (base 10) logaritmin. Jos `number` on tyhjäarvo, `Number.Log10` palauttaa tyhjäarvon.


## Examples

### Example #1
Hae luvun 2 kymmenkantainen (base 10) logaritmi.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

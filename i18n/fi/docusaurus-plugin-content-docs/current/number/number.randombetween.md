# Number.RandomBetween


Palauttaa satunnaisluvun kahden luvun väliltä.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Palauttaa satunnaisluvun lukujen `bottom` ja `top` väliltä.


## Examples

### Example #1
Hae satunnaisluku lukujen 1 ja 5 väliltä.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

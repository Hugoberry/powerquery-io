# Number.BitwiseOr


Palauttaa bittitason Or-toiminnon kahden syötteen välillä suorittamisen tuloksen.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Palauttaa bittitason Or-toiminnon kohteiden `number1` ja `number2` välillä suorittamisen tuloksen.

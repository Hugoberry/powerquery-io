# Number.BitwiseShiftRight


Siirtää bittijoukkoa oikealle.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Palauttaa bittitason määritetyn bittien määrän `number2` verran kohteessa `number1` oikealle siirtämisen tuloksen.

Number.Bytes

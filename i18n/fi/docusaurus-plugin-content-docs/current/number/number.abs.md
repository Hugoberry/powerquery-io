# Number.Abs


Palauttaa luvun itseisarvon.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Palauttaa luvun itseisarvon `number`. Jos `number` on tyhjäarvo, `Number.Abs` palauttaa tyhjäarvon.

-   `number`: kohde `number`, jolle itseisarvo lasketaan.


## Examples

### Example #1
Luvun -3 itseisarvo.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Number.Tan


Palauttaa luvun tangentin.


## Syntax

```powerquery
Number.Tan(
    number as number
) as number
```


## Remarks

Palauttaa kohteen `number` tangentin.


## Examples

### Example #1
Selvitä kulman 1 tangentti.
```powerquery
Number.Tan(1)
```

Result: 
```powerquery
1.5574077246549023
```

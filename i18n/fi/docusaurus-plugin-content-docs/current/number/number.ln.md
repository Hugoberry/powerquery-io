# Number.Ln


Palauttaa luvun luonnollisen logaritmin.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Palauttaa luvun `number` luonnollisen logaritmin. Jos `number` on tyhjäarvo, `Number.Ln` palauttaa tyhjäarvon.


## Examples

### Example #1
Hae luvun 15 luonnollinen logaritmi.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

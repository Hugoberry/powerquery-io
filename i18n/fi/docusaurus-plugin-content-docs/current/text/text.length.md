# Text.Length


Palauttaa merkkien määrän.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Palauttaa tekstin `text` merkkien määrän.


## Examples

### Example #1
Selvitä, montako merkkiä on tekstissä "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

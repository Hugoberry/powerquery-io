# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Tekee annetusta kohteesta `text` käänteisen.


## Examples

### Example #1
Tee tekstistä 123 käänteinen.
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

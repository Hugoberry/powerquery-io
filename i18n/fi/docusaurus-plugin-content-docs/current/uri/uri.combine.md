# Uri.Combine


Palauttaa absoluuttisen URI-tunnuksen, joka on syötteen perus-URI-tunnuksen ja suhteellisen URI-tunnuksen yhdistelmä.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Palauttaa absoluuttisen URI-tunnuksen, joka on syötteiden `baseUri` ja `relativeUri` yhdistelmä.

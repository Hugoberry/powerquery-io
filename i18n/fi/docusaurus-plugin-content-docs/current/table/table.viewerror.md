# Table.ViewError


Luo muokatun virhetietueen, joka ei käynnistä varatoimintoa, kun näkymässä määritetty käsittelijä käynnistää sen (Table.View-näkymän kautta).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Luo muokatun virhetietueen kohteesta `errorRecord`, josta ei voi käynnistää varatoimintoa, kun näkymässä määritetty käsittelijä käynnistää sen (Table.View-toiminnon kautta).

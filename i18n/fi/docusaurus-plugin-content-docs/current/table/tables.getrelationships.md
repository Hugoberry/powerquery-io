# Tables.GetRelationships


Noutaa taulukkojoukon väliset suhteet.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Noutaa taulukkojoukon väliset suhteet. Joukon `tables` rakenteen oletetaan olevan siirtymistaulukon rakenteen kaltainen. Kohteen `dataColumn` määrittämä sarake sisältää itse tietotaulukot.

# Table.FirstValue


Palauttaa taulukon ensimmäisen rivin ensimmäisen sarakkeen tai määritetyn oletusarvon.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Palauttaa taulukon `table` ensimmäisen rivin ensimmäisen sarakkeen tai määritetyn oletusarvon.

Table.Row operations

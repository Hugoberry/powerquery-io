# Text.Length


Retorna o número de caracteres.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Retorna o número de caracteres no texto `text`.


## Examples

### Example #1
Localize quantos caracteres existem no texto "Olá, Mundo".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

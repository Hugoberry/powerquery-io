# BinaryFormat.ByteOrder


Retorna um formato binário com a ordem de bytes especificada por uma função.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Retorna um formato binário com a ordem de bytes especificada por `binaryFormat`. A ordem de byte padrão é `ByteOrder.BigEndian`.

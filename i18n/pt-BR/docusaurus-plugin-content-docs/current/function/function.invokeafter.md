# Function.InvokeAfter


Invoca a função determinada depois da duração especificada ter decorrido.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Retorna o resultado da invocação de `function` depois da duração `delay` ter decorrido.



## Category
Function

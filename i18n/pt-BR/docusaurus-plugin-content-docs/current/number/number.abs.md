# Number.Abs


Retorna o valor absoluto do número.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Retorna o valor absoluto de `number`. Se `number` for nulo, `Number.Abs` retornará nulo.

-   `number`: um `number` cujo valor absoluto deve ser calculado.


## Examples

### Example #1
Valor absoluto -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Number.Atan2


Retorna o arco tangente da divisão dos dois números.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Retorna o ângulo, em radianos, cuja tangente é o quociente `y`/`x` dos números `y` e `x`.

# Number.BitwiseOr


Retorna o resultado da execução de uma operação bit a bit "Or" entre as duas entradas.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna o resultado da execução de uma operação bit a bit "Or" entre `number1` e `number2`.



## Category
Number.Bytes

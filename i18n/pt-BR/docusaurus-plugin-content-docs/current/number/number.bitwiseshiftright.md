# Number.BitwiseShiftRight


Desloca os bits definidos para a direita.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna o resultado da execução de um deslocamento bit a bit para a direita em `number1`, com base no número especificado de bits `number2`.

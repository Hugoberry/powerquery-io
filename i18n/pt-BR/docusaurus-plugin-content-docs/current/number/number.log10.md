# Number.Log10


Retorna o logaritmo de base 10 do número.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Retorna o logaritmo de base 10 de um número, `number`. Se `number` for nulo, `Number.Log10` retornará nulo.


## Examples

### Example #1
Obtém o logaritmo de base 10 de 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

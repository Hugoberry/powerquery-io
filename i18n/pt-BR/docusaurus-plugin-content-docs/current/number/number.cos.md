# Number.Cos


Retorna o cosseno do número.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Retorna o cosseno do ângulo especificado.

-   `number`: um ângulo, medido em radianos.


## Examples

### Example #1
Localize o cosseno do ângulo 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Encontre o cosseno de π radianos.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

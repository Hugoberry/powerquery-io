# Number.BitwiseShiftLeft


Desloca os bits definidos para a esquerda.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna o resultado da execução de um deslocamento bit a bit para a esquerda em `number1`, com base no número especificado de bits `number2`.

# Number.BitwiseXor


Retorna o resultado da execução de uma operação bit a bit "XOR" (Exclusive-OR) entre as duas entradas.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Retorna o resultado da execução de uma operação bit a bit "XOR" (Exclusive-OR) entre `number1` e `number2`.

Number.Bytes

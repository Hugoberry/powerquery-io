# Type.ReplaceFacets


Substitui as facetas de um tipo.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Substitui as facetas de `type` pelas facetas contidas no registro `facets`.

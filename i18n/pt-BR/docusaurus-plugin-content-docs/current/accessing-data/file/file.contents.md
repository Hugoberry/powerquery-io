# File.Contents


Retorna o conteúdo do arquivo especificado como binário.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Retorna o conteúdo do arquivo, `path`, como binário. O parâmetro `options` é atualmente destinado apenas para uso interno.

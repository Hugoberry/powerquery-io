# Exchange.Contents


Retorna um sumário de uma conta do Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Retorna um sumário da conta do Microsoft Exchange `mailboxAddress`. Se `mailboxAddress` não for especificado, a conta padrão para a credencial será usada.

# Cube.AttributeMemberProperty


Retorna uma propriedade de um atributo de dimensão.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Retorna a propriedade `propertyName` do atributo de dimensão `attribute`.

Cube

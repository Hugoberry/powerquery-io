# Cube.MeasureProperty


Retorna uma propriedade de uma medida (propriedade de célula).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Retorna a propriedade `propertyName` da medida `measure`.

Cube

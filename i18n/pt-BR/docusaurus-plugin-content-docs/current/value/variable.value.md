# Variable.Value


Retorna o valor da variável especificada.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Retorna o valor da variável especificada `identifier` definida pelo ambiente de avaliação atual. Se a variável não for definida, um erro será gerado.

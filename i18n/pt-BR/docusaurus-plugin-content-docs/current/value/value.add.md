# Value.Add


Retorna a soma dos dois valores.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Retorna a soma de `value1` e `value2`. Um parâmetro `precision` opcional pode ser especificado; `Precision.Double` é usado por padrão.

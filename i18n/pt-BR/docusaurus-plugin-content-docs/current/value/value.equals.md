# Value.Equals


Especifica se os dois valores são iguais.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Retornará true se o valor `value1` for igual ao valor `value2`; do contrário, false será retornado.

Values

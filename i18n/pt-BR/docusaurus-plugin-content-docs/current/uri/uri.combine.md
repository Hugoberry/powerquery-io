# Uri.Combine


Retorna um URI absoluto que é a combinação do URI base de entrada e URI relativo.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Retorna um URI absoluto que é a combinação do `baseUri` de entrada e do `relativeUri`.

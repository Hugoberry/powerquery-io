# Cube.Measures


Повертає таблицю, що містить набір доступних мір.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Повертає таблицю, що містить набір доступних мір у значенні `cube`. Кожна міра представлена як функція. Міри можна застосувати до куба за допомогою Cube.AddMeasureColumn.

# Cube.Parameters


Повертає таблицю з набором параметрів, які можна застосувати до куба.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Повертає таблицю з набором параметрів, які можна застосувати до елемента "`cube`". Кожен параметр – це функція, яка повертає елемент "`cube`" із застосованим параметром і його аргументами.

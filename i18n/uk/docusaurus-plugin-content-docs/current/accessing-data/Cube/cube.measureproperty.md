# Cube.MeasureProperty


Повертає властивість міри (властивість клітинки).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Повертає властивість `propertyName` міри `measure`.

Cube

# SapHana.Database


Повертає пакети в базі даних SAP HANA.


## Syntax

```powerquery
SapHana.Database(
    server as text,
    optional options as record
) as table
```


## Remarks

Повертає таблицю багатовимірних пакетів із бази даних SAP HANA `server`. Можна вказати додатковий параметр запису `options`, щоб керувати наведеними нижче параметрами.

-   `Query` : Власний SQL-запит для отримання даних. Якщо за запитом виявлено кілька наборів результатів, повертається лише перший набір.
-   `Distribution` : Параметр SapHanaDistribution, який установлює значення властивості "Distribution" у рядку підключення. Маршрутизація за інструкцією – це метод, що визначає правильний серверний вузол системи для розповсюдження, перш ніж виконувати інструкцію. Стандартне значення – SapHanaDistribution.All.
-   `Implementation` : Визначає впровадження з’єднувача SAP Hana, який потрібно використовувати.
-   `EnableColumnBinding` : Дає змогу зв’язувати змінні зі стовпцями з набору результатів SAP Hana під час отримання даних. Може покращувати продуктивність за рахунок використання трохи більшого обсягу пам’яті. Стандартне значення – false.
-   `ConnectionTimeout` : Дає змогу контролювати тривалість очікування для спроби встановити підключення до сервера, після досягнення якої спроба переривається. Стандартне значення – 15 секунд.
-   `CommandTimeout` : Дає змогу контролювати тривалість виконання запиту на сервері, після досягнення якої він скасовується. Стандартне значення – 10 хвилин.

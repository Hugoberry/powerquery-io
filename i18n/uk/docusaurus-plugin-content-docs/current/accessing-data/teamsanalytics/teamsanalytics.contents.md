# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Цей аналітичний з’єднувач для Teams дає змогу отримувати висновки щодо використання рішення. Переглядайте дані щодо своїх окремих дій і активності в групах.

Відомості доступні за попередні 90 днів.

Щоб дізнатися більше про типи доступних даних, див. довідкову документацію, зокрема:

-   **про використання Teams** – https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **про активність користувача** – https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

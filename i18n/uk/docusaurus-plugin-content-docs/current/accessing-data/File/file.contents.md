# File.Contents


Повертає вміст указаного файлу у двійковому вигляді.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Повертає вміст файлу `path` як бінарний. Параметр `options` зараз призначений лише для внутрішнього використання.

# Vertica.Database


Імпорт даних із Vertica.


## Syntax

```powerquery
Vertica.Database(
    server as text,
    database as text,
    optional options as record
) as table
```


## Remarks

Повертає таблицю схем, доступних на сервері (ім’я зазначається параметром `server`) у базі даних (ім’я зазначається параметром `database`). Можна вказати додатковий параметр запису `options`, щоб визначити додаткові властивості. Запис може містити описані нижче поля.

-   `ConnectionTimeout`: параметр тривалості, який визначає, як довго очікувати на підключення до сервера, перш ніж перервати спробу. Стандартне значення залежить від драйвера.
-   `CommandTimeout`: параметр тривалості, який визначає, як довго запиту на боці сервера дозволено працювати до скасування. Стандартне значення залежить від драйвера.

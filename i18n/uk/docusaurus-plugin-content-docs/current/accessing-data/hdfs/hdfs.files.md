# Hdfs.Files


Повертає таблицю, яка містить властивості та вміст файлів, знайдених у вказаній папці та вкладених папках файлової системи Hadoop.


## Syntax

```powerquery
Hdfs.Files(
    url as text
) as table
```


## Remarks

Повертає таблицю, яка містить рядок для кожного файлу, знайденого за URL-адресою папки, `url`, і вкладених папок файлової системи Hadoop. Кожен рядок містить властивості файлу та посилання на його вміст.

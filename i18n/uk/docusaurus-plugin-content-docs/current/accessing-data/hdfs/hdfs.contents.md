# Hdfs.Contents


Повертає таблицю, яка містить властивості та вміст файлів і папок, знайдених у вказаній папці файлової системи Hadoop.


## Syntax

```powerquery
Hdfs.Contents(
    url as text
) as table
```


## Remarks

Повертає таблицю, яка містить рядок для кожної папки та кожного файлу, знайдених за URL-адресою папки, `url`, файлової системи Hadoop. Кожен рядок містить властивості папки або файлу та посилання на їхній вміст.

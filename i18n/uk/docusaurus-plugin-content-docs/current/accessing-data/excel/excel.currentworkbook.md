# Excel.CurrentWorkbook


Повертає вміст поточної книги Excel.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Повертає вміст поточної книги Excel: таблиці, іменовані діапазони та динамічні масиви. На відміну від `excel.Workbook` ця функція не повертає аркуші.

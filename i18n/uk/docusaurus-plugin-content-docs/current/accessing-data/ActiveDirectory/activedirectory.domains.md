# ActiveDirectory.Domains


Повертає список доменів Active Directory в лісі, у якому розташований вказаний домен або домен поточного комп'ютера, якщо жодний домен не вказано.


## Syntax

```powerquery
ActiveDirectory.Domains(
    optional forestRootDomainName as text
) as table
```


## Remarks

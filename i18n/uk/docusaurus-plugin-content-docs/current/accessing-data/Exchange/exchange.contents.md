# Exchange.Contents


Повернення змісту, знайденого за обліковим записом Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Повертає таблицю вмісту з облікового запису Microsoft Exchange `mailboxAddress`. Якщо параметр `mailboxAddress` не вказано, використовуються облікові дані стандартного облікового запису.

# Cube.ApplyParameter


Повертає куб після застосування до нього параметра.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Повертає куб після застосування параметрів "`parameter`" і "`arguments`" до елемента "`cube`".

Cube

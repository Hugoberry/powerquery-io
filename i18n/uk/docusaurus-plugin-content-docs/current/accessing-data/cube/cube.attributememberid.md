# Cube.AttributeMemberId


Повертає унікальний ідентифікатор елемента зі значення властивості елемента.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Повертає унікальний ідентифікатор елемента зі значення властивості елемента. `attribute`. Повертає Null-значення для будь-яких інших значень.

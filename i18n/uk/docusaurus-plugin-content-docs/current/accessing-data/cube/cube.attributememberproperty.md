# Cube.AttributeMemberProperty


Повертає властивість атрибута виміру.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Повертає властивість "`propertyName`" атрибута виміру "`attribute`".

Cube

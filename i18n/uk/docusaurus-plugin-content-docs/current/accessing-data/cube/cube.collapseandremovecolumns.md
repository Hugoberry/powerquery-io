# Cube.CollapseAndRemoveColumns


Змінює деталізацію вимірів контексту фільтра для куба, згортаючи атрибути, зіставлені з указаними стовпцями.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Змінює деталізацію вимірів контексту фільтра для `cube`, згортаючи атрибути, зіставлені з указаними стовпцями `columnNames`. Стовпці також видалено з табличного подання куба.

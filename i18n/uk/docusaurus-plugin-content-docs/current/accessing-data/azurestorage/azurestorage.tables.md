# AzureStorage.Tables


Повернення навігаційної таблиці, яка містить таблиці, знайдені за вказаним обліковим записом у сховищі Azure.


## Syntax

```powerquery
AzureStorage.Tables(
    account as text,
    optional options as record
) as table
```


## Remarks

Повертає навігаційну таблицю, яка містить окремі рядки для всіх таблиць за URL-адресою облікового запису `account`, зі сховища Azure. У кожному рядку наводиться посилання на таблицю Azure. Можна надати додатковий параметр запису (`options`), щоб указати додаткові властивості. Запис може містити такі поля:

-   `Timeout` : Дає змогу контролювати тривалість очікування на виконання запиту до сервера, після досягнення якої спроба переривається. Стандартне значення залежить від джерела.

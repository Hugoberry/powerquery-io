# Uri.Combine


Повертає абсолютний URI, який є комбінацією URI вхідної бази та відносного URI.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Повертає абсолютний URI, який є комбінацією вхідного `baseUri` та `relativeUri`.

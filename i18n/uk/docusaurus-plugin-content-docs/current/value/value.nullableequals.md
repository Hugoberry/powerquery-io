# Value.NullableEquals


Повертає результат, чи два значення рівні.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Повертає нуль, якщо один з аргументів "`value1`" або "`value2`" є Null-значенням; інакше еквівалентно Value.Equals.

Values

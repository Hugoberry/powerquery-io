# Variable.Value


Повертає значення вказаної змінної.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Повертає значення вказаної змінної `identifier`, визначене поточним середовищем обчислення. Якщо змінну не визначено, виникає помилка.

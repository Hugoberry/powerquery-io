# Value.Subtract


Повертає різницю двох значень.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Повертає різницю `value1` і `value2`. Можна вказати додатковий параметр `precision`. За замовчуванням використовується `Precision.Double`.

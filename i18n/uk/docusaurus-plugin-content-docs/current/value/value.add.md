# Value.Add


Повертає суму двох значень.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Повертає суму `value1` і `value2`. Можна вказати додатковий параметр `precision`. За замовчуванням використовується `Precision.Double`.

# Value.Optimize


Указує, що функція Value.Expression має повернути оптимізований вираз для значення.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Ця функція вказує, що має бути повернуто оптимізований вираз, якщо її вказано разом із функцією Value.Expression, а `value` – це запит, який можна оптимізувати. Інакше `value` буде передано без змін.

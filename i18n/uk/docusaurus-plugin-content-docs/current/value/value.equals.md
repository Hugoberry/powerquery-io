# Value.Equals


Повертає результат, чи два значення рівні.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Повертає значення true, якщо значення `value1` дорівнює значенню `value2`, у протилежному випадку повертає значення false.

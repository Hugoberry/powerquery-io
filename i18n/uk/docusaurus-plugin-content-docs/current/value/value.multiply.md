# Value.Multiply


Повертає добуток двох значень.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Повертає добуток множення `value1` на `value2`. Можна вказати додатковий параметр `precision`. За замовчуванням використовується `Precision.Double`.

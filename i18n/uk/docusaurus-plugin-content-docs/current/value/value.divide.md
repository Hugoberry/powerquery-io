# Value.Divide


Повертає результат ділення першого значення на друге.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Повертає результат ділення `value1` на `value2`. Можна вказати додатковий параметр `precision`. За замовчуванням використовується `Precision.Double`.

# DateTimeZone.LocalNow


Повертає поточну дату та час у місцевому часовому поясі.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Повертає значення `datetimezone`, установлене для поточних дати й часу в системі. Повернуте значення містить інформацію про місцевий часовий пояс.

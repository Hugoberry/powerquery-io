# Table.ViewError


Створює модифікований запис про помилку, який не ініціює перехід у разі генерування обробником, зазначеним у поданні (через Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Створює модифікований запис про помилку від `errorRecord`, який не ініціює перехід у разі генерування обробником, зазначеним у поданні (через Table.View).

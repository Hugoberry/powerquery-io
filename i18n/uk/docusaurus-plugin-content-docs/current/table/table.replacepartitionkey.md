# Table.ReplacePartitionKey


Замінює ключ розділу вказаної таблиці.


## Syntax

```powerquery
Table.ReplacePartitionKey(
    table as table,
    partitionKey as list
) as table
```


## Remarks

Замінює ключ розділу вказаної таблиці.

# Tables.GetRelationships


Отримує зв’язки між таблицями набору.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Отримує зв’язки між таблицями набору. Припускається, що структура набору "`tables`" подібна до таблиці переходів. Визначений параметром "`dataColumn`" стовпець містить фактичні таблиці даних.

# Table.FirstValue


Повертає перший стовпець першого рядка таблиці або вказане стандартне значення.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Повертає перший стовпець першого рядка таблиці `table` або вказане стандартне значення.

Table.Row operations

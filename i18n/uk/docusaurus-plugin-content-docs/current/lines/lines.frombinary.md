# Lines.FromBinary


Перетворює двійкове значення на список текстових значень, розділених розривами рядків. Якщо вказано стиль цитування, розриви рядків можуть відображатися в лапках. Якщо параметр includeLineSeparators має значення true, символи розривів рядків включаються в текст.


## Syntax

```powerquery
Lines.FromBinary(
    binary as binary,
    optional quoteStyle as any,
    optional includeLineSeparators as logical,
    optional encoding as TextEncoding.Type
) as list
```


## Remarks

Перетворює бінарне значення на список текстових значень, розділених розривами рядків.

-   `binary`: бінарне значення, яке потрібно перетворити на список.
-   `quoteStyle`: указує, як обробляються розриви рядків. Значення "`quoteStyle`" може бути `null`. Стандартне значення – `QuoteStyle.None`.
-   `includeLineSeparators`: указує, чи слід включати символи розриву рядка в текст. Значення "`includeLineSeparators`" може бути `null`. Стандартне значення – `false`.
-   `encoding`: указує кодування тексту бінарного значення. Значення "`encoding`" може бути `null`. Стандартне значення – `65001` (UTF-8).

Якщо для "`quoteStyle`" вказано запис (а "`includeLineSeparators`" і "`encoding`" мають значення `null`), можна вказати такі поля записів:

-   `QuoteStyle`: указує, як обробляються розриви рядків у лапках.
    -   `QuoteStyle.Csv`: розриви рядків у лапках обробляються як частина даних, а не як кінець поточного рядка.
    -   `QuoteStyle.None`: усі розриви рядків обробляються як кінець поточного рядка, навіть якщо вони зустрічаються в рамках значення в лапках. Це значення використовується за замовчуванням, якщо не вказано параметр `CsvStyle`.
-   `CsvStyle`: визначає, як обробляти лапки. Не слід використовувати з `QuoteStyle.None`.
    -   `CsvStyle.QuoteAfterDelimiter`: лапки в полі мають значення лише безпосередньо після `роздільника`.
    -   `CsvStyle.QuoteAlways`: лапки в полі завжди мають значення незалежно від позиції.
-   `Роздільник`: роздільник стовпців з одного символу. Слід використовувати лише з `CsvStyle.QuoteAfterDelimiter`.
-   `IncludeLineSeparators`: указує, чи потрібно включати символи розриву рядка в текст. Стандартне значення – `false`.
-   `Encoding`: кодування тексту файлу бінарного значення. Стандартне значення – `65001` (UTF-8).

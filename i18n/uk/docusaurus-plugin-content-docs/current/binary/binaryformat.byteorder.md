# BinaryFormat.ByteOrder


Повертає двійковий формат із порядком байтів, указаними за допомогою функції.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Повертає двійковий формат із порядком байтів, указаними за допомогою `binaryFormat`. Порядок байтів за замовчуванням: `ByteOrder.BigEndian`.

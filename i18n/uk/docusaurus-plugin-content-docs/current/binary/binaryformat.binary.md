# BinaryFormat.Binary


Повертає двійковий формат, який читає двійкове значення.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Повертає двійковий формат, який читає двійкове значення. Якщо задано `length`, двійкове значення міститиме вказану кількість байтів. Якщо `length` не вказано, двійкове значення міститиме байти, що залишилися. `length` можна вказувати у форматі звичайного числа або двійкового представлення довжини, що передує двійковим даним.

# Binary.ViewError


Створює модифікований запис про помилку, який не ініціює перехід у разі генерування обробником, зазначеним у поданні (через Binary.View).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Створює модифікований запис про помилку від `errorRecord`, який не ініціює перехід у разі генерування обробником, зазначеним у поданні (через Binary.View).

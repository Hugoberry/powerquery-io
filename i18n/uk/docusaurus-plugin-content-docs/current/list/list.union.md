# List.Union


Повертає об'єднання значень списку, знайдених у вхідних даних.


## Syntax

```powerquery
List.Union(
    lists as list,
    optional equationCriteria as any
) as list
```


## Remarks

Бере список списків `lists`, об’єднує елементи в окремі списки та повертає їх у вихідному списку. У результаті повертається список, який містить усі елементи будь-яких вхідних списків. Ця операція підтримує традиційну мультимножинну семантику, тому повтори значень зіставляються в рамках об’єднання. Можна вказати додаткове значення умов рівняння `equationCriteria`, щоб керувати перевіркою на рівність.


## Examples

### Example #1
Створити об'єднання списків \{1..5\}, \{2..6\}, \{3..7\}.
```powerquery
List.Union({{1..5}, {2..6}, {3..7}})
```

Result: 
```powerquery
{1, 2, 3, 4, 5, 6, 7}
```

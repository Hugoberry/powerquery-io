# List.MinN


Повертає мінімальні значення в списку. Можна вказати кількість значень, які необхідно повернути, або умову фільтрування.


## Syntax

```powerquery
List.MinN(
    list as list,
    countOrCondition as any,
    optional comparisonCriteria as any,
    optional includeNulls as logical
) as list
```


## Remarks

Повертає мінімальні значення списку `list`. Параметр `countOrCondition` визначає кількість значень, які слід повернути, або умову фільтрування. Додатковий параметр `comparisonCriteria` визначає, як порівнювати значення в списку.

-   `list`: список значень.
-   `countOrCondition`: якщо вказано число, функція повертає список з упорядкованими за зростанням елементами кількістю до `countOrCondition`. Якщо вказано умову, функція повертає список елементів, які спочатку відповідають цій умові. Щойно виявиться невідповідність елемента умові, наступні елементи не розглядаються. Якщо цей параметр має Null-значення, повертається одне найменше значення в списку.
-   `comparisonCriteria`: *(необовʼязково)* можна вказати додаткове значення `comparisonCriteria`, щоб визначити спосіб порівняння елементів у списку. Якщо цей параметр має Null-значення, використовується стандартний засіб порівняння.


## Examples

### Example #1
Знайти 5 найменших значень у списку `{3, 4, 5, -1, 7, 8, 2}`.
```powerquery
List.MinN({3, 4, 5, -1, 7, 8, 2}, 5)
```

Result: 
```powerquery
{-1, 2, 3, 4, 5}
```

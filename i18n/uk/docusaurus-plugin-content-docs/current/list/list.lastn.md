# List.LastN


Повертає список останнього елемента або елементів у вказаному списку. Можна додатково вказати кількість значень, які необхідно повернути, або описову умову.


## Syntax

```powerquery
List.LastN(
    list as list,
    optional countOrCondition as any
) as any
```


## Remarks

Повертає список останнього елемента або елементів у вказаному списку.

-   `list`: список, який потрібно перевірити. Якщо список пустий, повертається пустий список.
-   `countOrCondition`: (необов’язково) підтримує збір кількох елементів або фільтрування елементів. Хоча цей параметр зазначено як необов’язковий, помилка виникає, якщо це значення не надано або є `null`. Цей параметр можна вказати двома способами:
    -   Якщо вказано певну кількість елементів, повертається не більше вказаної кількості.
    -   Якщо вказано умову, повертають усі елементи, які відповідають цій умові, починаючи з кінця списку. Якщо один елемент не виконає умову, наступні елементи не розглядають.


## Examples

### Example #1
Знайти останнє значення у списку \{3, 4, 5, -1, 7, 8, 2\}.
```powerquery
List.LastN({3, 4, 5, -1, 7, 8, 2}, 1)
```

Result: 
```powerquery
{2}
```


### Example #2
Знайти останні значення у списку \{3, 4, 5, -1, 7, 8, 2\}, які більші 0.
```powerquery
List.LastN({3, 4, 5, -1, 7, 8, 2}, each _ > 0)
```

Result: 
```powerquery
{7, 8, 2}
```

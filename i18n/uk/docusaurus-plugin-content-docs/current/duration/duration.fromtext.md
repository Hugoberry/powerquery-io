# Duration.FromText


Повертає значення тривалості з текстових форм часу, що минув (d.h:m:s).


## Syntax

```powerquery
Duration.FromText(
    text as text
) as duration
```


## Remarks

Повертає значення тривалості з указаного тексту `text`. За допомогою цієї функції можна проаналізувати вказані нижче формати.

-   (-)гг:хх(:сс(.чч))
-   (-)ддд(.гг:хх(:сс(.чч)))

(Усі діапазони включають граничні значення)

-   ддд: кількість днів.
-   гг: кількість годин, від 0 до 23.
-   хх: кількість хвилин, від 0 до 59.
-   сс: кількість секунд, від 0 до 59.

чч: частка секунди, від 0 до 9999999.


## Examples

### Example #1
Перетворити `"2.05:55:20"` на значення `duration`.
```powerquery
Duration.FromText("2.05:55:20")
```

Result: 
```powerquery
#duration(2, 5, 55, 20)
```

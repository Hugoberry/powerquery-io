# Text.Length


Повертає кількість символів.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Повертає кількість символів у тексті `text`.


## Examples

### Example #1
Знайти кількість символів у тексті "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

# Value.FromText


Створює чітко типізоване значення з текстового представлення.


## Syntax

```powerquery
Value.FromText(
    text as any,
    optional culture as text
) as any
```


## Remarks

Розшифровує значення з текстового представлення та інтерпретує його як значення відповідного типу.

-   `text`: текст для інтерпретації.
-   `culture`: (Необовʼязково) мова та регіональні параметри для інтерпретації тексту (наприклад, "uk-UA").

Ця функція приймає текстове значення та повертає значення типу `число`, `логічне`, `null-значення`, `дата й час`, `тривалість` або `текст`. Пусте текстове значення інтерпретується як `null-значення`.


## Examples

### Example #1
Перетворити текст, що позначає число, на відповідне числове значення.
```powerquery
Value.FromText("12345.6789")
```

Result: 
```powerquery
12345.6789
```


### Example #2
Перетворити текст, що позначає відсоток, на відповідне числове значення.
```powerquery
Value.FromText("25.4%")
```

Result: 
```powerquery
0.254
```


### Example #3
Перетворити текст, що позначає значення французького євро, на відповідне числове значення.
```powerquery
Value.FromText("€1,190", "fr-FR")
```

Result: 
```powerquery
1.19
```


### Example #4
Перетворити текст, що позначає німецьку дату й час, на відповідне значення дати та часу.
```powerquery
Value.FromText("24 Dez 2024 14:33:20", "de-DE")
```

Result: 
```powerquery
#datetime(2024, 12, 24, 14, 33, 20)
```

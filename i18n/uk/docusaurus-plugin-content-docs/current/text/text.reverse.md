# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Обертає порядок тексту `text` на зворотний.


## Examples

### Example #1
Обернути текст "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

# Time.From


Створює час із заданого значення.


## Syntax

```powerquery
Time.From(
    value as any,
    optional culture as text
) as time
```


## Remarks

Повертає значення `time` із заданого параметра `value`. Крім того, можна вказати необов’язковий параметр `culture` (наприклад, "uk-UA"). Якщо заданий параметр `value` має значення `null`, функція `Time.From` повертає `null`. Якщо заданий параметр `value` має значення `time`, повертається `value`. Значення таких типів можна перетворити на значення `time`:

-   `text`: значення `time` із текстового представлення. Див. опис функції `Time.FromText`, щоб дізнатися більше.
-   `datetime`: компонент часу параметра `value`.
-   `datetimezone`: компонент часу еквівалента місцевих дати й часу параметра `value`.
-   `number`: еквівалент `time` значення кількості неповних днів, вираженого значенням `value`. Якщо `value` має від’ємне значення або значення, не менше за 1, повертається помилка.

Якщо параметр `value` має інше значення, повертається помилка.


## Examples

### Example #1
Перетворити `0.7575` на значення `time`.
```powerquery
Time.From(0.7575)
```

Result: 
```powerquery
#time(18, 10, 48)
```


### Example #2
Перетворити `#datetime(1899, 12, 30, 06, 45, 12)` на значення `time`.
```powerquery
Time.From(#datetime(1899, 12, 30, 06, 45, 12))
```

Result: 
```powerquery
#time(06, 45, 12)
```

# Type.TablePartitionKey


Повертає ключ розділу для вказаного типу таблиці, якщо вона має ключ.


## Syntax

```powerquery
Type.TablePartitionKey(
    tableType as type
) as list
```


## Remarks

Повертає ключ розділу для вказаного типу таблиці, якщо вона має ключ.

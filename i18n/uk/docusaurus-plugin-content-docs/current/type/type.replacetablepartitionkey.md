# Type.ReplaceTablePartitionKey


Повертає новий тип таблиці з ключем розділу, заміненим на вказаний ключ розділу.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Повертає новий тип таблиці з ключем розділу, заміненим на вказаний ключ розділу.

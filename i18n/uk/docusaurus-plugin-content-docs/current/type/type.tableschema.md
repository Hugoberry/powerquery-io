# Type.TableSchema


Повертає таблицю, що містить опис стовпців (тобто схему) указаного типу таблиці.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Повертає таблицю з описом стовпців у таблиці "`tableType`".

Ознайомтеся з документацією про функцію `Table.Schema`, щоб переглянути відомості про таблицю, що в результаті генерується.

# Відкрийте для себе мову
Мова формул Power Query M оптимізована для створення надзвичайно гнучких запитів для об'єднання даних. Це функціональна мова з урахуванням регістру, схожа на F#. Мова формул Power Query використовується в низці продуктів Microsoft, таких як Power BI Desktop, Excel та Analysis Services.

Цей сайт є довідником із функцій Power Query, що пропонує швидкий і прямий доступ до детальної інформації та практичних прикладів для кожної функції.
:::note
Зверніть увагу, що автор не претендує на жодні авторські права на матеріали, представлені на цьому сайті. Інформація зібрана та надана в надії, що вона буде корисною для тих, хто прагне розширити свої знання та застосування Power Query.
:::

Функція пошуку на цьому вебсайті має спростити процес виявлення широкого спектра функцій Power Query. Обов'язково спробуйте її (Ctrl+K).

![Функцію пошуку надано Algolia](/img/search.png)

Для тих, хто зацікавлений у глибшому дослідженні або деталях реалізації, додаткову інформацію можна знайти в наступному репозиторії GitHub: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Цей репозиторій може містити додаткові приклади, оновлення та ресурси, що стосуються розробки та використання Power Query.

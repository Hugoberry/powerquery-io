# Number.Sin


Повертає синус числа.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Повертає синус `number`.


## Examples

### Example #1
Знайти синус кута 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

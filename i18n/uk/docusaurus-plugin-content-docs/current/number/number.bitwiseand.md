# Number.BitwiseAnd


Повертає результат виконання побітової операції "ТА" між двома вхідними даними.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Повертає результат виконання побітової операції "ТА" між `number1` і `number2`.



## Category
Number.Bytes

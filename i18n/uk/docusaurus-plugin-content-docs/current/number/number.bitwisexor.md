# Number.BitwiseXor


Повертає результат виконання побітового "XOR" (виключне АБО) між двома вхідними даними.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Повертає результат виконання побітового "XOR" (виключне АБО) між `number1` і `number2`.



## Category
Number.Bytes

# Number.Log10


Повертає логарифм числа за основою 10.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Повертає логарифм числа `number` за основою 10. Якщо параметр `number` має Null-значення, функція `Number.Log10` повертає Null-значення.


## Examples

### Example #1
Отримати логарифм числа 2 за основою 10.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

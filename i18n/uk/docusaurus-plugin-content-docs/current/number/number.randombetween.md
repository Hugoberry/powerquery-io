# Number.RandomBetween


Повертає випадкове число між двома числами.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Повертає випадкове число між `bottom` та `top`.


## Examples

### Example #1
Отримати випадкове число між 1 і 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

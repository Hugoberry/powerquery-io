# Number.BitwiseShiftRight


Зсовує набір бітів праворуч.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Повертає результат виконання побітового зсуву `number1` праворуч на вказану кількість бітів `number2`.

Number.Bytes

# Number.Abs


Повертає абсолютне значення числа.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Повертає абсолютну величину значення `number`. Якщо `number` має Null-значення, функція `Number.Abs` повертає Null-значення.

-   `number`: значення `number`, для якого потрібно обчислити абсолютну величину.


## Examples

### Example #1
Абсолютне значення від -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

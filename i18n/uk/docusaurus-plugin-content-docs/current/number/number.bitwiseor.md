# Number.BitwiseOr


Повертає результат виконання побітового "АБО" між двома вхідними даними.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Повертає результат виконання побітового "АБО" між `number1` і `number2`.



## Category
Number.Bytes

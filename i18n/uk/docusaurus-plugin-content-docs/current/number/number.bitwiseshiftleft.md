# Number.BitwiseShiftLeft


Зсовує набір бітів ліворуч.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Повертає результат виконання побітового зсуву `number1` ліворуч на вказану кількість бітів `number2`.



## Category
Number.Bytes

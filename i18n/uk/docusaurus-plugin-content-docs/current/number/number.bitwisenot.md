# Number.BitwiseNot


Повертає байт, в якому кожен біт протилежний до вхідних даних.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Повертає результат виконання побітової операції "НЕ" з `number`.



## Category
Number.Bytes

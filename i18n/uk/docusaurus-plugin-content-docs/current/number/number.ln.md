# Number.Ln


Повертає натуральний логарифм числа.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Повертає натуральний логарифм числа `number`. Якщо `number` має Null-значення, функція `Number.Ln` повертає Null-значення.


## Examples

### Example #1
Отримати натуральний логарифм числа 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

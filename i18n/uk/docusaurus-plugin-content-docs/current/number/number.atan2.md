# Number.Atan2


Повертає арктангенс частки двох чисел.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Повертає кут у радіанах, тангенс якого є часткою `y`/`x` двох чисел `y` і `x`.

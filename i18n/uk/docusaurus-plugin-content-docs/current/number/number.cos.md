# Number.Cos


Повертає косинус числа.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Повертає косинус указаного кута.

-   `number`: кут, виміряний у радіанах.


## Examples

### Example #1
Знайти косинус кута 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Знайдіть косинус π радіан.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

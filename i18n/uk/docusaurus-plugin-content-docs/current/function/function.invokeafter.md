# Function.InvokeAfter


Виклик указаної функції після визначеної тривалості.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Повернення результату виклику `function` після визначеної тривалості (`delay`).



## Category
Function

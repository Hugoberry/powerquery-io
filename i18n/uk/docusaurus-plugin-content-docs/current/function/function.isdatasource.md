# Function.IsDataSource


Повертає дані про те, чи вважається певна функція джерелом даних.


## Syntax

```powerquery
Function.IsDataSource(
    function as function
) as logical
```


## Remarks

Повертає дані про те, чи вважається `function` джерелом даних.

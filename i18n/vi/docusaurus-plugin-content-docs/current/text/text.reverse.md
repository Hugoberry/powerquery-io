# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Đảo ngược `text` được cung cấp.


## Examples

### Example #1
Đảo ngược văn bản "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

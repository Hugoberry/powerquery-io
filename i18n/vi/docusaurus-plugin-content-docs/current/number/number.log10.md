# Number.Log10


Trả về lô-ga-rít cơ số 10 của số.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Trả về lô-ga-rít cơ số 10 của số `number`. Nếu `number` là giá trị rỗng thì `Number.Log10` sẽ trả về giá trị rỗng.


## Examples

### Example #1
Nhận lô-ga-rít cơ số 10 của 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

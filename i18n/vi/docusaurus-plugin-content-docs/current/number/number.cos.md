# Number.Cos


Trả về cosin của số.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Trả về cosin của góc được chỉ định.

-   `number`: Một góc, được đo bằng radian.


## Examples

### Example #1
Trả về cosin của góc 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Tìm cosin của π radian.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

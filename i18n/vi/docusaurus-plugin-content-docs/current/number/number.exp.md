# Number.Exp


Tăng e lên lũy thừa cho sẵn.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Trả về kết quả sau khi đưa e lên lũy thừa `number` (hàm mũ).

-   `number`: `number` được tính hàm mũ. Nếu `number` có giá trị null thì `Number.Exp` sẽ trả về giá trị null.


## Examples

### Example #1
Tăng e lên lũy thừa 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

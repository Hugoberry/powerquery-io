# Number.Abs


Trả về giá trị tuyệt đối của số.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Trả về giá trị tuyệt đối của `number`. Nếu `number` là null, `Number.Abs` sẽ trả về null.

-   `number`: `number` cho giá trị tuyệt đối cần tính.


## Examples

### Example #1
Giá trị tuyệt đối là -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

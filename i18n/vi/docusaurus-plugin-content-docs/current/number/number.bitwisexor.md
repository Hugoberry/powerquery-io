# Number.BitwiseXor


Trả về kết quả thực hiện "XOR" (Exclusive-OR) theo bit giữa hai đầu vào.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Trả về kết quả thực hiện "XOR" (Exclusive-OR) theo bit giữa `number1` và `number2`.

Number.Bytes

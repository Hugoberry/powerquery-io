# Number.BitwiseAnd


Trả về kết quả thực hiện tác vụ "And" theo bit giữa hai đầu vào.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Trả về kết quả thực hiện tác vụ "And" theo bit giữa `number1` và `number2`.

Number.Bytes

# Number.BitwiseOr


Trả về kết quả thực hiện tác vụ "Or" theo bit giữa hai đầu vào.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Trả về kết quả thực hiện tác vụ "Or" theo bit giữa `number1` và `number2`.

Number.Bytes

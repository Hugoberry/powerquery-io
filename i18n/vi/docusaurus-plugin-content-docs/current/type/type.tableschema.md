# Type.TableSchema


Trả về một bảng chứa mô tả về các cột (tức là sơ đồ) của loại bảng được chỉ định.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Trả về bảng mô tả các cột của `tableType`.

Tham khảo tài liệu về `Table.Schema` để biết mô tả về bảng kết quả.

# Type.ReplaceTablePartitionKey


Trả về một loại bảng mới với khóa phân hoạch được thay thế bằng khóa phân hoạch đã chỉ định.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```

# File.Contents


Trả về nội dung của tệp được chỉ định ở dạng nhị phân.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Trả về nội dung của tệp, `path`, dưới dạng nhị phân. Tham số `options` hiện chỉ nhằm mục đích sử dụng nội bộ.

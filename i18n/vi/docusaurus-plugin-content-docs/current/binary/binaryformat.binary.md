# BinaryFormat.Binary


Trả về một định dạng nhị phân đọc một giá trị nhị phân.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Trả về một định dạng nhị phân đọc một giá trị nhị phân. Nếu `length` được chỉ định, giá trị nhị phân sẽ chứa số lượng byte đó. Nếu `length` không được chỉ định, giá trị nhị phân sẽ chứa số lượng byte còn lại đó. `length` có thể được chỉ định là một số hoặc một định dạng nhị phân có độ dài đứng trước dữ liệu nhị phân.

# Value.Multiply


Trả về tích của hai giá trị.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Trả về tích của phép nhân `value1` với `value2`. Có thể chỉ định tham số `precision` tùy chọn, theo mặc định `Precision.Double` được sử dụng.

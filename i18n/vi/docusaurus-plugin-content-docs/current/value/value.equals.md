# Value.Equals


Trả về kết quả hai giá trị bằng nhau hay không bằng nhau.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Trả về true nếu giá trị `value1` bằng giá trị `value2`, false nếu ngược lại.

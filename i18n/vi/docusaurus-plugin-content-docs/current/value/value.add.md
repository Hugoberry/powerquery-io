# Value.Add


Trả về tổng của hai giá trị.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Trả về tổng của `value1` và `value2`. Có thể chỉ định tham số `precision` tùy chọn, theo mặc định `Precision.Double` được sử dụng.

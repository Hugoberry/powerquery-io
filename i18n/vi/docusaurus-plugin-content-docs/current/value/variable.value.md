# Variable.Value


Trả về giá trị của biến được chỉ định.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Trả về giá trị của biến được chỉ định `identifier` do môi trường đánh giá hiện tại xác định. Nếu biến không được xác định, hệ thống sẽ trả về lỗi.

# DateTimeZone.LocalNow


Devolve a data e a hora actuais no fuso horario local.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Devolve un valor `datetimezone` definido como a data e a hora actuais no sistema. O valor devolto contén información do fuso horario que representa o fuso horario local.

# Tables.GetRelationships


Obtén as relacións existentes entre un conxunto de táboas.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Obtén as relacións existentes entre un conxunto de táboas. Dáse por feito que o conxunto `tables` ten unha estrutura similar á dunha táboa de navegación. A columna definida por `dataColumn` contén as táboas de datos reais.

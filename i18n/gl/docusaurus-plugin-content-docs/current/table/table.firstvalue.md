# Table.FirstValue


Devolve a primeira columna da primeira fila da táboa ou un valor predefinido especificado.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Devolve a primeira columna da primeira fila da táboa `table` ou un valor predefinido especificado.



## Category
Table.Row operations

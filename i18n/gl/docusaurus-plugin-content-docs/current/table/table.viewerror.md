# Table.ViewError


Crea un rexistro de erro modificado que non activará unha alternativa cando o xere un controlador definido nunha visualización (a través de Table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Crea un rexistro de erro modificado desde `errorRecord` que non activará unha alternativa cando o xere un controlador definido nunha visualización (a través de Table.View).

# Function.InvokeAfter


Invoca a función determinada despois de que pase a duración especificada.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Devolve o resultado de invocar `function` despois de que pase a duración `delay`.

Function

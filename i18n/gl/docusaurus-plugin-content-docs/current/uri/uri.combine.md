# Uri.Combine


Devolve un URI absoluto que é a combinación do URI base de entrada e o URI relativo.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Devolve un URI absoluto que é a combinación do `baseUri` de entrada e o `relativeUri`.

# Text.Length


Devolve o número de caracteres.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Devolve o número de caracteres no texto `text`.


## Examples

### Example #1
Buscar o número de caracteres que hai no texto "Ola, Mundo".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

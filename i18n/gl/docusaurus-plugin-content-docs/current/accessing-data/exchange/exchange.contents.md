# Exchange.Contents


Devolve unha táboa de contidos dunha conta de Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Devolve unha táboa de contidos da conta de Microsoft Exchange `mailboxAddress`. Se `mailboxAddress` non se especifica, usarase a conta predefinida para a credencial.

# File.Contents


Devolve o contido do ficheiro especificado como binario.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Devolve o contido do ficheiro `path` como binario. Agora, o parámetro `options` só está pensado para uso interno.

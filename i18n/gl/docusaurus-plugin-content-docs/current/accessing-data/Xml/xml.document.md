# Xml.Document


Devolve o contido do documento XML como unha táboa xerárquica.


## Syntax

```powerquery
Xml.Document(
    contents as any,
    optional encoding as TextEncoding.Type
) as table
```


## Remarks

Devolve o contido do documento XML como unha táboa xerárquica.

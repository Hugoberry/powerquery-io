# Soda.Feed


Devolve unha táboa do contido do enderezo URL especificado co formato segundo a API de SODA 2.0.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

Devolve unha táboa do contido do enderezo URL `url` especificado co formato segundo a API de SODA 2.0. O enderezo URL debe apuntar a unha orixe compatible con SODA válida que finalice cunha extensión .CSV.

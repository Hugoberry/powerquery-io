# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

O conector de análises de Teams permítelle obter información acerca do uso que fai de Teams. Dispón de datos tanto acerca da súa persoal actividade en Teams como da actividade en Teams da que forma parte.

Os datos dispoñibles corresponden aos 90 días anteriores.

Para obter detalles acerca dos tipos de datos dispoñibles, consulte a documentación de axuda seguinte:

-   **Uso de Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Actividade de usuario de Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

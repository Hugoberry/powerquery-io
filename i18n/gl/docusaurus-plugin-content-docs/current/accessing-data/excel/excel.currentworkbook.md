# Excel.CurrentWorkbook


Devolve o contido do libro de Excel actual.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Devolve o contido do libro de Excel actual. Devolve táboas, intervalos con nome e matrices dinámicas. A diferenza de `Excel.Workbook`, non devolve follas.

# Identity.IsMemberOf


Determina se unha identidade é membro dunha colección de identidades.


## Syntax

```powerquery
Identity.IsMemberOf(
    identity as record,
    collection as record
) as logical
```


## Remarks

Determina se unha identidade é membro dunha colección de identidades.

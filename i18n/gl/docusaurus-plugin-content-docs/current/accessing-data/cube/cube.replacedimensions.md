# Cube.ReplaceDimensions


Substitúe o conxunto de dimensións que devolveu Cube.Dimensions.


## Syntax

```powerquery
Cube.ReplaceDimensions(
    cube as table,
    dimensions as any
) as table
```


## Remarks

Substitúe o conxunto de dimensións que devolve `Cube.Dimensions`. Por exemplo, esta función pódese usar para engadir unha columna de ID a un atributo de dimensión, de xeito que a orixe de datos poida agruparse no ID e non no valor que se mostra.

# Cube.CollapseAndRemoveColumns


Modifica a granularidade dimensional do contexto de filtro do cubo mediante a contracción dos atributos asignados ás columnas especificadas.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Modifica a granularidade dimensional do contexto de filtro do `cube` cubo mediante a contracción dos atributos asignados ás columnas especificadas `columnNames`. As columnas tamén se eliminan da vista tabular do cubo.

# Cube.ApplyParameter


Devolve un cubo tras aplicarlle un parámetro.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Devolve un cubo tras aplicarlle `parameter` con `arguments` a `cube`.

# Cube.Dimensions


Devolve unha táboa que contén o conxunto de dimensións dispoñibles.


## Syntax

```powerquery
Cube.Dimensions(
    cube as table
) as table
```


## Remarks

Devolve unha táboa que contén o conxunto de dimensións dispoñibles dentro de `cube`. Cada dimensión é unha táboa que contén un conxunto de atributos de dimensión. Os atributos de dimensión represéntanse como columnas na táboa de dimensións. As dimensións poden expandirse no cubo mediante Cube.AddAndExpandDimensionColumn.

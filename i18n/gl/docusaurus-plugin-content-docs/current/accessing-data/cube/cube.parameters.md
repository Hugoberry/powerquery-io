# Cube.Parameters


Devolve unha táboa co conxunto de parámetros que se pode aplicar ao cubo.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Devolve unha táboa co conxunto de parámetros que se pode aplicar a `cube`. Cada parámetro é unha función que se pode invocar para obter `cube` co parámetro e os seus argumentos aplicados.

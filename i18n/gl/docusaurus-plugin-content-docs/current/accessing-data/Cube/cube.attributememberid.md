# Cube.AttributeMemberId


Devolve o identificador de membro único do valor da propiedade dos membros.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Devolve o identificador de membro único do valor da propiedade dun membro. `attribute`. Devolve un valor nulo para calquera outro valor.

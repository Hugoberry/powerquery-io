# Cube.MeasureProperty


Devolve unha propiedade dunha medida (propiedade da cela).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Devolve a propiedade `propertyName` da medida `measure`.

Cube

# Cube.DisplayFolders


Devolve unha árbore aniñada de táboas que representan a xerarquía de cartafoles dos obxectos (por exemplo, dimensións e medidas).


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Devolve unha árbore aniñada de táboas que representan a xerarquía do cartafol dos obxectos (por exemplo, dimensións e medidas) dispoñible para usar en `cube`.

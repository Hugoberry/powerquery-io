# Cube.Measures


Devolve unha táboa que contén o conxunto de medidas dispoñibles.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Devolve unha táboa que contén o conxunto de medidas dispoñibles dentro de `cube`. Cada medida represéntase como unha función. As medidas poden aplicarse ao cubo mediante Cube.AddMeasureColumn.

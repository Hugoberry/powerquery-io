# Number.Abs


Devolve o valor absoluto do número.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Devolve o valor absoluto de `number`. Se `number` é nulo, `Number.Abs` devolve nulo.

-   `number`: un `number` a partir do cal se debe calcular o valor absoluto.


## Examples

### Example #1
Valor absoluto de -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Number.Log10


Devolve o logaritmo en base 10 do número.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Devolve o logaritmo en base 10 dun número, `number`. Se `number` é nulo, `Number.Log10` devolve nulo.


## Examples

### Example #1
Obtén o logaritmo en base 10 de 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

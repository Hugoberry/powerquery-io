# Number.Cos


Devolve o coseno do número.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Devolve o coseno do ángulo especificado.

-   `number`: un ángulo medido en radiáns.


## Examples

### Example #1
Buscar o coseno do ángulo 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Atopa o coseno de π radiáns.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

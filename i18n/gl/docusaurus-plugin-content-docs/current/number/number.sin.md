# Number.Sin


Devolve o seno do número.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Devolve o seno de `number`.


## Examples

### Example #1
Buscar o seno do ángulo 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

# Number.BitwiseOr


Devolve o resultado de realizar unha operación "Or" bit a bit entre as dúas entradas.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devolve o resultado de realizar un "Or" bit a bit entre `number1` e `number2`.



## Category
Number.Bytes

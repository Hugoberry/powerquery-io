# Number.BitwiseShiftLeft


Despraza os bits definidos á esquerda.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devolve o resultado de realizar un desprazamento bit a bit á esquerda en `number1`, o número especificado de bits `number2`.

Number.Bytes

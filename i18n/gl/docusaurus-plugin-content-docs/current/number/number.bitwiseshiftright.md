# Number.BitwiseShiftRight


Despraza os bits definidos á dereita.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devolve o resultado de realizar un desprazamento bit a bit á dereita en `number1`, o número especificado de bits `number2`.

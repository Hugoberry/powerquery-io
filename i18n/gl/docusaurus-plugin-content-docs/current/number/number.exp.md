# Number.Exp


Eleva e á potencia indicada.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Devolve o resultado de elevar e á potencia de `number` (función exponencial).

-   `number`: un `number` a partir do que se debe calcular a función exponencial. Se `number` é nulo, `Number.Exp` devolve nulo.


## Examples

### Example #1
Eleva e á potencia 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.Factorial


Devolve o factorial do número.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

Devolve o factorial do número `number`.


## Examples

### Example #1
Buscar o factorial de 10.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

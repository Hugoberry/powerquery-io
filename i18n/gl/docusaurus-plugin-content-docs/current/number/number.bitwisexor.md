# Number.BitwiseXor


Devolve o resultado de realizar unha operación "XOR" (OR exclusivo) bit a bit entre as dúas entradas.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Devolve o resultado de realizar un "XOR" (OR exclusivo) bit a bit entre `number1` e `number2`.



## Category
Number.Bytes

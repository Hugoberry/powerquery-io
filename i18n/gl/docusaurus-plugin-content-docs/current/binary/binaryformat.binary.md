# BinaryFormat.Binary


Devolve un formato binario que le un valor binario.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Devolve un formato binario que le un valor binario. Se se especifica `length`, o valor binario conterá ese número de bytes. Se non se especifica `length`, o valor binario conterá os bytes restantes. O `length` pode especificarse como un número ou como un formato binario da lonxitude que precede os datos binarios.

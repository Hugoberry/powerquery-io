# BinaryFormat.ByteOrder


Devolve un formato binario coa orde de bytes especificada por unha función.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Devolve un formato binario coa orde de bytes especificada por `binaryFormat`. A orde de bytes predefinida é `ByteOrder.BigEndian`.

# Type.ReplaceTablePartitionKey


Devolve un novo tipo de táboa coa chave de partición substituída pola chave de partición especificada.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Devolve un novo tipo de táboa coa chave de partición substituída pola chave de partición especificada.

# Type.TableSchema


Devolve unha táboa que contén unha descrición das columnas (é dicir, o esquema) do tipo de táboa especificado.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Devolve unha táboa que describe as columnas de `tableType`.

Consulta a documentación de `Table.Schema` para obter unha descrición da táboa resultante.

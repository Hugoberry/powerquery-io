# Value.Equals


Devolve se os dous valores son iguais.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Devolve verdadeiro se o valor `value1` é igual que o valor `value2`, se non, devolve falso.

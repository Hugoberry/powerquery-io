# Value.Divide


Devolve o resultado de dividir o primeiro valor polo segundo.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Devolve o resultado de dividir `value1` por `value2`. Pódese especificar un parámetro opcional `precision`, por defecto, utilízase `Precision.Double`.

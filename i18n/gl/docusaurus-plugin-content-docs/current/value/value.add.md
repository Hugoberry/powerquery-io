# Value.Add


Devolve a suma dos dous valores.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Devolve a suma de `value1` e `value2`. Pódese especificar un parámetro opcional `precision`, por defecto, utilízase `Precision.Double`.

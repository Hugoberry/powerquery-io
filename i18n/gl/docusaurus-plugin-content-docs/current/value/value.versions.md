# Value.Versions


Devolve unha táboa de navegación que contén as versións dispoñibles do valor.


## Syntax

```powerquery
Value.Versions(
    value as any
) as table
```


## Remarks

Devolve unha táboa de navegación que contén as versións dispoñibles de `value`.

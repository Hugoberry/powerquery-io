# Value.Optimize


Sinala Value.Expression que vai devolver a expresión optimizada dun valor.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Cando se usa en Value.Expression, se `value` representa unha consulta que se pode optimizar, esta función indica que se debe devolver a expresión optimizada. No caso contrario, `value` pasará sen ningún efecto.

Expression

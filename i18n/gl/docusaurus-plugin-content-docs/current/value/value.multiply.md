# Value.Multiply


Devolve o produto de dous valores.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Devolve o produto de multiplicar `value1` por `value2`. Pódese especificar un parámetro opcional `precision`, por defecto, utilízase `Precision.Double`.

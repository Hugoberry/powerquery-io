# Value.Alternates


Expresa plans de consulta alternativos.


## Syntax

```powerquery
Value.Alternates(
    alternates as list
) as any
```


## Remarks

Expresa plans de consulta alternativos dentro dunha expresión de plan de consulta obtida mediante `Value.Expression(Value.Optimize(...))`. Non destinado a outros usos.

Expression

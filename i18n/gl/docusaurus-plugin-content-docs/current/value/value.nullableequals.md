# Value.NullableEquals


Devolve se os dous valores son iguais.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Devolve null se o argumento `value1` ou `value2` é null; se non, é equivalente a Value.Equals.

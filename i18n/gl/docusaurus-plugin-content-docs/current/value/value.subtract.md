# Value.Subtract


Devolve a diferenza dos dous valores.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Devolve a diferenza de `value1` e `value2`. Pódese especificar un parámetro opcional `precision`, por defecto, utilízase `Precision.Double`.

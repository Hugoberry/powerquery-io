# Variable.Value


Devolve o valor da variable especificada.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Devolve o valor da variable `identifier` especificada definida polo ambiente de avaliación actual. Se a variable non está definida, prodúcese un erro.

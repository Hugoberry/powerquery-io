# Cube.AttributeMemberId


Επιστρέφει το μοναδικό αναγνωριστικό μέλους από την τιμή ιδιότητας μέλους.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Επιστρέφει το μοναδικό αναγνωριστικό μέλος από μια τιμή ιδιότητας μέλους. `attribute`. Επιστρέφει τιμή null για κάθε άλλη τιμή.

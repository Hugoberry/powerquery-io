# Cube.ApplyParameter


Επιστρέφει έναν κύβο, αφού εφαρμοστεί παράμετρος σε αυτόν.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Επιστρέφει έναν κύβο, αφού εφαρμοστεί `parameter` με `arguments` σε `cube`.

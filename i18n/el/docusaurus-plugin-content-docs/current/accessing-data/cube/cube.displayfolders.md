# Cube.DisplayFolders


Επιστρέφει ένα ένθετο δέντρο πινάκων που αντιπροσωπεύει την ιεραρχία φακέλων εμφάνισης των αντικειμένων (για παράδειγμα, διαστάσεις και μετρήσεις).


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Επιστρέφει ένα ένθετο δέντρο πινάκων που αντιπροσωπεύει την ιεραρχία φακέλων εμφάνισης των αντικειμένων (για παράδειγμα, διαστάσεις και μετρήσεις) που είναι διαθέσιμα για χρήση στο `cube`.

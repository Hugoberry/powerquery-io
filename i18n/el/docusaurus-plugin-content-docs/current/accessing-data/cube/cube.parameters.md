# Cube.Parameters


Επιστρέφει έναν πίνακα που περιέχει το σύνολο των παραμέτρων που μπορούν να εφαρμοστούν στον κύβο.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Επιστρέφει έναν πίνακα που περιέχει το σύνολο των παραμέτρων που μπορούν να εφαρμοστούν στο `cube`. Κάθε παράμετρος είναι μια συνάρτηση που μπορεί να κληθεί για τη λήψη `cube` με την παράμετρο και τα ορίσματά της εφαρμοσμένα.

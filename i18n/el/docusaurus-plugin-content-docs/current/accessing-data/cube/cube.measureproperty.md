# Cube.MeasureProperty


Επιστρέφει μια ιδιότητα μιας μέτρησης (ιδιότητα κελιού).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Επιστρέφει την ιδιότητα `propertyName` της μέτρησης `measure`.



## Category
Cube

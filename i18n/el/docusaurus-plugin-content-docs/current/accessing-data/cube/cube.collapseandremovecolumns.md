# Cube.CollapseAndRemoveColumns


Αλλάζει τις υποδιαιρέσεις διάστασης του περιβάλλοντος φίλτρου για τον κύβο συμπτύσσοντας τα χαρακτηριστικά που αντιστοιχίστηκαν στις καθορισμένες στήλες.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Αλλάζει τις υποδιαιρέσεις διάστασης του περιβάλλοντος φίλτρου για το `cube` συμπτύσσοντας τα χαρακτηριστικά που αντιστοιχίστηκαν στις καθορισμένες στήλες `columnNames`. Οι στήλες καταργούνται επίσης από την προβολή πίνακα του κύβου.

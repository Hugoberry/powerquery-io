# Cube.AttributeMemberProperty


Επιστρέφει μια ιδιότητα ενός χαρακτηριστικού διάστασης.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Επιστρέφει την ιδιότητα `propertyName` του χαρακτηριστικού διάστασης `attribute`.

Cube

# Exchange.Contents


Επιστρέφει έναν πίνακα περιεχομένων από έναν λογαριασμό Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Επιστρέφει έναν πίνακα περιεχομένων από το λογαριασμό Microsoft Exchange `mailboxAddress`. Αν δεν έχει καθοριστεί `mailboxAddress`, χρησιμοποιείται ο προεπιλεγμένος λογαριασμός για τα διαπιστευτήρια.

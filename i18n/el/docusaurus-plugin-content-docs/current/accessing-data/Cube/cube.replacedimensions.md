# Cube.ReplaceDimensions


Αντικαθιστά το σύνολο των διαστάσεων που επιστρέφονται από το Cube.Dimensions.


## Syntax

```powerquery
Cube.ReplaceDimensions(
    cube as table,
    dimensions as any
) as table
```


## Remarks

Αντικαθιστά το σύνολο των διαστάσεων που επιστρέφονται από `Cube.Dimensions` Για παράδειγμα, αυτή η συνάρτηση μπορεί να χρησιμοποιηθεί για την προσθήκη μιας στήλης αναγνωριστικού σε ένα χαρακτηριστικό διάστασης έτσι ώστε η προέλευση δεδομένων να μπορεί να ομαδοποιήσει το αναγνωριστικό αντί για την εμφανιζόμενη τιμή.

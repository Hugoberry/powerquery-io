# Cube.AddMeasureColumn


Προσθέτει μια στήλη στον κύβο η οποία περιέχει τα αποτελέσματα της μέτρησης που εφαρμόστηκε στο περιβάλλον γραμμής κάθε γραμμής.


## Syntax

```powerquery
Cube.AddMeasureColumn(
    cube as table,
    column as text,
    measureSelector as any
) as table
```


## Remarks

Προσθέτει μια στήλη με το όνομα `column` στο `cube` στον κύβο η οποία περιέχει τα αποτελέσματα της μέτρησης `measureSelector` που εφαρμόστηκε στο περιβάλλον γραμμής κάθε γραμμής. Η εφαρμογή μέτρησης επηρεάζεται από τις αλλαγές στις υποδιαιρέσεις και την ανάλυση της διάστασης. Οι τιμές μέτρησης θα ρυθμιστούν μετά την εκτέλεση ορισμένων λειτουργιών κύβου.

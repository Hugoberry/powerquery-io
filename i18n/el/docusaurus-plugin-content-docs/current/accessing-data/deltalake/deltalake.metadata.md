# DeltaLake.Metadata


Με δεδομένο έναν πίνακα Delta Lake, επιστρέφει τις καταχωρήσεις του αρχείου καταγραφής για αυτόν τον πίνακα.


## Syntax

```powerquery
DeltaLake.Metadata(
    table as table
) as table
```

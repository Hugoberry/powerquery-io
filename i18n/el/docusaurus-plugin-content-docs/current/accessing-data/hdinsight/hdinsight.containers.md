# HdInsight.Containers


Επιστρέφει έναν πίνακα περιήγησης που περιέχει τα κοντέινερ που βρέθηκαν στον καθορισμένο λογαριασμό από ένα θάλαμο χώρου αποθήκευσης του Azure.


## Syntax

```powerquery
HdInsight.Containers(
    account as text
) as table
```


## Remarks

Επιστρέφει έναν πίνακα περιήγησης που περιέχει μια γραμμή για κάθε κοντέινερ που βρέθηκε στη διεύθυνση URL λογαριασμού `account` από ένα θάλαμο χώρου αποθήκευσης του Azure. Κάθε γραμμή περιέχει μια σύνδεση στα αντικείμενα blob του κοντέινερ.

# Folder.Contents


Επιστρέφει έναν πίνακα που περιέχει τις ιδιότητες και τα περιεχόμενα των αρχείων και φακέλων που βρέθηκαν στον καθορισμένο φάκελο.


## Syntax

```powerquery
Folder.Contents(
    path as text,
    optional options as record
) as table
```


## Remarks

Επιστρέφει έναν πίνακα που περιέχει μια σειρά για κάθε φάκελο και αρχείο που βρίσκονται στο φάκελο `path`. Κάθε σειρά περιέχει ιδιότητες του φακέλου ή του αρχείου και έναν σύνδεσμο προς το περιεχόμενό του. Η `options` παράμετρος προορίζεται προς το παρόν μόνο για εσωτερική χρήση.

# AdoDotNet.Query


Επιστρέφει το αποτέλεσμα εκτέλεσης ενός τοπικού ερωτήματος σε μια προέλευση δεδομένων ADO.NET.


## Syntax

```powerquery
AdoDotNet.Query(
    providerName as text,
    connectionString as any,
    query as text,
    optional options as record
) as table
```


## Remarks

Επιστρέφει το αποτέλεσμα εκτέλεσης του `query` με τη συμβολοσειρά σύνδεσης `connectionString` χρησιμοποιώντας την υπηρεσία παροχής ADO.NET `providerName`. Το `connectionString` μπορεί να είναι κείμενο ή εγγραφή ζευγών τιμών ιδιοτήτων. Οι τιμές ιδιοτήτων μπορούν να είναι είτε κείμενο είτε αριθμός. Μπορεί να καταχωρηθεί μια προαιρετική παράμετρος εγγραφής `options` για τον καθορισμό πρόσθετων ιδιοτήτων. Η εγγραφή μπορεί να περιέχει τα ακόλουθα πεδία:

-   `CommandTimeout` : Μια διάρκεια που ελέγχει για πόσο χρονικό διάστημα επιτρέπεται η εκτέλεση του ερωτήματος από την πλευρά του διακομιστή προτού αυτό ακυρωθεί. Η προεπιλεγμένη τιμή είναι δέκα λεπτά.
-   `SqlCompatibleWindowsAuth` : Μια λογική τιμή (true/false) που καθορίζει αν θα παράγονται επιλογές συμβολοσειράς σύνδεσης συμβατές με SQL Server για τον έλεγχο ταυτότητας των Windows. Η προεπιλεγμένη τιμή είναι true.

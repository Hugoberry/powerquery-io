# SharePoint.Tables


Επιστρέφει έναν πίνακα που περιέχει περιεχόμενο από μια λίστα του SharePoint.


## Syntax

```powerquery
SharePoint.Tables(
    url as text,
    optional options as record
) as table
```


## Remarks

Επιστρέφει έναν πίνακα που περιέχει μια γραμμή για κάθε στοιχείο λίστας που βρέθηκε στην καθορισμένη λίστα του SharePoint `url`. Κάθε γραμμή περιέχει ιδιότητες της λίστας. Το `options` μπορεί να καθοριστεί για τον έλεγχο των παρακάτω επιλογών:

-   `ApiVersion` : Ένας αριθμός (14 ή 15) ή το κείμενο "Auto" που καθορίζει την έκδοση SharePoint API για χρήση για αυτήν την τοποθεσία. Όταν δεν καθορίζεται, χρησιμοποιείται η έκδοση API 14. Όταν καθορίζεται η επιλογή "Auto", η έκδοση του διακομιστή θα εντοπίζεται αυτόματα, αν είναι δυνατό, διαφορετικά η προεπιλεγμένη έκδοση θα είναι η 14. Για τις τοποθεσίες SharePoint που δεν είναι στα Αγγλικά απαιτείται τουλάχιστον η έκδοση 15.
-   `Implementation` : Προαιρετική. Καθορίζει ποια έκδοση της σύνδεσης SharePoint θα χρησιμοποιηθεί. Οι αποδεκτές τιμές είναι "2.0" ή null. Εάν η τιμή είναι "2.0", χρησιμοποιείται η υλοποίηση 2.0 της σύνδεσης SharePoint. Εάν η τιμή είναι null, χρησιμοποιείται η αρχική υλοποίηση της σύνδεσης SharePoint.
-   `ViewMode` : Προαιρετική. Αυτή η επιλογή είναι έγκυρη μόνο για υλοποίηση 2.0. Οι αποδεκτές τιμές είναι "Όλα" και "Προεπιλογή". Εάν δεν έχει καθοριστεί τιμή, η τιμή ορίζεται σε "Όλα". Όταν καθορίζεται η επιλογή "Όλα", η προβολή περιλαμβάνει όλες τις στήλες που έχουν δημιουργηθεί από τον χρήστη και έχουν οριστεί από το σύστημα. Όταν καθορίζεται η επιλογή "Προεπιλογή", η προβολή θα συμφωνεί με αυτά που βλέπει ο χρήστης όταν κοιτά τη λίστα online σε οποιαδήποτε προβολή αυτού του χρήστη έχει οριστεί ως προεπιλογή στις ρυθμίσεις του. Εάν ο χρήστης επεξεργαστεί την προεπιλεγμένη προβολή του για να προσθέσει ή να καταργήσει στήλες που έχουν δημιουργηθεί από τον χρήστη ή έχουν οριστεί από το σύστημα ή δημιουργώντας μια νέα προβολή και ορίζοντας την ως προεπιλεγμένη, αυτές οι αλλαγές θα μεταδοθούν μέσω της σύνδεσης.
-   `DisableAppendNoteColumns` : Εμποδίζει τη σύνδεση από τη χρήση ενός ξεχωριστού τελικού σημείου για στήλες σημειώσεων.

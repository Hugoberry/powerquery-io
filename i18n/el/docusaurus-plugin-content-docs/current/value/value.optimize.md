# Value.Optimize


Ζητά από το Value.Expression να επιστρέψει τη βελτιστοποιημένη παράσταση για μια τιμή.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Όταν χρησιμοποιείται στο Value.Expression, αν το `value` αντιπροσωπεύει ένα ερώτημα που μπορεί να βελτιστοποιηθεί, αυτή η συνάρτηση υποδεικνύει ότι θα πρέπει να επιστραφεί η βελτιστοποιημένη παράσταση. Διαφορετικά, το `value` θα μεταβιβαστεί χωρίς καμία επίδραση.

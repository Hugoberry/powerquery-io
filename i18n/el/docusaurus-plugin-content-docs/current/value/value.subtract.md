# Value.Subtract


Επιστρέφει τη διαφορά των δύο τιμών.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Επιστρέφει τη διαφορά των `value1` και `value2`. Μπορεί να καθοριστεί μια προαιρετική παράμετρος `precision`, από προεπιλογή χρησιμοποιείται η `Precision.Double`.

# Value.Divide


Επιστρέφει το αποτέλεσμα της διαίρεσης της πρώτης τιμής με τη δεύτερη.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Επιστρέφει το αποτέλεσμα της διαίρεσης `value1` διά `value2`. Μπορεί να καθοριστεί μια προαιρετική παράμετρος `precision`, από προεπιλογή χρησιμοποιείται η `Precision.Double`.

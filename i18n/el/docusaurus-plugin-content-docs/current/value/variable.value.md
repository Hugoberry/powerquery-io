# Variable.Value


Επιστρέφει την τιμή της καθορισμένης μεταβλητής.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Επιστρέφει την τιμή της καθορισμένης μεταβλητής `identifier` που ορίζεται από το τρέχον περιβάλλον αξιολόγησης. Αν η μεταβλητή δεν έχει οριστεί, προκύπτει σφάλμα.

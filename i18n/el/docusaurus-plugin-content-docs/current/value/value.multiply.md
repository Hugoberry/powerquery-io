# Value.Multiply


Επιστρέφει το γινόμενο των δύο τιμών.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Επιστρέφει το διανυσματικό γινόμενο του πολλαπλασιασμού `value1` επί `value2`. Μπορεί να καθοριστεί μια προαιρετική παράμετρος `precision`, από προεπιλογή χρησιμοποιείται η `Precision.Double`.

# Value.Equals


Επιστρέφει αν δύο τιμές είναι ίσες.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Επιστρέφει true εάν η τιμή `value1` ισούται με την τιμή `value2`, διαφορετικά false.



## Category
Values

# Table.ReplacePartitionKey


Αντικαθιστά το κλειδί διαμερίσματος του καθορισμένου πίνακα.


## Syntax

```powerquery
Table.ReplacePartitionKey(
    table as table,
    partitionKey as list
) as table
```


## Remarks

Αντικαθιστά το κλειδί διαμερίσματος του καθορισμένου πίνακα.

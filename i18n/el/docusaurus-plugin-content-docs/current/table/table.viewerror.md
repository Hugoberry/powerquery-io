# Table.ViewError


Δημιουργεί μια τροποποιημένη εγγραφή σφάλματος η οποία δεν θα ενεργοποιήσει μια εναλλακτική λύση όταν εμφανίζεται από ένα πρόγραμμα χειρισμού που ορίζεται σε μια προβολή (μέσω table.View).


## Syntax

```powerquery
Table.ViewError(
    errorRecord as record
) as record
```


## Remarks

Δημιουργεί μια τροποποιημένη εγγραφή σφάλματος από `errorRecord` η οποία δεν ενεργοποιεί μια εναλλακτική λύση όταν προκαλείται από ένα πρόγραμμα χειρισμού που ορίζεται σε μια προβολή (μέσω Table.View).

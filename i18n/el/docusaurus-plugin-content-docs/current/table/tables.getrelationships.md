# Tables.GetRelationships


Λαμβάνει τις σχέσεις μεταξύ ενός συνόλου πινάκων.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Λαμβάνει τις σχέσεις μεταξύ ενός συνόλου πινάκων. Θεωρείται ότι το σύνολο `tables` έχει δομή όμοια με αυτήν ενός πίνακα πλοήγησης. Η στήλη που καθορίζεται από το στοιχείο `dataColumn` περιέχει τους πραγματικούς πίνακες δεδομένων.

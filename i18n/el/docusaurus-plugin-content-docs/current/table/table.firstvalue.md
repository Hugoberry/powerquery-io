# Table.FirstValue


Επιστρέφει την πρώτη στήλη της πρώτης σειράς του πίνακα ή μια καθορισμένη προεπιλεγμένη τιμή.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Επιστρέφει την πρώτη στήλη της πρώτης σειράς του πίνακα `table` ή μια καθορισμένη προεπιλεγμένη τιμή.

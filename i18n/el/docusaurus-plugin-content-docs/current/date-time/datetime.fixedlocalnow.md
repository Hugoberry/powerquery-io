# DateTime.FixedLocalNow


Επιστρέφει την τρέχουσα ημερομηνία και ώρα στην τοπική ζώνη ώρας. Αυτή η τιμή είναι σταθερή και δεν θα αλλάξει με τις διαδοχικές κλήσεις.


## Syntax

```powerquery
DateTime.FixedLocalNow(

) as datetime
```


## Remarks

Επιστρέφει μια τιμή `datetime` που έχει οριστεί στην τρέχουσα ημερομηνία και ώρα του συστήματος. Αυτή η τιμή είναι σταθερή και δεν θα αλλάξει με τις διαδοχικές κλήσεις, σε αντίθεση με την DateTime.LocalNow, η οποία ενδέχεται να επιστρέφει διαφορετικές τιμές κατά τη διάρκεια εκτέλεσης μιας παράστασης.

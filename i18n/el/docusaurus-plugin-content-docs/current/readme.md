# Ανακαλύψτε τη γλώσσα
Η γλώσσα τύπων Power Query M είναι βελτιστοποιημένη για τη δημιουργία εξαιρετικά ευέλικτων ερωτημάτων σύνθεσης δεδομένων. Είναι μια συναρτησιακή γλώσσα με διάκριση πεζών-κεφαλαίων, παρόμοια με την F#. Η γλώσσα τύπων Power Query χρησιμοποιείται σε μια σειρά προϊόντων της Microsoft, όπως το Power BI Desktop, το Excel και το Analysis Services.

Αυτός ο ιστότοπος αποτελεί σημείο αναφοράς για τις συναρτήσεις του Power Query, προσφέροντας γρήγορη και άμεση πρόσβαση σε λεπτομερείς πληροφορίες και πρακτικά παραδείγματα για κάθε συνάρτηση.
:::note
Λάβετε υπόψη ότι ο συγγραφέας δεν διεκδικεί κανένα δικαίωμα πνευματικής ιδιοκτησίας επί του υλικού που παρουσιάζεται σε αυτόν τον ιστότοπο. Οι πληροφορίες συλλέγονται και παρέχονται με την ελπίδα ότι θα είναι χρήσιμες για όσους επιθυμούν να διευρύνουν τις γνώσεις και την εφαρμογή του Power Query.
:::

Η λειτουργία αναζήτησης σε αυτόν τον ιστότοπο θα πρέπει να απλοποιεί τη διαδικασία ανακάλυψης της ευρείας γκάμας συναρτήσεων του Power Query. Φροντίστε να τη δοκιμάσετε (Ctrl+K).

![Λειτουργία αναζήτησης που παρέχεται από την Algolia](/img/search.png)

Για όσους ενδιαφέρονται για βαθύτερη εξερεύνηση ή λεπτομέρειες υλοποίησης, περισσότερες πληροφορίες μπορούν να βρεθούν στο ακόλουθο αποθετήριο GitHub: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Αυτό το αποθετήριο ενδέχεται να περιέχει πρόσθετα παραδείγματα, ενημερώσεις και πόρους σχετικούς με την ανάπτυξη και τη χρήση του Power Query.

# DateTimeZone.LocalNow


Επιστρέφει την τρέχουσα ημερομηνία και ώρα στην τοπική ζώνη ώρας.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Επιστρέφει μια τιμή `datetimezone` που έχει οριστεί στην τρέχουσα ημερομηνία και ώρα του συστήματος. Η τιμή που επιστρέφεται περιέχει πληροφορίες ζώνης ώρας που αντιπροσωπεύουν την τοπική ζώνη ώρας.

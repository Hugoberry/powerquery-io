# Binary.Split


Διαιρεί το καθορισμένο δυαδικό δεδομένο σε μια λίστα δυαδικών δεδομένων χρησιμοποιώντας το καθορισμένο μέγεθος σελίδας.


## Syntax

```powerquery
Binary.Split(
    binary as binary,
    pageSize as number
) as list
```


## Remarks

Διαιρεί `binary` σε μια λίστα δυαδικών δεδομένων όπου το πρώτο στοιχείο της λίστας εξόδου είναι ένα δυαδικό δεδομένο που περιέχει τα πρώτα `pageSize` byte από δυαδικό δεδομένο προέλευσης, το επόμενο στοιχείο της λίστας εξόδου είναι ένα δυαδικό δεδομένο που περιέχει τα επόμενη `pageSize` byte από το δυαδικό αρχείο προέλευσης και ούτω καθεξής.

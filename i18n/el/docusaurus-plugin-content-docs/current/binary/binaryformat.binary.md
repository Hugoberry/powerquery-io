# BinaryFormat.Binary


Επιστρέφει μια δυαδική μορφή που διαβάζει μια δυαδική τιμή.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Επιστρέφει μια δυαδική μορφή που διαβάζει μια δυαδική τιμή. Εάν οριστεί `length`, η δυαδική τιμή θα περιέχει τόσα byte. Εάν δεν έχει καθοριστεί `length`, η δυαδική τιμή θα περιέχει τα υπόλοιπα byte. Το `length` μπορεί να καθοριστεί είτε ως αριθμός, είτε ως δυαδική μορφή του μήκους που προηγείται των δυαδικών δεδομένων.

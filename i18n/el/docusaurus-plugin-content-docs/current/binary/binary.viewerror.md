# Binary.ViewError


Δημιουργεί μια τροποποιημένη εγγραφή σφάλματος, η οποία δεν ενεργοποιεί μια εναλλακτική όταν ενεργοποιείται από ένα πρόγραμμα χειρισμού που ορίζεται σε μια προβολή (μέσω Binary.View).


## Syntax

```powerquery
Binary.ViewError(
    errorRecord as record
) as record
```


## Remarks

Δημιουργεί μια τροποποιημένη εγγραφή σφάλματος από `errorRecord` η οποία δεν ενεργοποιεί μια εναλλακτική λύση όταν ενεργοποιείται από ένα πρόγραμμα χειρισμού που ορίζεται σε μια προβολή (μέσω Binary.View).

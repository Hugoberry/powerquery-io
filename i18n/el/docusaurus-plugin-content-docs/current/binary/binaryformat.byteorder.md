# BinaryFormat.ByteOrder


Επιστρέφει μια δυαδική μορφή με τη σειρά byte που καθορίζεται από μια συνάρτηση.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Επιστρέφει μια δυαδική μορφή με τη σειρά byte που καθορίζεται από το `binaryFormat`. Η προεπιλεγμένη σειρά byte είναι `ByteOrder.BigEndian`.

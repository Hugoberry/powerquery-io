# Text.Length


Επιστρέφει τον αριθμό των χαρακτήρων.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Επιστρέφει τον αριθμό χαρακτήρων του κειμένου `text`.


## Examples

### Example #1
Βρείτε πόσοι χαρακτήρες υπάρχουν στο κείμενο "Hello, World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

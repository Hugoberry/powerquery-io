# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Αντιστροφή του παρεχόμενου στοιχείου `text`.


## Examples

### Example #1
Αντιστροφή του κειμένου "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

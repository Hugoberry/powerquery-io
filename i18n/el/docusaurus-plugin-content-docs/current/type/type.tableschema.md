# Type.TableSchema


Επιστρέφει έναν πίνακα που περιέχει μια περιγραφή των στηλών (δηλαδή το σχήμα) του καθορισμένου τύπου πίνακα.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Επιστρέφει έναν πίνακα που περιγράφει τις στήλες του `tableType`.

Ανατρέξτε στην τεκμηρίωση για το `Table.Schema` για μια περιγραφή του πίνακα που προκύπτει.

# Type.TableColumn


Επιστρέφει τον τύπο μιας στήλης σε έναν πίνακα.


## Syntax

```powerquery
Type.TableColumn(
    tableType as type,
    column as text
) as type
```


## Remarks

Επιστρέφει τον τύπο μιας στήλης `column` σε έναν τύπο πίνακα `tableType`.

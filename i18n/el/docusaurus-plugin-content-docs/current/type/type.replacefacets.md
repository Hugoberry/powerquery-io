# Type.ReplaceFacets


Αντικαθιστά τις κλάσεις facet ενός τύπου.


## Syntax

```powerquery
Type.ReplaceFacets(
    type as type,
    facets as record
) as type
```


## Remarks

Αντικαθιστά τις κλάσεις facet του `type` με τις κλάσεις facet που περιέχονται στην εγγραφή `facets`.

# Type.ReplaceTablePartitionKey


Επιστρέφει έναν νέο τύπο πίνακα με το κλειδί διαμερίσματος να αντικαθίσταται από το καθορισμένο κλειδί διαμερίσματος.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Επιστρέφει έναν νέο τύπο πίνακα με το κλειδί διαμερίσματος να αντικαθίσταται από το καθορισμένο κλειδί διαμερίσματος.

# List.NonNullCount


Επιστρέφει τον αριθμό των στοιχείων της λίστας που δεν είναι null.


## Syntax

```powerquery
List.NonNullCount(
    list as list
) as number
```


## Remarks

Επιστρέφει τον αριθμό των στοιχείων που δεν είναι null στη λίστα `list`.

List.Information

# List.RemoveFirstN


Επιστρέφει μια λίστα που παραλείπει τον καθορισμένο αριθμό στοιχείων από την αρχή της λίστας.


## Syntax

```powerquery
List.RemoveFirstN(
    list as list,
    optional countOrCondition as any
) as list
```


## Remarks

Επιστρέφει μια λίστα που καταργεί το πρώτο στοιχείο της λίστας `list`. Εάν `list` είναι μια κενή λίστα, επιστρέφεται μια κενή λίστα. Αυτή η συνάρτηση λαμβάνει μια προαιρετική παράμετρο, `countOrCondition`, για να υποστηρίξει την κατάργηση πολλών τιμών, όπως αναφέρεται παρακάτω.

-   Εάν έχει καθοριστεί ένας αριθμός, καταργούνται έως και πολλά στοιχεία.
-   Εάν καθοριστεί μια συνθήκη, καταργούνται τυχόν διαδοχικά στοιχεία που ταιριάζουν στην αρχή του `list` .
-   Εάν αυτή η παράμετρος είναι null, παρατηρείται η προεπιλεγμένη συμπεριφορά.


## Examples

### Example #1
Δημιουργήστε μια λίστα από τη λίστα \{1, 2, 3, 4, 5\} χωρίς τους πρώτους 3 αριθμούς.
```powerquery
List.RemoveFirstN({1, 2, 3, 4, 5}, 3)
```

Result: 
```powerquery
{4, 5}
```


### Example #2
Δημιουργήστε μια λίστα από τη λίστα \{5, 4, 2, 6, 1\} που ξεκινά με αριθμό μικρότερο του 3.
```powerquery
List.RemoveFirstN({5, 4, 2, 6, 1}, each _ > 3)
```

Result: 
```powerquery
{2, 6, 1}
```

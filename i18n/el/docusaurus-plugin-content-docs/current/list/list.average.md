# List.Average


Επιστρέφει το μέσο όρο των τιμών. Λειτουργεί με αριθμητικές τιμές, τιμές ημερομηνίας, ημερομηνίας/ώρας, ημερομηνίας/ώρας/ζώνης ώρας και διάρκειας.


## Syntax

```powerquery
List.Average(
    list as list,
    optional precision as Precision.Type
) as any
```


## Remarks

Επιστρέφει τη μέση τιμή για τα στοιχεία της λίστας, `list`. Το αποτέλεσμα παρέχεται στον ίδιο τύπο δεδομένων όπως οι τιμές στη λίστα. Λειτουργεί μόνο με αριθμητικές τιμές, τιμές ημερομηνίας, ώρας, ημερομηνίας/ώρας, ημερομηνίας/ώρας/ζώνης ώρας και διάρκειας. Εάν η λίστα είναι κενή, επιστρέφεται η τιμή null.


## Examples

### Example #1
Βρείτε τον μέσο όρο της λίστας αριθμών, `{3, 4, 6}`.
```powerquery
List.Average({3, 4, 6})
```

Result: 
```powerquery
4.333333333333333
```


### Example #2
Βρείτε τον μέσο όρο των τιμών ημερομηνίας, 1 Ιανουαρίου 2011, 2 Ιανουαρίου 2011 και 3 Ιανουαρίου 2011.
```powerquery
List.Average({#date(2011, 1, 1), #date(2011, 1, 2), #date(2011, 1, 3)})
```

Result: 
```powerquery
#date(2011, 1, 2)
```

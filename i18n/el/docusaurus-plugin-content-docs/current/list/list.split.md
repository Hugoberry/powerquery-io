# List.Split


Διαιρεί την καθορισμένη λίστα σε μια λίστα με λίστες χρησιμοποιώντας το καθορισμένο μέγεθος σελίδας.


## Syntax

```powerquery
List.Split(
    list as list,
    pageSize as number
) as list
```


## Remarks

Διαιρεί `list` σε μια λίστα λιστών όπου το πρώτο στοιχείο της λίστας εξόδου είναι μια λίστα που περιέχει τα πρώτα στοιχεία `pageSize` από τη λίστα προέλευσης, το επόμενο στοιχείο της λίστας εξόδου είναι μια λίστα που περιέχει τα επόμενα στοιχεία `pageSize` από τη λίστα προέλευσης, και ούτω καθεξής.

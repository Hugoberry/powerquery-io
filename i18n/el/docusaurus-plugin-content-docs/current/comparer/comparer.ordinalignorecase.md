# Comparer.OrdinalIgnoreCase


Επιστρέφει μια συνάρτηση σύγκρισης χωρίς διάκριση πεζών-κεφαλαίων η οποία χρησιμοποιεί τακτικούς κανόνες για τη σύγκριση τιμών.


## Syntax

```powerquery
Comparer.OrdinalIgnoreCase(
    x as any,
    y as any
) as number
```


## Remarks

Επιστρέφει μια συνάρτηση σύγκρισης χωρίς διάκριση πεζών-κεφαλαίων η οποία χρησιμοποιεί Κανόνες Τακτικής για να συγκρίνει τις παρεχόμενες τιμές `x`και `y`.  
  
Μια συνάρτηση σύγκρισης δέχεται δύο ορίσματα και επιστρέφει -1, 0 ή 1 με βάση το αν η πρώτη τιμή είναι μικρότερη, ίση ή μεγαλύτερη από τη δεύτερη.


## Examples

### Example #1
Συγκρίνετε τις τιμές "Abc" και "abc" χρησιμοποιώντας τακτικούς κανόνες χωρίς διάκριση πεζών-κεφαλαίων. Λάβετε υπόψη ότι η τιμή "Abc" είναι μικρότερη από την τιμή "abc" με χρήση της συνάρτησης `Comparer.Ordinal`.
```powerquery
Comparer.OrdinalIgnoreCase("Abc", "abc")
```

Result: 
```powerquery
0
```

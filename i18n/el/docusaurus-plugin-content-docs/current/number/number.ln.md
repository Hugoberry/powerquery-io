# Number.Ln


Επιστρέφει τον φυσικό λογάριθμο του αριθμού.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Επιστρέφει τον φυσικό λογάριθμο ενός αριθμού, `number`. Αν το `number` είναι null, η συνάρτηση `Number.Ln` επιστρέφει τιμή null.


## Examples

### Example #1
Βρείτε τον φυσικό λογάριθμο του 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

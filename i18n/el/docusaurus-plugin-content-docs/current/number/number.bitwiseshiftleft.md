# Number.BitwiseShiftLeft


Μετακινεί το σύνολο bit προς τα αριστερά.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Επιστρέφει το αποτέλεσμα μιας μετακίνησης λειτουργίας bit προς τα αριστερά στο `number1`, κατά τον καθορισμένο αριθμό bit `number2`.

# Number.Cos


Επιστρέφει το συνημίτονο του αριθμού.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Επιστρέφει το συνημίτονο της καθορισμένης γωνίας.

-   `number`: Μια γωνία, μετρημένη σε ακτίνια.


## Examples

### Example #1
Βρείτε το συνημίτονο της γωνίας 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Βρείτε το συνημίτονο των π radians.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

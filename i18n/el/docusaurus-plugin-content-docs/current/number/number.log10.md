# Number.Log10


Επιστρέφει το λογάριθμο με βάση το 10 του αριθμού.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Επιστρέφει το λογάριθμο με βάση το 10 ενός αριθμού `number`. Αν το `number` είναι null, το `Number.Log10` επιστρέφει την τιμή null.


## Examples

### Example #1
Βρείτε το λογάριθμο με βάση το 10 του 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

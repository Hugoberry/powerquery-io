# Number.RandomBetween


Επιστρέφει έναν τυχαίο αριθμό μεταξύ δύο αριθμών.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Επιστρέφει έναν τυχαίο αριθμό μεταξύ `bottom` και `top`.


## Examples

### Example #1
Λάβετε έναν τυχαίο αριθμό μεταξύ1 και 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

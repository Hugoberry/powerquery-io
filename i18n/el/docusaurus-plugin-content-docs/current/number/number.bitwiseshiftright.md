# Number.BitwiseShiftRight


Μετακινεί το σύνολο bit προς τα δεξιά.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Επιστρέφει το αποτέλεσμα μιας μετακίνησης λειτουργίας bit προς τα δεξιά στο `number1`, κατά τον καθορισμένο αριθμό bit `number2`.

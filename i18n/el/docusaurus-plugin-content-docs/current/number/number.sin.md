# Number.Sin


Επιστρέφει το ημίτονο του αριθμού.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Επιστρέφει το ημίτονο του `number`.


## Examples

### Example #1
Βρείτε το ημίτονο της γωνίας 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

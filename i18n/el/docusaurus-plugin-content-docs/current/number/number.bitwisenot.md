# Number.BitwiseNot


Επιστρέφει ένα byte όπου κάθε bit είναι το αντίθετο της εισόδου.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Επιστρέφει το αποτέλεσμα μιας λειτουργίας bit "Not" στο `number`.



## Category
Number.Bytes

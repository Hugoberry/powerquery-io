# Number.Atan2


Επιστρέφει το τόξο εφαπτομένης του πηλίκου των δύο αριθμών.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Επιστρέφει τη γωνία, σε ακτίνια, της οποίας η εφαπτομένη είναι το πηλίκο `y`/`x` των δύο αριθμών `y` και `x`.

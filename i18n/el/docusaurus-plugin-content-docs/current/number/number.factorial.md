# Number.Factorial


Επιστρέφει το παραγοντικό του αριθμού.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

Επιστρέφει το παραγοντικό του αριθμού `number`.


## Examples

### Example #1
Βρείτε το παραγοντικό του 10.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

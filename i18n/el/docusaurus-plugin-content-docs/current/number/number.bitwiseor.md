# Number.BitwiseOr


Επιστρέφει το αποτέλεσμα μιας λειτουργίας bit "Or" μεταξύ των δύο εισόδων.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Επιστρέφει το αποτέλεσμα μιας λειτουργίας bit "Or" μεταξύ του `number1` και του `number2`.



## Category
Number.Bytes

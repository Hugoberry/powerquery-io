# Number.Abs


Επιστρέφει την απόλυτη τιμή του αριθμού.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Επιστρέφει την απόλυτη τιμή του `number`. Αν το `number` είναι null, η συνάρτηση `Number.Abs` επιστρέφει τιμή null.

-   `number`: Μια συνάρτηση `number` για την οποία θα υπολογιστεί η απόλυτη τιμή.


## Examples

### Example #1
Η απόλυτη τιμή του -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

# Number.BitwiseAnd


Επιστρέφει το αποτέλεσμα μιας λειτουργίας bit "And" μεταξύ των δύο εισόδων.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Επιστρέφει το αποτέλεσμα μιας λειτουργίας bit "And" μεταξύ του `number1` και του `number2`.



## Category
Number.Bytes

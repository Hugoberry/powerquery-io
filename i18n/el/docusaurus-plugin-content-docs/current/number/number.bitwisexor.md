# Number.BitwiseXor


Επιστρέφει το αποτέλεσμα μιας λειτουργίας bit "XOR" (Exclusive-OR) μεταξύ των δύο εισόδων.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Επιστρέφει το αποτέλεσμα μιας λειτουργίας bit "XOR" (Exclusive-OR) μεταξύ του `number1` και του `number2`.

Number.Bytes

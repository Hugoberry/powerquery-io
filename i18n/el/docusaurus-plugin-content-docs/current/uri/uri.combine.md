# Uri.Combine


Επιστρέφει ένα απόλυτο URI που είναι ο συνδυασμός του URI βάσης εισόδου και του σχετικού URI.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Επιστρέφει ένα απόλυτο URI που είναι ο συνδυασμός της εισόδου `baseUri` και του `relativeUri`.

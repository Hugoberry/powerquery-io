# Lines.FromBinary


Μετατρέπει μια δυαδική τιμή σε μια λίστα τιμών κειμένου διαιρεμένων με αλλαγές γραμμής. Αν καθοριστεί στυλ εισαγωγικών, οι αλλαγές γραμμής ενδέχεται να εμφανίζονται μέσα σε εισαγωγικά. Αν η includeLineSeparators είναι true, οι χαρακτήρες αλλαγής γραμμής συμπεριλαμβάνονται στο κείμενο.


## Syntax

```powerquery
Lines.FromBinary(
    binary as binary,
    optional quoteStyle as any,
    optional includeLineSeparators as logical,
    optional encoding as TextEncoding.Type
) as list
```


## Remarks

Μετατρέπει μια δυαδική τιμή σε μια λίστα τιμών κειμένου διαιρεμένων σε αλλαγές γραμμής.

-   `binary`: Η δυαδική τιμή που θα μετατραπεί στη λίστα.
-   `quoteStyle`: Καθορίζει τον τρόπο χειρισμού των αλλαγών γραμμής. Η τιμή του `quoteStyle` μπορεί να είναι `null`. Η προεπιλεγμένη τιμή είναι `QuoteStyle.None`.
-   `includeLineSeparators`: Καθορίζει αν θα συμπεριληφθούν οι χαρακτήρες αλλαγής γραμμής στο κείμενο. Η τιμή του `includeLineSeparators` μπορεί να είναι `null`. Η προεπιλεγμένη τιμή είναι `false`.
-   `encoding`: Καθορίζει την κωδικοποίηση κειμένου της δυαδικής τιμής. Η τιμή του `encoding` μπορεί να είναι `null`. Η προεπιλεγμένη τιμή είναι `65001` (UTF-8).

Αν έχει καθοριστεί μια εγγραφή για `quoteStyle` (και `includeLineSeparators` και `encoding` είναι `null`), μπορούν να παρέχονται τα ακόλουθα πεδία εγγραφής:

-   `QuoteStyle`: Καθορίζει τον τρόπο χειρισμού των αλλαγών γραμμής σε εισαγωγικά.
    -   `QuoteStyle.Csv`: Οι αλλαγές γραμμής σε εισαγωγικά αντιμετωπίζονται ως μέρος των δεδομένων και όχι ως το τέλος της τρέχουσας γραμμής.
    -   `QuoteStyle.None`: Όλες οι αλλαγές γραμμής αντιμετωπίζονται ως το τέλος της τρέχουσας γραμμής, ακόμα και όταν προκύπτουν μέσα σε μια τιμή σε εισαγωγικά. Αυτή η τιμή είναι η προεπιλεγμένη αν δεν έχει καθοριστεί η επιλογή `CsvStyle`.
-   `CsvStyle`: Καθορίζει τον τρόπο χειρισμού των εισαγωγικών. Δεν πρέπει να χρησιμοποιείται με `QuoteStyle.None`.
    -   `CsvStyle.QuoteAfterDelimiter`: Τα εισαγωγικά σε ένα πεδίο είναι σημαντικά μόνο αμέσως μετά τον `Οριοθέτη`.
    -   `CsvStyle.QuoteAlways`: Τα εισαγωγικά σε ένα πεδίο είναι πάντα σημαντικά, ανεξάρτητα από το πού εμφανίζονται.
-   `Οριοθέτης`: Ένας οριοθέτης ενός χαρακτήρα. Θα πρέπει να χρησιμοποιείται μόνο με `CsvStyle.QuoteAfterDelimiter`.
-   `IncludeLineSeparators`: Καθορίζει αν θα συμπεριληφθούν οι χαρακτήρες αλλαγής γραμμής στο κείμενο. Η προεπιλεγμένη τιμή είναι `false`.
-   `Κωδικοποίηση`: Η κωδικοποίηση κειμένου της δυαδικής τιμής. Η προεπιλεγμένη τιμή είναι `65001` (UTF-8).

# Function.InvokeAfter


Anropar den givna funktionen efter det att den angivna varaktigheten har löpt ut.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Returnerar resultatet av anropandet av `function` efter det att varaktigheten `delay` har löpt ut.



## Category
Function

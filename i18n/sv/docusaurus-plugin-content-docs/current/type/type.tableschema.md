# Type.TableSchema


Returnerar en tabell som innehåller en beskrivning av den angivna tabelltypens kolumner (t.ex. schemat).


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Returnerar en tabell som beskriver kolumnerna i `tableType`.

En beskrivning av den resulterande tabellen finns i dokumentationen till `Table.Schema`.

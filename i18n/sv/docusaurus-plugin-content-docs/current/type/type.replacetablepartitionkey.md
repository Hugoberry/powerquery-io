# Type.ReplaceTablePartitionKey


Returnerar en ny tabelltyp där partitionsnyckeln har ersatts med den angivna partitionsnyckeln.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Returnerar en ny tabelltyp där partitionsnyckeln har ersatts med den angivna partitionsnyckeln.

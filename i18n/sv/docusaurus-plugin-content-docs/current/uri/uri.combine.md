# Uri.Combine


Returnerar en absolut URI som är en kombination av bas-URI:n och den relativa URI:n i angivna indata.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Returnerar en absolut URI som är en kombination av `baseUri` och `relativeUri` i angivna indata.

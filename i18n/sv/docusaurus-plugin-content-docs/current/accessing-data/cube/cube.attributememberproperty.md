# Cube.AttributeMemberProperty


Returnerar en egenskap för ett dimensionsattribut.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Returnerar egenskapen `propertyName` för dimensionsattributet `attribute`.

Cube

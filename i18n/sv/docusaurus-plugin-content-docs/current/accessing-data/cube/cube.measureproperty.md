# Cube.MeasureProperty


Returnerar en egenskap för ett mått (cellegenskap).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Returnerar egenskapen `propertyName` för dimensionsattributet `measure`.

Cube

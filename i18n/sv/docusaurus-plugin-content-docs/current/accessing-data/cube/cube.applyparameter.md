# Cube.ApplyParameter


Returnerar en kub efter det att en parameter har tillämpats på den.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Returnerar en kub efter att ha tillämpat `parameter` med `arguments` på `cube`.

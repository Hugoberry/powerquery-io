# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Med Teams-analysanslutningsappen får du djupare kunskap om din användning av Teams. Data är tillgängliga för både din personliga aktivitet i Teams och den aktivitet i Teams som du är medlem i.

Data är tillgängliga 90 dagar bakåt.

Mer information om vilka typer av data som är tillgängliga hittar du i följande hjälpdokumentation:

-   **Teams-användning:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Teams-användaraktivitet** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

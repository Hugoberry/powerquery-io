# BinaryFormat.ByteOrder


Returnerar ett binärformat med den byteordning som anges med en funktion.


## Syntax

```powerquery
BinaryFormat.ByteOrder(
    binaryFormat as function,
    byteOrder as ByteOrder.Type
) as function
```


## Remarks

Returnerar ett binärformat med den byteordning som anges med `binaryFormat`. Standardbyteordningen är `ByteOrder.BigEndian`.

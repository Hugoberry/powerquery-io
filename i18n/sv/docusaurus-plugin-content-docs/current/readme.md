# Upptäck språket
Formelspråket Power Query M är optimerat för att bygga mycket flexibla frågor för datasammanställning. Det är ett funktionellt, skiftlägeskänsligt språk som liknar F#. Formelspråket Power Query används i ett antal Microsoft-produkter såsom Power BI Desktop, Excel och Analysis Services.

Den här webbplatsen fungerar som en referens för Power Query-funktioner och erbjuder snabb och direkt åtkomst till detaljerad information och praktiska exempel för varje funktion.
:::note
Observera att författaren inte gör anspråk på någon upphovsrätt till materialet som presenteras på den här webbplatsen. Informationen samlas in och tillhandahålls i hopp om att den ska vara användbar för dem som vill utöka sin kunskap om och tillämpning av Power Query.
:::

Sökfunktionen på den här webbplatsen bör förenkla upptäcktsprocessen för det breda utbudet av Power Query-funktioner. Se till att prova den (Ctrl+K).

![Sökfunktion tillhandahållen av Algolia](/img/search.png)

För dem som är intresserade av djupare utforskning eller implementeringsdetaljer finns mer information i följande GitHub-repository: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Det här repositoryt kan innehålla ytterligare exempel, uppdateringar och resurser som är relevanta för utveckling och användning av Power Query.

Specifikationen beskriver de värden, uttryck, miljöer och variabler, identifierare och den utvärderingsmodell som utgör de grundläggande begreppen i Power Query M-språket.

# Number.Atan2


Returnerar arctangens för divisionen av de två talen.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Returnerar vinkeln, i radianer, vars tangens är kvoten `y`/`x` av de två talen `y` och `x`.

Number.Trigonometry

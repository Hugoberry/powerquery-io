# Number.BitwiseShiftRight


Skiftar bitarna till höger.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerar resultatet från ett bitvis skifte till höger för `number1` med angivet antal bitar, `number2`.



## Category
Number.Bytes

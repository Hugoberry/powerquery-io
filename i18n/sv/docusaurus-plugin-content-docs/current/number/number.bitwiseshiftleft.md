# Number.BitwiseShiftLeft


Skiftar bitarna till vänster.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerar resultatet från ett bitvis skifte till vänster för `number1` med angivet antal bitar, `number2`.



## Category
Number.Bytes

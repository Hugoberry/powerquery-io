# Number.BitwiseOr


Returnerar resultatet av en bitvis "Or"-åtgärd mellan de två indatavärdena.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerar resultatet av en bitvis "Or"-åtgärd mellan `number1` och `number2`.



## Category
Number.Bytes

# Number.Cos


Returnerar cosinus för talet.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Returnerar cosinus för den angivna vinkeln.

-   `number`: En vinkel, mätt i radianer.


## Examples

### Example #1
Hitta cosinus för vinkeln 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Beräkna cosinus för π radianer.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

# Number.BitwiseAnd


Returnerar resultatet av en bitvis "And"-åtgärd mellan de två indatavärdena.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerar resultatet av en bitvis "And"-åtgärd mellan `number1` och `number2`.



## Category
Number.Bytes

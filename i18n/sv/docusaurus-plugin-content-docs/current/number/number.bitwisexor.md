# Number.BitwiseXor


Returnerar resultatet av en bitvis "XOR"-åtgärd (Exclusive-OR) mellan de två indatavärdena.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Returnerar resultatet av en bitvis "XOR"-åtgärd (Exclusive-OR) mellan `number1` och `number2`.



## Category
Number.Bytes

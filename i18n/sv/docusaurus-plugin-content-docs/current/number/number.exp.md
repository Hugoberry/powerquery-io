# Number.Exp


Upphöjer e med angivet tal.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Returnerar resultatet från att e upphöjs till `number` (exponentialfunktion).

-   `number`: Ett `number` som exponentialfunktionen ska beräknas från. Om `number` är null returnerar `Number.Exp` null.


## Examples

### Example #1
Upphöj e till 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

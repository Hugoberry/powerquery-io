# Variable.Value


Returnerar värdet för den angivna variabeln.


## Syntax

```powerquery
Variable.Value(
    identifier as text
) as any
```


## Remarks

Returnerar värdet för den angivna variabeln `identifier` som definieras av den aktuella utvärderingsmiljön. Om variabeln inte har definierats, utlöses ett fel.

# Value.Equals


Kontrollerar om två värden är lika.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Returnerar true om värdet `value1` är lika med värdet `value2`. Annars returneras false.

Values

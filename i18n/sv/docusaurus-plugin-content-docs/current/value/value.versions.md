# Value.Versions


Returnerar en navigeringstabell som innehåller tillgängliga versioner av värdet.


## Syntax

```powerquery
Value.Versions(
    value as any
) as table
```


## Remarks

Returnerar en navigeringstabell som innehåller tillgängliga versioner av `value`.

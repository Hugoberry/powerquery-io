# Value.Add


Returnerar summan av de två värdena.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Returnerar summan av `value1` och `value2`. En valfri `precision`\-parameter kan anges. `Precision.Double` används som standard.

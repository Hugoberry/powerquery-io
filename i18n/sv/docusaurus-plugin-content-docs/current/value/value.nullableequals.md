# Value.NullableEquals


Kontrollerar om två värden är lika.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Returnerar null om något av argumenten `value1` eller `value2` är null. Annars motsvarar detta Value.Equals.

Values

# Text.Length


Returnerar antalet tecken.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Returnerar antalet tecken i texten `text`.


## Examples

### Example #1
Kontrollera hur många tecken det finns i texten "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

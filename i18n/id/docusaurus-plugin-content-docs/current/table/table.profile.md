# Table.Profile


Menghasilkan profil kolom tabel.


## Syntax

```powerquery
Table.Profile(
    table as table,
    optional additionalAggregates as list
) as table
```


## Remarks

Menghasilkan profil untuk kolom di `table`.

Informasi berikut dihasilkan untuk setiap kolom (jika berlaku):

-   minimum
-   maksimum
-   rata-rata
-   deviasi standar
-   jumlah
-   jumlah null
-   jumlah terpisah

# Table.FirstValue


Menghasilkan kolom pertama dari baris pertama tabel atau nilai default yang ditentukan.


## Syntax

```powerquery
Table.FirstValue(
    table as table,
    optional default as any
) as any
```


## Remarks

Menghasilkan kolom pertama dari baris pertama tabel `table` atau nilai default yang ditentukan.

Table.Row operations

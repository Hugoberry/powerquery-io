# Tables.GetRelationships


Mendapatkan hubungan antara himpunan tabel.


## Syntax

```powerquery
Tables.GetRelationships(
    tables as table,
    optional dataColumn as text
) as table
```


## Remarks

Mendapatkan hubungan antara himpunan tabel. `tables` himpunan dianggap memiliki struktur yang sama dengan tabel navigasi. Kolom yang didefinisikan oleh `dataColumn` berisi tabel data aktual.

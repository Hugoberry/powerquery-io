# BinaryFormat.Binary


Menghasilkan format biner yang membaca nilai biner.


## Syntax

```powerquery
BinaryFormat.Binary(
    optional length as any
) as function
```


## Remarks

Menghasilkan format biner yang membaca nilai biner. Jika `length` ditetapkan, nilai biner akan berisi banyak byte. Jika `length` tidak ditetapkan, nilai biner akan berisi byte tersisa. `length` dapat ditetapkan sebagai angka, atau sebagai format biner sepanjang yang melebihi data biner.

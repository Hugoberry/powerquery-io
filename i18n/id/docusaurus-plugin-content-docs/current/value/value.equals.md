# Value.Equals


Menghasilkan apakah dua nilai sama.


## Syntax

```powerquery
Value.Equals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Menghasilkan benar jika nilai `value1` sama dengan nilai `value2`, atau salah.

Values

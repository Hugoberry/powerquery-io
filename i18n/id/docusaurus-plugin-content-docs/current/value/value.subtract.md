# Value.Subtract


Menghasilkan perbedaan dari dua nilai.


## Syntax

```powerquery
Value.Subtract(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Menghasilkan perbedaan dari `value1` dan `value2`. Parameter `precision` opsional dapat ditetapkan, secara default `Precision.Double` akan digunakan.

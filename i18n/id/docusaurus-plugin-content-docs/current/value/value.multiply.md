# Value.Multiply


Menghasilkan produk dari dua nilai.


## Syntax

```powerquery
Value.Multiply(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Menghasilkan produk perkalian `value1` dengan `value2`. Parameter `precision` opsional dapat ditetapkan, secara default `Precision.Double` akan digunakan.

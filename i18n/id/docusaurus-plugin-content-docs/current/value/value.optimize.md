# Value.Optimize


Sinyal Value.Expression untuk menghasilkan ekspresi yang dioptimalkan untuk sebuah nilai.


## Syntax

```powerquery
Value.Optimize(
    value as any
) as any
```


## Remarks

Saat digunakan dalam Value.Expression, jika `value` mewakili kueri yang dapat dioptimalkan, fungsi ini menunjukkan bahwa ekspresi yang dioptimalkan harus dikembalikan. Jika tidak, `value` akan diteruskan tanpa efek.

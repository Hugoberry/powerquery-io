# Value.Divide


Memberikan hasil dari pembagian nilai pertama dengan kedua.


## Syntax

```powerquery
Value.Divide(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Memberikan hasil pembagian `value1` dengan `value2`. Parameter `precision` opsional dapat ditetapkan, secara default `Precision.Double` akan digunakan.

# Value.Add


Menghasilkan jumlah dari dua nilai.


## Syntax

```powerquery
Value.Add(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as any
```


## Remarks

Menghasilkan jumlah dari `value1` dan `value2`. Parameter `precision` opsional dapat ditetapkan, secara default `Precision.Double` akan digunakan.

# Value.NullableEquals


Menghasilkan apakah dua nilai sama.


## Syntax

```powerquery
Value.NullableEquals(
    value1 as any,
    value2 as any,
    optional precision as Precision.Type
) as logical
```


## Remarks

Menghasilkan null jika argumen `value1` atau `value2` adalah null, atau sama dengan Value.Equals.

# SqlExpression.ToExpression


Mengonversi kueri SQL yang diberikan ke kode M. Fungsi ini hanya ditujukan untuk penggunaan internal.


## Syntax

```powerquery
SqlExpression.ToExpression(
    sql as text,
    environment as record
) as text
```


## Remarks

Mengonversi kueri `sql` yang diberikan ke kode M, dengan pengidentifikasi tersedia yang ditentukan oleh `environment`. Fungsi ini hanya ditujukan untuk penggunaan internal.

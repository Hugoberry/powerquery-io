# Temukan bahasanya
Bahasa formula Power Query M dioptimalkan untuk membangun kueri penggabungan data yang sangat fleksibel. Ini adalah bahasa fungsional yang peka huruf besar-kecil, mirip dengan F#. Bahasa Formula Power Query digunakan dalam sejumlah produk Microsoft seperti Power BI Desktop, Excel, dan Analysis Services.

Situs ini berfungsi sebagai referensi untuk fungsi-fungsi Power Query, menawarkan akses cepat dan langsung ke informasi terperinci serta contoh praktis untuk setiap fungsi.
:::note
Harap dicatat, penulis tidak mengklaim hak cipta apa pun atas materi yang disajikan di situs ini. Informasi dikumpulkan dan disediakan dengan harapan akan bermanfaat bagi mereka yang ingin memperluas pengetahuan dan penerapan Power Query.
:::

Fungsionalitas pencarian di situs web ini akan menyederhanakan proses penemuan berbagai macam fungsi Power Query. Pastikan Anda mencobanya (Ctrl+K).

![Fungsionalitas pencarian disediakan oleh Algolia](/img/search.png)

Bagi mereka yang tertarik pada eksplorasi lebih mendalam atau detail implementasi, informasi lebih lanjut dapat ditemukan di repositori GitHub berikut: [https://github.com/Hugoberry/powerquery-io](https://github.com/Hugoberry/powerquery-io). Repositori ini mungkin berisi contoh tambahan, pembaruan, dan sumber daya yang relevan dengan pengembangan dan penggunaan Power Query.

# Number.BitwiseShiftLeft


Menggeser kumpulan bit ke kiri.


## Syntax

```powerquery
Number.BitwiseShiftLeft(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Memberikan hasil dari menjalankan penggeseran bitwise ke kiri pada `number1`, berdasarkan jumlah bit yang ditetapkan `number2`.

Number.Bytes

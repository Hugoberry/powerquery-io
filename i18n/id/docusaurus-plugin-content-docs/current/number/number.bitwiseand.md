# Number.BitwiseAnd


Memberikan hasil dari menjalankan operasi bitwise "And" di antara kedua input.


## Syntax

```powerquery
Number.BitwiseAnd(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Memberikan hasil dari menjalankan operasi bitwise "And" antara `number1` dan `number2`.

Number.Bytes

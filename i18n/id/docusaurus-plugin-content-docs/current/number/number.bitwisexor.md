# Number.BitwiseXor


Memberikan hasil dari menjalankan operasi bitwise "XOR" (Exclusive-OR) di antara kedua input.


## Syntax

```powerquery
Number.BitwiseXor(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Memberikan hasil dari menjalankan operasi bitwise "XOR" (Exclusive-OR) antara `number1` dan `number2`.

# Number.Tan


Menghasilkan tangen bilangan.


## Syntax

```powerquery
Number.Tan(
    number as number
) as number
```


## Remarks

Menghasilkan tangen `number`.


## Examples

### Example #1
Mencari tangen sudut 1.
```powerquery
Number.Tan(1)
```

Result: 
```powerquery
1.5574077246549023
```

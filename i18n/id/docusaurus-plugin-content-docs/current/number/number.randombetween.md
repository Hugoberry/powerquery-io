# Number.RandomBetween


Menghasilkan bilangan acak di antara dua bilangan.


## Syntax

```powerquery
Number.RandomBetween(
    bottom as number,
    top as number
) as number
```


## Remarks

Menghasilkan bilangan acak antara `bottom` hingga `top`.


## Examples

### Example #1
Mengambil bilangan acak antara 1 hingga 5.
```powerquery
Number.RandomBetween(1, 5)
```

Result: 
```powerquery
2.546797
```

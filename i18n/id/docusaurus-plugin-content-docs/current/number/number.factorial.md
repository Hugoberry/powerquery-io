# Number.Factorial


Menghasilkan faktorial bilangan.


## Syntax

```powerquery
Number.Factorial(
    number as number
) as number
```


## Remarks

Menghasilkan faktorial bilangan `number`.


## Examples

### Example #1
Mencari faktorial 10.
```powerquery
Number.Factorial(10)
```

Result: 
```powerquery
3628800
```

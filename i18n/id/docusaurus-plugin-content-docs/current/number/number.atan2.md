# Number.Atan2


Menghasilkan tangen inversi divisi dua bilangan.


## Syntax

```powerquery
Number.Atan2(
    y as number,
    x as number
) as number
```


## Remarks

Mengembalikan sudut, dalam radian, yang tangennya adalah hasil bagi `y`/`x` dari dua angka `y` dan `x`.

# Number.BitwiseOr


Memberikan hasil dari menjalankan operasi bitwise "Or" di antara kedua input.


## Syntax

```powerquery
Number.BitwiseOr(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Memberikan hasil dari menjalankan operasi bitwise "Or" antara `number1` dan `number2`.

Number.Bytes

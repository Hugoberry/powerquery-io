# Number.Ln


Menghasilkan logaritma natural dari suatu bilangan.


## Syntax

```powerquery
Number.Ln(
    number as number
) as number
```


## Remarks

Menghasilkan logaritma natural dari suatu bilangan, `number`. Jika `number` null `Number.Ln` akan menghasilkan null.


## Examples

### Example #1
Mengambil logaritma natural dari bilangan 15.
```powerquery
Number.Ln(15)
```

Result: 
```powerquery
2.70805020110221
```

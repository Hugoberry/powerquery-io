# Number.Abs


Menghasilkan nilai absolut bilangan.


## Syntax

```powerquery
Number.Abs(
    number as number
) as number
```


## Remarks

Mengembalikan nilai absolut `number`. Jika `number` null, `Number.Abs` akan menghasilkan null.

-   `number`: `number` yang nilai absolutnya akan dihitung.


## Examples

### Example #1
Nilai absolut -3.
```powerquery
Number.Abs(-3)
```

Result: 
```powerquery
3
```

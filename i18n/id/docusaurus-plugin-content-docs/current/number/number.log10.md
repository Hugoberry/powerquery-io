# Number.Log10


Menghasilkan logaritma basis-10 dari bilangan.


## Syntax

```powerquery
Number.Log10(
    number as number
) as number
```


## Remarks

Menghasilkan logaritma Basis-10 dari bilangan, `number`. Jika `number` null `Number.Log10` menghasilkan null.


## Examples

### Example #1
Mengambil logaritma basis-10 dari 2.
```powerquery
Number.Log10(2)
```

Result: 
```powerquery
0.3010299956639812
```

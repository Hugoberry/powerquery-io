# Number.IsEven


Menunjukkan apakah nilai bersifat genap.


## Syntax

```powerquery
Number.IsEven(
    number as number
) as logical
```


## Remarks

Menunjukkan apakah nilai, `number`, genap dengan menghasilkan `true` jika genap, `false` jika sebaliknya.


## Examples

### Example #1
Memastikan 625 adalah bilangan genap.
```powerquery
Number.IsEven(625)
```

Result: 
```powerquery
false
```


### Example #2
Memastikan 82 adalah bilangan genap.
```powerquery
Number.IsEven(82)
```

Result: 
```powerquery
true
```

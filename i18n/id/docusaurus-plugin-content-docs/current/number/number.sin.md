# Number.Sin


Menghasilkan sinus bilangan.


## Syntax

```powerquery
Number.Sin(
    number as number
) as number
```


## Remarks

Menghasilkan sinus `number`.


## Examples

### Example #1
Mencari sinus sudut 0.
```powerquery
Number.Sin(0)
```

Result: 
```powerquery
0
```

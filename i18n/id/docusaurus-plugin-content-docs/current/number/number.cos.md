# Number.Cos


Menghasilkan kosinus bilangan.


## Syntax

```powerquery
Number.Cos(
    number as number
) as number
```


## Remarks

Menghasilkan kosinus dari sudut yang ditentukan.

-   `number`: Sudut, diukur dalam radian.


## Examples

### Example #1
Mencari kosinus sudut 0.
```powerquery
Number.Cos(0)
```

Result: 
```powerquery
1
```


### Example #2
Temukan kosinus dari π radian.
```powerquery
Number.Cos(Number.PI)
```

Result: 
```powerquery
-1
```

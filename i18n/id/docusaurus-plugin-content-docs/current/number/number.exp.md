# Number.Exp


Menggunakan e dengan pangkat tertentu.


## Syntax

```powerquery
Number.Exp(
    number as number
) as number
```


## Remarks

Mengembalikan hasil dari menggunakan e dengan pangkat `number` (fungsi eksponensial).

-   `number`: `number` yang fungsi eksponensialnya akan dihitung. Jika `number` null, `Number.Exp` akan menghasilkan null.


## Examples

### Example #1
Menggunakan e dengan pangkat 3.
```powerquery
Number.Exp(3)
```

Result: 
```powerquery
20.085536923187668
```

# Number.BitwiseShiftRight


Menggeser kumpulan bit ke kanan.


## Syntax

```powerquery
Number.BitwiseShiftRight(
    number1 as number,
    number2 as number
) as number
```


## Remarks

Memberikan hasil dari menjalankan penggeseran bitwise ke kanan pada `number1`, berdasarkan jumlah bit yang ditetapkan `number2`.

# Number.BitwiseNot


Menghasilkan byte dengan setiap bit merupakan kebalikan dari input.


## Syntax

```powerquery
Number.BitwiseNot(
    number as any
) as any
```


## Remarks

Memberikan hasil dari menjalankan operasi bitwise "Not" pada `number`.



## Category
Number.Bytes

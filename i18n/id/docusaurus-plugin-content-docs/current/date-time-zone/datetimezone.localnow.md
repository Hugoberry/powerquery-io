# DateTimeZone.LocalNow


Menghasilkan tanggal & waktu saat ini dalam zona waktu lokal.


## Syntax

```powerquery
DateTimeZone.LocalNow(

) as datetimezone
```


## Remarks

Mengembalikan serangkaian nilai `datetimezone` yang ditetapkan ke tanggal dan waktu saat ini pada sistem. Nilai yang dihasilkan berisi informasi zona waktu yang menunjukkan zona waktu lokal.

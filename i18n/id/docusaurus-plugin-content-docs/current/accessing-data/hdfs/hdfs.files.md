# Hdfs.Files


Menghasilkan tabel berisi properti dan konten dari file yang ditemukan dalam folder dan subfolder yang ditetapkan dari sistem file Hadoop.


## Syntax

```powerquery
Hdfs.Files(
    url as text
) as table
```


## Remarks

Menghasilkan tabel berisi baris untuk setiap file yang ditemukan pada URL folder, `url`, dan subfolder dari sistem file Hadoop. Setiap baris berisi properti file dan link ke kontennya.

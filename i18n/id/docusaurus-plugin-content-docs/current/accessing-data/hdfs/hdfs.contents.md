# Hdfs.Contents


Menghasilkan tabel berisi properti dan konten dari file dan folder yang ditemukan dalam folder yang ditetapkan dari sistem file Hadoop.


## Syntax

```powerquery
Hdfs.Contents(
    url as text
) as table
```


## Remarks

Menghasilkan tabel berisi baris untuk setiap folder dan file yang ditemukan pada URL folder, `url`, dari sistem file Hadoop. Setiap baris berisi properti folder atau file dan link ke kontennya.

# TeamsAnalytics.Contents



## Syntax

```powerquery
TeamsAnalytics.Contents(

) as table
```


## Remarks

Konektor Teams Analytics memungkinkan Anda mendapatkan wawasan tentang penggunaan Teams. Data tersedia untuk aktivitas pribadi Anda di Teams serta aktivitas dalam Teams tempat Anda menjadi anggota.

Data tersedia untuk 90 hari sebelumnya.

Untuk detail jenis data yang tersedia, lihat dokumentasi bantuan berikut:

-   **Penggunaan Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/teams-usage-report
-   **Aktivitas Pengguna Teams:** https://docs.microsoft.com/en-us/microsoftteams/teams-analytics-and-reports/user-activity-report

# Excel.CurrentWorkbook


Menghasilkan konten dari buku kerja Excel saat ini.


## Syntax

```powerquery
Excel.CurrentWorkbook(

) as table
```


## Remarks

Menghasilkan konten buku kerja Excel saat ini. Ini menghasilkan tabel, rentang bernama, dan array dinamis. Tidak seperti `Excel.Workbook`, tidak menghasilkan lembar.

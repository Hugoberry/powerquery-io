# File.Contents


Menghasilkan konten dari file yang ditetapkan sebagai biner.


## Syntax

```powerquery
File.Contents(
    path as text,
    optional options as record
) as binary
```


## Remarks

Menghasilkan konten file, `path`, sebagai biner. Parameter `options` saat ini hanya ditujukan untuk penggunaan internal.

# Cube.AttributeMemberId


Mengembalikan pengenal unik anggota dari nilai properti anggota.


## Syntax

```powerquery
Cube.AttributeMemberId(
    attribute as any
) as any
```


## Remarks

Mengembalikan pengenal unik anggota dari nilai properti anggota. `attribute`. Mengembalikan null untuk semua nilai lainnya.

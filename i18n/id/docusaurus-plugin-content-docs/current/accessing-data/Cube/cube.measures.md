# Cube.Measures


Menghasilkan tabel berisi kumpulan pengukuran yang tersedia.


## Syntax

```powerquery
Cube.Measures(
    cube as any
) as table
```


## Remarks

Mengembalikan tabel berisi kumpulan pengukuran yang tersedia dalam `cube`. Setiap pengukuran ditampilkan sebagai fungsi. Pengukuran dapat diterapkan pada kubus menggunakan Cube.AddMeasureColumn.

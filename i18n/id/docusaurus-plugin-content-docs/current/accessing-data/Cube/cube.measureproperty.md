# Cube.MeasureProperty


Mengembalikan properti pengukuran (properti sel).


## Syntax

```powerquery
Cube.MeasureProperty(
    measure as any,
    propertyName as text
) as any
```


## Remarks

Mengembalikan properti `propertyName` dari pengukuran `measure`.

# Cube.Parameters


Menghasilkan tabel berisi himpunan parameter yang dapat diterapkan ke kubus.


## Syntax

```powerquery
Cube.Parameters(
    cube as table
) as table
```


## Remarks

Menghasilkan tabel berisi himpunan parameter yang dapat diterapkan ke `cube`. Tiap parameter adalah fungsi yang dapat dijalankan untuk mendapatkan `cube` dengan parameter dan argumen yang diterapkan.

Cube

# Cube.DisplayFolders


Menghasilkan pohon tabel bersarang yang menunjukkan hierarki folder tampilan objek (misalnya, dimensi dan pengukuran).


## Syntax

```powerquery
Cube.DisplayFolders(
    cube as table
) as table
```


## Remarks

Menghasilkan pohon tabel bersarang yang menunjukkan hierarki folder tampilan objek (misalnya, dimensi dan pengukuran) yang dapat digunakan di `cube`.

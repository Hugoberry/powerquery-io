# Cube.Properties


Menghasilkan tabel yang berisi set properti yang tersedia untuk dimensi yang diperluas dalam kubus.


## Syntax

```powerquery
Cube.Properties(
    cube as table
) as table
```


## Remarks

Menghasilkan tabel yang berisi set properti yang tersedia untuk dimensi yang diperluas dalam kubus.

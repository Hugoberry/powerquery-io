# Cube.Dimensions


Menghasilkan tabel berisi kumpulan dimensi yang tersedia.


## Syntax

```powerquery
Cube.Dimensions(
    cube as table
) as table
```


## Remarks

Menghasilkan tabel berisi kumpulan dimensi yang tersedia dalam `cube`. Setiap dimensi adalah tabel berisi kumpulan atribut dimensi dan setiap atribut dimensi ditampilkan sebagai kolom dalam tabel dimensi. Dimensi dapat dibuka dalam kubus menggunakan Cube.AddAndExpandDimensionColumn.

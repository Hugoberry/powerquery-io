# Cube.ApplyParameter


Menghasilkan kubus setelah menerapkan parameter ke kubus.


## Syntax

```powerquery
Cube.ApplyParameter(
    cube as table,
    parameter as any,
    optional arguments as list
) as table
```


## Remarks

Menghasilkan kubus setelah menerapkan `parameter` dengan `arguments` ke `cube`.

Cube

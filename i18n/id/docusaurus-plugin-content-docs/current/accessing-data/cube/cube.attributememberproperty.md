# Cube.AttributeMemberProperty


Mengembalikan properti atribut dimensi.


## Syntax

```powerquery
Cube.AttributeMemberProperty(
    attribute as any,
    propertyName as text
) as any
```


## Remarks

Mengembalikan properti `propertyName` dari atribut dimensi `attribute`.

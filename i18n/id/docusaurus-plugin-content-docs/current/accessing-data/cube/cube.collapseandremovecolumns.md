# Cube.CollapseAndRemoveColumns


Mengubah granularitas dimensi konteks filter pada kubus dengan menutup atribut yang dipetakan pada kolom yang ditentukan.


## Syntax

```powerquery
Cube.CollapseAndRemoveColumns(
    cube as table,
    columnNames as list
) as table
```


## Remarks

Mengubah granularitas dimensi konteks filter pada `cube` dengan menutup atribut yang dipetakan pada kolom `columnNames` yang ditentukan. Kolom juga dihapus dari tampilan tabular kubus.

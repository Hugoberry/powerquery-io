# Exchange.Contents


Menghasilkan tabel konten dari akun Microsoft Exchange.


## Syntax

```powerquery
Exchange.Contents(
    optional mailboxAddress as text
) as table
```


## Remarks

Menghasilkan daftar isi dari akun Microsoft Exchange `mailboxAddress`. Jika `mailboxAddress` tidak ditentukan, akun default untuk kredensial akan digunakan.

# Soda.Feed


Menghasilkan tabel dari konten di URL tertentu yang diformat berdasarkan API SODA 2.0.


## Syntax

```powerquery
Soda.Feed(
    url as text
) as table
```


## Remarks

Menghasilkan tabel dari konten di URL `url` tertentu yang diformat berdasarkan API SODA 2.0. URL harus mengarah ke sumber yang sesuai dengan SODA yang valid dan diakhiri dengan ekstensi .csv.

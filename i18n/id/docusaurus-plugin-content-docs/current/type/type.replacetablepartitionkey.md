# Type.ReplaceTablePartitionKey


Menghasilkan tipe tabel baru dengan kunci partisi yang digantikan oleh kunci partisi yang ditentukan.


## Syntax

```powerquery
Type.ReplaceTablePartitionKey(
    tableType as type,
    partitionKey as list
) as type
```


## Remarks

Menghasilkan tipe tabel baru dengan kunci partisi yang digantikan oleh kunci partisi yang ditentukan.

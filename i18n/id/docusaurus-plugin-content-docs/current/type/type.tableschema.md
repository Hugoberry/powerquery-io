# Type.TableSchema


Mengembalikan tabel yang berisi deskripsi kolom (skema) jenis tabel yang ditentukan.


## Syntax

```powerquery
Type.TableSchema(
    tableType as type
) as table
```


## Remarks

Menghasilkan tabel yang menjelaskan kolom `tableType`.

Lihat dokumentasi untuk `Table.Schema` untuk deskripsi tabel yang dihasilkan.

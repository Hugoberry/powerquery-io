# Text.Length


Menghasilkan jumlah karakter.


## Syntax

```powerquery
Text.Length(
    text as text
) as number
```


## Remarks

Menghasilkan jumlah karakter pada teks `text`.


## Examples

### Example #1
Mencari jumlah karakter pada teks "Hello World".
```powerquery
Text.Length("Hello World")
```

Result: 
```powerquery
11
```

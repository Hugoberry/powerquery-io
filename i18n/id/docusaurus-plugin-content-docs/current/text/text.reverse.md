# Text.Reverse


Text.Reverse


## Syntax

```powerquery
Text.Reverse(
    text as text
) as text
```


## Remarks

Membalik `text` yang diberikan.


## Examples

### Example #1
Membalik teks "123".
```powerquery
Text.Reverse("123")
```

Result: 
```powerquery
"321"
```

# Function.InvokeAfter


Meminta fungsi yang diberikan setelah durasi yang ditentukan terlewati.


## Syntax

```powerquery
Function.InvokeAfter(
    function as function,
    delay as duration
) as any
```


## Remarks

Mengembalikan hasil `function` yang diminta setelah durasi `delay` terlewati.



## Category
Function

# Uri.Combine


Menghasilkan URI absolut yang merupakan kombinasi URI dasar input dan URI relatif.


## Syntax

```powerquery
Uri.Combine(
    baseUri as text,
    relativeUri as text
) as text
```


## Remarks

Menghasilkan URI absolut yang merupakan kombinasi input `baseUri` dan `relativeUri`.
